# Preset Style Recipes (预置风格配方)

Pre-extracted style specs ready to apply directly. Each recipe includes the full 画风说明书 format so it can be plugged into any prompt's style block without running Step 1.

## How to use

1. Pick a recipe from this file
2. Skip Step 1 (extraction) — the style spec is already done
3. Optionally generate a color card using the recipe's `调色` values (Step 1.5)
4. Proceed to Step 2 (application) as normal

## Recipe 1: Vox Collage (Vox 复古拼贴动画)

外网爆火的复古报纸拼贴风格，适合科普、财经、文化、历史类内容的可视化叙事。核心特征是多层纸质拼贴的立体感 + 复古印刷质感 + 纵深运镜。

### 画风说明书：Vox Collage

**提取自：** Vox 频道视觉风格 + DannyZ 复古拼贴教程

#### 逐维度风格声明

```
风格：复古报纸拼贴动画——多层纸质剪贴的立体纸艺感，手工剪贴的层次与拙趣，非3D建模
摄影：纪录片式叙事运镜 × 手工定格动画质感
质感：旧报纸/牛皮纸/印刷品的纤维纹理，边缘有手撕毛边或剪刀裁切痕迹，
      纸张表面可见折痕、泛黄氧化斑、打字机油墨不均
光追：无——本风格禁止写实光追，使用平面化的手绘阴影模拟层次
灯光：无方向性主光——均匀的扫描仪式平光，层次感完全由纸片的叠压关系和投影实现，
      投影为硬边45度手绘阴影（非真实光照计算）
调色：60:30:10——泛黄牛皮纸色60% / 旧报纸灰白30% / 红色线条与图表点缀10%，
      整体低饱和偏暖黄，墨色为深棕而非纯黑
动态光源：无
噪点：明显的纸质纤维纹理噪点，模拟扫描旧纸张的效果
锐化：中低——边缘柔和保留手工感，禁止锐利数码边缘
动态范围：低对比——模拟旧报纸印刷品的低对比度，高光不过曝（纸张不反光），
         暗部不死黑（墨色为深棕）
完美度：低——刻意保留手工拼贴感、拙趣。禁过度精修、禁完美对称、禁AI光滑质感、
       禁3D渲染质感。边缘要有手撕/剪切的不规则感
```

#### 氛围关键词

复古、手工、学术、怀旧、纸质

#### 禁止（与此风格冲突的元素）

```
禁3D渲染质感、禁光滑表面、禁写实光影、禁高饱和色彩、
禁纯黑色（用深棕替代）、禁完美几何边缘、禁数码感渐变、
禁真实光照/光追/全局光照、禁照片级写实材质、
禁现代极简设计（圆角、毛玻璃、渐变阴影）
```

#### 平面设计维度

```
字体：复古印刷体/打字机体为主，标题用粗衬线报纸标题字体，
      正文用打字机等宽体，允许字号不统一、间距不均匀——模拟活字印刷的不完美
装饰元素：手绘红色线条图表、箭头、圆圈标注、下划线、
         剪报碎片、邮戳、回形针、胶带痕迹、图钉、钢笔批注
版式：非对称拼贴——元素以3-5度随机倾斜角度叠放，
      层次关系=前景剪纸片→中景图表/文字→背景旧报纸/牛皮纸底
背景处理：旧报纸或牛皮纸全幅铺底，有明显的折痕、泛黄、氧化斑
```

#### 拼贴层次结构（Vox 特有）

Vox 拼贴风格的核心是 **3-4 层纸质层叠**，每层有独立的视觉深度：

```
Layer 4 (最前景)：重点标注——红色箭头、圆圈、手写批注、图钉
         ↑ 移动速度最快（视差最强）
Layer 3 (前景)：主体剪纸片——人物/物体的报纸风格剪影，手撕/剪切边缘
         ↑ 跟随镜头移动
Layer 2 (中景)：信息图表——柱状图、折线图、流程图、数据标签，红色线条
         ↑ 轻微视差移动
Layer 1 (背景)：底纸——旧报纸/牛皮纸铺底，印刷文字模糊可见，不可读
         ↑ 移动速度最慢（视差最弱）或静止
```

#### 运镜规则（Vox Collage 专用）

| 运镜 | 效果 | Prompt 描述 |
|------|------|------------|
| 纵深推镜 | 穿越纸层进入画面深处，视差感最强 | 镜头沿Z轴缓慢推进，前景剪纸片向两侧滑出画外，中景图表放大，背景报纸纹理保持静止 |
| 俯视下降 | 从上方下降至桌面，模拟"俯看桌面文件" | 正上方俯视角度缓慢下降，纸片层次逐渐清晰，边缘泛黄的报纸铺满画面 |
| 平移扫描 | 水平扫过拼贴板，展示多组信息 | 镜头水平平移，依次经过不同的剪纸片和图表区域，前景纸片以更快速度移动（视差） |
| 缓慢旋转 | 围绕中心主体微幅旋转，增加纵深感 | 镜头以画面中心为轴缓慢顺时针旋转5-10度，所有纸层随旋转角度产生微幅位移 |
| 弹出定格 | 新纸片从画面外弹入并"钉"在当前层 | 一张剪纸片从画面右侧快速滑入，伴随图钉声效，定格在中景层，轻微弹跳后静止 |

#### 色卡参数（可直接用于 Step 1.5 色卡生成）

```
主色（60%）：泛黄牛皮纸色 HEX:#D4B896
辅色（30%）：旧报纸灰白 HEX:#E8E0D4
点缀色（10%）：复古红 HEX:#C4463A
阴影色调：深棕墨色 HEX:#3E2F23
整体饱和度：低饱和
整体对比度：低对比
```

#### 跑偏自检清单

| # | 检查项 | 通过标准 | ⚠️常见跑偏 |
|---|---|---|---|
| 1 | 纸质质感 | 看得见纸张纤维/折痕/泛黄 | AI 生成光滑数码表面 |
| 2 | 边缘处理 | 手撕毛边或剪刀裁切痕 | AI 生成完美几何边缘 |
| 3 | 层叠关系 | 可辨认至少3层纸片叠压 | 所有元素在同一平面 |
| 4 | 色调 | 整体偏暖黄/棕 | AI 偏冷蓝或高饱和 |
| 5 | 红色点缀 | 仅图表/线条/标注使用红色 | 红色扩散到主体元素 |
| 6 | 黑色使用 | 深棕替代纯黑 | 出现纯黑色#000000 |
| 7 | 光影 | 平面化手绘阴影 | 出现写实3D光照/投影 |
| 8 | 文字 | 打字机/印刷体，不完美间距 | 出现现代无衬线字体 |
| 9 | 完美度 | 手工拙趣感 | 过度精修、边缘锐利 |

#### 适用内容类型

| 类型 | 适合度 | 示例 |
|------|--------|------|
| 科普/知识解释 | ★★★★★ | 比特币原理、物理定律、历史事件 |
| 财经/商业分析 | ★★★★★ | 经济趋势、公司故事、市场分析 |
| 文化/社会议题 | ★★★★☆ | 文化现象、社会变迁、人物传记 |
| 历史纪录片 | ★★★★☆ | 历史事件、时代变迁、老照片风 |
| 科技产品介绍 | ★★★☆☆ | 适合讲"背后原理"，不适合展示现代UI |
| 情感/剧情 | ★☆☆☆☆ | 不适合——拼贴风格与情感叙事冲突 |

## Recipe 2: INS Sticker Healing / Notion 手账拼贴（VibePaper）

真实照片背景 + Notion / 手账风黑白单线人物切模贴纸。核心是高清实景与扁平线稿贴纸的反差，做成 INS 风动态拼贴，适合宣发物料、Vlog 片头片尾、生活方式短视频。

别名触发：`Notion 线稿`、`手账贴纸`、`INS 拼贴动画`、`VibePaper`、`黑白切模贴纸`。

### 画风说明书：INS Sticker Healing

**提取自：** 抖音创作者 VibePaper — INS 风拼贴动画教程 + 既有 INS 治愈贴纸配方

#### 逐维度风格声明

```
风格：真实照片+Notion风格黑白单线人物切模贴纸——实景高清背景上叠加手绘扁平线稿人物，
      人物以手账贴纸形态存在（粗黑轮廓 + 白色裁切白边），而非融入场景
摄影：静态平面摄影视角，模拟手机直拍的自然构图；视频模式镜头锁定
质感：背景保持原片高清质感（实景光影/环境完整保留），
      贴纸人物为粗黑色轮廓 + 少量纯黑色块阴影 + 纯白填充，
      纯黑白无渐变，贴纸自带一圈白色裁切白边，简约涂鸦 / 手账风
光追：无——贴纸层完全平面化，不参与场景光照计算
灯光：仅背景实景保留自然光照，贴纸人物无写实光影——
      仅允许少量纯黑色块作平面阴影，无灰阶渐变
调色：背景保持原片色调，贴纸层仅黑白两色；装饰可用白线涂鸦，文案多为大号英文
动态光源：无
噪点：背景保持原片噪点，贴纸层无噪点——矢量干净线条
锐化：背景中等锐化，贴纸线条边缘锐利无锯齿
动态范围：背景保持原片；贴纸层二值黑白
完美度：混合——背景照片级真实；贴纸手绘极简（线条可有轻微不规则）
```

#### 氛围关键词

治愈、清新、文艺、极简、INS风、Notion、手账贴纸、拼贴

#### 禁止（与此风格冲突的元素）

```
禁贴纸人物出现彩色（仅黑白）
禁贴纸人物出现写实光影/灰阶渐变（仅允许纯黑色块平面阴影）
禁贴纸人物与背景融合（必须保留白色裁切边的"贴上去"感）
禁改动真实场景、光影、环境质感、原构图
禁背景模糊/滤镜化/卡通化
禁装饰拥挤杂乱（少量点缀、留白充足）
禁装饰遮挡人物面部与核心场景主体
禁暗色压抑调（整体偏明亮温柔治愈）
禁贴纸人物五官过细（概括即可）
```

#### 平面设计维度（海报 / 静帧）

```
字体：顶部巨大英文字句为主（海报标题感），可辅轻手写体；
      文案结合场景氛围，不挡脸、不挡主体
装饰元素：白色简约手绘涂鸦——云朵、弯月、迷你蝴蝶结、虚线圆点、
         小气球、几何波浪线、四角星、迷你方块；可用红笔标注区
         让 AI 在指定位置生成装饰（如风筝）
版式：3:4 竖幅常见；留白充足；装饰绕人物周边与空白区
背景处理：INS 图实景完整保留，不改场景/光影/环境
```

#### 混合媒介层次结构

```
Layer 3 (最前景)：文案标题 + 白色涂鸦装饰（可微动：轻微漂浮/闪烁）
Layer 2 (贴纸层)：黑白单线切模人物——白色裁切边，节奏点动作（扫弦、点头等）
Layer 1 (背景层)：真实照片——完全静止，禁止改动
```

### 四步生产流程（VibePaper）

按顺序执行；每步一张图，最后一步才出视频。不要一步把线稿+文案+动态全塞进同一条 prompt。

#### Step 1 — 人物转线稿贴纸

上传日常照片 → 只把人物变成 Notion 风切模贴纸，**实景原样保留**。

**可直接复用提示词：**

```
把画面中的 N 个人物做成 Notion 风格黑白单线人物切模贴纸，粗黑色轮廓，少量纯黑色块阴影，纯黑白无渐变，每张贴纸自带一圈白色裁切白边简约涂鸦风，实景照片保持真实高清质感，原边：手账贴纸叠加效果，扁平极简手绘，ins 图实景完整保留，不改动真实场景、光影、环境质感。
```

把 `N` 换成实际人数。

#### Step 2 — 标注并添加装饰元素（可选）

用工具红笔/标注圈出位置（如天空空白处），再让 AI 在该区域生成线稿装饰（风筝、云朵等）。  
原则：装饰与人物同风格（黑白单线或白色涂鸦），不改人物造型与实景。

#### Step 3 — 添加文案与小装饰

以 Step 1（或 Step 2）成图为参考，叠加海报文案 + 留白涂鸦。

**可直接复用提示词：**

```
完整保留原实景场景、原生构图、光影、环境质感，画面内黑白人物线稿完整留存，人物造型、动作、比例、服饰全部原样不修改；叠加添加 ins 态海报纸元素，画面顶部放巨大英文字句；在人物周边、空白区域添加白色简约手绘涂鸦装饰（云朵、弯月、迷你蝴蝶结、虚线圆点、小气球、几何波浪线条、四角星、迷你方块），少量点缀不拥挤杂乱，整体画面留白充足，温柔治愈质感，所有装饰元素避开人物面部、核心场景主体，不遮挡主体、背景色投影光影，画面构图全程无改动，文案结合原图场景氛围适配搭配，高清细腻，3:4 画幅。
```

文案内容按场景改写顶部英文句；勿改人物与背景。

#### Step 4 — 静态拼贴 → 动态视频

指定**一个主节奏点人物**及其动作；背景与风格锁定。

**模板（吉他示例，可替换动作）：**

```
保留画面风格不变，中央弹吉他的男生为主要节奏点：双手在吉他上进行具有音乐节奏感的自然扫弦与拨弦动作，手指灵活不僵硬；身体随演奏节奏前后微微摇摆。
```

**通用骨架：**

```
保留画面风格不变，[主人物位置与身份]为主要节奏点：[具体肢体动作，要求自然有节奏、手指/关节不僵硬]；身体随节奏轻微[摇摆/点头/起伏]。背景实景完全静止；贴纸白边与黑白线稿风格不变；镜头固定。
```

规格建议：`3–8秒，3:4，30fps`（宣发 loop）或按平台改为 `9:16`。

结构化写法（可选，对接 Seedance / 视频模型）：

```
【规格】5秒，3:4竖版，30fps

【电影化动态描述】
高清实景背景完全静止——[场景一句]。
黑白 Notion 切模贴纸人物保留白色裁切边；[主节奏人物]做[扫弦/点头/递物等]微幅循环动作，手指灵活不僵硬，身体轻微随节奏摇摆。
装饰与顶部英文文案可极轻微漂浮，不遮脸。
⚠️ 仅贴纸层微动，背景静止；禁改构图；禁给贴纸上色或加写实光影。
⚠️ 镜头完全固定——零推拉、零摇动、零平移。
```

### 动态规则汇总

| 规则 | 说明 |
|------|------|
| **背景** | 完全静止——禁推拉摇移、禁改光影环境 |
| **贴纸人物** | 一小幅循环：扫弦、点头、递物、翻书等 |
| **动作幅度** | 人物锚点不位移；关节自然，忌僵硬 |
| **时长** | 3–8 秒 loop（INS / 宣发 / Vlog 物料） |
| **主节奏点** | 每镜只强调 1 个主动作人物，避免全员大幅乱动 |

### 色卡参数

本风格通常不需要传统色卡——背景跟原片，贴纸仅黑白。多海报统一时可用：

```
主色（60%）：背景实景主色调（随场景）
辅色（30%）：纯白（贴纸填充+裁切边+涂鸦+留白）
点缀色（10%）：纯黑（轮廓线+色块阴影+标题字重）
```

### 跑偏自检清单

| # | 检查项 | 通过标准 | ⚠️常见跑偏 |
|---|---|---|---|
| 1 | 贴纸 vs 背景 | 白色裁切边清晰，「贴上去」 | 人物融入实景、无白边 |
| 2 | 贴纸色彩 | 纯黑白，无彩色无渐变 | 上色、灰阶渲染 |
| 3 | 实景锁定 | 构图/光影/环境未改 | 背景被重绘或美颜滤镜化 |
| 4 | 人物锁定 | Step 3/4 后造型动作服饰不变 | 换脸、改姿势 |
| 5 | 装饰密度 | 留白充足，不挡脸与主体 | 涂鸦堆满、挡脸 |
| 6 | 动态范围 | 仅贴纸微动，背景静 | 背景跟着动、镜头推拉 |
| 7 | 动作质量 | 手指/关节有节奏、不僵 | 滑步、融化、多指 |
| 8 | 氛围 | 温柔治愈、INS/手账 | 暗调、复古报纸（那是 Recipe 1 Vox） |

### Skill 协作

```
1. style-extractor（本配方）     → 选风格 + 四步提示词
2. 图像模型（分步 1→3）         → 线稿贴纸 → 装饰文案静帧
3. 视频模型 / seedance-2        → Step 4 动态（只动贴纸节奏点）
4. post-production（可选）      → 配乐、字幕、导出；或静帧 PNG 叠在实拍上
```

与 **Recipe 1 Vox Collage** 的区别：Vox = 复古报纸多层剪贴 + 视差运镜；本配方 = **实景不动 + Notion/手账黑白切模贴纸微动**，不要混用光影与纸质泛黄设定。

## Recipe 3: Magazine Art Director（杂志级祛塑料感海报）

用光学参数 + 定向漫射光，把「廉价电商平光」拉成时尚杂志 / 艺术海报质感。核心：**高级感来自微小光学瑕疵，而非过度干净。**

别名触发：`祛塑料感`、`杂志封面`、`艺术海报`、`85mm f/1.8`、`美术指导提示词`、`非叔海报`。

来源吸收：[absorption/AIGC-杂志级祛塑料感吸收.md](absorption/AIGC-杂志级祛塑料感吸收.md)。

### 画风说明书（静帧）

```
风格：超现实主义精致艺术海报 × 情感现实主义摄影
摄影：全画幅，85mm，f/1.8，ISO 200，约 1/160s；浅景深，锐利对焦点，镜头边缘自然虚化
灯光：禁止大平光。必须写明光源方向与衰减——默认「前方左侧（或由主题指定）柔和漫射光」，
      主体上形成有呼吸感的明暗交界线；低调、低饱和、故事感
质感：柔和自然纹理，细微胶片色调，非 AI 塑料高光；允许微小光学瑕疵
调色：深沉低饱和工作室背景，平滑柔焦边缘，丰富但克制的色调对比
构图：极简强烈；胸部以上或物件特写；主体偏心或居中；画家般亲密构图
完美度：中高——杂志品质，但禁过度磨皮、禁均匀棚拍平光、禁廉价电商白底闪光感
```

### 禁止

```
禁大平光抹平立体、禁过度干净无瑕、禁塑料皮肤、禁默认居中商品棚拍闪光、
禁高饱和快消感（除非主题明确要求）、禁杂乱信息墙
```

### 与 video-render-quality 的关系

| 本配方 | `video-render-quality` |
|--------|-------------------------|
| 静帧杂志/海报/KV | 动态视频片塑料感 |
| 85mm / f/1.8 / ISO / 定向漫射光 写进图像 prompt | 引擎级光追、胶片、材质物理写进视频 prompt |
| 可同时参考：光学瑕疵、禁平光 | 电影写实管线仍服从 `STYLE_BLOCK` practicals-only |

### 跑偏自检

| # | 检查 | 失败表现 |
