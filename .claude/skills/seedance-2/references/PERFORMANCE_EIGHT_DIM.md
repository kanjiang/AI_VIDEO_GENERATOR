# 八维表演提示词公式

长对白 / 对手戏 / 情绪弧（积累→转折→崩塌）专用。  
目标：表情随台词时间轴变化，禁止「摆表情 + 念台词」。

联用：[AU_FACS.md](AU_FACS.md) · [seedance-emotion-micro-skill.md](seedance-emotion-micro-skill.md) · `../shotlist-builder/reference/MICRO_BEATS.md` · `../video-dialogue-punctuation/SKILL.md`

来源：[absorption/AIGC-八维表演提示词吸收.md](absorption/AIGC-八维表演提示词吸收.md)

## 0. 硬规则

1. **不写笼统情绪标签当表演**（「非常悲伤地说」）。写可见肌肉、呼吸、目光、停顿。
2. **情绪曲线 ≠ 情绪跳切**。真实路径常是「保护层逐步失效」：先用愤怒/质问护住自己 → 裂缝 → 才流露脆弱。
3. **台词是表情的时间轴**，不是旁白。每句至少绑一次面部/呼吸变化。
4. **镜头层与表演层分开写**：先机位时间轴，再每镜八维表演。
5. 单镜仍遵守：1 个主情绪 + 最多 1 个次级波动；长弧靠**多镜节拍**展开，不靠单镜堆满。

## 1. 三层提示词结构

### 第一层：全局控制（短写）

锁定规格与一致性，**把篇幅留给表演**：

| 项 | 写什么 | 勿写 |
|----|--------|------|
| 时长 / 画幅 / fps | 如 30s、20:9 或 16:9、24fps | — |
| 场景 | 年代、地点、关键光（黄昏侧光等） | 冗长布景散文 |
| 人物一致性 | 同脸、同服、同发、同体型 | 重复外貌小说 |
| 影像风格 | 风格库名或一句胶片/颗粒 | 挤占表演字数的空泛「电影感」 |

### 第二层：镜头时间轴

按 **镜头分级 + 时间码子集**，每条写清：时长、机位/景别、观察主体、切换点。

```
0–4.5s   近景｜男人｜胸部以上
4.5–11.5s 近景｜女人｜胸部以上
11.5–16.5s 特写｜女人｜脸部
16.5–20s  近景｜男人｜反应镜
```

禁止只堆一串时间码而无「谁 / 什么景别 / 为何切」。

### 第三层：表演控制（情绪节拍）

在镜头时间轴上再拆**情绪节拍**，例如女方第二段：

| 时间 | 节拍意图 |
|------|----------|
| 反击 | 仍在质问、保护自己 |
| 证明牺牲 | 用力陈述代价 |
| 愤怒出现裂缝 | 音量/目光开始破 |
| 声音第一次破裂 | 保护层撑不住 |
| 近乎羞耻的坦白 | 脆弱露出后的静止 |

## 2. 台词 × 表情六要素

每句对白按序写满（缺一项易变「摆脸念词」）：

1. **说话前状态**（脸、呼吸、目光）
2. **触发变化的台词**（原文）
3. **加重词**（鼻翼/咬肌/音量落点）
4. **眼神 / 唇 / 身体**（可见动作）
5. **呼吸与停顿**（为何停：决定是否说出下一句，不是「为了电影感」）
6. **说完后结束状态**（含短暂静止反应）

### 反例 → 正例

❌ `女人非常悲伤地说："What about my life? What about me?"`

✅ 时间轴写法（意译结构可套中文台词）：

| 点 | 动作 |
|----|------|
| 第一句 | 音量较高，直视对方，仍在质问 |
| 句间 | 短促吸气，目光向下离开不到半秒 |
| 第二句 | 更轻更慢，重新看回对方，攻击性消失 |
| 停顿 | 人物在决定是否说出脆弱的话 |

## 3. 八维公式（每镜 / 每节拍填表）

| # | 维度 | 写什么 |
|---|------|--------|
| 1 | 时间段 | 起止秒或镜内子节拍 |
| 2 | 人物目的 | 这几秒她/他要达成什么（反击 / 隐瞒 / 求证） |
| 3 | 情绪变化 | 从 A→B 的**过程**，勿只写终点标签 |
| 4 | 台词触发词 | 哪几个词触发表情升级 |
| 5 | 面部动作与 AU | 可见描述 + 可选 AU（见 [AU_FACS.md](AU_FACS.md)） |
| 6 | 目光和身体 | 视线路径、肩/手/重心 |
| 7 | 声音、呼吸与停顿 | 音量、气口、破音点 |
| 8 | 结束状态与静止反应 | 说完后 0.3–1s 的脸与身体 |

### 拼装模板

```
【表演 · t=a–b】目的：[目的]。情绪：[起点]→[终点]（保护层：[仍在/裂缝/失效]）。
台词：「……」；加重：「[词]」。
面部：[肌肉可见描述]；AU：[编号+强度A–E，起/峰/消]。
目光/身体：[……]。呼吸/停顿：[……]。
结束：[静止反应，眼泪是否落下须明示；默认不落]。
```
