# 05 — Detail Page（卖点可视化，不堆字）

传统详情：大段文字 → 用户划走。  
本流程：**先规划分屏结构，再逐屏把卖点「画」出来**；字只作锚点标题。

---

## 推荐分屏骨架（可按品类增删）

| 屏 | 目标 | 展示重点 |
|----|------|----------|
| 1 | 建立认知 | 产品全貌 + 品类定位一句 |
| 2 | 核心卖点 | Top1 卖点场景化/可视化 |
| 3 | 功能细节 | 局部放大、结构拆解、工艺 |
| 4 | 使用场景 | 真人/情景使用（引用模特规范） |
| 5 | 购买引导 | 规格/套装/信任背书/下单区（合规） |

美妆可加「质地特写」；科技可加「爆炸图/接口」；食品可加「原料/工艺时间线」。

---

## 卖点 → 画面（转化表）

| 抽象卖点 | 可视化手段 |
|----------|------------|
| 材质好 | 微距局部、纹理光、截面 |
| 功能强 | 使用前后、动态示意静帧、标注 sparingly |
| 设计感 | 结构拆解、三视图艺术化、工艺步骤 |
| 方便 | 一手操作步骤 3 格 |
| 安全/认证 | 图标化认证墙（勿造假章） |

---

## 逐屏生成

每屏先写一行「本屏设计目标」，再出图 prompt。

```
电商详情页第 N 屏，竖版长图单屏构图（宽度适配手机详情，高度按模块）。
设计目标：[建立认知/突出卖点X…]。
视觉重点：[局部放大/场景/拆解…]；产品外观锁定精修参考。
标题区仅短句「[≤12字]」，禁止大段正文；留白与品牌色来自 brief。
高清商业设计质感。禁杂乱弹窗风、禁假评论截图（除非用户提供真实素材）。
```

输出记录到 `detail-page.md`。

---

## 分层交付（PSD）

若用户要给客户改图：

1. 生成时尽量要求「主体/背景/文字区可分层意识」（不少模型只出成图）。  
2. 成图后：可用 Photoshop / Photopea / 支持「AI 分层」的工具拆为 `产品 / 背景 / 文案占位`。  
3. 交付说明模板：

```markdown
## Handoff
- 格式：PSD 或 分层 PNG 序列
- 图层建议：背景 / 产品 / 光效 / 文案层（客户可改字）
- 字体：客户品牌字体自替换
- 禁止改动的锁定层：产品外形（与精修一致）
```

本 skill **不绑定**某一「一键导出 PSD」按钮；按用户实际工具写操作要点即可。

---

## 完成定义

- 分屏顺序符合认知→卖点→细节→场景→转化  
- 每屏一个主信息，无墙字  
- 产品与 Phase 2 底座一致  
- 物料清单可勾选归档
