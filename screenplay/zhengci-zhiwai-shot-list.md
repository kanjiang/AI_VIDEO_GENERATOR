# 证词之外 逐镜 Shot List

用途：导演分镜、摄影计划、AI 视频生成、后续故事板细化。

本版基于 2026-06-08 最新剧本重拆，当前全片按 6 个场次、32 个镜头组织，所有镜头固定为 15 秒。结构重点从“高密度短切 72 镜”调整为“15 秒定长镜头块”，保证完整台词与剧情不断裂，同时每镜保留一个明确钩子。

格式说明：

| 字段 | 说明 |
| --- | --- |
| 镜号 | 连续镜头编号 |
| 场次 | 对应剧本场次 |
| 景别 | 建议景别 |
| 机位/运动 | 固定、推进、横移、俯拍、主观等 |
| 画面内容 | 镜头内发生的主要动作 |
| 台词/声音 | 该镜头内完整关键对白或主导声音 |
| 时长 | 固定 15 秒 |
| 备注 | 用于节奏钩子、表演、调度与视频生成提示 |
