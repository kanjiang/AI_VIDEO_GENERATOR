# Episode 04 — 陆夫人的电话

### 制作前置

**接续 Ep3**：翌日清晨。沈星野答应留下继续白日观察。**陆母首次以声音出场**——电话形态，不给面孔。她的正面首登要等 Ep13 家宴。

**人格出场边界**：本尊 + 小小。**1 次全切换**（本尊→小小），触发 B（陆母话里的抛弃信号 + 联姻施压 = 童年"她不喜欢就会赶走"语言的复读）。夜不出场。

**陆母的语气锁**：温柔、得体、带上位者裁决感。她把命令说成建议，把施压说成关心，把威胁说成家务事。声音永远保持在低八度。**她不问，她只通知**。

**本尊在陆母电话前的固定动作**：接电话前一定会先在袖扣上按一下。他自己没意识到。这是二十年被驯化的应激起手式，Ep1 客厅擦手动作的同源变体。

**观众信息层**：观众到本集为止应该已经收到——(1) 陆母遥控陆宅、(2) 陆母投影疏漏、(3) 陆母调虎离山、(4) 陆母的**声音**。她越靠近，越不露脸。这个"缺席在场"是陆母 Ep1-Ep12 的整体调度锁。

### 渐入:

**内景 陆宅主卧 · 落地窗前 — 晨**

（Hook 3 秒：手机屏亮起。屏上两个字："母亲"。）

陆景深看着屏幕。

指节先在袖扣上按了一下。

（他自己没意识到。）

他接起。

**陆母**（V.O., 温柔）

景深，昨晚睡得好不好？

陆景深顿一秒。

**陆景深**

……好。

**陆母**（V.O.）

沈医生今天还在？

**陆景深**

她今天下午会走。

**陆母**（V.O.）

那就好。她一个实习医生，别把临时看护误认成能进陆家的资格。景深，这不是我在防人，是替她好。她这个年纪，被外面的舆论多说几句，就废了。

陆景深没答。

**陆母**（V.O.）

对了。晚棠上周回来了，托我问你有没有空一起吃饭。你这几天状态稳一些，就答应下来。妈是替你着想。

（一秒沉默。）

**陆母**（V.O.）

景深，别让我失望。

（挂断。）

陆景深握着手机。

（一秒。目光空半秒。）

（血色从脸上退了一层。）

（袖扣上那颗——松了。）

（他没有意识到。）

（呼吸放慢。）

**内景 陆宅二楼走廊 — 晨**

沈星野从客房走出来，正要下楼。

她停在楼梯口。

陆景深靠着楼梯栏杆坐着。膝盖抱着自己。

手腕上——不知何时——挂着一根发绳。

（袖扣松开一颗又没系回去。）

（不是本尊。是小小。）

沈星野的心跳漏一拍。

她走过去。

蹲下来。慢。

**沈星野**（很轻）

我在。

小小抬眼看她。

**小小**

姐姐。

**沈星野**

嗯。

**小小**

姐姐……

（他捏紧发绳。）

**小小**

如果她妈妈不喜欢姐姐——

（停了一下。）

**小小**

姐姐是不是也会被赶走？

沈星野的心脏被这句话捏了一下。

（他记着。他也怕。他把陆母对本尊说的话——听进去了。）

（她意识到——陆母甚至不需要在场。她二十年对本尊说过的话，已经写进这个孩子体内。）

沈星野缓缓伸手，把外套披到他肩上。

**沈星野**

姐姐不走。

（她说得很稳。稳到她自己都知道——这一秒开始，她不是被推荐信绑在这里。她是自己选的。）

（她第一次对自己说清楚：我在。）

小小把头搁在膝盖上。像卸了半层重。

**小小**

……嗯。

一秒。

**小小**（更小声）

姐姐，你别告诉本尊。

（他自己说了这两个字：**本尊**。）

沈星野的手一顿。

（小小知道那个"稳的他"叫本尊。**小小是知情的**。）

（她此刻不能追问。她把这个词记在心里。）

**沈星野**

好。姐姐不告诉他。

**小小**

……嗯。

镜头拉远。

沈星野坐在楼梯上一级台阶。没走。

阳光落在他手腕上的发绳。

切黑。

**字幕：三个他，只许你知道。**

### 分析

价值弧：**陆母的裁决 → 本尊压不住 → 小小顶出来 → 沈星野的第一次主动承诺**。她说"姐姐不走"的时候，观众第一次听见她不是在做医生，是在做选择。她的位置从"接住的人"抬成"选边的人"。

激活的 hamartia：
- **本尊**：陆母的电话第一次在观众面前示范——他接电话前必按袖扣。他自己没意识到。二十年应激起手式**可见**了。
- **小小**：陆母的语言（"她一个实习生"）直接触发小小的抛弃恐惧。他脱口说"如果她妈妈不喜欢姐姐"——**他把陆母认作"她妈妈"，观众此时收到关键信息：小小的世界里，陆母是掌管"喜不喜欢"的最高裁判**。
- **沈星野**：她第一次说"姐姐不走"。四步爬梯完成：Ep1 想退没退 → Ep2 记录 → Ep3 主动进局 → Ep4 主动承诺留下。

红旗 1：Switching Protocol 命中。触发 B（陆母话里的抛弃信号 + 联姻施压 = 童年语言复读）。三拍完整：呼吸放慢 + 目光空半秒 + 袖扣松开 → 走到楼梯 + 手指绕栏杆 → 膝盖抱着 + 手腕挂上发绳 + 软声"姐姐"。**本集用完 1 次全切换额度**。

红旗 2：**陆母只用声音出场**——不给面孔。这是"温柔控制"的视觉隐喻：她无处不在，但你抓不住她。她的正面首登要等 Ep13 家宴，此前她要一直"在场却不露脸"。

红旗 3：**"是不是也会被赶走"**是本集第一个 Act 3 钩子。要在 Ep34 陆母亲口承认"让他怕一次才会学乖"时形成回响。观众此时看见小小的恐惧结构——**被丢下 = 我不乖 = 我错了**。

红旗 4：**小小自己说出"本尊"**——这一秒把 Ep1-Ep2 埋的"知情结构"钩起来。**小小是知情的**：他知道那个稳的他叫本尊，也知道自己是那个"不该出来"的。观众此时拿到的信息比本尊多。本尊完全不知道这两个词的存在。**Ep15 抽屉打开时本尊会第一次说"这些东西我不知道是谁放的"——那时观众要瞬间意识到：小小和夜都在他不知道的地方留了痕迹**。

红旗 5：陆母的电话本集提三件事——"沈医生临时看护不算资格" + "宋晚棠回来了" + "别让我失望"。三件事同时压下来，为 Ep7 集团偷拍、Ep13 家宴、Ep16 官宣舆论提前埋线。**Ep4 的三件事是 Act 2 前半的三条线的种子**。

红旗 6：沈星野"姐姐不走"落地方式——她**没有碰他**，只把外套披上。这是她的边界锁：她可以承诺，可以留下，但她不用身体接触去骗小小"我是妈妈"。她在替一个孩子做他母亲从没做过的事——**给稳定的承诺，而不给身体的欺骗**。

红旗 7：小小最后一句"你别告诉本尊"——这是本剧集内"三个他之间的知情不对称"第一次被口头点破。观众此后要带着这个信息看：本尊说的每一句"我不记得"，都建立在小小 + 夜 + 母亲 + 御医共同的沉默之上。
