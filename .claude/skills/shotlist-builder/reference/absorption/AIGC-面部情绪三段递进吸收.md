## 总判断

| 观点 | 决策 |
|------|------|
| 面部情绪三段递进（蓄→转→爆） | **吸收**进 `MICRO_BEATS.md` §8 |
| 同台词不同哭法 | **吸收**为对照表 |
| 提示词拆解五官 | 与仓库「禁笼统情绪」一致，强化模板 |
| LibTV 可视化点选 20+ 微表情 | **不绑 UI**；选定后写回 prompt |
| 人像质感去磨皮 + 人景光影融合 | **吸收**为活人感门；细节链 `video-render-quality` |
| 角色库一键调用 | 原则等同 asset 锁定，不建 Liblib 专用 skill |
| 无限画布/节点工作流介绍 | 不吸收（产品宣传） |

公式沉淀：**情绪三段递进法 + 有活人感的人物图**。
