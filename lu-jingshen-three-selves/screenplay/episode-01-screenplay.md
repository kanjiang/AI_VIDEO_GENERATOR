# Episode 01 — 她看见了

### 制作前置（不进画面，仅供拍摄参考）

**人格出场边界（Ep1 硬锁）**：本集只出现 **2 个人格**——本尊 + 夜。小小到 Ep3 才首次登场。观众此时应模糊感知到"另一个他"，但没有名字、没有形态。

**切换次数**：本集 **1 次全切换**（陆氏总部 本尊→夜），命中触发 A（会议室独处、暖色降下来）+ 触发 B（"陆家封存"章闪过 = 童年创伤物件在场）。陆宅天台的本尊是从夜"回归"的残余状态，属于协议"空白后自然回归本尊"的非睡眠变体，不算 visible 切换、不占额度。镜中半浮现同样不算。

**相识机制**（Option 3 锁）：陆承岳在董事会推"独立第三方精神健康评估"，陆母被迫合规但施压院方派实习生级别的支援。沈星野以带教主任助手身份被派到陆氏总部走流程。她**不是**男主主动找的，男主也**不知道**自己需要找。

**投影为什么闪过"陆家封存"**：陆母亲自审自己封存档案时留了一个投影窗口，本尊提前到评估室，她没来得及关屏——这是陆母控制体系在 Ep1 的**第一处疏漏**，为她后续被拆穿铺垫。

**Ep1 双方自知锁**：
- **本尊**：完全不知道自己有 DID；相信"焦虑症"是全部诊断。他今天晚上第一次心里冒出一个"我刚才在哪？"的未问出口的问句——他没让自己问。
- **沈星野**：开场前完全不知道男主有多人格。她 Ep1 三段发现走：医院走廊撞见"另一个他"（无名） → 天台认出"这只手"（下午威胁她的那只手回到了本尊身上）→ 客厅问出"你不记得，还是不知道？"——他答不出，她意识到他自己也不知道。
- **"你不是他"的可信度机制**：沈星野在走廊被抵墙那两秒**不是**做出 DID 诊断，而是做出一个**同一人物两秒内身体使用方式反转**的观察对比。她**门缝里刚看过**陆景深的本尊形态（袖扣紧扣、领口整齐、指节按袖扣发白、呼吸从鼻腔）——门开的两秒后压在她眼前的这个人是**同一具身体的另一套使用参数**（领口松、袖扣脱、火机旧习惯、下颌用力方向反转、呼吸从胸腔）。她作为精神科实习生知道"焦虑发作"不会在两秒内让人重新学一遍身体用法，所以她的第一句是**观察式的核对**（"你袖扣没扣"），第二句是**观察结论**（"你不是他"）——不是诊断结论。她此时**没有**在心里说"这是 DID"，她只是说"这具身体的用法变了"。

### 渐入:

**外景 陆宅天台 — 雨夜**

雨砸栏杆。

陆景深站在天台边缘。西装被淋透。袖扣一颗松开。领带偏了。

沈星野从楼梯口出来。停在离他六步的地方。

他没听见她。

他在看远处。

他的呼吸不像 CEO。

沈星野看着他右手——那只手在西装口袋里，捏着什么。指节发白。

（她认得这只手。）

**沈星野**（很轻）

……陆总？

陆景深慢慢回头。

眼神先空。

再对焦。

再一秒——他重新记起自己是谁。

**陆景深**

你怎么在这里？

声音是本尊的。冷。规矩。

（仿佛下午没有发生过任何事。）

**闪回：内景 陆氏总部评估等候区外走廊 — 傍晚**

沈星野抱着病历夹，停在会议室外。带教主任的空咖啡杯搁在椅背上——他刚接了个电话出去。

（带教挂电话回来时眼神一躲。她没看见。）

病历夹夹层露出一角文件——「陆氏董事会紧急动议·关于陆总精神健康评估」。签名列首位：**陆承岳**。

（观众此时不需要记住这个名字。Ep8-10 他正面登场时会对上号。）

手机屏一亮。带教主任的邮件预览："下周推荐信名单再审。请勿失误。"

她按灭屏幕。

门缝里，陆景深扣紧袖扣，抬眼看向满墙投影。

投影一角闪过「儿童精神评估·陆家封存」——一秒钟。

投影一灭。

指节按向袖扣，发白。

呼吸沉半拍。

门猛地拉开。

领口松开。

同一具成年身体逼近。

火机贴亮她的下巴。

夜把她抵上墙。

**夜**

说出去，我毁的不只是你的实习。

沈星野攥紧病历夹。

（脚跟往门框贴了半寸。她想退。她没退到门外。）

（她的眼睛先她的脑子动了——**两秒前**门缝里那个人：袖扣扣紧、领口到喉结、指节按袖扣发白、呼吸从鼻腔走。**现在压在她眼前**这个人：领口松了一颗、右腕袖扣脱开、火机在指间转得像旧习惯、下颌肌肉的用力方向反过来、呼吸从胸腔走。同一具身体。两秒。两种用法。）

（她读过 200 小时精神科门诊。她知道**"焦虑发作"** **不会在两秒内让一个人重新学一遍怎么用自己的身体**。）

**沈星野**（很轻，像在跟自己核对一个不敢确认的观察）

你……袖扣没扣。

（一顿。她的声音更轻。像在说给刚才门缝里那个人听。）

**沈星野**

……你不是他。

夜的手指压紧她的下颌。

顿。

火机灭。

**夜**

……你什么都不懂。

夜松开手。转身走开。

沈星野贴墙站着。手在抖。

（她意识到——她刚才做的判断，是一个精神科实习生**不该**在两秒内下的判断。她也知道她**说出口**的那句话，比"焦虑症发作"更接近**某个更不该被说出口的东西**。她 Ep1 傍晚**已经**看见了他自己都不知道的裂缝——只是她此刻还不知道这个裂缝叫什么名字。）

**内景 陆宅客厅 — 雨夜**

行李箱滚进门。管家推着。

**管家**

夫人交代，沈医生今晚开始留下。房间已经备好。

沈星野还没答。

陆景深从楼梯下来。刚换过衬衫。袖扣扣好了。

**陆景深**

我不需要日间照护。你可以走。

沈星野没走。

**沈星野**

下午在陆氏，你抵我上墙的时候——

陆景深顿住。

**陆景深**

我不记得抵过你上墙。

**沈星野**

你不记得，还是——不知道？

（很短的一顿。他没答。他也答不了。）

陆景深绕过她，走向楼梯。

镜墙映出他的脸。

袖扣整齐。

眼神先硬住。

再一颤。

（半浮现——不是任何具名的人格，只是"他自己不知道的某个自己"在镜里看了她一眼。观众看到"他"其实不止一个，但没有名字，没有形态，只有一层裂缝。）

沈星野没走。

切黑。

**字幕：三个他，只许你知道。**

### 分析

价值弧：**目击 → 求证 → 意识到他不知道**。她在雨里认出那只手（下午威胁过她的手），在客厅问了他"你不记得，还是不知道？"，他答不出。她不再是"看见了他的秘密"的人，她是"看见了他自己都不知道的秘密"的人。

激活的 hamartia：
- **本尊**：他二十年一直用"焦虑症发作"解释所有异常。今天从雨里"回来"的时候，脑中第一次冒出一个未问出口的问句——"我刚才在哪？"——他没让自己问。他的 hamartia 在这一秒开始有裂缝。他二十年下意识的自我合理化模板（"应该是助理放的" "应该是我自己顺手带的"）今晚要开始撑不住。
- **夜**：在医院走廊被投影里的"陆家封存"章触发到最高警报——外部威胁到童年秘密。他过激但没杀，是因为沈星野一句"你不是他"戳中了他"我不是本尊"这层认知。夜的知情结构（他知道小小、他知道陆母的清场系统、他不知道陆母是童年真凶）在 Ep1 一律收敛，不显山不露水。
- **沈星野**：她本能地想退——脚跟贴门框半寸——但没退到门外。这是她第一次可见的害怕，也是她第一次主动选择留下。她此时完全不知道男主有多人格，只知道"下午那个他"和"晚上这个他"不是同一个人。

本集人格出场硬锁：**只有本尊 + 夜**。小小到 Ep3 才首次登场。

红旗 1：Switching Protocol 命中。
- 陆氏总部 本尊→夜：触发 A（会议室独处，暖色降下来）+ 触发 B（"陆家封存"章闪过 = 童年创伤物件）。三拍完整（指节按袖扣发白 + 呼吸沉半拍 → 领口松开 + 火机贴亮 → 抵墙 + 威胁台词）。
- 陆宅天台 夜→本尊：属于"空白后自然回归本尊"变体（非睡眠，靠夜在雨里站到情绪沉淀）。不做 visible 三拍，观众通过"眼神先空再对焦"识别本尊已归位。不占本集切换额度。
- 陆宅客厅 镜中半浮现：无名无形——只是"裂缝"。不算切换，不占额度。

红旗 2：夜的知情结构在 Ep1 一律收敛。他没有说任何暗示"我记得小小刚做过什么" / "我在保护另一个我"的话。他的过激用"陆家封存"章触发来解释——投影触发的是他的**外部威胁警报**（有人要碰童年秘密），不是他跟小小之间的连接。alter 间连接的暴露留到 Ep5 以后。

红旗 3：本尊"未问出口的问句"要在雨中回来那一秒有一个身体信号——他手在口袋里捏着什么（观众看不清是什么，但那不是本尊平时会带的东西），指节发白。他没有掏出来看。他没让自己问。这是他二十年 hamartia 的可见 tick。

红旗 4：沈星野"脚跟贴门框半寸"是她第一次可见的害怕。演员必须演出来——她不是钢铁女侠，她只是不逃。这也保住她"实习医生"的可信人设。

红旗 4b：沈星野"你不是他"的**可信度机制**是本剧最容易被观众质疑的一处（"她凭什么两秒就断定人格切换"）。修法不是删掉这句台词——这句是夜停手的钥匙，必须留——而是**让观察过程可见**。她**门缝里刚看过**本尊的形态参数（袖扣紧扣、领口整齐、指节按袖扣发白、鼻腔呼吸），门开两秒后压在她眼前的这个人**参数完全反转**（领口松、袖扣脱、火机旧习惯、下颌用力方向反转、胸腔呼吸）。演员表演层——沈星野的视线必须**先扫他手腕的袖扣位置、再扫领口、再抬到眼睛**，观众要看到她**眼睛比脑子先动**。台词也走两拍：**第一拍是观察式核对**（"你袖扣没扣"——她在替刚才门缝里那个人核对现在这个人为什么不是同一套用法）；**第二拍才是观察结论**（"你不是他"——不是诊断，是一个精神科实习生**不敢下但已经下了**的判断）。旁白同步锁住她的自知边界——"她此刻还不知道这个裂缝叫什么名字"——为 Ep3 首次听见"小小"这个具名人格留出发现空间。

红旗 5：投影"陆家封存"闪过是陆母控制体系的**Ep1 第一处疏漏**——她自己审自己封存档案时留了窗口，本尊提前到，她没来得及关屏。观众看到"她控制不是完美的"，她后续被拆穿有第一块砖。

红旗 6：带教主任接完电话回来眼神一躲——1 秒微表情，不解释。埋伏笔：他可能被陆母买通、或被陆承岳授意、或纯粹畏懦。Ep2/Ep4 展开。

红旗 7：陆承岳在 Ep1 完全不出场。给他一个 1 秒信号：评估文件抬头或走廊背景董事会海报里出现他的名字。观众此时不需要记住，Ep8-10 他正面登场时再对上号。
