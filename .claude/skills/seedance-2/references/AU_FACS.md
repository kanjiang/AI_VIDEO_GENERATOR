# AU / FACS 面部动作编码（表演提示词用）

用**可观察动作单元**替代「悲伤/愤怒」标签。强度 A–E（A=刚能察觉，E=极限），每个 AU 尽量写 **开始 → 峰值 → 消退**。

联用：[PERFORMANCE_EIGHT_DIM.md](PERFORMANCE_EIGHT_DIM.md) · `../shotlist-builder/reference/MICRO_BEATS.md`

来源：[absorption/AIGC-八维表演提示词吸收.md](absorption/AIGC-八维表演提示词吸收.md)

---

## 1. 常用 AU 速查

| AU | 可见动作 |
|----|----------|
| AU1 | 眉毛内侧抬起 |
| AU4 | 眉毛下压 |
| AU5 | 上眼睑抬起（眼裂略开） |
| AU7 | 眼睑收紧 |
| AU15 | 嘴角向下 |
| AU17 | 下巴绷 / 颏部绷紧 |
| AU23 | 嘴唇收紧 |
| AU25 | 嘴唇分开 |
| AU26 | 下颌下降 / 张口预备 |

写 Prompt 时：**中文可见描述为主，AU 编号为辅**（模型更吃肌肉描述；编号便于自检与复用）。

---

## 2. 情绪 → AU 组合（克制默认）

### 悲伤（克制，强度 A–C）

`AU1 + AU4 + AU5 + AU7 + AU15 + AU17`  
分阶段出现，禁止一上来「泪流满面」。默认：**眼眶可湿，泪不落**（除非剧本明确要求）。

### 愤怒（克制 → 破口再收）

1. 基底：`AU4 + AU7 + AU23`
2. 刺激词瞬间：`AU25 + AU26` 短时增强
3. 说完：迅速减弱 → 「忍住 → 失控 → 重新控制」

与 `MICRO_BEATS.md` §8 三段递进同构。

---

## 3. 写法对照

❌ `女人非常悲伤，眼泪止不住流下来`

✅  
`眉毛内侧缓慢抬起，嘴角轻微下沉，下巴开始绷紧；张口想继续说话却没有立刻出声；眼眶逐渐湿润，眼泪暂时不落下。辅助：AU1、AU15、AU17 轻度（A–B）增强，峰值在加重词后 0.3–0.6s，随后部分消退。`

---

## 4. 填写清单

- [ ] 每个 AU 有强度字母或「轻/中」
- [ ] 有起/峰/消，或明确「维持」
- [ ] 与台词加重词对齐
- [ ] 未把 4+ 个高强度 AU 同时拉满
- [ ] 泪/吼/大叫仅在剧情需要时出现
