# 《汽车记数字》资产生成提示词

## 项目概述

用 10 款热门汽车帮孩子记住 0-9 十个数字。每个数字对应一款车名中含有该数字的汽车，再把数字变形成一个形象的物品（鸡蛋、铅笔、鸭子……），三重记忆锚点让孩子过目不忘。

## 风格说明

所有资产统一风格：3D卡通渲染，Pixar级圆润质感，高饱和明亮色彩，白色纯净背景，适合儿童教育动画。

汽车为Q版卡通造型（保留品牌辨识度但比例夸张——大灯圆润、车身圆滚、轮毂Q弹），不是写实渲染。

## 场景资产

### 彩虹赛道（主场景）

```
3D卡通风格，Pixar质感。一条宽阔的彩虹色赛道从画面底部延伸到远方，赛道表面有光泽反射，两侧有糖果色护栏和气球装饰。天空是渐变的浅蓝到浅紫色，飘着几朵棉花糖般的白云。远处有彩色山丘起伏。整体明亮温暖充满童趣。16:9宽屏构图。
```

### 数字变形舞台（特写场景）

```
3D卡通风格，Pixar质感。一个圆形聚光灯舞台，地面是光滑反光的淡金色，四周有柔和的霓虹光环。背景是渐变的深蓝到紫色（像夜空但没有星星，保持干净）。舞台中央有柔和的顶光照射区域。16:9宽屏构图。
```

## 色卡

### 色卡生成提示词

```
抽象色彩参考图，无具象内容。色调分布：主色金黄+天蓝60%（代表阳光活力与天空），辅色彩虹渐变色30%（代表赛道和多彩童趣），点缀色亮红+亮绿10%（代表汽车点缀）。整体高饱和、高明度、温暖欢快。色块过渡柔和，无锐利边界。
```
