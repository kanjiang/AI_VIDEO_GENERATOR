# AIGC 导演级运镜术语吸收说明

来源：导演级专业运镜术语全套（叙事定格 / 氛围景别 / 运动 / 动作 / 情绪 五类）。

---

## 总判断

| 观点 | 决策 |
|------|------|
| 名称+提示词直接写入 Seedance | **吸收**为 `CAMERA_LEXICON.md` |
| 五类分册便于选型 | 保留分类结构 |
| 单镜不堆 2+ 复杂运镜 | **硬规则**写入词库与 SKILL |
| 与 180°/跳切/蓄力静默联用 | 交叉引用，不重复造轮子 |
| 与现有 CAMERA_EMOTION | 情绪→运镜选型仍以 CAMERA_EMOTION 为准；本库提供**中文名称与提示词句** |
