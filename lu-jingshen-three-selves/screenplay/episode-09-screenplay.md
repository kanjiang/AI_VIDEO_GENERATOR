# Episode 09 — 盯梢开始

### 制作前置

**接续 Ep8**：Ep8 匿名短信之后。沈星野从医院下班开始注意到有车跟。她记录三天，确定不是巧合。她把这件事告诉本尊——**这是她第一次主动告诉他外部压力**（Ep8 那次她没说）。

**人格出场边界**：本尊 + 夜。**1 次全切换**（本尊→夜），触发 B（沈星野被威胁的信号 = 本尊童年"我保护不了她"语言的应激）。**首次由沈星野安危触发的切换**——之前触发都指向陆景深自己。

**重要设定锁**：**本剧内夜的触发条件本集扩展**——不是只有陆景深自己被逼才切换。**当沈星野被威胁到，本尊也会崩**。这一秒观众要收到关键信息：**沈星野在本尊心里已经进入"要护住"的名单**。本尊自己不承认。夜替他承认。

**沈星野的策略**：她提议由她**继续当明面上的诱饵**——先逼盯梢的人露出真正的主子。这是她第一次主动给本尊出策略，不是被动执行。夜听完之后**没有阻拦她**——但他补了一条件：**"你走哪里我看着"**。

**观众到 Ep9 应该收到的信息**：偷拍照的下游流转已经过了两轮——陆承岳 → 陆承岳的助理 → 私家侦探。沈星野被盯梢是**陆承岳线**的执行。**陆母对偷拍照的存在暂时不知情**。这是 Ep10 陆承岳试探本尊时的关键前提。

### 渐入:

**内景 街道 · 医院侧门 — 傍晚**

（Hook 3 秒：沈星野下班走出侧门。灰色 SUV 停在马路对面。她抬头。SUV 不动。）

（她已经看见三天了。）

沈星野打开手机。录音键按下。放进衣兜。

她故意绕路。

（不走地铁站。走小巷。）

后视镜——那辆 SUV 跟着拐进来了。

（她的呼吸稳住。她心跳很快，但她走得慢。）

（她要看这辆车跟到哪里为止。）

**内景 陆宅书房 — 夜**

沈星野坐在陆景深对面。

她把一张便签放到桌上。

（便签上是三天车牌号 + 时间 + 地点。）

**沈星野**

有人跟我三天。医院下班开始跟。到陆宅门口停。

陆景深看那张便签。

**陆景深**

……你什么时候开始注意的？

**沈星野**

Ep8 那天晚上。

（她没提匿名短信。她先给他物理证据。）

**陆景深**

（一秒沉默。）

**陆景深**

沈医生。

（他重新用"沈医生"这个称呼。）

**陆景深**

明天开始你先回医院轮转。陆宅这边——

**沈星野**

不。

（她打断他。她第一次主动打断本尊。）

**沈星野**

你把我摘出去，跟我的人就会转去跟别的线。你现在能出去的线只有母亲、陆承岳、董事会——你摘我，你就把三条线的问题都暴露给他们了。

**陆景深**

——

（他一顿。）

（**她说得对**。）

（他二十年应激第一反应是"把风险摘出去"。她此刻拆的正是这个反应。）

**沈星野**

让我留在明面。三个方向的问题会自己朝我聚过来。我们能看清是谁。

**陆景深**（低）

你想把自己当饵。

**沈星野**

我在你家已经十天了。我不当饵，我已经就是饵。

（一秒。）

陆景深的呼吸浅了半档。

（"我在你家已经十天了"——这句话在他耳里响。他没想过。这十天他把她放在陆宅——**他已经把她挂在他们家族战场上了**。他自己没意识到。）

（一秒。他按了袖扣。）

（Switching Protocol 命中。触发 B——本尊意识到"我把她放在危险里而不自知"的应激。这一秒他二十年"我保护不了任何人"的心底封印被戳到。）

（血色反涨。领口松开一寸。）

**夜**（低）

你走。

（不是本尊了。）

**夜**（对沈星野）

我不能让你在明面上被人跟三个星期。你这几天下班的路线换一半我认得的地方。医院侧门到地铁——你换车。走陆宅老巷。老巷有我的人。

（他不像本尊那样"把她摘出去"。）

（他跟她**排兵**。）

（观众此时收到关键信息：**夜不是暴力，夜是策略**。他能布防。他甚至能规划路线。）

沈星野看他。

**沈星野**

你不阻拦我当饵？

**夜**

你已经是了。他刚才说得没错——你在这家已经十天。

**夜**

但你走哪里我看着。

（他把最后这一句压得很低。）

（**这是他 Ep7 之后第二次不威胁地跟她说话**。第一次他跟她讲规则。这一次他跟她讲——**我在**。）

（他没有说"我保护你"。他说的是"我看着"。）

（这四个字比"我保护你"更真——他不承诺保护。他承诺不撒开视线。）

沈星野的心停了半秒。

（她意识到——**夜也在爱她**。他自己没意识到，或者他知道自己没资格承认。他把"爱"翻译成"看着"。）

（她没接。）

（她把这一秒**记在心里**。她要留到 Ep15 或 Ep17 再决定怎么用这一秒。）

**沈星野**

好。

**夜**

你回房间。我今晚不睡。

（他没解释。）

沈星野起身。

走到门口。回头。

（夜站在书房中央。灯从上打下来。他领口松着，袖扣上那颗还压着——那颗是本尊的。**领口是他的，袖扣是本尊留下的**。人格切换的物件差从来没有像今晚这么明确。）

**内景 沈星野客房 — 夜**

沈星野把门锁上。

她坐在床边。

她的手机响了一下。

（另一条陌生号码短信。）

（——但这一次不是照片。是一段录音的音频文件。）

（她按播放。）

（三秒的录音。是她今天下班的脚步声。加一句男人的低语：**"再走一次医院侧门。看她敢不敢报警。"**）

（她的呼吸停了半秒。）

（她把手机拿起——她要转给夜。）

（她的手停在半空。）

（她没有转。）

（她把音频保存到相册。加密。）

（**她自己扛**。）

（Ep8 起她做出的这个"独自扛"的选择，Ep9 再走了一步——**她不告诉夜，因为夜今晚已经在守，她不想给他加压**。）

（观众此时应该开始担心：**她一个人能扛多久？**）

镜头拉远。

书房里，夜坐在陆景深的椅子上。领口松开。眼睛盯着窗外的铁门。

一夜。

切黑。

**字幕：三个他，只许你知道。**

### 分析

价值弧：**沈星野主动交底 → 本尊二十年"摘出去"应激被她拆穿 → 夜首次以"排兵者"身份接管 → 她再次选择独自扛录音**。她的主动性 Ep9 到达 Act 1 的最高点。夜的形象在观众眼里第二次翻——他不是暴力，他是策略 + "看着"。

激活的 hamartia：
- **本尊**：他被沈星野正面拆穿了他二十年的应激反应——"把风险摘出去 = 我保护不了任何人"的深层封印。他刚要按袖扣，就切走了。**本尊自己没能力面对"我把她挂在家族战场上"这个事实**。夜接过来面对。
- **夜**：他第一次以**策略者**身份接管，不是暴力者。他跟沈星野讲路线、讲布防、讲"我看着"。他的形象 Ep7 是"懂公众场"，Ep9 是"懂战场"。观众此时应该开始意识到——**夜是三个人格里真正懂"活下去"的那一部分**。
- **沈星野**：她再次选择独自扛。Ep8 她不告诉本尊匿名短信；Ep9 她不告诉夜录音。她的"独自扛"到 Ep10-Ep20 会累积成一个心态债——**她一个人替三个人扛外部世界**。这个债 Ep26 她被夜误解站错边时会一次性爆发。

红旗 1：Switching Protocol 命中。**触发条件本集扩展**：触发 B 从"本尊自身童年语言复读"扩展到"沈星野被威胁 = 本尊'我保护不了任何人'语言复读"。这一秒观众要收到——**沈星野已经进入本尊的应激触发名单**。这个新扩展 Ep20 宴会失控 + Ep22 夜先动手时是核心机制。**本集用完 1 次全切换额度**。

红旗 2：**"你走哪里我看着"** ——夜第一次以"爱"的替代语言开口。他不承诺保护。他承诺不撒开视线。这四个字的重量比"我保护你"重——**他不敢承认爱，他只承认在场**。这一秒是夜 arc 的第一个情感锚点。Ep15 抽屉章节 + Ep20 宴会救场 + Ep22 夜先动手 + Ep28 夜要带她走 + Ep31 站到同一边 都会反复回到这四个字。

红旗 3：**领口松 + 袖扣压 = 本尊留下的痕迹 + 夜的痕迹并存**——本集视觉锁第一次演示"两个人格的物件差在同一个身体上同时可见"。**这是身体作为容器的第一次视觉表述**。Ep38 "我是我们"整合时，这个"多痕并存"要一次性收官——本尊会自己把领口松开一颗，同时不解袖扣，代表**接纳三者共存**。

红旗 4：**陆承岳的执行链**——盯梢的人自称"她敢不敢报警"。这一秒观众收到的信息是：**陆承岳线在测试沈星野的底线**。她不报警——因为报警就把陆家的丑闻推到警察局。她的策略是让盯梢的人转到更明处。**这个策略 Ep10 会促使陆承岳自己走到陆宅试探本尊**。

红旗 5：**沈星野第二次独自扛证据**（Ep8 短信 + Ep9 录音）。她的心态是——**她不想给夜和本尊加压**。她替他们扛。**但她不知道，她扛的每一个证据，都会在 Ep26 被误解为"她跟陆母/陆承岳同一边"的凭据**。红旗 2 的"看着"跟红旗 5 的"独自扛"要形成 Ep26 的核心误解——**他没看到她所有独自扛的地方**。

红旗 6：本集没有小小。Method 2 lock 严格执行——每集只出现 2 人格。本尊 + 夜。夜守到天亮，第二天本尊会通过 Pacing Rule 13 自然回归。

红旗 7：**沈星野"我在你家已经十天了"**——这句话是她 Ep9 拆本尊二十年应激的关键锤。她把"我进这家"的动作可视化 = 她已经不是外人。**这一句话在 Ep20 宴会失控前，会被本尊在酒会敬酒前默默回想一次**（Ep20 埋点）。
