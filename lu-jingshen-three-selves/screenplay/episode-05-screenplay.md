# Episode 05 — 怕黑的人

### 制作前置

**接续 Ep4**：当日夜里。一场夏末雷雨到达陆宅，备用电源短暂失灵——**这次不是陆母调虎离山，是真的环境事故**，触发 A 的自然形态。

**人格出场边界**：小小 → 夜。**1 次全切换**（小小→夜），本集**不回本尊**。这是全剧第一次同集内部人格间接力（不是本尊居中）。

**接力机制锁**：小小先在黑里被拽出。安抚到一半时，走廊外传来低吼式动静（保镖冲进来加大惊吓），小小的恐惧临界翻页——**恐惧翻到极致就外翻成攻击**。夜接管出来，第一动作是替小小挡门——**这是夜第一次不威胁沈星野**。

**夜的行为学新增点**：本集夜只做一件事——"把干扰源清出去"。他把保镖和佣人全部赶开。他不打人，但他站门口，谁都不敢进。**他不是护本尊，他是护小小**——这是夜和小小的关系第一次被观众看见。

**沈星野的方法论**：不追问创伤。她只做三件事——守灯、守门、守呼吸。她把"我在"变成可以一次次兑现的动作。

### 渐入:

**内景 陆宅长走廊 — 夜**

（Hook 3 秒：一声惊雷。整条走廊灯忽然全灭。）

黑。

一秒。

应急灯亮起一半。冷白。

（观众此时不知道谁在走廊里。听见——一个成年身体压抑的抽气声。）

**内景 陆宅长走廊 · 尽头凹间 — 夜**

沈星野拿着手电冲过来。

灯光扫过——

小小蹲在墙角。抱着膝盖。整个人在抖。

（袖扣完全松开。发绳挂在手腕。）

沈星野立刻放慢脚步。

（她不能扑上去。她见过 Ep3，冲得太快小小会更缩。）

她把手电放低，光斜着照墙，不照他脸。

**沈星野**（很轻）

小小。

**小小**

姐——姐——

（他的牙在打颤。）

**小小**

灯——灯灭了——门也——

沈星野走到他身边。慢。

她没碰他。

她把手电立在地上，光柱朝上，照亮一小片墙面。

**沈星野**

你看。有光。

**小小**

……

**沈星野**

你听我数。一。二。三。

（她自己数呼吸给他听。）

**沈星野**

一。二。三。灯会回来。

小小的呼吸开始跟着她走。

（很慢。）

（一寸一寸。）

远处——脚步声。

三四个人。硬底鞋。走得急。

（保镖 + 管家 + 佣人正冲过来查——是陆宅的应急预案。）

小小听见。

（他不知道这些是自家人。他只听见——**门外有人来了**。）

（他童年最深的记忆里，"门外的脚步声"就是那晚灯坏了以后没有来开门的那些脚步。）

他的呼吸整个乱掉。

（临界翻页。）

（呼吸从抖变成短促。眼底最后一层"孩子的等"退掉。）

（一秒。）

（血色从脸上升上来。）

（那只手——从抱膝盖变成撑地。）

（起身。）

沈星野看着他站起来。

（没有袖扣。领口松开了一寸。）

（不是小小了。是夜。）

夜看她一眼。

**夜**（低）

站我身后。

沈星野一顿。

（他没有威胁她。他在保护她。**这是夜第一次不冲她来**。）

她起身。退到他身后半步。

**内景 陆宅长走廊 · 通道口 — 夜**

保镖和管家冲进走廊。

夜站在凹间口。灯下。

他抬手。

**夜**

出去。

（一个字都不多。）

管家想开口——

**夜**

出去。

夜没抬声。但那个"出去"两个字压得整条走廊都低了半度。

保镖僵在原地。看管家。

管家一咬牙，转身。

**管家**

……都退到主楼。留一个值班。

一群人退走。

灯——啪，全部恢复。

明亮。

夜站在灯下。领口松着。手指还搭在门框上。

（他没看沈星野。他在守。）

沈星野的呼吸慢慢平下来。

（她第一次看见——夜的刀不是对着她的。夜的刀是对着"要靠近的人"的。**小小怕的东西，夜替他挡**。）

（她意识到——夜不是小小的对立面。夜是**小小恐惧外翻后的形态**。）

**沈星野**（很轻）

……谢谢。

夜没回头。

**夜**

别谢。

**夜**

他信你。你别让他等。

（他说的"他"是小小。）

（这是夜第一次替小小开口。）

沈星野的心停了半秒。

镜头拉远。

雨还在下。

夜站在灯下。手指扣在门框上。

切黑。

**字幕：三个他，只许你知道。**

### 分析

价值弧：**黑 → 小小翻页 → 夜接管 → 夜第一次替她挡人**。夜的形象在观众眼里第一次翻——他不是危险，他是恐惧外翻后的刀。她意识到：三个人格不是三个对立面，是同一个孩子在不同伤口上的三个反应。

激活的 hamartia：
- **小小**：他童年"关灯 + 门外脚步 + 没人开门"的复合创伤第一次以可见形式外显。他不会说，但他会抖。
- **夜**：他第一次不威胁沈星野，反而替小小挡门。他也第一次替小小开口——"他信你，你别让他等"。**观众此时应该开始怀疑：夜比本尊知道得多**。
- **沈星野**：她第一次学会**不追问创伤**。她只做"守灯守门守呼吸"三件事。她的方法论第三次进化：Ep1 目击 → Ep2 记录 → Ep3 承诺 → Ep5 **护住呼吸的节奏**。

红旗 1：Switching Protocol 命中。**这是全剧第一次同集内小小→夜的接力**（本尊不居中）。触发是"小小恐惧临界翻页"——恐惧翻到极致就外翻成攻击。三拍：呼吸从抖变短促 + 眼底"孩子的等"退掉 + 血色反涨 → 手撑地起身 → 领口松开 + 低声"站我身后"。**本集用完 1 次全切换额度**。

红旗 2：**夜第一次不威胁沈星野，甚至替她挡人**。他没看她。他只是站在门框上守。这是夜 arc 的第一次转向。Ep1 他把她按上墙威胁她；Ep5 他站她身后替她挡人。Act 2 他会开始不情愿地"用她"——先是训练她认人 (Ep11)，再是允许她冒险 (Ep9-10)。

红旗 3：**"他信你，你别让他等"**——夜第一次替小小开口。**这一秒把 characters.md "夜的知情结构"钩起来**：夜知道小小存在。他甚至替小小说话。观众此时收到关键信息：夜和小小是彼此认识的；只有本尊不知道他们。**Ep15 抽屉章节 + Ep27 封存病历时这个"知情不对称"要爆炸**。

红旗 4：**保镖和管家的"应急预案"暴露陆母系统**——陆宅长期备有专门应对"发作"的岗位。观众此时看见"陆家有一整套包起来处理陆景深异常的人手"。这套系统 Ep27 揭穿病历时会被沈星野拆穿：这不是护理，这是**长期封锁真相的工具**。

红旗 5：**夜说"出去"两个字压住整个应急队**——他的威慑力不来自嗓门。他的位置感、气场、目光就够。Ep11 起夜要开始进入"能被辨认的公开身份"，本集是他"权威感"的第一次亮相。

红旗 6：本集**不回本尊**。这打破了 Ep1-Ep4 每次都以本尊落尾的节奏——观众此时应该意识到：**本尊不是三个人的中心，是并列的一个**。这是叙事结构上的第一次真正翻页。
