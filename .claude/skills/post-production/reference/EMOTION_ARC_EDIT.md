# Emotion Arc Edit（蓄力 → 静默 → 爆发）

把平淡素材剪出电影级情绪感染力的**声画节奏模板**。  
灵感：**「别有幽愁暗恨生，此时无声胜有声」**（《琵琶行》）。

与 [SHOT_CONTINUITY.md](SHOT_CONTINUITY.md) 分工：组接管空间/切点；**本文件管情绪潮汐**。  
规划层可与 [DIRECTOR_BEATS.md](../../shotlist-builder/reference/DIRECTOR_BEATS.md) 的「屏息/得答案」对齐。  
配乐 drop 可与 `bgm-scoring` 联用。

来源：[absorption/AIGC-蓄力静默爆发剪辑吸收.md](absorption/AIGC-蓄力静默爆发剪辑吸收.md)。

---

## 底层三段

| 段 | 声 | 画 | 观众 |
|----|----|----|------|
| **1 蓄力** | 高噪音 / 快节奏音乐 / 环境嘈杂 | 全景、快切、热闹或压迫铺垫 | 紧张、被推着走 |
| **2 静默** | **抽掉几乎所有声音**（可留极弱底噪或 bass drop 一瞬） | 慢动作特写，拉长关键动作 | 期待拉满（无声胜有声） |
| **3 爆发** | 声音爆发（欢呼、撞击、音乐高潮、史诗鼓点） | 全景或特写，与声画高潮帧对齐 | 情绪释放 |

**阴影先行（登场变体）：** Boss/威胁真身前，先给阴影或压迫轮廓——压迫感先到，解释后到。与静默段可叠用。开场六维全表见 [VISUAL_LANGUAGE_SIX.md](../../shotlist-builder/reference/VISUAL_LANGUAGE_SIX.md)。

经典参照（只取结构）：《灌篮高手》末球长静默再进球；《奥本海默》核爆抽声再炸响；《玩具总动员3》开场停顿蓄 Boss。

## 公式 1 — 基础版（紧张 / 高潮）

```
全景（高噪音） + 特写（慢动作 + 静音） + 全景/特写（声音爆发）
```

| 阶段 | 做法 |
|------|------|
| 全景 | 高噪、偏快节奏，快速蓄力 |
| 特写 | 突然静音；关键动作慢放（可智能补帧）；可加短暂 bass drop / 低频呼吸感 |
| 爆发 | 欢呼/音乐高潮/重击与画面高光帧（进球、拔剑、阳光破云、反转脸）对齐 |

---

## 公式 2 — 进阶版（情感深度）

```
全景（高噪音） + 特写（慢动作+静音） + 一句话（重点） + 全景/特写（声音爆发）
```

在静默末或爆发前，插入 **一句核心独白/旁白**（短、可记），再进声音爆发。  
例（旅拍）：「那些在写字楼里想不通的事，风一吹就散了。」

漫剧/悬疑：独白改成一句关键对白或内心 OS，勿写成说明书。

## CapCut / 剪映操作（旅拍可复用）

1. **蓄力**  
   - 铺欢快摇滚或嘈杂环境 + 全景/快切。  
2. **静默入口**  
   - 在关键动作起点（发丝、出手、门将开）切开。  
   - 该段：**变速慢放**（如 0.3–0.5x）+ 智能补帧（若有）。  
   - **音乐轨静音或硬切掉**；可垫极短 bass drop / 低频 whoosh。  
3. **爆发**  
   - 接史诗或高潮乐；把 **music hit / 鼓点** 与阳光出现、进球、反转等画面帧对齐。  
4. **收尾（进阶）**  
   - 独白可放在静默末（纯净）或爆发初（被音乐托住）——二选一，勿两头都喊。

参数经验：

| 项 | 建议 |
|----|------|
| 静默段 | 剧情短片常 1–4s；高潮戏可更长（参考电影级「长静默」） |
| 慢放 | 以看清微表情/布料/发丝为准，勿拖成无聊 |
| 爆发对齐 | 误差尽量 ≤1–2 帧体感 |
| 与强音断奏 | 爆发前音乐切断可参考 sound-design「强音断奏」 |

## 生成前（Seedance）可选预埋

若已知要用本弧，在分镜标注：

```
【情绪弧】蓄力→静默→爆发
蓄力：全景嘈杂/快切
静默：特写慢动作关键帧——[动作]；后期抽声
爆发：对齐[事件]；史诗乐/重击
```

静默段生成时仍可带环境声，**后期再抽**；或生成时写「近乎无声，只留风声极弱」减少清理。

## IP 速配

| 类型 | 用法 |
|------|------|
| 悬疑 | 静默放大「要揭穿」；爆发对齐反转/人影 |
| 古风情感 | 静默咬住眼神/袖口；爆发对齐音乐或一声哭腔 |
| 武打 | 蓄力对峙嘈杂→静默出招前一秒→爆发兵器交击 |
| 科普 | 蓄力问题堆叠→静默「答案将现」→爆发可视化揭晓 |
| 旅拍/Vlog | 教程原版四步 |
| AI 漫剧 | 单集高潮点用 1 次即可，勿段段静默导致麻木 |

---

## 避坑

1. 静默过长且画面无信息 → 观众无聊，不是高级。  
2. 静默时仍留大声音乐 → 「无声」失效。  
3. 爆发不对齐画面事件 → 廉价卡点感。  
4. 进阶独白太长 → 冲掉爆发。  
5. 与两极景别联用时：静默宜特写，爆发可两极跳一次（见分镜规范），勿连跳。
