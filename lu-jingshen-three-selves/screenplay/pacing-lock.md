# Pacing Lock — 三个他，只许你知道

## Format
- Aspect: 9:16 vertical
- Episode length: 60–90s
- Episode count target: 40

## Hard rules
1. First 3 seconds: switch OR conflict line OR threat object
2. Every 8–15s: info gain or mini-reversal
3. Episode end: open hook (no tidy HE until series finale)
4. Core dialogue ≤ 6 lines per episode
5. Reality casting: adult male body only for 陆景深/夜/小小
6. Alter tells: 袖扣整齐=本尊；领口松开/烟=夜；发绳+捏衣角=小小
7. Villain lock: 陆母 = childhood perpetrator; 叔伯 = inheritance rival only
8. 小小 gender lock: girl alter because 陆母 stigmatized fear as “像女孩”; not a boy alter, not random casting flavor
9. Alter switch trigger lock: 每次切换必须命中「黑暗/密闭环境」或「童年创伤重演事件」之一；详见下方 Switching Protocol。

## Switching Protocol

### 允许的触发（二选一，缺一不可）

**A. 黑暗 / 密闭环境**
- 停电、灯灭、走廊/储藏室独处、关门声、狭小车内、夜雨阴影、密闭电梯
- 首选触发：小小

**B. 童年创伤重演事件**
- 陆母式羞辱话术：「体面一点」/「不像样」/「哭什么」/「像个女孩」
- 抛弃信号：脚步走远、门被锁、承诺来的人没来、被独自留下
- 创伤物件在场：兔子夜灯、旧发绳、旧儿童房物件、封存处置单
- 秘密即将被撞破、面具即将失守（威胁到「再一次被害 / 被丢」的感觉）
- 首选触发：小小（重演受害面）或 夜（重演「有人要伤害我们」的一面）

### 禁止

- 无触发切换
- 单一场景内 A→B→A 往返切换
- 一集切换次数 > 3 次（目标 ≤ 2 次）
- 快速跳脸——必须走过渡三拍

### 过渡三拍（可拍可听）

1. 微症：呼吸变、瞳孔散、指节顿一下
2. 道具动：袖扣被压 / 领口松 / 发绳被摸 / 手滑向火机
3. 新人格接管：站姿、语气、称呼一起变

### 半浮现（不算切换，一集 ≤ 1 次）

只在镜面、玻璃倒影或一秒眼神里露另一个人格，本体身份仍在。用于集末钩或情感回响，不占「≤ 2 次切换」的额度。

### 睡眠后自然回归本尊（协议下的第二类回归）

任意非本尊人格进入睡眠后，次日自然回归本尊。视为**时间压缩隐含切换**，不做 visible 三拍，只用剪辑标签（雨声转晨光 / 长镜头黑到亮 / 音效反差）暗示时间跳跃。

- 仍占用「≤ 2 次切换」额度（本尊接管后要能被观众识别归位）
- 本尊醒来无记忆，只能通过身体上留下的物证（袖口的发绳、口袋的烟头、松开的袖扣、莫名的位置）感知"发作过"
- 本尊对物证的反应决定他的自知阶段：Act 1 归"发作"、Act 2 开始困惑、Act 3 承认"这不是我做的"、Act 4 承认"这是另一个我做的"

**Rule 13 双向扩展（Ep10 起生效）**

Rule 13 起初只允许"其他人格 → 本尊"方向。Ep10 起扩展为**双向**：

- 本尊入夜精神耗尽 → 其他人格自然浮出（不走三拍，用剪辑 + 灯自灭 + 呼吸放慢暗示）
- 触发条件：本尊白日承受了重大情感冲击（如 Ep10 陆承岳试探、Ep20 敬酒逼婚、Ep29 递统一口径），入夜后失去意识屏障
- 通常"接管"方是**这一天陪伴需求最强的一人格**：小小陪安、夜守夜、本尊晨起
- 仍占用「≤ 2 次切换」额度

### 夜的主动退回机制（Ep7 起演示，Ep10 定型）

夜可以在**局势稳定后主动让位给本尊**。三拍反向：血色褪 + 呼吸平 → 抬手扣领口 → 袖扣压紧 → 本尊回来。

- 不需要外部触发
- 是夜的主动判断"这里不需要我了"
- 本尊醒来同样无记忆，只知道自己"走神了半分钟"
- 仅夜有此机制，小小无——小小要通过睡眠或本尊被外部呼唤回归

### 三人格同集 lock

- 全剧允许三人格同集出现，但**必须通过合法机制**（切换 + Rule 13 + Rule 13 双向）
- 一集内**最多 2 次全切换**——三人格同集 ≠ 三次切换
- Ep10 首次演示（1 切换 + 1 主动退回 + 1 Rule 13 反向）
- Ep20、Ep29、Ep38 是全剧其他三人格同集时机

## 沈星野"独自扛"心态债 lock

Ep8 起沈星野开始独自替本尊 + 夜 + 小小过滤外部压力（匿名短信、盯梢录音、陆承岳对话）。

- 累积节奏：每 Act 最多爆一次
- Ep10 她自己意识到"这就是陆母做过的事" → 划下心态锁"只能撑一段时间"
- Ep26 她被夜误解站错边时，"独自扛"心态债一次性爆发——她无法当场解释所有独自扛的证据
- Ep29 董事会前她把所有独扛证据一次交出——债还清

**这个心态债是她 Act 2-Act 3 走向的核心动力。任何后续集不能把"沈星野告诉他"当作默认动作——她的默认是"独自扛"。**

### 场景冷却

- 一次切换后 ≥ 8 秒不再切
- 公开权力场景（董事会 / 记者会 / 联姻场合）：本尊用体感强锁——袖扣被按发白、指甲入掌、深呼吸——延迟切换，直到场景结束或触发升级为 A 或 B

## Usage note
This lock applies to every later screenplay file in the project. Any future scene, treatment, or episode draft must keep the 3-second hook, 8–15 second information cadence, and open-hook ending.
