## 项目决策锁定

| 项 | 决策 | 理由 |
| --- | --- | --- |
| 参赛信息 | B 站 AI 启蒙动画创作大赛 | 目标时长 > 90 秒 |
| 目标受众 | 3-6 岁幼儿园儿童 | 家长/幼儿园教育场景使用 |
| 视频形式 | **单集 100 秒**（10 节拍 / 25 镜头） | 满足大赛 >90 秒要求，同时保留幼儿注意力节奏 |
| 视觉风格 | 3D 皮克斯风（角色圆润 Q 版，糖果色系） | 情感代入强、细菌拟人不恐怖、质感高 |
| 画面比例 | 16:9 横屏 | B 站主投放，家庭电视友好 |
| 语言 | 简体中文简单短句 + 拟声词 + 少量汉字字幕 | 3-6 岁大多不识字，需口播为主 |
| 叙事结构 | **"一天时间循环"**：偷懒不刷 → 夜里受苦 → 早上后悔 → 学会刷牙 → 升华 → 邀请你 | 因果闭环最强，行为改变驱动力最大 |
| 关键科普点 | 正确刷牙**三步法**（上下刷 + 里外刷 + 每颗都要）| 大赛评委喜欢的实用知识 |
| 结尾手法 | **打破第四堵墙**（主角对镜头邀请小朋友一起刷） | 幼儿动画经典手法，直接提升行为转化 |

## 科普设计原则（来自 `science-explainer` 技能）

1. **一段一个知识点** — 每 8-12 秒讲清一件事，不贪多
2. **Show 不 Lecture** — 抽象概念（细菌、酸蚀、菌斑）必须视觉化拟人化
3. **尺度跳跃是节奏引擎** — 客厅 ↔ 卧室 ↔ 口腔显微 ↔ 卫生间 交替，视觉不疲劳
4. **Hook 用反差** — 开场用"生日狂欢 → 偷懒埋雷"制造悬念
5. **因果闭环是核心** — "不刷牙 → 真的痛 → 学会刷 → 恢复笑容"完整走一遍，比任何说教都强
6. **数据是视觉的，不是听觉的** — 关键指令（三步法、2分钟、早晚各一次）用字幕+图标+沙漏三重视觉呈现
7. **收尾用升华 + 打破第四堵墙** — 从"打败细菌"升华到"闪亮笑容"，然后主角对镜头邀请小朋友一起刷

## 立项声明

本片不是恐吓片，也不是说教片。它借鉴皮克斯的方式，把"细菌 vs 牙刷"变成一场 100 秒的完整成长小剧——**小朋友看到"糖糖犯了错、受了苦、然后学会了正确做法"**，比任何家长的唠叨都更能推动行为改变。

结尾一句"你也要早晚刷牙哦"，是给屏幕前每一个小朋友的邀请函。
