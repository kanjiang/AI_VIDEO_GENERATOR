# Manga Shot Pack（AI 漫剧 50 组运镜配方）

场景化运镜，可直接写入 Seedance `【电影化动态描述】` / `机位：`。  
与 [CAMERA_LEXICON.md](CAMERA_LEXICON.md) 关系：词库 = 通用术语；**本包 = 带情节动作的完整镜方**。

**组合模板：** `人物设定 +【表情】+【运镜配方名或全文】+ 光影画质 + 负面词`  
表情库：[MICRO_EXPRESSION_LIBRARY.md](MICRO_EXPRESSION_LIBRARY.md) · 本文件末「表情 50」

来源：[absorption/AIGC-漫剧生产素材包吸收.md](absorption/AIGC-漫剧生产素材包吸收.md)

---

## 硬规则

1. 单镜 **1 个主运镜配方**（可加轻手持）；勿叠 2 个复杂运动。  
2. **一句对白 ↔ 一组【表情+运镜】**，长戏分段生成。  
3. 转场类（39–50）放在**两段衔接**；后期加音效/声桥。  
4. 动作镜（27–38）必须配表情，禁「拳脚狠、脸木」。  
5. 占位/轴线仍遵守 [分镜规范.md](分镜规范.md)。

---

## Prompt 套用示例

```
年轻女生，温柔破防，眼眶微湿，克制的笑容慢慢松开，
【呼吸推进镜：从胸口缓慢推至眼部，背景持续虚化】，
柔和侧逆光，电影质感，面部肌肉自然联动，五官稳定，自然真人肌理。
```

负面：`面部扭曲、五官错位、眼球畸形、表情僵硬、画面闪烁、过度磨皮`
