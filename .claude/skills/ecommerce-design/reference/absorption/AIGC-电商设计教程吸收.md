# AIGC 电商设计教程吸收说明

来源：AI 电商设计全流程保姆级教程（Lovart「专属 AI 设计师 Skill」思路整理）

本文记录取舍，以及已落到本仓库 skill 的映射。与漫剧制作、INS 贴纸配方无关——本线是**电商静帧全案**（精修 → 主视觉 → 主图 → 详情页）。

---

## 1. 总判断

| 维度 | 教程强项 | 本仓库现状 | 决策 |
|------|----------|------------|------|
| 先分析再生成 | 产品拆解 → 视觉方向 | 易直接出图 | **吸收** |
| 全损照片精修 / 三视图 | 一致性底座 | 无电商专用流程 | **吸收** |
| 主视觉延展整套物料 | 一套风格多尺寸 | 无 | **吸收** |
| 主图 vs 营销海报分工 | 卖点传递 vs 氛围 | 无 | **吸收** |
| 详情页卖点可视化 | 不堆文字、分屏结构 | 无 | **吸收** |
| Lovart 平台操作 | 工具绑定 | 本仓库工具无关 | **不绑平台**，抽象为流程 |
| 「训练专属 Skill」 | 经验复用 | 即本 skill 本身 | **用本 skill 承接**，不另造聊天套壳 |

一句话：教程教「不会设计也能出电商全案」；本仓库沉淀为可复用的 **ecommerce-design** 工作流，与 `product-video`（宣传片）并列、不合并。

---

## 2. 不吸收

- Lovart 专属按钮/界面操作说明
- 「一键得到全部方案」营销承诺（仍按阶段确认）
- 与本仓库电影写实 prompt 体系混用（电商主图默认商业静帧逻辑）

---

---

## 4. 流水线

```
产品资料+照片
  → Brief / 视觉方向（禁直接「做张高级海报」）
  → 精修图 + 三视图（一致性底座）
  → 一张主视觉
  → 延展：模特套图 / 多尺寸海报 / 样机
  → 电商主图套装（卖点导向）
  → 详情页分屏（卖点画出来）
  →（可选）PSD 分层交付说明 / 电商短视频交 product-video
```
