# 角色身份板提示词 — 《Kiki, Ready Set Go!》

四个固定角色的 16:9 身份板生成提示词。全部**纯白 / 米白背景**、**艺术书非对称布局**、**多角度全车身严格锁定身份**。

**共通视觉锚：**
- 整体风格 = Pixar《Cars》系列 3D + Q 版比例（车身长宽比 ≈ 1:1，头灯做眼睛，前脸做嘴巴）
- 灯光 = 柔和棚拍光，无强阴影，无环境反射
- 材质 = 高质感烤漆，金属件微反光，橡胶件哑光
- 每张板必须包含：主英雄视角（正 3/4 全车身）+ 辅助研究（正侧、正前脸部特写、后 3/4、俯视 / 三视图缩略）+ 表情条 + 剪影研究 + 简约角色 ID 卡

**共通负面约束：**
不要人类角色，不要背景环境，不要广告海报感，不要车展摆拍感，不要网格 / 蓝图目录布局，不要重叠不同视角，不要裁掉车轮 / 前脸，不要让不同视角失去身份一致性。

## 1. Rosie · 红色伦敦双层小巴士（**本项目全新角色**）

**Rosie 角色身份板提示：**

创建一张艺术性的 16:9 角色身份板。

[主体]：一辆 Q 版拟人化的迷你伦敦双层小巴士，名叫 Rosie。她是《Kiki, Ready Set Go!》系列的英文教学角色，一位温柔又热心的本地导游。

[车身设计]：经典邮筒红色车漆，光泽感烤漆质感；白色车顶；金色装饰条围绕车窗一圈；下层车身正面金色手写字母招牌"ROSIE"。车身比例为 Q 版短胖版（长宽比约 1.2:1，只有一辆普通巴士高度的 60%）。四个圆胖轮胎，黑色橡胶配白色轮毂。

[脸部设计]：车头两颗圆形前灯做眼睛，虹膜为独特的翠绿色（本剧唯一绿眼睛角色），瞳孔中等大小，可放大缩小做表情。前保险杠向上弯成永久性温柔微笑弧形。车头正中金色小徽章。

[标志道具]：二层车顶上有一块可翻转的白色告示牌，本次身份板上告示牌翻到显示 "GAS STATION" 字样，字体为可爱手写体。告示牌本身是角色标志性道具，必须清晰可见但不可占画面 C 位。

[背景]：纯白色背景，无环境、无道具、无标志、无水印。

[设计方向]：不要创建标准的车展摆拍图。创建一张感觉像 Pixar 前期开发部艺术书的角色身份板。布局不对称、优雅、大片留白，多种视角尺寸交错。避免网格布局、蓝图三视图目录、宣传海报构图。

[重要布局规则]：不要重叠任何车身视角。每个视角必须清晰分离、有呼吸空间。所有车身研究、剪影和细节区必须视觉区分。禁止裁切车头 / 车尾 / 车轮。禁止用局部特写替代完整车身视角。

[主要构图]：放置一个大型英雄视角作为视觉锚点——正 3/4 全车身（车头微微偏向观众，能同时看到前脸、右侧车身和右侧后轮），略微偏离画面中心。围绕它以干净间距排列较小的辅助研究：
- 正侧全车身（右侧或左侧，展示双层结构和车顶告示牌）
- 后 3/4 全车身（看到车尾灯和二层顶）
- 正前脸部特写（放大展示绿眼睛、微笑弧形嘴、金色徽章、车顶告示牌）
- 俯视缩略（车顶告示牌和整体轮廓）
- 一个轻微行驶前倾姿势（展示"介绍教学"时的招牌姿态：车头略前伸）

⚠️ 所有车身视角必须完整可见（前保险杠到后保险杠、车顶到车轮底），禁止半截 / 局部裁切。

[身份锁定]：所有视角保持严格一致——同款邮筒红烤漆、同款绿眼虹膜、同款金色 ROSIE 招牌位置、同款白色车顶告示牌、同款 Q 版比例、同款温柔微笑弧形嘴。

[艺术性区域]：
- 剪影研究区：3 个纯黑色 Rosie 车身剪影，展示轮廓清晰度
- 表情研究区：5 个正前脸小图，情绪分别为温柔、鼓励、微笑教学、惊喜、慢速讲解（眼睛半闭）
- 细节研究区：车头徽章特写、告示牌可翻转机制说明、车轮花纹、金色字母字体特写

[角色 ID 块]：简约、大胆、艺术导向的手写风格标签。仅使用以下字段：
- Name: ROSIE
- Role: English Town Guide / 英文小镇导游
- Voice: Warm British RP / 温柔英式
- Signature: "Oh love, let me show you!"
- Palette: 邮筒红 + 金 + 白 + 翠绿

[风格]：简约、电影感、Pixar 高端艺术书感、干净、富有表现力、适用于制作。

[最终目标]：图像应能帮助 AI 后续在任何角度、任何情绪下重现 Rosie 的身份一致性，包括绿眼睛虹膜、金色 ROSIE 招牌、双层结构和永久微笑弧形嘴。

## 2. Kiki · 亮橙红小摩托车（母世界 + 新增 K 字贴纸）

**Kiki 角色身份板提示：**

创建一张艺术性的 16:9 角色身份板。

[主体]：一辆 Q 版拟人化的小型运动摩托车，名叫 Kiki。她/他（中性）是《Kiki, Ready Set Go!》主角，一位敢开口、爱抢话、精力过剩的英语启蒙学习者。

[车身设计]：亮橙红色主色车漆（明亮饱和度 90% 以上），白色装饰条从油箱延伸到座椅后侧，银色高亮排气管。Q 版超短胖比例（车身长宽比约 1:1，油箱圆胖如南瓜），两个圆胖轮胎，黑色橡胶配银色辐条。

[脸部设计]：挡风罩下方两颗圆形前灯做眼睛，虹膜为金黄色，瞳孔可以放大缩小做惊讶 / 兴奋 / 得意等表情。挡风罩下缘的黑色橡胶做成"嘴"，可上扬 / 下撇 / 张成 O 型。

[标志道具]：车头正面油箱下方贴一张**红色手绘 K 字贴纸**（本项目专属识别标志，母世界没有）。贴纸边缘有轻微不规则手撕感，颜色是明亮的番茄红。K 字贴纸必须在正 3/4 和正前视角清晰可见。

[背景]：纯白色背景，无环境、无道具、无标志、无水印。

[设计方向]：Pixar 前期开发部艺术书感，非对称优雅布局，大留白，多视角尺寸交错。避免网格 / 蓝图 / 海报构图。

[重要布局规则]：不重叠、清晰分离、有呼吸空间。禁止裁切车头 / 车尾 / 车轮。禁止用局部特写替代完整车身视角。

[主要构图]：
- 大型英雄视角：正 3/4 全车身，前倾冲刺姿态（暗示"我先冲"性格），略偏画面中心
- 辅助研究：正侧全车身、后 3/4 全车身、正前脸部特写（放大 K 字贴纸、金眼、O 型嘴）、俯视缩略、一个"腾空一格"的小跳姿势（Q 版可爱夸张）

⚠️ 所有车身视角必须完整可见。

[身份锁定]：所有视角保持严格一致——同款亮橙红烤漆、同款金黄虹膜、同款红色手绘 K 字贴纸位置和风格、同款 Q 版超短胖比例、同款上翘银色排气管。

[艺术性区域]：
- 剪影研究区：3 个纯黑色 Kiki 剪影，展示前倾冲刺 / 直立 / 跳跃三种能量姿态
- 表情研究区：6 个正前脸小图，情绪分别为兴奋（眼睛巨大瞳孔炸开）、得意（嘴角上扬双眼半闭）、假装没事（回避视线）、专注模仿（嘴 O 型）、惊讶（眼睛铜铃）、哭笑不得（嘴弯八字）
- 细节研究区：K 字贴纸特写、排气管字母云喷出示意（几个立体英文字母从排气管飘出）、金眼虹膜纹路

[角色 ID 块]：
- Name: KIKI
- Role: Main Student / 主学员
- Voice: High energetic boy-ish / 高亢少年声
- Signature: "Ready, set, GO!"
- Palette: 亮橙红 + 白 + 银 + 番茄红 K + 金黄眼

[风格]：Pixar 高端艺术书、干净、动能感强、适用于制作。

[最终目标]：图像应帮助 AI 后续在任何角度稳定重现 Kiki 的橙红车身、K 字贴纸、金黄眼虹膜和前倾冲刺能量。

## 3. Momo · 淡蓝色迷你两厢小车（母世界原型 + 后视镜挂件）

**Momo 角色身份板提示：**

创建一张艺术性的 16:9 角色身份板。

[主体]：一辆 Q 版拟人化的迷你两厢小车，名叫 Momo。她/他（中性）是《Kiki, Ready Set Go!》第二主角，一位害羞、慢热、想说但不敢说的英语启蒙陪跑角色。

[车身设计]：淡天蓝色主色车漆（哑光低饱和度，柔和），白色车顶延伸到 A 柱，米黄色内饰从车窗玻璃透出。Q 版短胖比例（车身长宽比约 1.15:1），四个圆胖轮胎，黑色橡胶配白色轮毂。

[主要构图]：

[身份锁定]：所有视角保持严格一致——同款淡天蓝哑光车漆、同款浅褐色大瞳孔、同款下弯保险杠嘴、同款后视镜褪色照片挂件、同款 Q 版短胖比例。

[艺术性区域]：

- Voice: Gentle boy child / 稚嫩男童
- Signature: "...you did it, Kiki."

[风格]：Pixar 高端艺术书、干净、温柔感强、适用于制作。

⚠️ 所有车身视角必须完整可见，尤其是车厢黑板必须在多个视角清晰可读。

## 6. Bubbles · 天蓝色洗车小拖车（Ep 02 客串 NPC）

**Bubbles 角色身份板提示：**

创建一张艺术性的 16:9 角色身份板。

[主体]：一辆 Q 版拟人化的小型洗车服务拖车，名叫 Bubbles。他是《Kiki, Ready Set Go!》Ep 02 洗车房的服务车，一位爱笑爱嘻哈的少年男声澳洲口音角色。

[车身设计]：天蓝色主色车漆（清爽饱和），Q 版短胖比例（车身长宽比约 1.15:1，比普通拖车更圆润）。车身**永久性覆盖一层薄薄的白色洗车泡沫**（像穿了一件蓬松的泡泡外套），泡沫堆积在车顶、引擎盖、后厢，随处可见细小气泡。车头有小型拖钩，后厢有一根卷曲的高压水管。四个圆胖轮胎，橡胶湿润带水珠。

[脸部设计]：车头两颗圆形前灯做眼睛，虹膜为**明亮的天青蓝色**（比车身颜色更饱和），瞳孔中等大小，眼神灵动活泼。前保险杠向上弯成灿烂大笑弧形（比 Rosie 的微笑更夸张、更开），能看到"牙齿"（下保险杠缝隙露出的白色格栅像少年门牙）。

[标志道具]：车顶戴一顶用泡沫堆成的"泡泡帽"，随时可能滑落但一直保持；车身左侧挂一个**海豚形状的软管喷头**（青蓝色橡胶，海豚嘴巴当喷口），用于喷泡沫；车头贴一个手写"BUBBLES"字样贴纸，字体是儿童蜡笔风格。

[背景]：纯白色背景，无环境、无道具、无标志、无水印。

[设计方向 / 布局规则]：同前规范，纯白背景 + 艺术书非对称布局 + 多角度全车身。

[主要构图]：
- 大型英雄视角：正 3/4 全车身，前倾嬉皮笑姿态（Q 版超可爱），略偏画面中心
- 辅助研究：正侧全车身（展示海豚喷头 + 泡泡帽）、后 3/4 全车身（展示水管卷曲）、正前脸部特写（大笑弧嘴 + 天青蓝眼 + 泡泡帽）、俯视缩略、一个"甩头抖水"的动感姿势

⚠️ 所有车身视角必须完整可见，泡沫覆盖必须一致。

[身份锁定]：所有视角保持严格一致——同款天蓝车漆、同款白色泡沫外套、同款天青蓝眼、同款大笑弧嘴、同款海豚软管喷头、同款泡泡帽、同款 BUBBLES 蜡笔字贴纸。

[艺术性区域]：
- 剪影研究区：3 个纯黑色 Bubbles 剪影，展示泡泡帽 + 海豚喷头轮廓识别度
- 表情研究区：5 个正前脸小图，情绪分别为灿烂大笑、惊讶、憋笑、竖大拇指式满意、按按钮式期待
- 细节研究区：海豚喷头特写、泡泡帽结构、水珠动态、BUBBLES 蜡笔字体

[角色 ID 块]：
- Name: BUBBLES
- Role: Car Wash Attendant / 洗车房小助手
- Voice: Cheerful Australian teen boy
- Signature: "One wash, mate!"
- Palette: 天蓝 + 白泡沫 + 天青眼 + 蜡笔字
