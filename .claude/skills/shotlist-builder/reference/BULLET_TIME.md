# 子弹时间（Bullet Time）通用提示词

**定义：** 在动作冲击峰值瞬间**时间冻结**，主体定格，悬浮物悬停；摄影机以主体为圆心做平滑 **360° 环绕**（高速摄影机阵列感）。

与仓库内两种写法分工：

| 类型 | 用途 | 文档 |
|------|------|------|
| **完整冻结环绕**（本文） | 英雄高光、漂移、爆炸、抛牌等特效秀 | 本文件 |
| **短插慢放**（1–2s） | 格斗着弹点，不环绕 | [SPATIAL_BLOCKING.md](SPATIAL_BLOCKING.md) Combat · Bullet time insert |
| **常速 360° 环绕** | 主体仍在动，只环拍环境 | [CAMERA_EMOTION.md](CAMERA_EMOTION.md) §8.5 |

来源：[absorption/AIGC-子弹时间模板吸收.md](absorption/AIGC-子弹时间模板吸收.md)

---

## 1. 可套用核心结构

```
【主体】正在【具体动作】，在动作达到最强冲击力的一瞬间，画面进入子弹时间（Bullet Time），时间瞬间冻结。
摄影机以主体为画面中心，进行平滑、稳定的360度环绕运镜，全程保持主体清晰突出，呈现真实高速摄影机阵列拍摄效果。
主体的动作完全定格，周围的【悬浮元素】全部悬浮在空中，保持真实自然的飞散状态。
【后续动作（解冻后，可选）】。场景为【场景环境】，电影级灯光，体积光，自然电影调色。
```

【规格】里写时长/画幅/HDR/分辨率（如 8K），正文少堆「真实8K质感」咒语（与 STYLE_BLOCK 一致）。

## 2. 替换槽

| 槽 | 示例 |
|----|------|
| 主体 | 男子、忍者、特工、女孩、魔术师、黑色超级跑车 |
| 具体动作 | 爆炸前回头、躲飞镖、侧身躲子弹、撑伞入暴雨、扑克牌抛向空中、高速过弯漂移 |
| 悬浮元素 | 玻璃碎片、雨滴、水花、文件、纸张、扑克牌、花瓣、羽毛、树叶、雪花、沙粒、尘土、轮胎浓烟、碎石、火星 |
| 后续动作 | 爆炸吞没画面、紧急刹停、雨滴重新落下、甩尾冲出弯道 |
| 场景 | 城市十字路口、金融街、地铁大厅、废弃工厂、盘山公路、复古赌场 |

**悬浮元素规则：** 必须写清**材质 + 飞散姿态**（旋转、交错、拖尾），禁止只写「特效粒子」。

## 3. 完整示例

### 魔术师抛牌

```
一名身穿黑色西装的魔术师正在将一副扑克牌猛地抛向空中，就在扑克牌从手中高速散开、彼此交错飞舞的瞬间，画面进入子弹时间（Bullet Time），时间瞬间冻结。
摄影机以主体为画面中心，进行平滑、稳定的360度环绕运镜，全程保持主体清晰突出，呈现真实高速摄影机阵列拍摄效果。
主体的动作完全定格，周围的52张高速旋转、翻飞、交错穿插的扑克牌以及空气中细小灰尘全部悬浮在空中，保持自然真实的飞散状态。
场景为复古赌场大厅，电影级灯光，体积光，自然电影调色。
```

### 跑车漂移

```
一辆黑色超级跑车正在高速过弯漂移，在动作达到最强冲击力的一瞬间，画面进入子弹时间（Bullet Time），时间瞬间冻结。
摄影机以主体为画面中心，进行平滑、稳定的360度环绕运镜，全程保持主体清晰突出，呈现真实高速摄影机阵列拍摄效果。
主体的动作完全定格，周围的轮胎扬起的浓烟、飞溅的碎石、火星、尘土全部悬浮在空中，保持漂移发生瞬间的真实物理形态。
解冻后赛车甩尾冲出弯道。场景为黄昏盘山公路，电影级灯光，体积光，自然电影调色。
```

## 4. 负面约束（建议粘贴）

```
禁主体在环绕过程中继续大幅动作（冻结期内须定格）；禁悬浮物糊成一片光斑；
禁环绕抖动/手持乱晃（须稳定器/阵列感匀速）；禁换脸换车型；禁背景建筑在环绕中拓扑乱变。
```

挂载：人物/车辆身份板 + 场景板；环绕半径与起始方位可按 CAMERA_EMOTION §8.5 补一句。
