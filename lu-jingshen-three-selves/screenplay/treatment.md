# Treatment — 三个他，只许你知道

格式：每集 3–5 句叙述，无大段对白。标注：钩子类型 / 出场人格 / 集末钩。

## 幕 1｜威胁同居（Ep1–10）

### Ep1｜她看见了
- 钩子类型：人格切换 + 危险物件
- 出场人格：小小 / 夜 / 本尊

夜雨天台上，成年身体的陆景深歪戴发绳、捏着衣角，像被困住的小小一样怯生生等人；下一秒，同一具身体已经领口松开，夜掐灭烟，确认沈星野已经看到了不该看的东西。闪回医院走廊，沈星野原本只是在会议间外补送病历，却撞见本尊的冷静外壳在关门后瞬间裂开，夜把她抵到墙边，用她的实习和前途逼她闭嘴。她明明在发抖，却抓住了唯一能让夜停手的软肋，指出小小怕黑、而且只会信她。夜当晚就把人和行李一起送进陆宅，本尊却在客厅冷脸质问“谁允许你住进来的”，镜子里又一闪而过那双属于小小的怯眼。
- 集末钩：镜子里的怯意到底是谁在求她别走？

### Ep2｜第一夜规矩
- 钩子类型：冲突句 + 同居失控
- 出场人格：本尊 / 小小

沈星野刚在客房落脚，本尊就把“只准待在分内位置”的规矩一条条摆到她面前，像要把昨夜的失控彻底抹掉。可夜里一停电，同一具成年身体又抱着枕头站到她门口，小小攥着发绳不肯回房，只肯确认灯会不会再灭、她会不会走。沈星野第一次看见，所谓“入住监护”不是她单方面被看管，而是这个家里有人比她更怕被丢下。第二天早上本尊恢复如常，却否认自己来过她门前，还把她手边那根发绳看成新的把柄。
- 集末钩：本尊究竟是真的不知道，还是更怕承认小小昨晚出来过？

### Ep3｜留下的条件
- 钩子类型：危险物件 + 契约绑定
- 出场人格：夜 / 本尊

沈星野试图把入住改成白天观察、晚上离开，夜却当着她的面把保密协议和打火机一起推过来，明确告诉她，这里没有“看完就走”的选项。她不肯只做被威胁的囚徒，反过来开出自己的条件：她留下可以，但她要看见所有预警信号，不能再让小小独自熬过每一次切换。白天回来的本尊听见这套安排，像是在听别人替他决定病情和生活，语气冷得近乎羞辱，却没有真正把她赶出门。沈星野由此确认，真正让入住成立的不是陆家的体面，而是三个他都已经离不开有人在场。
- 集末钩：本尊默认她留下，到底是为了体面，还是因为夜已经先替他求了救？

### Ep4｜陆夫人的电话
- 钩子类型：上位者施压
- 出场人格：本尊 / 小小

陆母第一次直接介入时没有提高音量，只是一通电话就把“关心”说成裁决，提醒沈星野别把临时照看误认成能进陆家的资格。她同时向本尊施压，要求尽快恢复正常作息、减少外人接触，还轻描淡写地提起与宋晚棠重修旧好的安排。电话那头温柔得体，电话这头的陆景深却明显绷紧到近乎窒息，连袖扣都被按得发白。等他挂断电话再回头时，眼底已经换成小小的惶然，小小只问了一句：如果她妈妈不喜欢姐姐，姐姐是不是也会被赶走。
- 集末钩：陆母口中的“体面安排”，会不会先拿沈星野开刀？

### Ep5｜怕黑的人
- 钩子类型：环境危机 + 情感黏连
- 出场人格：小小 / 夜

一场突发雷雨让陆宅备用电源短暂失灵，长走廊陷进半明半暗，小小立刻在成年身体里缩成一团，连门都不敢一个人关上。沈星野没有追问创伤，只先守住灯、门和呼吸，把“我在”变成可以一次次兑现的动作。夜在她身后短暂接管，像是本能地想把所有佣人和保镖都赶开，却第一次没有把威胁先丢给她，而是站在门边替小小挡住黑暗。等灯重新亮起，沈星野已经明白，夜不是小小的对立面，他是小小所有恐惧外翻后的刀。
- 集末钩：夜为什么会在她安抚小小时，突然松了第一寸防备？

### Ep6｜本尊的否认
- 钩子类型：身份反差 + 情绪误伤
- 出场人格：本尊 / 小小

第二天本尊恢复成无懈可击的陆总，把昨夜一切都归类成“发作”，连沈星野的安抚都被他定义为职业越界。沈星野第一次正面顶回去，指出他不是在控制局面，而是在把最害怕的那部分自己继续锁回黑里。本尊嘴上依旧否认需要她，身体却没有拒绝她为他记录切换前的呼吸、动作和小物件反应。可就在气氛刚有一点松动时，沈星野在他西装袖口里摸出被悄悄藏好的发绳，说明小小根本没有真正退远。
- 集末钩：本尊藏起发绳，是想掩盖小小，还是已经开始替她留位置？

### Ep7｜越界保护
- 钩子类型：公开场合险兆
- 出场人格：本尊 / 夜

沈星野第一次跟着本尊去集团做短时观察，本以为只是确认工作环境的触发点，却在电梯和会议室之间看见他被高压议程逼得呼吸失序。她借着递文件的动作替他挡掉一道逼问，让外人只以为这是医生对老板的例行提醒。可一离开人群，夜就接管出来，先质问她为什么要替本尊挡，再警告她别把这种保护误当成亲近。走廊尽头恰好有人抬手按下手机快门，把“陆总身边多了个年轻女医生”拍成了一张足以惹麻烦的照片。
- 集末钩：那张偷拍，会先送到陆母手里，还是送到更会算计的人手里？

### Ep8｜被看见的人
- 钩子类型：偷拍证据 + 旁支入局
- 出场人格：本尊 / 小小

那张照片没有立刻掀起风浪，而是先被转到陆承岳手里；他一眼看出，陆景深突然允许陌生女人贴身出入，不可能只是普通医嘱。另一边，沈星野在陆宅继续磨合，本尊坚持白天的边界，小小却已经会在没人时主动去找她确认今天的灯是不是还会亮。两个截然不同的需求把她钉在这个家里，也让她第一次意识到自己正站在陆家的视线中心。陆承岳嘴上仍是“一家人关心景深”，却已经让人去查这个实习医生的医院背景和下班路线。
- 集末钩：陆承岳查到的第一条线索，会是她的职业身份，还是她已经住进陆宅？

### Ep9｜盯梢开始
- 钩子类型：尾随压迫
- 出场人格：本尊 / 夜

沈星野很快察觉自己上下班被同一辆车跟着，连医院门口和陆宅外的停留点都像被提前踩好。她把异常告诉本尊，本尊第一反应仍是让她暂时抽身，像是只要她离开，所有风险就能重新关在门内。夜却在同一晚接管出来，直接确认这不是偶然，而是有人顺着她这条线在摸三重人格的把柄。沈星野没有退，反而提出由她留在明面继续当诱饵，先逼盯梢的人露出真正的主子。
- 集末钩：夜会允许她冒险，还是先一步对盯梢的人下手？

### Ep10｜谁先出手
- 钩子类型：家族暗战启动
- 出场人格：本尊 / 夜 / 小小

陆承岳拿着一副长辈口吻试探本尊，旁敲侧击问起那个最近常出入陆宅的“沈医生”，表面是关心作息，实则是在测他会不会为了一个外人失态。本尊越克制，越说明这个问题碰到了不能碰的地方；夜在镜中短暂冒头，已经把危险从“封口一个实习生”升级成“有人盯上了她”。当晚小小又悄悄抱着枕头坐到沈星野门口，不问病，不问家，只问外面是不是有人想把姐姐带走。沈星野抬头时，看见陆宅铁门外停着那辆熟悉的车，车里的人没有下车，只是继续看。
- 集末钩：第一个真正把手伸进陆宅的人，会是陆承岳，还是被他借来的另一把刀？

## 幕 2｜依赖与心动（Ep11–20）

### Ep11｜认人的第一课
- 钩子类型：未完成动作 + 身份辨认
- 出场人格：夜 / 本尊 / 小小

因为陆宅外的盯梢没有撤，夜直接把沈星野带进监控室，要她在最短时间里学会分辨“谁出来了”，否则下次出事她连该拦谁都不知道。沈星野不再只看发绳和袖扣，而是把三个人格的站姿、呼吸和看人的先后顺序一一记下，第一次在切换前半秒叫出了“夜”。白天本尊接管回来，本想把这场训练定义成夜的擅作主张，却在听见她准确复述细节后，第一次没有否认“认人”这件事有用。夜里小小抱着记满符号的纸页睡着，纸页上写着三个字：姐姐认得。
- 集末钩：她刚学会认人，陆母那边就已经安排好了要让谁来“接手”陆景深？

### Ep12｜陆总的例外
- 钩子类型：身份反差 + 权限破例
- 出场人格：本尊 / 沈星野

第二天，本尊把一张带集团门禁权限的临时卡放到沈星野手边，冷声强调这只是“防止意外”的工作需要，却等于亲手撕开了自己从不让外人近身的规矩。她第一次被允许进入总裁办公室旁的休息间，也第一次看到他把备用药、会议表和紧急联络方式交给另一个人。陆承岳恰好来访，一眼看见那张门禁卡，表面打趣陆景深终于学会信人，眼底却像已经记下新的突破口。沈星野还没来得及问本尊为什么破例，手机上就收到陌生号码发来的照片，正是她拿着门禁卡走进总裁层的背影。
- 集末钩：那张照片被继续转发下去时，宋晚棠的名字第一次出现在收件人列表里。

### Ep13｜宋晚棠回国
- 钩子类型：第三者入场 + 上位者施压
- 出场人格：本尊 / 宋晚棠 / 陆母

陆母以“家宴”为名把陆景深叫回老宅，真正等在餐桌边的人却是刚回国的宋晚棠，她穿着得体，开口就是多年前两家谈过的婚约。陆母当着沈星野的面把宋晚棠介绍成最适合站在继承人身边的人，不止因为门当户对，更因为宋家手里握着陆氏急需的医疗基金和董事票。宋晚棠没有立刻示威，反而温柔地替陆景深夹菜、替陆母圆场，像一位早被默许的未婚妻，只有看向沈星野时才多停了一秒。沈星野第一次意识到，自己要对抗的不只是情敌，而是一场被利益包装好的联姻。
- 集末钩：宋晚棠笑着问她“沈医生平时主要照顾景深哪一面”，这句话到底是试探，还是她已经知道了什么？

### Ep14｜差点叫错的人
- 钩子类型：公开场合险兆
- 出场人格：本尊 / 小小

宋晚棠回国后，陆母顺势安排了一场基金会参观，要陆景深和她在公开场合重新同框，顺便让外界习惯“陆宋两家重修旧好”的风向。参观途中，闪光灯和孩子哭声同时响起，陆景深的指尖先是僵住，接着无意识去摸本不该出现在西装口袋里的发绳。沈星野在人群里只看了半秒，就先一步喊他“陆景深”，又把一颗薄荷糖塞进他掌心，把小小硬生生稳在将出未出的边缘。宋晚棠全程看在眼里，别人只当沈医生反应快，只有她注意到，那个瞬间陆景深看向沈星野的眼神根本不像老板看医生。
- 集末钩：宋晚棠离场前把那颗没拆开的薄荷糖捡了起来，她想查的显然不只是沈星野的身份。

### Ep15｜只对她开门
- 钩子类型：裂缝温柔 + 私域靠近
- 出场人格：本尊 / 小小

基金会风波过后，本尊嘴上仍说那只是一次意外处置，却默许沈星野把应急物件从客房带进他的休息间，连向来锁着的内侧抽屉也第一次对她开了门。抽屉里没有商业机密，只有备用发绳、旧糖纸和一张被折得发白的儿童画，说明他一直在替小小收着那些不肯见光的东西。沈星野没有追问，只把新的识别笔记放回抽屉，告诉他下次不舒服不用硬撑到切出来才找她。本尊沉默很久，最终只说了一句“以后会议前你先看我一眼”，这已经是他能给出的最大让步。门外的宋晚棠恰好听见半句，脸上的笑第一次淡了。
- 集末钩：本尊刚把钥匙递给她，陆母就决定把这把钥匙彻底收回去。

### Ep16｜官宣预演
- 钩子类型：舆论布局 + 双线逼近
- 出场人格：宋晚棠 / 陆母 / 夜

陆母很快放出试探消息，借媒体口风暗推“陆宋联姻将近”，还让宋晚棠以基金合作人的身份频繁出入陆氏，像是在为真正的官宣预演。集团内部的闲话随即转向沈星野，大家开始猜这个年轻医生还能在陆景深身边待多久。夜在停车场里短暂接管，几乎要顺着偷拍视频的来源去抓人，沈星野却拦住他，提醒他现在最危险的不是偷拍，而是有人想逼他们在公众视线里出错。夜第一次听完了她的话，没有立刻动手，只把查到的一串媒体名单递给她，其中宋家的公关公司赫然在列。
- 集末钩：既然联姻、舆论和基金都连在一起，那下一次公开露面就绝不会只是吃饭拍照那么简单。

### Ep17｜她站在他这边
- 钩子类型：当众站队 + 权力反转
- 出场人格：本尊 / 沈星野 / 宋晚棠

董事会前的晨会上，有人借着联姻传闻阴阳怪气，直接质疑沈星野继续贴身跟进是否合适，宋晚棠也顺水推舟，温声提议让自家医疗团队“接手更专业的照护”。本尊却当着众人把文件扣回桌面，明确说沈星野的安排只由他本人决定，谁都无权换人。那一句不算情话，却是他第一次在公开场合把她从“临时住进陆宅的人”抬成自己亲自保下的人。会后宋晚棠仍带着笑，眼底却彻底冷下来，因为她终于确认，陆景深会为沈星野破例，而且不止一次。
- 集末钩：本尊刚公开护住她，陆母就把更大的场合和更狠的局一起摆上了台面。

### Ep18｜发布会上的半秒
- 钩子类型：公开场合险些切换失败
- 出场人格：本尊 / 夜 / 小小

新品基金联合发布会上，陆母故意把宋晚棠和沈星野都安排在陆景深视线之内，又临时加了一段让他回答童年公益缘起的采访。提问一出，陆景深的呼吸立刻乱掉，眼神先沉成夜的锋利，下一秒又因台下孩子手里的兔子气球险些滑向小小。沈星野隔着镜头和人群，只凭他指节扣台的节奏就判断出这不是普通紧张，随即借递演讲稿的动作挡住长枪短炮，用提前写好的关键词把本尊硬拉回来。整场发布会勉强撑过去，但后台已经有人在传，陆总刚才那几秒像完全变了个人。
- 集末钩：偷拍视频里那段“完全变了个人”的三秒钟，会不会在今晚就流出去？

### Ep19｜认人升级
- 钩子类型：能力升级 + 亲密确认
- 出场人格：本尊 / 夜 / 小小

发布会后，沈星野把三次险些失控的时间点全部摊开复盘，第一次不靠外物，只靠节奏和语气差别说出“这次先抬头的是夜，不是本尊”。她不再只是认出谁已经来了，而是能提前半步看出谁要出来、为什么出来，这让三个人格都第一次真正把她当成“能接得住的人”。小小躲在被子里问她，如果有一天大家一起出来，她还能不能认得；夜站在门边没说话，本尊也没有打断。沈星野只把手放到他掌心，说认错一次是事故，认对很多次就是选择。
- 集末钩：她刚说完会认得，陆承岳那边就收到一段模糊视频，画面里陆景深在台上有一瞬像换了三张脸。

### Ep20｜宴会失控边缘
- 钩子类型：结果前置 + 公共暴露风险
- 出场人格：本尊 / 夜 / 小小 / 宋晚棠

陆母趁热打铁，在周年酒会上直接把宋晚棠推到陆景深身边，半公开暗示两家好事将近，还刻意让媒体围住他们拍合照，逼沈星野只能站在镜头外。陆承岳则把发布会上的模糊视频送给几位董事，等着看陆景深在更大的场合再失一次手。敬酒环节里，陆景深先因逼婚起了夜的杀意，又在乐队忽然停电的瞬间被小小的恐惧顶上喉口，整个失控只差半步就会砸在所有镜头前；沈星野当众冲过去握住他的手，连叫三次“陆景深”，才把本尊拉回台前。镜头确实拍到了这一幕，而酒会结束前，已经有匿名账号预告明早将爆出“陆氏继承人精神异常”的完整视频。
- 集末钩：如果完整视频真的放出来，下一个被逼到台前承认秘密的人，会是陆景深，还是站在他身边的沈星野？

## 幕 3｜信任崩塌（Ep21–30）

### Ep21｜爆料倒计时
- 钩子类型：匿名预告 + 公共危机
- 出场人格：本尊 / 夜 / 沈星野

凌晨零点，匿名账号放出倒计时和三秒模糊片段，“陆氏继承人精神异常”的词条瞬间爬上热搜，集团公关和董事会同时逼陆景深给出解释。本尊第一反应是把沈星野摘出去，连夜让法务准备切割说辞，仿佛只要她离远一点，这场火就不会烧到她。夜却在监控里看见有人开始蹲守她的医院和陆宅，把这场爆料认定成已经越过边界的围猎。沈星野没有退，只先把三个人格的触发点重新排好，因为她知道真正的倒计时不是视频上线，而是谁会先被逼崩。
- 集末钩：删掉热搜容易，删掉已经盯上沈星野的人，真的还来得及吗？

### Ep22｜夜先动手
- 钩子类型：危险物件 + 失控保护
- 出场人格：夜 / 沈星野

偷拍视频源很快被夜顺着车牌和媒体名单挖出来，地下车库里，他把对方的手机和录音笔一起砸在地上，几乎要把“别再碰她”变成真正见血的警告。沈星野第一次看见，夜的过激不是单纯护主，而是把她也划进了必须一起护住的范围，哪怕代价是把局势彻底做绝。她强行按住他的手，逼他明白现在最想看见他动手的人，根本不是偷拍视频的人，而是背后等着把“危险人格”坐实的人。夜最终停了，却把那部碎屏手机留给她，因为偷拍视频的人提到过一句“夫人那边催得很急”。
- 集末钩：偷拍视频背后真正急着把丑闻做实的人，为什么会和陆母扯上关系？

### Ep23｜体面的一边
- 钩子类型：上位者施压 + 二选一
- 出场人格：本尊 / 陆母 / 沈星野

陆母很快以“保护景深”为名接管局面，给沈星野递来一份统一口径，要她以医生身份对外证明昨晚只是短暂应激，把所有异常都压回“过劳失态”的面具里。她说得依旧温柔得体，条件却很清楚，只要沈星野站到体面的一边，联姻、丑闻、偷拍都可以一起压下去。沈星野第一次被明着逼到选择题前面：是继续替陆景深守住完美假面，还是顺着那道裂缝去追问他为什么会怕黑、为什么每次提到童年都像被活活勒住喉咙。本尊希望风波先过去，却没有开口命令她签字，因为他也知道，那份声明一旦落笔，很多真相就会永远被埋掉。
- 集末钩：沈星野若选“体面”，她保住的是陆景深，还是陆母一直想留下的那个假继承人？

### Ep24｜黑暗里的兔子灯
- 钩子类型：危险物件 + 创伤回扣
- 出场人格：小小 / 沈星野 / 本尊

陆母安排沈星野陪同陆景深回老宅做“短暂休整”，实则想把人重新放回她最能控制的地方；偏偏那一晚老宅偏楼突发跳闸，长廊和旧儿童房一起陷进熟悉的黑。小小几乎是被黑暗硬拽出来的，成年身体死死抱住一盏碎了外壳的兔子小夜灯，哭到只会重复“那晚灯坏了，门也打不开”。沈星野第一次碰到比发绳更深的物件回扣，也第一次确认，小小怕黑不是普通应激，而是有一段被关在黑里的童年记忆一直没被说出口。等本尊接回来时，他看见那盏兔子灯的瞬间脸色发白，像是连自己都不愿碰那一晚留下来的证物。
- 集末钩：那盏本该早被丢掉的兔子灯，为什么会一直留在陆家旧儿童房里？

### Ep25｜谁把门锁上
- 钩子类型：旧人证词 + 真相裂缝
- 出场人格：沈星野 / 小小 / 本尊

借着安抚小小的机会，沈星野从老宅旧保姆口中拼出第一块碎片：那一晚不是意外停电，而是有人吩咐过“先别开门，让他哭够就懂事”。保姆不敢多提名字，只说叔伯那时根本不在主宅，真正能一句话让所有人闭嘴的人，只有夫人。沈星野再回头看那盏兔子灯，才发现底座里还压着一张多年旧维修单，签名栏上的字迹正是陆母常用的签批。她终于明确意识到，陆景深童年最深的黑暗并不是家族旁支造成的，真正下令的人一直站在“母亲”的位置上。
- 集末钩：如果陆母就是“那一晚”的主使，那她这些年到底是在治病，还是在反复掩埋罪证？

### Ep26｜她像是站错边
- 钩子类型：误会反转 + 信任崩口
- 出场人格：夜 / 本尊 / 沈星野

为了继续往下查，沈星野表面上接过陆母给的统一口径，甚至答应出席董事会前的闭门说明会，这让夜第一时间认定她已经选了“面具”那一边。夜把她堵在车里，几乎是失控地问她是不是也觉得只要把小小、本尊和所有伤口一起藏好，陆景深就还能做那个完美继承人；本尊站在更冷的一边，没有发火，却把失望压得比威胁更疼。沈星野没法当场解释自己是在借机调档，只能看着他们把她当成可能背叛的人。她第一次明白，选边危机最痛的不是站到哪边，而是你为了靠近真相，必须先承受被他们一起推开的代价。
- 集末钩：她若继续演下去，先查到真相的人会是她，还是会先彻底失去陆景深？

### Ep27｜封存病历
- 钩子类型：证据入手 + 旧伤加码
- 出场人格：沈星野 / 本尊 / 陆母

闭门说明会前，沈星野借陆母授权调到一批被封存多年的病历和家庭干预记录，里面没有完整真相，却足够让她看见童年创伤从一开始就被包装成“矫正”和“治疗”。其中一页紧急处置单清楚写着，某次夜间失控后，监护人要求“隔离、断光、限制安抚对象”，落款仍是陆母。她终于懂了为什么小小会对黑暗和关门怕到发抖，也懂了夜为什么总把“先动手”当成唯一活路。可就在她拿到复印件时，本尊出现在档案室门口，眼神冷得像认定她真的成了陆母那边的人。
- 集末钩：本尊看见她手里的病历时，最先崩开的会是愤怒，还是他一直强撑的遗忘？

### Ep28｜夜要带她走
- 钩子类型：冲突句 + 过激护主
- 出场人格：夜 / 小小 / 沈星野

夜在看见那张处置单后彻底炸开，认定陆母既然敢再次碰旧档，就说明老宅和董事会都已经不安全，他甚至打算直接带沈星野离开，把所有人一起从局里撤出去。可小小却在同一晚抱着兔子灯缩在墙角，断断续续说出“妈妈说关灯就会乖”，让逃离第一次变得不够了，因为真正该被拉到光下的人不是偷拍视频者，而是陆母。沈星野没有顺着夜逃，而是把兔子灯和复印病历并排放在他面前，告诉他现在若只顾着护，她永远都替小小讨不回那一晚。夜第一次把刀意咽回去，因为他终于看懂，她不是在选陆母，而是在选真相。
- 集末钩：夜收了手，可陆母会允许那盏兔子灯和病历一起出现在明天的董事会吗？

### Ep29｜面具还是证词
- 钩子类型：公开对峙 + 选择落地
- 出场人格：本尊 / 沈星野 / 陆母

匿名账号在董事会前放出更完整的视频，董事和媒体几乎同时堵上门，所有人都在等陆景深用一个“过劳失控”的面具把这件事压过去。陆母当众递出那份早准备好的医生说明，只要沈星野签字，丑闻、联姻和继承盘就还能维持表面平稳；可她也会亲手把小小和那一晚继续锁回黑里。沈星野最终没有签，她选择站到陆景深身边，却拒绝替任何人继续说谎，直言公开视频是恶意操控，而更早的伤害来自陆家内部。那一刻，本尊终于明白她这些天承受的误会不是摇摆，而是在“面具”和“真相”之间，替他们把最疼的一边也一起扛了。
- 集末钩：她把矛头指向陆家内部之后，下一个被迫开口的人，会是陆母，还是还活着的旧证人？

### Ep30｜那一晚的主使
- 钩子类型：危险物件 + 真凶指向
- 出场人格：本尊 / 夜 / 小小 / 沈星野

董事会没有当场散场，陆母却已经失了最稳的从容，因为沈星野拿出的不只是复印病历，还有那盏兔子小夜灯和维修单，证明确有一晚，陆家把一个怕黑的孩子连同坏掉的灯一起关进了黑里。旧保姆也终于松口承认，当年下令“别开门”的不是叔伯，不是外人，就是夫人本人；她要的从来不是治好孩子，而是逼出一个足够听话、足够体面的继承人。真相仍未全盘揭开，可方向已经无比明确，陆母不再是能替陆景深挡风雨的盟友，而是那场童年黑暗的主使。风暴尚未结束，陆景深却第一次在镜头和家族面前没有推开沈星野，因为小小的恐惧、夜的刀和本尊的面具，终于开始站到了同一边。
- 集末钩：既然主使已经浮出水面，下一次真正掀桌的人，会是陆景深，还是被逼到绝路的陆母？
