# 打烊以后 资产基础 Prompt

用途：生成角色卡、场景基底图、关键道具图，供后续逐镜视频 prompt 复用

使用建议：

- 角色统一用纵向 4:5 或 3:4，单角色，完整造型清楚
- 场景统一用横向 16:9，尽量无角色或只保留极弱氛围人影
- 道具统一用 1:1 或 4:5，产品级清晰展示
- 整体风格保持：合家欢奇幻、商业零售质感、温暖不阴森、细节真实、可爱但不幼稚

店铺名字设定：奇盒星球

店铺气质说明：年轻人会专门来逛、抽盲盒、拍照打卡的头部潮玩集合店，名字带一点童话和收藏宇宙感，不是普通零售商铺，也不是奢侈品牌门店
