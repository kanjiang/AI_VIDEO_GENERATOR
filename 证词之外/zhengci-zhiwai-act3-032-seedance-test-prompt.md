# 《证词之外》第三幕 032 Seedance 单镜测试稿

用途：单独测试“周妍坠地后录音笔从衣缝弹出并回放 -> 黑色制式皮鞋走入 -> 拾起证据 -> 离开”的最终落点。

@制式皮鞋近景=制式皮鞋近景
@录音笔近景=录音笔近景
@周妍=周妍

【挂载资源与音频硬约束】严格使用黑色制式皮鞋近景、微型录音笔近景与周妍形象参考；皮鞋款式、录音笔外观、周妍衣料边缘和地面质感不重新设计。无字幕、无标题、无背景音乐。录音笔回放必须沿用林深参考 MP3 声纹，但带录音笔小喇叭压缩、轻微底噪和地面近距离混响。

【首帧衔接】首帧承接031尾帧：黑屏后风声回归深夜12点雨后停雨的露台/楼下冷硬地面环境，林深空手和护栏边缘的记忆闪回刚结束；本镜以低角度固定机位接周妍坠落后的地面结果，不展示坠落过程和血腥细节。

【规格】约15秒，21:9，真人电影质感，深夜12点雨后停雨，固定低角度 one-shot，无剪辑，低饱和暗冷色调。

【电影化动态描述】固定低角度 one-shot，景别为特写到近景。深夜12点雨已经停了，楼下冷硬地面、周妍衣料边缘、录音笔外壳和黑色制式皮鞋周边保留潮湿反光与零星水痕，但画面中不再下雨。第一拍：画面先落在潮湿冷硬地面和周妍衣料边缘，不展示面部和血腥；构图留出大片空地，让缺席本身形成压力。一声远处重物落地闷响后，微型录音笔从衣缝边缘弹出，滚到画面中央，红色录音灯仍在闪。第二拍：录音笔停稳后自动回放，镜头不切，只让录音笔成为画面中心；地面灰尘、小碎屑和零星水痕被风吹动。第三拍：黑色制式皮鞋从画面右侧走入，停在录音笔旁，鞋尖先遮住一部分录音笔灯光；脚步停下后先不要立刻捡，停半秒，让观众意识到有人听见了。随后一只手从画面上缘伸入，捡起录音笔，但人物不露脸。第四拍：皮鞋转身离开，镜头末尾极慢后移，只留下空地面、衣料边缘和逐渐远去的脚步声。最后一秒落在录音笔被带走后的空地面，结局不落在死亡，而落在证据被谁带走。

【音画同步】说话者锁定：录音笔回放=林深本人录音回放声，沿用林深固定声纹，但带录音笔小喇叭压缩、轻微底噪和地面近距离混响；画内无人开口对白，周妍不说话，黑色制式皮鞋主人不说话。重物落地闷响在镜头开始前半秒后传来，不展示撞击画面；闷响后留极短空白，再让录音笔滚动声出现。录音笔滚动声与它从衣缝弹出、滚到画面中央同步。录音笔回放林深上一镜原句：“只有死人，才能永远保守秘密。” “只有死人”带轻微爆音，“秘密”尾音有录音设备底噪。皮鞋脚步声进入时压低回放声；脚步停住后留半秒静默，手捡起录音笔时回放声变闷，离开后脚步声渐远，最后只剩风声和空地面。

【负面约束】不展示血腥、尸体正脸或坠落撞击过程；不让皮鞋主人露脸或说话；不新增解释性字幕、新闻画面、警笛或旁白；不改变录音笔外观；不把结尾做成煽情音乐段。
