# 04 — Main Images（电商主图）

| | 营销海报 | 产品主图 |
|--|----------|----------|
| 目的 | 品牌氛围、活动声量 | **快速传递产品价值** |
| 内容 | 情绪、大字、战役感 | 产品展示、卖点、功能、场景、用户价值 |
| 阅读 | 可被种草 | 3 秒内看懂「是什么 + 为什么买」 |

---

## 套装结构（按渠道改数量）

常见天猫/淘宝主图逻辑示例（可删减）：

| 序号 | 模块目标 | 画面重点 |
|------|----------|----------|
| 1 | 认知 | 产品英雄展示 + 品类一句 |
| 2 | 核心卖点 | 单一 Top 卖点可视化 |
| 3 | 功能/参数 | 结构或功能示意（少字） |
| 4 | 使用场景 | 真实使用语境 |
| 5 | 用户价值/对比 | 前后对比或利益点（合规） |

抖音/短视频封面可只要 1 张英雄主图。

---

## 操作

1. 引用精修产品图（必须）。  
2. 每张主图 **只打 1 个主信息**，避免海报式堆文案。  
3. 文案以短标题+要点图标化；长说明留给详情页。

### 单张主图 prompt 骨架

```
电商平台产品主图，[1:1 或渠道比例]。白底或浅色干净背景（若渠道要求白底则纯白）。
产品精修外观准确居中；信息层级：主卖点「[一句]」用视觉表达（图标/局部光/ dial），
禁止大段说明文字占画面；商业棚拍，清晰锐利，可加极简角标区。
风格对齐 brief：[关键词]。禁虚假对比、禁未证实功效承诺。
```

写入 `main-images.md`：表格（序号 / 目标 / 卖点 / prompt / 输出文件名）。

---

## 质检

- 缩略图下产品仍可识别  
- Logo 方向正确  
- 与精修同款  
- 主图看起来不像「氛围海报」（信息更硬、更清晰）
