# 《证词之外》第二幕视频提示词

范围说明：第二幕 = S3-S4（门口对峙、假声暴露、LEFT 解锁、隐藏录音落地）。

使用说明：以下为 15 秒一条的 Seedance 风格中文提示词，每条均为完全自包含重度版，可单独投喂模型。复制到 Seedance 时，必须连同每条 prompt 上方的 `@image` 行一起复制；`@image1`、`@image2` 的编号跟随本次上传顺序变化，但括号里的名字应保持稳定。307 室内部镜头现可优先参考 `room_307_reverse.png`，并继续沿用锁定的空间文字设定；天花板播音孔暂无单独图参，严格按剧本设定生成。本文件是段落压缩版，用于快速测试整段节奏；实际单镜头执行时，以 `zhengci-zhiwai-act2-video-prompts-shot-by-shot.md` 的镜头语气、光线逻辑和构图尺度为准。第二幕整体拍法统一为：空间轴线稳定、人物压抑克制、真假声源必须明确分离、屏幕 UI 以最终结果清晰优先，不追求复杂逐帧动画。
