# Design: 果酱岛 · 水果世界爆笑冒险动画

**Date:** 2026-08-09
**Working title:** 果酱岛控制中心
**Project folder (proposed):** `fruit-jam-island/`
**Format:** 横屏 16:9，第一季 10 集 × 约 4 分钟
**Genre lane:** 学龄前～低龄爆笑冒险喜剧（3–8 岁通吃，成年人可刷）
**Art style:** 皮克斯 3D 糖果色（与 `kiki-english-adventure`、`tangtang-good-habits` 同一视觉家族）

---

## 1. Logline

一颗坚信「每个按钮都在等我按」的小番茄，和一颗还记得上次大喷发的柠檬，在一座会打嗝喷果酱的菠萝火山底下值班——每天的任务是哄火山保持心情稳定，而每天的结局是全岛被果酱淹一次。

## 2. Premise locks

| 项 | 锁定 |
|----|------|
| 起点 | 从零原创，全新 IP；仓库内无同题材项目 |
| 定位 | 爆笑冒险喜剧（非教育向、非科普向），物理喜剧为主 |
| 形式 | 横屏 16:9 / 约 4 分钟 / 单元剧，可做完整三幕 |
| 世界逻辑 | **万物皆活**：火山、电脑、船、按钮都是有脾气的角色，不是死道具 |
| 主角配置 | 双主角相声结构：手贱情（啵啵）+ 收残局侠（柠七） |
| 火山定位 | **不是灾难源，是全岛的果酱工厂 + 暖气 + 发电厂**；日常工作是哄它按时打嗝 |
| 喷发物 | 滚烫菠萝果酱（非岩浆） |
| 威胁形态 | 被果酱粘住 → 糖化变硬。卡通式威胁：不会死，会被凿出来，只是很丢脸 |
| 尺度 | 世界里没有人类，水果就是这个世界的正常尺度，不需要参照物 |
| 单集变量 | **唯一变量 = 这次按的是哪颗葡萄**，其余骨架固定 |
| 季度长线 | 葡萄串末端一颗干瘪黑葡萄，贴着「绝对不要按」，第 10 集按下去 |
| 常设场景 | 仅 4 个（控制中心 / 火山口 / 全岛全景 / 果酱码头），10 集复用 |

### 2.1 为何选定「控制中心」而非「公路片」

同期评估过三个方向：控制中心倒计时单元剧（选定）、香蕉船跨海公路片、沙盒作死实验。

选定理由是成本结构：控制中心方案把全部核心意象变成**每集必用的常设资产**（火山＝场景，西瓜电脑＝中枢，葡萄＝引爆装置，香蕉船＝交通，小番茄＝主角），一套锁定资产复用十集，AI 出图抽卡成本最低、角色一致性最好。公路片方案每集需要新场景加新居民，资产成本数倍，且会把火山与西瓜电脑降格为偶尔露脸的道具。沙盒方案梗密度最高但无情感线与角色成长，不适合养成 IP。

## 3. Characters

角色设计遵循一条统一原则：**每个角色的生理构造 = 它的喜剧机制 = 它的性格外化。**番茄会爆、柠檬会酸、西瓜会掉籽、葡萄会尖叫、香蕉怕水。这样永远不缺笑点，且每个角色的招牌动作都是可视化的，便于出图锁定。

### 3.1 啵啵 · 小番茄（主角 / 实习员）

- **外形:** 圆滚滚，皮薄，弹性极好，通体番茄红，顶上一小撮绿蒂
- **Want:** 按下每一个按钮
- **Need:** 学会在按之前想一秒后果
- **核心缺陷:** 不是手贱——**他真心相信每一个按钮都在等他去按**，那是一种天真的使命感
- **生理机制:** 情绪激动 → 膨胀 → 撑到极限爆浆 → 变成软塌塌一张皮 → 需要时间慢慢重新充气，期间说话漏气跑风
- **视觉记忆点:** 爆完瘪着一张皮继续跟着救火
- **例台词:** 「它在等我。你看它都亮了。」

### 3.2 柠七 · 柠檬（主角 / 值班主管）

- **外形:** 明黄，表皮带孔洞质感，眉眼常皱成一团
- **Want:** 让一切按流程走
- **Need:** 学会放手、信任别人
- **核心缺陷:** 过度控制。**好几次灾难恰恰是流程本身导致的**
- **背景锚点:** **她是岛上唯一还记得上一次大喷发的水果。**她的严厉有来源，不是刻薄工具人
- **生理机制:** 紧张时从眼角挤出柠檬汁，喷到谁谁睁不开眼
- **口头禅:** 「我早就说了。」

### 3.3 瓜叔 · 西瓜电脑（控制中枢）

- **外形:** 一整颗西瓜嵌在控制台里，屏幕是切面，内部电路由西瓜籽构成
- **功能:** 他知道所有问题的解决办法
- **喜剧机制:** **讨价还价**——每次都要啵啵先付出一点代价才肯说（「你先说对不起」「先叫我一声瓜爷」）。这是全片最好用的节奏节拍器，能在紧张的倒计时里硬插一段闲聊，张力反而更强
- **弱点:** 开机要转半天；籽掉出来等于丢内存
- **例台词:** 「查到了。但你刚才那个语气，我不太舒服。」

### 3.4 葡萄串（控制台按钮 / 集体角色）

- **设定:** 一串葡萄嵌在控制台上，每颗是一个按钮，被按到的那颗会尖叫
- **人格:** 有集体人格的合唱团，互相推卸责任——「别按我！按老三！」
- **关键机制:** **标签早就掉了，连葡萄自己都不知道哪颗对应什么功能**，所以按下去连它们自己都吓一跳。这一条彻底解决了「为什么总会误操作」的逻辑，不需要主角很蠢
- **长线:** 串子最末端一颗干瘪发黑的葡萄，从不说话，旁边贴着「绝对不要按」

### 3.5 蕉蕉 · 香蕉船（交通工具）

- **设定:** 一条香蕉皮做的船，**有恐水症**
- **喜剧机制:** 只有被唱歌哄的时候才肯下水，所以每次紧急出发都得先花时间唱歌，急得柠七跳脚
- **作用:** 强制在第二幕开头插入一个延迟节拍，把观众的着急感拉满

### 3.6 菠萝火山（场景 / 准角色）

- **设定:** 一座山那么大的菠萝，全岛的果酱工厂、暖气与发电厂
- **日常:** 每天定时打一个嗝，喷出适量果酱供全岛使用
- **情绪:** 有脾气。心情不好就打嗝不规律；情绪失控就是大喷发
- **唯一光源:** **火山是全岛唯一的暖光源**，夜景全靠它打嗝时那一下橙光扫过全岛

## 4. 单集结构（4 分钟固定骨架）

| 时间 | 段落 | 内容 |
|------|------|------|
| 0:00–0:20 | 冷开场 | 火山定时打嗝的清晨日常，建立世界 + 一个小笑点 |
| 0:20–0:40 | 任务布置 | 柠七交代一件极简单的事，通常是「今天你只要别碰控制台」 |
| 0:40–1:10 | 引爆点 | 啵啵按了葡萄，葡萄尖叫，倒计时启动 |
| 1:10–2:30 | 救援闹剧 | 唱歌哄蕉蕉下水 → 环岛救援 → 第一招失败 → 第二招把事情搞得更大 → 啵啵爆浆 |
| 2:30–3:00 | 低谷 | 瓜叔讨价还价后给出线索 |
| 3:00–3:40 | 高潮 | 用一个更荒谬的办法解决，**通常是某个角色的缺陷反而成了唯一的解** |
| 3:40–4:00 | 收尾 | 火山打嗝平息，留下小烂摊子当片尾梗；柠七「我早就说了」，啵啵已在盯下一颗葡萄 |

### 4.1 六个固定桥段（Runners）

火山打嗝、葡萄推卸责任、唱歌哄船、瓜叔讨价还价、啵啵爆浆、结尾对照。

这些既是 IP 记忆点，也是**成本控制点**：固定桥段意味着固定机位与可复用镜头，AI 出图不必每集重造。

### 4.2 单集创意来源

每集唯一的变量是「这次按的是哪颗葡萄」。第一季候选灾难：

| # | 按到的葡萄 | 灾难 |
|---|-----------|------|
| 1 | 重力 | 全岛水果开始漂浮，果酱往天上喷 |
| 2 | 温度 | 果酱冷凝成硬糖，整座火山变成一根巨型棒棒糖，堵住了，压力在里面积累 |
| 3 | 倒放 | 火山开始往里吸，把全岛东西吞进去 |
| 4 | 加速 | 打嗝频率变成每三秒一次 |
| 5 | 合唱 | 全岛所有东西不受控地唱歌，而噪音正是让火山情绪失控的东西 |
| 6 | 复制 | 啵啵被复制成一百个小番茄，每一个都想按按钮 |
| 7 | 静音 | 全岛失声。火山靠听见居民的日常吵闹才安心，突然的寂静让它以为大家都不在了 |
| 8 | 分裂 | 火山裂成两半，两半为了「谁先打嗝」吵起来，谁都不肯让 |
| 9 | 礼貌 | 火山变得过度客气，憋着不肯打嗝，压力积累到临界 |
| 10 | 黑葡萄 | 季终，长线悬念揭晓 |

### 4.3 第一季情感线

柠七学会放手信任；啵啵学会看后果。两条线在第 10 集黑葡萄事件上收束。

## 5. 视觉锁

| 项 | 锁定 |
|----|------|
| 画幅 | 16:9 |
| 风格 | 皮克斯 3D 糖果色 |
| **质感签名** | **果蜡高光、水珠、半透明果肉、糖浆拉丝**——这是本 IP 区别于其他 3D 儿童动画的核心，写入 project-lock 硬锁 |
| 主色 | 果酱琥珀金（环境光）+ 番茄红（啵啵）+ 柠檬黄（柠七）+ 葡萄紫（控制台）；西瓜绿作冷色平衡 |
| **光照规则** | **火山是全岛唯一的暖光源**。夜景全靠火山打嗝时的橙光扫过——明确的实用光源规则，AI 出图一致性好锁 |
| 尺度 | 无人类参照物，水果即正常尺度 |
| BGM | 生成阶段抑制 BGM，音乐后期加（沿用仓库既有规范） |

### 5.1 常设场景（4 个，10 集复用）

1. **控制中心内部** — 西瓜电脑 + 葡萄控制台 + 能看到火山的观景窗
2. **菠萝火山口**
3. **果酱岛全景** — 清晨态 / 喷发态两版
4. **果酱码头** — 香蕉船停泊处

## 7. 实施范围

**第一阶段只做到「跑通一集」**：系列圣经 + 角色 + project-lock + 第一季分集大纲 + 第一集剧本 + 第一集分镜与出图 prompt。验证一集的实际出片效果后再批量推进 2–10 集。

流程沿用仓库既有管线：`screenwriter-skill` → `shotlist-builder` / `storyboard-table-skill` / `scene-board-skill` → `seedance-2` → `bgm-scoring` → `post-production`。

低抽卡出图顺序：角色身份板 → 黑白故事板表格 → 场景图 → 视频生成。
