# Micro-Expression Library（微表情提示词库 · 上篇）

以**面部肌肉细节**替代笼统情绪词，解决 AI 人物面部僵硬、表情同质化。  
直接拼进 Seedance / 可灵正向 Prompt。

**总公式（与 §8 三段递进兼容）：**  
`人物描述 + 【微表情名或原文】 + 镜头参数 + 电影光影 + 面部细节丰富，五官自然联动，无面部崩坏，自然真人肌理`

来源：[absorption/AIGC-微表情提示词库吸收.md](absorption/AIGC-微表情提示词库吸收.md)（上篇）。下篇（沉思/慵懒/猜忌等）待补。

联用：[MICRO_BEATS.md](MICRO_BEATS.md)（选型与三段递进）· [CAMERA_LEXICON.md](CAMERA_LEXICON.md)（景别）

---

## 拼接模板

```
[角色身份与外貌]，[微表情提示词全文]，[景别/运镜]，[光影]，
面部细节丰富，五官自然联动，无面部崩坏，自然真人肌理，禁过度磨皮蜡像脸。
```

示例：

```
年轻短发女生，单侧嘴角挑起，眼神灵动，带着调皮试探感的坏笑，近景特写，柔和侧逆光，
面部肌肉自然联动，不扭曲，五官稳定，自然真人肌理。
```

**负面建议：** `面部扭曲、五官错位、眼球异常、嘴巴畸形、表情僵硬、美颜磨皮过度`

---

## 硬规则

1. **单镜一种主微表情**；禁同时堆冲突表情（狂喜+痛哭）。  
2. **长对白：** 按句/按意群换微表情，**分段生成**，避免全程一张脸。  
3. 复杂升级情绪（隐忍→破防）优先 [MICRO_BEATS.md](MICRO_BEATS.md) §8 三段；本库条目作①或②或③的「单段填充」。  
4. 写 Prompt 时可用「**坏笑**」点名，但正文须带表内肌肉描述，勿只留情绪标签。
