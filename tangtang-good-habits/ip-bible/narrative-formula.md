# 每集叙事公式 · Narrative Formula

《糖糖的小英雄》系列的**每一集**都必须遵守这套 10 节拍叙事公式。**这是 IP 的骨架，写新集时按此模版填空**，可以保证：

1. 系列风格高度一致（观众看到第 3 集就能预期节奏）
2. 每集独立可看（不需要看过前面几集）
3. 每集有相同的教育目标结构（问题 → 后果 → 学习 → 邀请）
4. 每集有相同的时长约束（100 秒左右）

## 一、公式一览

```
Beat 1  HOOK        · 8s   · 日常场景 · 埋雷（糖糖处于"某种诱惑"中）
Beat 2  WRONG       · 8s   · 犯错示范 · 糖糖选择偷懒/放纵
Beat 3  ENEMY       · 12s  · 建立敌人 · 反派狂欢揭示（微观/幻境）
Beat 4  DAMAGE      · 12s  · 严重后果 · 时间流逝 + 伤害积累
Beat 5  CONSEQUENCE · 8s   · 现实报应 · 糖糖真的疼了/累了/找不到东西了
Beat 6  HERO        · 10s  · 守护者登场 · 转折反攻
Beat 7  TEACHING    · 14s  · 教学核心 · 正确做法三步/多步
Beat 8  RITUAL      · 12s  · 生活锚定 · 频率/时长/晨昏对照
Beat 9  ELEVATION   · 8s   · 情感升华 · 糖糖闪亮笑容
Beat 10 CALL        · 8s   · 打破第四堵墙 · 糖糖对镜头邀请
────────────────────────────
总时长 : 100s
```

## 二、每一节拍的功能说明

### Beat 1 · HOOK · 埋雷 · 8s

**功能**：抓注意力 + 建立糖糖的"当集诱惑"

**每集变体举例**：
- Ep01 刷牙：糖糖生日狂吃蛋糕糖果
- Ep02 早睡：糖糖睡前抱着平板看短视频停不下来
- Ep03 洗手：糖糖玩完泥巴/画画满手脏就冲去餐桌
- Ep04 吃饭：糖糖只顾玩玩具不吃青菜
- Ep05 收拾：糖糖玩玩具玩得地上一片狼藉
- Ep06 用眼：糖糖近距离盯着屏幕看很久
- Ep07 分享：糖糖抱着一大盒糖果拒绝分享
- Ep08 运动：糖糖赖在沙发上不肯动

**规则**：
- MACRO 场景
- 情感值：+ （极乐 / 沉迷）
- 无字幕
- 结尾**必须有"即将出问题"的埋雷信息**（暗示观众待会会有后果）

---

### Beat 2 · WRONG · 犯错示范 · 8s

**功能**：让糖糖做出"错误选择"，建立因果起点

**每集变体举例**：
- Ep01：拒绝刷牙就睡觉
- Ep02：拒绝放下屏幕，"再看一集嘛~"
- Ep03：跳过洗手直接吃饭
- Ep04：把青菜挑到桌边
- Ep05：不收拾玩具就跑去做别的
- Ep06：把屏幕拉得更近
- Ep07：把糖果全部藏在自己身后
- Ep08：说"不要嘛~"继续瘫沙发

**规则**：
- MACRO 场景（通常与 Beat 1 同一空间或相邻）
- 情感值：+ → ±（快乐 → 偷懒可爱，观众开始担心）
- **守护者第一次挥手提醒 → 被糖糖忽视 → 守护者叹气**（这是本 IP 独特的守护者出场铺垫）
- 台词固定句式："**太累啦~**"、"**再一次嘛~**"、"**明天再 X X X~**"

---

### Beat 3 · ENEMY · 建立敌人 · 12s

**功能**：反派军团出场，进入微观/幻境世界

**每集变体举例**：
- Ep01：口腔内部细菌派对
- Ep02：糖糖脑内 / 屏幕世界的熬夜怪派对
- Ep03：糖糖手上的脏脏虫开心地要"随饭一起进肚子"
- Ep04：糖糖内脏世界的挑食小恶魔庆祝"又没吃青菜"
- Ep05：地板上的邋遢小怪把玩具堆变成他们的城堡
- Ep06：糖糖眼球里的近视虫开始遮挡视线

**规则**：
- MICRO / 幻境 场景（**必须做一次尺度跳跃**）
- 情感值：± → −（反派得意）
- 通过 Whip-Zoom 或类似过渡进入
- **反派 Boss 有招牌宣言台词**：如糖糖菌"糖糖来啦！开派对！"、熬夜怪"再看一集嘛~"
- 数据标注：反派名字（如"坏坏菌"/"熬夜怪"）用卡通小旗/招牌

---

### Beat 4 · DAMAGE · 严重后果 · 12s

**功能**：可视化后果 + 时间流逝

**每集变体举例**：
- Ep01：细菌集体喷酸 + 月夜划过 + 牙齿黑点
- Ep02：熬夜怪在糖糖脑内狂欢 + 夜色渐深 + 大脑指挥室灯光一盏盏熄灭
- Ep03：脏脏虫钻进糖糖肚子 + 肚子发出"咕噜咕噜"警告声
- Ep04：营养罗盘断电 + 糖糖的"力气条"下降
- Ep05：邋遢小怪把糖糖最爱的玩具藏起来 + 时钟滴答走过

**规则**：
- MICRO / 幻境 场景（延续 Beat 3）
- 情感值：− → −−（严重伤害）
- **必须有时间流逝的视觉表现**（月亮划过、时钟滴答、灯光熄灭、罗盘断电…）
- **结尾必须有一个"现实种子"**：一个具体的物理证据（如门牙黑点、大脑黑眼圈、肚子咕噜咕噜、找不到玩具的空位置）——为 Beat 5 做闭环铺垫

---

### Beat 5 · CONSEQUENCE · 现实报应 · 8s

**功能**：**因果闭环的关键节拍**——糖糖真实感受到后果

**每集变体举例**：
- Ep01：早晨牙痛捂嘴 + 镜前发现黑点
- Ep02：早晨闹钟响糖糖起不来 + 上幼儿园路上打盹撞门柱
- Ep03：吃完饭肚子疼跑厕所
- Ep04：幼儿园跑步没力气跌倒
- Ep05：找不到最喜欢的小熊玩具 + 大哭
- Ep06：看不清老师黑板上的字，问旁边小朋友

**规则**：
- MACRO 场景（跳回现实世界）
- 情感值：−− → −（后悔痛哭）
- **本节拍决定全片教育效果**——把 Beat 4 的抽象后果变成糖糖真实感受
- 表情组合：**E04 惊恐 → E05 泪汪汪**
- 台词固定句式："**哎哟！**" + "**呜——**"
- **黑点/证据物必须与 Beat 4 结尾种下的种子对应**（因果一致性）

---

### Beat 6 · HERO · 守护者登场 · 10s

**功能**：转折反攻 + 守护者觉醒

**每集变体举例**：
- Ep01：牙刷警长从牙刷架活过来
- Ep02：睡眠精灵从月亮夜灯里飞出来
- Ep03：泡泡骑士从洗手液瓶跳出来
- Ep04：蔬菜战队从冰箱冲出来
- Ep05：玩具箱先生张开大嘴
- Ep06：眼镜精灵从眼镜里翩翩起舞

**规则**：
- MACRO → MICRO / 幻境（双世界联动）
- 情感值：− → ± → +
- **必然流程**：糖糖发现物品 → 物品眨眼活过来 → 敬礼 → 台词"**别怕，交给我！**"
- 战斗方式因守护者而异（挥刷/撒星光沙/喷泡泡/彩虹光…）
- 反派溃败必须滑稽（**遵守反派设计禁忌**）
- 结尾"叮叮叮"清洁/救援音

---

### Beat 7 · TEACHING · 教学核心 · 14s

**功能**：**大赛评委最看重的实用知识点段落**

**每集三段式变体**：
- Ep01：三步刷牙法（上下 / 里外 / 每颗）
- Ep02：三步入睡法（放下屏幕 / 关灯 / 抱抱守护者进梦乡）— 也可以设计为"睡前三件事：洗脸→刷牙→读绘本"
- Ep03：三步洗手法（湿手 / 打泡揉搓 / 冲干净）—或简化版七步洗手法
- Ep04：三步吃饭法（一口青菜 / 一口米饭 / 一口肉）
- Ep05：三步收拾法（分类 / 归位 / 关箱）
- Ep06：护眼三步法（远看 / 眨眼 / 揉一揉）

**规则**：
- MACRO 场景 + 每步插入 1 秒 MICRO 示范（守护者在幻境里同步演示）
- 情感值：+（学习进取）
- **每步 4-5 秒**，共 3 步 = 12-15 秒
- **字幕必须极清晰**：糖果色描边圆润字体
- **箭头图标必须动**：⬆️⬇️ / ⬅️➡️ / ①②③
- 口播节奏：每句话之间留 0.3 秒停顿，让小朋友跟着念

---

### Beat 8 · RITUAL · 生活锚定 · 12s

**功能**：把学到的做法**锚定到日常时间**

**每集变体举例**：
- Ep01：早晚各一次 + 2 分钟沙漏
- Ep02：每天晚上 8:30 睡觉 + "8 小时睡眠"沙漏
- Ep03：饭前 · 便后 · 出门回家 三次洗手 + 30 秒沙漏
- Ep04：每一餐都要吃青菜 + "一天三顿"图标
- Ep05：每天玩完就收 + "一次一次积累" 时钟

**规则**：
- MACRO 场景（通常是卫生间/卧室/餐厅）
- 情感值：+（生活仪式）
- **必用分屏或多画面对照**（比如晨昏分屏、饭前饭后对照）
- 沙漏 / 时钟 / 图标类数据标注
- 温馨童声主题歌前奏起

---

### Beat 9 · ELEVATION · 情感升华 · 8s

**功能**：情感峰值 + 视觉高潮

**每集变体举例**：
- Ep01：糖糖对镜大笑，门牙闪光 + "闪闪亮"
- Ep02：糖糖第二天早晨精神饱满起床，头顶冒出小太阳 + "精神满满"
- Ep03：糖糖手洗干净后手上冒出光辉 + "干干净净"
- Ep04：糖糖吃饱后力气条满格 + "力气满满"
- Ep05：糖糖玩具全部归位后房间闪亮 + "整整齐齐"

**规则**：
- MACRO 场景（通常是卧室或客厅）
- 情感值：+ → ++（情感峰值）
- 糖糖服装**回到 Beat 1 的日常装**（象征"新一天开始，一切变好"）
- 门牙/手部/身体某个部位闪光 → 拉出全景 → 守护者站在糖糖肩上/身边敬礼
- 数据标注：主题词（闪闪亮 / 精神满满 / 干干净净 / 力气满满…）+ 星星特效

---

### Beat 10 · CALL · 打破第四堵墙 · 8s

**功能**：**IP 品牌记忆锚点** + 行为转化

**规则**（**这个节拍在所有集里格式几乎相同**）：
- MACRO 中性背景（可以是当集卧室/卫生间的模糊延续）
- 情感值：++（邀请高潮）
- **糖糖眼神必须直视镜头**
- 台词固定句式：**"你也要 X X X 哦！"**
  - Ep01："你也要早晚刷牙哦！"
  - Ep02："你也要早点睡觉哦！"
  - Ep03："你也要认真洗手哦！"
  - Ep04："你也要好好吃饭哦！"
  - Ep05："你也要收拾玩具哦！"
- 守护者从糖糖肩上跳到画面前敬礼："**交给你啦！**"
- 主题歌尾句字幕（格式固定，只换动词）：
  - Ep01："**早晚刷刷刷，笑容闪闪亮！**"
  - Ep02："**乖乖睡觉觉，精神满满亮！**"
  - Ep03："**饭前洗洗手，健康闪闪亮！**"
  - Ep04："**样样都吃好，力气满满亮！**"
  - Ep05："**玩完收收拾，房间闪闪亮！**"

**主题歌尾句都以"闪闪亮"或"满满亮"押韵结尾**——这是 IP 的**声音品牌锚点**。

## 四、写新集时的流程

1. **确认当集主题**（如"早睡"）
2. **从 `guardian-roster.md` 挑选或新增守护者**
3. **从 `villain-roster.md` 挑选或新增反派**
4. **按公式填空**：从 `episodes/ep01-brush-teeth/` 复制文件模版，把每个 Beat 里的具体场景/动作/台词替换为当集内容
5. **锁死"哪些是 IP 通用、哪些是当集变化"**：糖糖形象、叙事公式、结尾格式 = 通用；场景、反派、守护者、教学内容、闪光主题词 = 变化
6. **拆分逐镜 shot-plan.md**（25 镜左右）
7. **交给下游 skill**（storyboard/scene-board/shotlist/bgm/post）
