# 场景图提示词示例

**场景图提示：**

创建一张电影化的 16:9 场景设定图。

[主体]：使用场景参考图像；如果同时提供角色参考，角色只能作为空间比例和站位参考，不能抢占场景主体。

[空间目标]：明确这个场景的用途，是建立空间、固定镜头朝向、统一灯光逻辑，还是为后续视频生成锁定背景连续性。整张图必须先解决空间问题，再解决装饰问题。

[场景结构]：准确描述前景、中景、后景的关系，主要入口、出口、通道、窗户、桌椅、道具、墙面、地面和关键视觉锚点的位置。让观众一眼看懂人物未来能从哪里进入、停留、转身、离开。

[视觉氛围]：强调环境材质、色温、空气感、空间压迫感或开放感、时间状态和情绪基调。氛围必须服务叙事，不要只追求漂亮。

[灯光设计]：说明主光方向、辅光来源、暗部关系、实景光源和画面亮度重心。后续视频生成必须能沿用这个灯光逻辑，而不是重新随机打光。

[镜头兼容性]：画面应适合作为后续故事板和视频生成的空间底板，保留清晰透视、稳定地平线和可靠尺度关系。不要做成纯概念海报，不要过度夸张透视，不要为了风格牺牲可拍性。

[附加信息]：如有必要，可加入少量手写批注，标明角色站位区、主要运动路径、摄影机大致朝向或关键道具位置，但整体仍应以干净的场景阅读性为主。

[最终要求]：这张图必须能作为视频生成时的场景锚点，帮助稳定背景、空间方位、灯光逻辑和环境叙事。

负面约束：不要做成海报，不要让人物喧宾夺主，不要过度设计装饰元素，不要让空间关系模糊，不要忽略入口出口和主运动路径，不要出现与后续镜头语言冲突的极端视角。
