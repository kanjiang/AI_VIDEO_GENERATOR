# 打烊以后 资产清单

用途：为逐镜 AI prompt 生成准备角色图、场景图、关键道具图

当前状态：脚本、分镜节拍表、逐镜 shot list 已完成；下一步生成 prompt 前，需要先锁定资产

## Characters

- 林麦：22 岁，潮玩旗舰店实习店员，瘦高，动作利落，黑色低马尾，淡妆，浅灰工作服围裙，白天拘谨，夜里逐渐放松
- 小牙：原创精灵玩偶，尖耳，坏笑，体型小，盒角压皱，盒体有裂缝，表情顽皮，颜色可走奶白加浅暖色点缀
- 莓莓熊：原创旧粉色大熊玩偶，体型较大，动作慢，抱一颗塑料草莓灯，绒面有轻微旧磨损，气质稳重温柔
- 奶昔：原创奶嘴脸队长型玩偶，偏圆润，表情认真，带小哨子和小册子，像玩偶世界的小官僚
- 小玩偶群演：若干不同形态的原创潮玩角色，体型要统一在货架可活动尺度内，适合做夜市群像
- 秦店长：30+，零售管理者，干练，利落短发或整洁发型，手持平板，气场偏压迫但不邪恶
- 小女孩：6-8 岁，白天顾客，短暂停留角色
- 妈妈：小女孩母亲，白天顾客，干净简洁都市穿着
- 年轻情侣：清晨开门后购买玩偶的顾客，一男一女，气质时尚但日常

## Locations

- 潮玩旗舰店白天版：明亮商业灯光，大面积货架，玻璃橱窗，收银台，盲盒岛，现代商场气质
- 潮玩旗舰店闭店版：灯熄后空间更空，卷帘门关闭，收银区与货架区有静止感
- 盲盒区夜市：由货架缝、小灯串、价签绳、扭蛋壳、贴纸路构成的微缩夜间城市
- 主橱窗：白天是标准陈列，夜里可改造成“打烊以后”主题装置，适合主视觉镜头
- 后台仓库：电脑、库存系统屏幕、打印机、周转箱、狭窄通道
- 旧陈列角：藏在货架后的废弃展示区，堆满断挂钩、裂塑封、旧宣传卡、废价签
- 商场外走廊：仅需少量，服务清晨开门和店长提前到场

## Props

- 退仓板夹：纸质清单夹板，红笔圈出“小牙优先退仓”
- 平板：秦店长手持，显示“零瑕疵橱窗计划”及试播数据
- 小牙外盒：透明罩、压皱盒角、后期可见裂缝升级
- 莓莓熊草莓灯：柔和发光核心道具
- 奶昔小册子：夜巡册或规章册，小尺寸，像一本小条例手册
- 奶昔小哨子：夜间秩序标志性道具
- 电子钟：能清晰显示 11:59 到 12:00，再到 04:59、05:00
- 库存系统屏幕：需要 UI，包含红框弹窗、锁定提示、自动生成退仓码、提前联线巡检
- 标签打印机：高潮时被林麦拔电源的关键装置
- 价签绳：夜市里当跳绳使用
- 扭蛋壳圆桌：夜市核心视觉道具
- 贴纸路：夜市地面装饰，也是童话感来源
- 小卡文案：
  - 挤皱一角，也在等你
  - 晒旧一点，更像被抱过
  - 不是瑕疵，是冒险证据
  - 打烊以后，每个小碰撞都还发光

## Style Base

- 白天风格：商业零售摄影感，冷白灯，规整、标准、对称
- 夜里风格：暖色串灯，微缩城市感，童话夜市，旧物再利用，轻奇幻，合家欢
- 摄影方向：白天多固定与中轴构图，夜里多低机位、轻推进、贴近玩偶尺度
- 情绪底色：温暖、俏皮、不是恐怖奇幻，不走阴森路线
