# Camera Lexicon（导演级运镜术语库）

直接提取 **镜头名称 + 提示词** 写入 Seedance `机位：` / `【电影化动态描述】`。  
解决运镜杂乱、镜头语言无叙事逻辑。

**套用模板：** `【景别】+【运镜名称+提示词】+光影/风格`  
**场景化完整镜方（雾城建立镜等 50 组）：** [MANGA_SHOT_PACK.md](MANGA_SHOT_PACK.md)  
**硬规则：** 单镜复杂运镜 ≤1 种（最多再加轻微手持）；一场戏风格统一，转折再换类。  
**联用：** [分镜规范.md](分镜规范.md) · [CAMERA_EMOTION.md](CAMERA_EMOTION.md) · [CHARACTER_STAGING.md](CHARACTER_STAGING.md) · [COMPOSITION_CORE.md](COMPOSITION_CORE.md) · [EMOTION_ARC_EDIT.md](../../post-production/reference/EMOTION_ARC_EDIT.md)

## 0. Prompt 示例

```
机位：85mm中近景。推近压迫镜头——慢速推进，焦点锁定面部，背景逐渐压缩；浅景深，呼吸可闻，眼神颤动。
```

```
中近景，推近压迫镜头，慢速推进，焦点锁定人物面部，背景逐渐压缩，呼吸可闻，眼神颤动，85mm f/1.8，电影感光影，浅景深。
```

## 一、叙事 & 定格（8）

| # | 名称 | 提示词 | 适配情节 |
|---|------|--------|----------|
| 01 | 推镜头 | 缓慢推进，聚焦主体，压缩环境信息，增强情绪沉浸 | 觉醒、发现线索、情绪递进 |
| 02 | 拉镜头 | 镜头后撤，逐步交代空间关系，释放信息量 | 结局揭晓、关系疏离、命运展开 |
| 03 | 摇镜头 | 水平横向移动视线，引导浏览场景与人物关系 | 空间展示、多人对话、环境铺陈 |
| 04 | 移镜头 | 机位平行移动，保持主体节奏，形成流动叙事 | 跟随行走、过程展示、日常叙事 |
| 05 | 跟镜头 | 持续跟随主体运动，保持行动临场感 | 追逐奔跑、主观行动、任务执行 |
| 06 | 升降镜头 | 垂直升降改变视角层级，强化气势与空间维度 | 登场亮相、场面揭示、权力关系 |
| 07 | 俯拍定格 | 高角度静止构图，强调秩序、孤立与画面设计 | 群像调度、情绪停顿、场景总结 |
| 08 | 特写定格 | 静态特写锁定表情或物件，放大细节与象征 | 情绪爆点、关键道具、结尾余韵 |

## 六、分镜搭配策略

| 类型 | 优先从哪类抽 |
|------|----------------|
| 悬疑 | 情绪镜头 + 动作镜头：俯拍孤立、侧向切入、突停凝视、反打对峙；少用倾斜 |
| 古风文戏 | 环绕、后撤疏离、定格凝视 |
| 武打 | 贴地掠行、节奏点爆发、跟镜、甩镜（单镜仍只选 1 个主运镜） |
| 开场建世界 | 超远景 / 航拍 / 递进式景别 |
| 对话文戏 | 中近景 + 过肩 + 反打；运镜宜稳 |

## 七、避坑

1. **单镜 ≤1 种复杂运镜**（可 + 轻手持），堆 2+ 易崩。  
2. 一场戏运镜风格统一，情绪转折再换类。  
3. 写清轴线侧与画左画右（分镜规范）。  
4. 情绪镜头仍要五官微表演，勿只写运镜名。  
5. 「推镜头」与「推近压迫」选一写全，避免同义重复灌进一句。
