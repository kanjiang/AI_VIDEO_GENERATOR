## 3. 核心动机

### 主旋律 A（明亮版 · 小焰成长 / 决赛）

BPM=132，4/4，D大调

```
| 1  2  3  5 | 6  5  3  2 |
| 1  2  3  5 | 6  7  1' - |
```

说明：上行线条代表“新人加速”，用于训练后半段、顿悟和决赛冲刺。

### 主旋律 B（柔情版 · 麦昆 / 传承）

BPM=76，4/4，B小调转D大调

```
| 6,  1  2  3 | 2  1  6, - |
| 5,  6, 1  2 | 3  2  1  - |
```

说明：前半句有告别感，后半句落回 D大调，表达“终点也是起点”。

### 俏皮变体 C（板牙 / 训练失误）

BPM=120，2/4，D大调

```
| 1  1  3  1 | 5  0  5  0 |
| 3  2  1  0 | 1  1  1  - |
```

说明：木块、班卓琴拨弦、短号滑音配合撞草垛和锥桶飞起。

### 尾声变体 D（传承收束）

BPM=72，4/4，D大调

```
| 1  -  2  - | 3  -  5  - |
| 6  -  5  - | 3  -  1  - |
```

说明：钢琴 + 口琴独奏，留下宽阔空间给旁白。

## 4. 分镜配乐表

### Shot 1 — 黄昏独影（0:00–0:10）

| 层 | 内容 |
|---|---|
| 过渡 | 从静默进入，先给 0.5 秒沙漠风声，再进音乐。 |
| 音乐 | 主旋律B前4小节，口琴 pp 独奏，钢琴低音单音点缀；0:08 莎莉靠近时加入极弱弦乐垫。 |
| 节奏 | BPM 76，Rubato，自由呼吸感，避免鼓点。 |
| 音效 | 沙漠风声 0:00 -12dB；远处引擎余音 0:03 -14dB；莎莉轻柔引擎 0:08 -10dB。 |
| 情绪 | “旧冠军站在终点前，但身边还有人相信他会继续前进。” |
| 技法 | 0:08 由 B小调色彩转向 D大调，为“新的起点”铺垫。 |

### Shot 2 — 板牙带新人（0:10–0:20）

| 层 | 内容 |
|---|---|
| 过渡 | Shot 1 的弦乐垫快速收掉，班卓琴两下拨弦切入喜剧节奏。 |
| 音乐 | 俏皮变体C，班卓琴 + 木块 + 单簧管短句；0:16 麦昆说话时音乐降到 p。 |
| 节奏 | BPM 112→120，拖车入画时节奏逐步变密。 |
| 音效 | 扬尘碎石 0:10 -6dB；拖钩解除“clang” 0:12 0dB；板牙引擎突突 0:10–0:14 -8dB；小焰急刹 0:13 -3dB。 |
| 情绪 | “新麻烦被老朋友拖到门口，故事重新热闹起来。” |
| 技法 | 0:17 麦昆台词前插 0.2 秒音乐抽空，让吐槽更清楚。 |

### Shot 3 — 训练蒙太奇（0:20–0:35）

| 层 | 内容 |
|---|---|
| 过渡 | 用拖钩金属尾音直接接第一下鼓点。 |
| 音乐 | 主旋律A碎片化：原声吉他 ostinato + 刷镲鼓组 + 低音提琴 pizzicato；每次失败加入俏皮变体C的木块反拍。 |
| 节奏 | BPM 126，0:29 后加速到 136。 |
| 音效 | 撞草垛 0:22 0dB；板牙“太酷了”下方加短号滑音 0:23 -5dB；奎多换胎嗖嗖 0:26.5 -3dB；锥桶飞起 0:29 -2dB；沙尘旋风 0:32 -6dB。 |
| 情绪 | “失败越来越多，但节奏告诉观众她正在接近答案。” |
| 技法 | 每次失误后音乐不完全停止，只短暂停顿半拍，保持成长动能。 |

### Shot 4 — 向右打，向左转（0:35–0:43）

| 层 | 内容 |
|---|---|
| 过渡 | 训练鼓点在 0:35 前突然抽空，只留低音提琴一声长音。 |
| 音乐 | 麦昆示范时口琴奏主旋律B后半句；小焰成功时主旋律A完整上行，加入弦乐和钟琴。 |
| 节奏 | BPM 96 起，0:39 成功后加速到 132。 |
| 音效 | 漂移沙地摩擦 0:36 -4dB；俯拍轮胎弧线风切 0:37 -8dB；顿悟“叮” 0:38.5 -2dB；成功漂移 0:40 -3dB；板牙欢呼 0:42 -4dB。 |
| 情绪 | “她终于听懂了老冠军真正想教的东西。” |
| 技法 | 0:38.5 使用钟琴 + 竖琴上滑，作为全片的“顿悟闪光”。 |

### Shot 5 — 决赛冲刺（0:43–0:53）

| 层 | 内容 |
|---|---|
| 过渡 | 从 Shot 4 的欢呼声直接切入赛场环境，BGM 全编制进入。 |
| 音乐 | 主旋律A全奏：弦乐快速分解 + 铜管短句 + 鼓组；0:50 过最后一弯时加入圆号长音，0:52 冲线全奏强音。 |
| 节奏 | BPM 148，稳定高速。 |
| 音效 | 观众底噪 0:43–0:53 -12dB；引擎高转 0:43–0:52 -6dB；轮胎尖叫 0:49 -2dB；漂移弹射 0:50 -1dB；冲线轰声 0:52 0dB；彩花喷射 0:52.3 -3dB。 |
| 情绪 | “她不是复制麦昆，而是用自己的方式赢下这一圈。” |
| 技法 | 0:49–0:50 音乐短暂降到 mf，让漂移声冲出来；0:52 全部回归 f。 |

### Shot 6 — 传承之光（0:53–1:00）

| 层 | 内容 |
|---|---|

## 7. 后期混音建议

- BGM 主轨整体压到 `-5dB` 左右，台词出现时自动 duck 到 `-10dB`。
- Shot 5 决赛段可以让 BGM 到 `-3dB`，但 0:49–0:52 给漂移和冲线音效留频率空间。
- 旁白句子（0:05、0:56）下方只保留口琴/钢琴，不要鼓组。
- 最终母带目标：`-16 LUFS`，True Peak 不超过 `-1.5dB`。
