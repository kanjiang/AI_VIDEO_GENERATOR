# Editing Techniques (剪辑手法)

7 种核心镜头切换手法，用于 AI 视频片段在 CapCut/剪映 中的后期组装。

前 4 种（跳切、快切、闪切、叠印）是**纯后期操作**——在编辑器中对已生成的 AI 视频片段进行裁剪、重组、叠加。后 3 种（离切、平行蒙太奇、交叉剪辑）同时影响**提示词设计**和**后期编排**——需要在 AI 生成阶段就规划好素材，然后在后期组装。

---

## 1. 跳切 (Jump Cut)

**原理：** 去掉画面中多余的动作和停顿，跳过无效时间，直接拼接关键画面。  
**效果：** 加快节奏、提高信息密度与完播率。  
**本质：** 同一主体/场景中打破连续时间线，只留核心节点。

**有意 vs 无意：** 有意跳切是手法（景别/角度差够大）；同角度微差「闪一下」是事故 → [ai-footage-qa.md](ai-footage-qa.md) / [分镜规范.md](../../shotlist-builder/reference/分镜规范.md) §H。

**适用场景：** 悬疑提速、武打节点、Vlog/科普去过程；**抒情长情绪慎用**。

### 两大实战场景

| 场景 | 做法 |
|------|------|
| 同场换景别 | 全景→中景→近景快速切（可叠递进式） |
| 同主体抓节点 | 抬手切特写、关门切全景等动作关键瞬间 |

### 分镜前置

写 prompt 时标注 `跳切节点`，只生成可跳的核心画面，减少后期废片。规范见分镜规范 §H。

### CapCut 操作

1. 将完整 AI 视频片段拖入时间线
2. 定位到无效段落的起点，按 `S` 分割
3. 定位到无效段落的终点，再按 `S` 分割
4. 选中中间的无效片段，按 `Delete` 删除
5. 后段自动前移，形成跳切
6. 可选：切点对齐鼓点/环境音

### 参数建议

| 参数 | 值 | 说明 |
|---|---|---|
| 跳切保留段时长 | 通常 ≥0.5–0.8秒 | 以能看清信息为准；过碎会懵 |
| 连续跳切数量 | 建议 ≤5 段一组 | 超过易丢空间感；可分组「三画面一组」 |
| 跳切间画面变化 | 景别或角度明显差 | 变化太小=无意跳切感 |

### Tips

- 优先切在**关键动作节点**（抬手、关门、亮证），或动作自然断点
- AI 常见 1–2 秒启动静止：直接掐掉
- 紧张快跳、抒情慢跳或不用；配鼓点更咬节奏
- 保持故事逻辑：不能为快而快

## 2. 快切 (Quick Cut)

**原理：** 用大量时长极短的画面快速衔接，每段画面仅 0.2-0.5 秒。

**效果：** 强烈的节奏感、冲击力和氛围感。

**适用场景：** 运动剪辑、产品展示、快剪视频、预告片等需要提升情绪的内容。

### CapCut 操作

1. 准备多段 AI 视频素材（建议 ≥ 8 段）
2. 将所有素材拖入时间线
3. 逐段裁剪，每段只保留 0.2-0.5 秒的**最佳瞬间**
4. 按叙事或视觉逻辑排列顺序
5. 在"音频"面板添加节奏感强的音乐
6. 微调每段长度，让切点落在音乐鼓点上

### 参数建议

| 参数 | 值 | 说明 |
|---|---|---|
| 单段时长 | 0.2-0.5秒 | 产品展示偏长(0.4-0.5)，运动/情绪偏短(0.2-0.3) |
| 总段数 | 8-20段 | 一个快切序列通常持续 3-8秒 |
| 画面景别变化 | 每段不同 | 大景-中景-特写-大景交替，禁连续相同景别 |

### Tips

- 快切序列的**前后**各需要一个 ≥ 2秒的稳定镜头做"呼吸"，否则全片都是快切会让观众疲劳
- AI 生成素材时，专门生成"快切素材段"——每段 3-5秒，后期再切成 0.2-0.5秒片段
- 避免快切中出现人脸特写——极短时长下人脸会产生"恐怖谷"效果

## 3. 闪切 (Flash Cut)

**原理：** 短时间内用多个画面快速切换，传递关键信息和情感冲击。与快切类似但更极端，常搭配闪白/闪黑。

**效果：** 快速传递核心情绪，制造心理冲击。

**适用场景：** 情绪爆发（回忆涌上、创伤闪回）、广告片高潮、MV 副歌段。

### CapCut 操作

1. 准备 3-6 段代表核心情绪的 AI 视频片段
2. 每段裁剪到 0.1-0.3秒
3. 在每段之间插入**闪白转场**（时长 0.05-0.1秒）
4. 路径：转场 → 基础 → 闪白 → 时长设为 2-3帧
5. 整个闪切序列总时长控制在 1-3秒

### 参数建议

| 参数 | 值 | 说明 |
|---|---|---|
| 单段时长 | 0.1-0.3秒 | 比快切更短 |
| 闪白/闪黑间隔 | 2-3帧(0.07-0.1秒) | 太长会变成淡入淡出 |
| 序列总时长 | 1-3秒 | 超过3秒会失去冲击力 |
| 段数 | 3-6段 | 少于3段不够密集，多于6段信息过载 |

### Tips

- 闪切的每一帧都要传递**不同的信息**——禁止放相似画面
- 闪切前后各需 ≥ 1秒的静止/缓慢镜头做反差
- 搭配音效（心跳、金属撞击、电流声）效果翻倍
- 也可参考 `text-effects.md` 的 Effect 5（全屏闪光转场）配合使用

## 4. 叠印 (Superimposition / Double Exposure)

**原理：** 将两个或多个画面叠加在一起，形成新的视觉效果。

**效果：** 表现回忆、梦境、幻想等非现实场景，或制造艺术化的视觉碰撞。

**适用场景：** 文艺片、情感片、回忆段落、MV、个人表达类内容。

### CapCut 操作

#### 方法 A：混合模式叠加

1. 将主画面拖入主轨道
2. 将叠加画面拖入**上方的叠加轨道**（画中画）
3. 选中叠加层 → 混合模式 → 选择 `滤色`（亮部叠加）或 `正片叠底`（暗部叠加）
4. 调整叠加层透明度（建议 40-60%）
5. 可添加关键帧让透明度从 0% 渐变到目标值，实现渐入效果

#### 方法 B：蒙版叠加（精细控制）

1. 主画面在主轨道
2. 叠加画面在上方轨道
3. 选中叠加层 → 蒙版 → 选择形状蒙版或手绘蒙版
4. 调整蒙版范围，只让叠加画面出现在特定区域（如人物轮廓内）
5. 蒙版羽化值设 15-30，避免硬边缘

### 参数建议

| 参数 | 值 | 说明 |
|---|---|---|
| 叠加层透明度 | 40-60% | 低于40%看不清，高于60%遮挡主画面 |
| 混合模式 | 滤色(回忆/梦境) / 正片叠底(暗调) / 柔光(自然) | 按情绪选择 |
| 渐入时长 | 0.5-1.5秒 | 叠印不要突然出现 |
| 渐出时长 | 0.5-1.5秒 | 同上 |
| 蒙版羽化 | 15-30 | 硬边缘会破坏梦幻感 |

### Tips

- 叠印的两层画面**色调要协调**——一暖一冷的叠印容易脏
- 人物特写 + 风景广角 是最经典的叠印组合（人物在风景中若隐若现）
- AI 生成叠印素材时，可以专门生成"纯背景/纯纹理"段，后期叠上去
- 叠印段落建议配柔和、缓慢的音乐，禁快节奏

### Prompt-level alternative

某些叠印效果也可以直接在 AI 提示词中实现，无需后期：

```
【电影化动态描述】画面双重曝光效果——前景为人物面部特写（透明度50%），背景为城市天际线夜景，两层画面叠加融合，人物轮廓内可见城市灯火。
```

但后期叠加的控制精度更高（可调透明度、可加蒙版），推荐复杂叠印在后期完成。

## 5. 离切 (Interrupted Cut / Smash Cut)

**原理：** 打断当前连贯运动的画面，动作未完成就直接切换下一个镜头。

**效果：** 制造悬念，给观众留下遐想空间。

**适用场景：** 预告片、悬疑片、剧情反转等需要引导观众思考的内容。

### CapCut 操作

1. 找到动作的**最高张力点**（拳头即将击中、门即将关上、角色即将转身）
2. 在张力点按 `S` 分割
3. 删除张力点之后的所有画面（动作完成部分）
4. 直接接入下一个完全不同的场景

### 与提示词的关系

离切的关键在于**AI 生成时就要让动作在正确的位置中断**。参见 `PROMPT_PATTERNS.md` 的 `【尾帧转场】§11.2 动作剪辑`——在提示词中设计"动作未完成"的尾帧。

如果 AI 生成的视频中动作已经完成，后期也可以用：在动作完成前的帧分割 → 删除后段 → 接入新场景。

### Tips

- 离切点选在**观众最想看到结果的瞬间**——越接近结果、越不给看，悬念越强
- 离切后接入的画面要**完全不同**（不同场景、不同角色），否则看起来像跳切
- 连续使用离切（3次以上）可以制造极强的不安感，适合预告片

## 6. 平行蒙太奇 (Parallel Montage)

**原理：** 两条或多条不同场景、不同地点的故事线交替剪辑，且故事线时间同步推进。

**效果：** 丰富剧情，让叙事更立体，暗示因果关系或对比关系。

**适用场景：** 多线叙事的剧情片、纪录片、Vlog。

### CapCut 操作

1. 分别准备线 A 和线 B 的 AI 视频片段
2. 按时间顺序排列：A1 → B1 → A2 → B2 → A3 → B3...
3. 每段时长 3-8秒，保持节奏均匀
4. 交替点选在**自然停顿处**（动作完成、台词结束、情绪到达）
5. 可用音乐/音效做跨线桥接——同一首音乐贯穿 A、B 两线

### 参数建议

| 参数 | 值 | 说明 |
|---|---|---|
| 单段时长 | 3-8秒 | 两线段长尽量接近，节奏对称 |
| 交替频率 | 每 3-8秒切换一次 | 太快会混乱，太慢会忘记另一条线 |
| 高潮段加速 | 逐渐缩短每段 | 从8秒→5秒→3秒→2秒，制造紧迫感 |
| 线数 | 2-3条 | 超过3条线普通观众难以跟踪 |

### 与提示词/剧本的关系

平行蒙太奇需要在**剧本阶段**就设计好两条线的时间同步关系。参见 `shotlist-builder/PROMPT_DENSITY.md` 中新增的蒙太奇编排规则。

AI 生成时，两条线的视频分别独立生成（各自有完整的场景、角色、光影），后期交替剪辑。

### Tips

- 两条线要有**视觉区分**（不同色调、不同景别、不同光影），否则观众分不清在看哪条线
- 交替点要有**信息钩子**——切走时留一个悬念，回来时给答案（或新的悬念）
- 最终两条线**必须交汇**或**产生对比结论**，否则平行蒙太奇没有意义

## 7. 交叉剪辑 (Cross-Cutting)

**原理：** 多条看似无关的画面交替切换，最终交汇碰撞。与平行蒙太奇的区别是：平行蒙太奇的线从一开始就明确相关；交叉剪辑的线看似无关，到最后才揭示关系。

**效果：** 制造紧张感，拉高悬念，最终碰撞时产生强烈冲击。

**适用场景：** 动作片、悬疑片、追逐戏、反转剧情。

### CapCut 操作

操作流程与平行蒙太奇相同，区别在于**节奏设计**：

1. 开始阶段：每段 5-8秒，节奏缓慢，让观众分别认识每条线
2. 中段：每段 3-5秒，节奏加快，暗示线之间有联系
3. 高潮段：每段 1-3秒，快速交替，线即将碰撞
4. 碰撞点：所有线汇合到同一画面，用 ≥ 3秒的长镜头收尾

### 参数建议

| 参数 | 值 | 说明 |
|---|---|---|
| 开始段时长 | 5-8秒 | 建立各条线 |
| 中段时长 | 3-5秒 | 暗示联系 |
| 高潮段时长 | 1-3秒 | 碰撞前最短 |
| 碰撞收尾 | ≥ 3秒 | 给观众消化冲击的时间 |
| 节奏递减比 | 约 2:1 | 每轮切换时长约为上轮的一半 |

### 与提示词/剧本的关系

交叉剪辑的素材同样需要分别独立生成。关键是**碰撞点的画面**——这个镜头需要在提示词中同时包含之前各条线的元素。

### Tips

- 交叉剪辑的核心是**节奏递减**——必须越来越快，给观众"即将发生什么"的感觉
- 碰撞点的画面要**足够震撼**，对得起之前积累的悬念
- 音效是交叉剪辑的核心工具——在切换点使用相同音效（心跳、时钟）贯穿各条线

## 8. 虚实 / 时空转场三招（开场常用）

结构来源见 `shotlist-builder/reference/VISUAL_LANGUAGE_SIX.md` §6。不抄具体影片镜头。

| 招 | 做法 | AI 注意 |
|----|------|---------|
| **匹配前推速度** | 内外景色调可跳，推/拉速度曲线尽量一致 | 两段生成时写明同一推镜秒速（如「2秒内推近至中景」） |
| **动作连续剪** | 按键→开盖→投掷等因果动作串场景 | 每段尾帧停在动作中段，下段首帧接下一动作（见离切/尾帧设计） |
| **声音桥梁** | 配乐骤停，用笑声/门响/呼吸接幻想→现实 | 剪映里声轨可先于或同于画切；与 EMOTION_ARC 静默衔接 |

## 手法组合速查

| 情绪需求 | 推荐组合 | 示例 |
|---|---|---|
| 紧凑叙事 | 跳切 + 偶尔快切 | Vlog、日常剧情 |
| 极致冲击 | 快切序列 + 闪切高潮 | 运动剪辑、产品发布 |
| 情感回忆 | 叠印 + 闪切(回忆涌入) | 文艺片、情感MV |
| 悬疑紧张 | 离切 + 交叉剪辑 | 悬疑短剧、预告片 |
| 多线叙事 | 平行蒙太奇 → 交叉剪辑(高潮) | 复杂剧情片 |
| 节奏控制 | 长镜头 → 快切 → 长镜头 | 广告片、形象片 |

## AI 视频专项注意

1. **AI 片段有"启动延迟"：** 多数 AI 生成的视频前 0.5-1秒画面几乎静止，跳切/快切时直接掐掉
2. **AI 片段有"结尾衰减"：** 最后 0.5-1秒动作可能减速或变形，离切时选在衰减前的帧
3. **相同提示词生成的多段素材可用于快切：** 同一提示词生成 3-5 次，每次选最佳 0.3秒，组成快切序列
4. **叠印要用不同风格的素材：** 用 `video-render-quality` 的不同 render profile 生成同一场景的两个版本，叠印后产生风格碰撞
5. **平行/交叉剪辑的各条线要分别生成独立的视频段：** 在 `shotlist-builder` 中为每条线单独生成提示词序列
