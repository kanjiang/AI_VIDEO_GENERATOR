# AIGC 导演级分镜三步法吸收说明

来源：导演级分镜设计实战（找重点 → 找节奏 → 找关系）。

---

## 总判断

| 教程观点 | 本仓库 | 决策 |
|----------|--------|------|
| 每场唯一重点，铺垫快切、重点拉长 | 有钩子/时长规则，缺「场次唯一重点」规划卡 | **吸收** |
| 节奏 = 控制观众心理预期 | `CAMERA_EMOTION`、漫剧 pacing 偏镜头/产品层 | **吸收**为导演层节拍卡 |
| 找关系：前景窥视等提前埋危险 | `COMPOSITION_LIBRARY` 有前景遮挡等 | **吸收**为「爆发前关系镜头」检查项 |
| 避坑：信息重复、节奏平均、无铺垫爆发 | 部分散落 | **吸收**为写 prompt 前三禁 |

不新建独立 skill；落入 `shotlist-builder`，编剧阶段可选用。
