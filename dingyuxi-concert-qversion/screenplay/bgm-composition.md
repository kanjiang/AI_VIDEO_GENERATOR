# 丁禹兮Q版演唱会 — BGM配乐方案

> 本方案使用 `bgm-scoring` skill 方法论生成。Skill 路径：`.claude/skills/bgm-scoring/SKILL.md`

## 总体设定

| 项目 | 参数 |
|------|------|
| 总时长 | ~90秒（含前后留白） |
| 调性 | C大调（温暖明亮），镜头4-5转Am小调（柔情），镜头6回C大调 |
| 基础BPM | 100（中速偏慢，匹配定格动画的顿挫节奏） |
| 核心音色 | 八音盒（celesta/music box）贯穿全片 |
| 辅助音色 | 木琴(glockenspiel)、钢琴、拨弦吉他(pizzicato)、弦乐铺底、竖琴 |
| 情绪关键词 | 手工感、温暖、童真、治愈、有泪有笑 |
| 禁止 | 电子合成器、鼓机、低音炮、说唱、摇滚吉他、任何"大片感"编曲 |

## 核心主题旋律（八音盒主旋律 · "小丁的八音盒"）

以下用简谱标注，八音盒音色演奏：

```
主旋律 A（明亮版 · 用于欢快段）
BPM=100  4/4拍  C大调

| 1  3  5  5 | 6  5  3  1 | 2  3  4  3 | 2 · 1  -  - |
| 1  3  5  5 | 6  5  3  1 | 5  4  3  2 | 1 · -  -  - |

（两句共8小节，约19秒，前4小节为"问"，后4小节为"答"）
```

```
主旋律 B（柔情版 · 用于感动/治愈段）
BPM=80（减速）  Am小调  钢琴+八音盒交替

| 6  1̇  7  6 | 5  -  3  - | 4  3  2  1 | 6̣ · -  -  - |
| 6  1̇  7  6 | 5  3  5  3 | 2  1  7̣  1 | 1 · -  -  - |

（同样8小节，约24秒，旋律线下沉，音符间距拉大，呼吸感更强）
```

```
尾声旋律 C（极慢收束版 · 用于道别+片尾）
BPM=60（极慢）  回C大调  纯八音盒独奏

| 5 · -  3 · - | 1 · -  -  - | 5 · -  3 · - | 1 · -  -  - |

（4小节，约16秒，只保留主旋律骨干音，每个音之间大量留白，像八音盒快转完了）
```

## 逐镜头编曲详解

### 镜头 0 — 片头：黏土之手（0:00 - 0:05）

| 层 | 内容 |
|---|---|
| 音乐 | 静默2秒 → 单声八音盒"叮"一声（C5）→ 停顿1秒 → 再"叮咚"两声（E5 G5）→ 像有人在上发条 |
| 音效 | 黏土按压"啪嗒"、手指捏泥"咕唧"、小灯亮起时最后一声"叮"和八音盒第一个音重合 |
| 情绪 | 安静 → 期待 |
| 技法 | 不要急，这5秒只有3-4个音符，留白是重点 |

---

### 镜头 1 — 开场唱歌（0:05 - 0:14）

| 层 | 内容 |
|---|---|
| 音乐 | **主旋律A前4小节**正式启动，八音盒主奏。第2小节加入木琴(glockenspiel)叠双音增加厚度。第3小节加入轻柔的拨弦吉他(pizzicato strings)做低音伴奏：|1 - 5 - |1 - 5 - |，形成简单的I-V跳动 |
| 节奏 | BPM=100，每拍"叮—叮—叮—叮"的八音盒匀速节奏，匹配定格动画的逐帧感 |
| 音效 | 远场欢呼声在第1秒轻柔混入，3秒后渐弱让位给音乐 |
| 情绪 | 明亮、开心、"演唱会开始了！" |

---

### 镜头 2 — 人形八音盒旋转（0:14 - 0:23）

| 层 | 内容 |
|---|---|
| 音乐 | **主旋律A后4小节**（"答"句），八音盒主奏。⚠️关键设计：每当Q版丁禹兮转到一面观众时（约每2.25秒一次），加一声高音"叮"（C6），像八音盒转盘上的突起敲击金属齿。形成"旋律走着走着—叮！—旋律继续—叮！—继续—叮！—叮！"的节奏 |
| 伴奏 | 拨弦吉他继续，加入竖琴琶音 arpeggio 每小节扫一次：| 1 3 5 1̇ |，像水波荡漾 |
| 音效 | 八音盒底座轻微"咔嗒咔嗒"机械转动声，与BPM同步 |
| 情绪 | 可爱中带着一丝感动，"他真的在为每一面的观众转" |

---

### 镜头 3 — 切蛋糕分享（0:23 - 0:32）

| 层 | 内容 |
|---|---|
| 音乐 | **主旋律A再走一遍前4小节**，但换音色：八音盒降为背景层（音量-6dB），主旋律交给**钢琴右手**演奏（音色更温暖更人情味）。左手钢琴加简单和弦伴奏：| C - Am - | F - G - | |
| 新元素 | 第3小节（吹蜡烛瞬间）：所有乐器静默0.5秒 → 只剩一声"呼"（吹气声）→ 停顿 → 然后一声清脆的竖琴"叮铃"重启音乐，同时加入温柔的弦乐长音铺底（小提琴+中提琴 pp） |
| 音效 | 蛋糕刀"咔嚓"轻响，掌声从第6秒开始轻柔混入 |
| 情绪 | 温暖、用心、"他在把甜的分给你们每一个人" |

---

### 镜头 4 — 感动落泪跺脚（0:32 - 0:43）⚠️情绪转折点

| 层 | 内容 |
|---|---|
| 过渡 | 镜头3结尾的弦乐长音不收，直接连入镜头4。BPM从100 → 渐慢至80（2秒内完成 ritardando） |
| 前半（0:32-0:37）| **转入主旋律B**（Am小调柔情版）。第一拍起，八音盒+钢琴齐奏，但音量极轻（pp），像有人在心里哼。弦乐铺底从长音变为缓慢的上行叹息音型：|6̣ - 1 - | 2 - 3 - |，每个音之间留呼吸 |
| 听到生日歌 | 第3秒起，远处传来模糊的合唱"祝你生日快乐"（人声混响很重，像从四面观众席飘来，不需要清晰歌词，只要旋律轮廓），和主旋律B形成双线交织 |
| 后半（0:37-0:43）| ⚠️**跺脚节点**：音乐突然抽空1秒 → 只剩心跳般的低音大鼓"咚—咚—咚"（和跺脚同步，BPM=120的三连击）→ 每声跺脚后有0.3秒完全静默 → 然后八音盒用极弱音量弹出主旋律B的最后两个音 | 1 · - - - |（像一句没说完的话） |
| 音效 | 抽泣声（轻微、不夸张）在第5秒混入；跺脚"咚咚咚"要有黏土质感（闷而软，不是金属硬地面） |
| 情绪 | 心疼、"他急得跺脚，因为他觉得他给的还不够" |

---

### 镜头 5 — 小丁不哭 · 粉丝抱抱（0:43 - 0:54）⚠️全片最温暖

| 层 | 内容 |
|---|---|
| 过渡 | 镜头4末尾的八音盒悬停音不消失，像一口气没呼完 |
| 第一拍（0:43-0:46）| 小粉丝跑来——加入"哒哒哒哒"轻快小脚步声（用木琴快速十六分音符模拟：|5656 5656|，像小人跑步），钢琴右手轻轻弹出主旋律B的前两个音 |6 1̇|，试探性地，像问"可以抱抱你吗？" |
| 第二拍（0:46-0:49）| 粉丝抱住——⚠️**全片编曲最厚处**：弦乐铺底突然从pp → mp展开（小提琴+大提琴+中提琴三层），八音盒和钢琴齐奏**主旋律B完整后4小节**（"答"句），竖琴琶音在每小节头扫一次。音量从极轻到温暖饱满，像一个拥抱慢慢收紧 |
| 第三拍（0:49-0:51）| 蹲下团抱——BPM回升至90，主旋律B最后一个音 |1 · -|  落在长音上不走，弦乐在下方做一个大的上行解决：|6̣ - 1 - 3 - 5 - | → 最终落在C大调的I级和弦上（⚠️从Am回到C大调，调性回归=情绪从心疼回到温暖） |
| 第四拍（0:51-0:54）| 俯拍星光——纯八音盒独奏主旋律A最后两个音 | 1 · - - - |（和镜头4末尾呼应，但这次音色明亮、从容，是被接住之后的安心）。加入微弱的风铃声（wind chimes）做空间延伸 |
| 音效 | 拥抱时一声柔软的"扑"（布偶靠在一起的声音）；童声轻轻说"小丁不哭"（只在弦乐间隙出现，不抢旋律） |
| 情绪 | 被接住的温暖，"你不用完美，我们爱的就是你" |

---

### 镜头 6 — 彩带缠脖翻车（0:54 - 1:01）⚠️情绪急转

| 层 | 内容 |
|---|---|
| 过渡 | 镜头5结尾的风铃声还在回响时——一声滑稽的"啵"打破宁静 |
| 音乐 | ⚠️**回到主旋律A**（C大调明亮版），BPM回到100甚至105（稍加速=轻快俏皮）。但编曲完全变了：八音盒做主旋律，加入**木鱼/木块敲击**做节奏（"嗒-嗒嗒-嗒"，像定格动画的机械节拍器），拨弦吉他(pizz)在低音做跳跃伴奏 |1 · 5 · |1 · 5 · | |
| 彩带缠住瞬间 | 主旋律突然"卡带"——同一个音重复3次 |3 3 3|（像八音盒齿轮卡住了），然后"啪"一声恢复正常继续走 |
| 放弃挣扎 | 旋律正常收束，最后加一声滑音下行的长号/伸缩号"哇——"（卡通喇叭音效，1秒），配合小丁耸肩无奈笑 |
| 音效 | 彩带"沙沙"飘落、缠绕"呲啦"、观众"哈哈"笑声（远场，轻） |
| 情绪 | 从感动直接跳到搞笑，观众破防一笑 |

---

### 镜头 7 — 酒店门口道别（1:01 - 1:10）

| 层 | 内容 |
|---|---|
| 过渡 | 镜头6的笑声和"哇——"渐弱，2秒内过渡到安静。加入夜虫"唧——"声铺底 |
| 音乐 | **尾声旋律C**登场（BPM=60极慢，纯八音盒独奏）。只有骨干音 | 5 · - 3 · - | 1 · - - - |，每个音之间3-4秒的沉默。像八音盒快要转完了，发条的力气只剩最后几圈 |
| 握手瞬间 | 八音盒在 |3| 这个音上停顿稍长（1.5秒），然后轻柔的钢琴在八音盒下方弹出一个C大调分解和弦 | 1 3 5 | ← 像一只手接住另一只手 |
| 目送离开 | 八音盒弹出最后一个音 |1|（低八度的C4，比前面所有八音盒音都低），声音自然衰减消失。只剩夜虫声和极远处的一声"晚安"（轻声，混响深） |
| 音效 | 脚步声（去→远），夜虫声，微风声 |
| 情绪 | 安静的珍重，"今天很好，下次再见" |

---

### 镜头 8 — 片尾：八音盒谢幕（1:10 - 1:20）

| 层 | 内容 |
|---|---|
| 过渡 | 镜头7结尾的夜虫声渐弱，1秒静默 |
| 音乐 | ⚠️**主旋律A完整重现一次**（回到BPM=100明亮版），但只用**纯八音盒独奏**，没有任何伴奏乐器——和开场的镜头1形成首尾呼应，但这次听起来更亲切更温柔，因为经历了中间的起伏后回到原点 |
| 八音盒转动 | 配合画面中八音盒底座旋转，音符严格和旋转同步。每转过一个角度敲一个音 |
| 鞠躬瞬间 | 主旋律走到倒数第2个音时——暂停0.8秒（鞠躬定格）——然后落下最后一个音 | 1 · |（明亮的C5，饱满，不衰减）|
| 渐弱收束 | 最后3秒：八音盒声自然衰减，像发条跑完。加入极轻的竖琴泛音 harmonic（高音区 C7）做最后一声"叮"，然后——完全静默 |
| 情绪 | 像把一段美好的记忆装进盒子，盖上盖，放在心里 |

## AI音乐生成提示词（Suno / Udio / 可灵音乐）

如果用AI工具生成BGM，可以直接使用以下提示词：

### 版本A：完整一条生成（推荐先试）

```
[Instrumental] [Music Box] [Orchestral]

A 90-second music box theme for a heartwarming clay stop-motion animation about a concert.

Style: music box melody + piano + soft strings + glockenspiel + harp arpeggios. 
Inspired by Pixar and Studio Ghibli soundtracks. Joe Hisaishi gentle warmth.
No drums, no bass guitar, no synth, no EDM, no vocals.

Structure:
[Intro 0-5s] Single music box notes, sparse, winding up. C major. BPM 100.
[Section A 5-23s] Bright cheerful music box melody, add pizzicato bass and glockenspiel. Light and bouncy, like a toy coming alive.
[Section B 23-32s] Piano takes the melody, music box becomes background. Add gentle string pad. Warmer, like sharing birthday cake.
[Transition 32-35s] Ritardando to BPM 80. Shift to A minor. Strings swell softly.
[Section C 35-43s] Emotional, tender. Piano and music box interweave. A pause at 40s, then three deep heartbeat-like thuds. Music nearly stops.
[Section D 43-54s] Healing climax. Strings bloom from silence, piano restates melody warmly. Music box joins. Modulate back to C major at 51s. Gentle wind chimes. The warmest moment.
[Section E 54-61s] Playful, comedic. BPM back to 105. Music box with wood block percussion. A brief "stuck gear" repetition. Cartoon trombone slide at the end.
[Section F 61-70s] Very slow, BPM 60. Solo music box, sparse notes with long silences. A single piano chord. Night atmosphere.
[Outro 70-90s] Music box replays the opening melody one last time at BPM 100, solo, no accompaniment. Gentle resolution. Final harp harmonic "ding". Silence.

Mood: handmade, warm, innocent, tearful-then-healing, clay animation, toy-like, Ghibli
```

### 版本B：分段生成（更精准控制）

如果一条出不来想要的效果，可以分三段：

**段1：欢快段（0-32秒）**
```
[Instrumental] Bright music box melody in C major, BPM 100. Glockenspiel, pizzicato strings, harp arpeggios. Playful, bouncy, like a toy concert. Pixar animation style. No drums. 32 seconds.
```

**段2：感动段（32-54秒）**
```
[Instrumental] Emotional transition from A minor to C major. Start with slow tender piano + music box duet, BPM 80. Three deep heartbeat thuds at 8 seconds. Then strings bloom warmly, building to a gentle climax. Healing, like being held. Wind chimes at the end. 22 seconds.
```

**段3：收束段（54-90秒）**
```
[Instrumental] Start playful in C major BPM 105 with music box and wood block, brief comedic moment. Then slow to BPM 60 for a lonely solo music box with long pauses. Finally replay opening melody one last time at BPM 100, solo music box, resolving gently. Final harp harmonic. 36 seconds.
```
