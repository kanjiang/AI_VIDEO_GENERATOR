# Storyboard Type Selector (故事板类型选择器)

不同场景需要不同类型的故事板作为 AI 视频生成的参考图。选错类型 = AI 生成时缺少关键控制维度。本文件定义 10 种故事板类型，每种的适用场景、核心功能、生成提示词模板，以及与现有 skill 的关系。

---

## 快速选择表

| 场景类型 | 推荐故事板类型 | 控制维度 | 对应 Skill |
|---|---|---|---|
| 追逐、飙车、高速动作 | ① 全维度分镜 | 动作 + 镜头 + 空间 | `storyboard-table-skill` |
| 做饭、整理、连贯日常动作 | ② 调度分镜 | 动线 + 站位 + 时序 | `SPATIAL_BLOCKING.md` |
| 格斗、拳击、对抗 | ③ 动作分镜 | 力量感 + 冲击力 + 攻防节奏 | `storyboard-table-skill` |
| 校园偶遇、情感互动 | ④ 叙事分镜 | 情绪铺垫 + 互动细节 | `storyboard-table-skill` |
| 街舞、体操、高难度技巧动作 | ⑤ 动作拆解 | 关键帧分解 + 发力点 | `storyboard-table-skill` |
| 奇幻、史诗、宏大世界观 | ⑥ 导演轨道 | 人物 + 场景 + 镜头三维统一 | `storyboard-table-skill` + `scene-board-skill` |
| 卡通角色、拟人化、动画 | ⑦ 3D 白模 | 角色位置 + 动作 + 空间框架 | 新增类型 |
| 古城、集市、宏大场景全貌 | ⑧ 场景概览 | 整体布局 + 空间逻辑 | `scene-board-skill` |
| 室内设计、功能分区 | ⑨ 场景规划 | 功能区 + 家具摆放 + 动线 | `scene-board-skill` |
| 同一空间多角度展示 | ⑩ 场景固定 | 固定结构 + 多机位角度 | `scene-board-skill` |

## ① 全维度分镜故事板 (Full-Dimension Storyboard)

**适用：** 高速追逐、动作场景、涉及复杂镜头运动的序列。

**核心功能：** 手绘线稿 + 镜头标注，将复杂的动作序列拆解为清晰的镜头序列。重点是 **动作 + 镜头 + 空间** 三个维度同时控制。

**与默认 12-panel 板的区别：** 默认 12-panel 板注重叙事节奏。全维度板的每个面板都必须标注镜头运动方向和速度，适合动作密集的场景。

### 提示词模板

```
**[场景名]全维度分镜故事板提示：**

为故事板创建一个高速动作场景，专注于[核心动作序列]的完整镜头分解。

16:9 故事板表格，12 个电影风格面板。黑白粗糙铅笔线稿。

⚠️每个面板必须包含：
- 手绘动作线稿（人物姿态、运动方向）
- 蓝色箭头标注：摄影机运动方向和类型（推/拉/横移/跟拍/俯冲）
- 红色箭头标注：主体运动方向和速度（快/中/慢）
- 面板左下角：镜头焦距（24mm/35mm/50mm/85mm）和景别

[描述完整动作序列——从起始到高潮到收束，每3-4个面板为一个动作阶段]

环境只保留空间定位必需元素。动作势能和镜头运动是核心，不是细节渲染。

标注系统：红色箭头=主体运动方向及速度；蓝色箭头=摄影机运动；绿色=景别标注；黑色文本=面板编号和简短动作描述。
```

## ② 调度分镜故事板 (Blocking / Scheduling Storyboard)

**适用：** 连贯的日常动作序列（做饭、收拾、换装等）。

**核心功能：** 极简火柴人 + 动线标注，规划人物完整的动作流程。重点是 **动线连续性** 和 **时序逻辑**——从A动作到B动作的过渡必须没有逻辑断层。

**与现有 `SPATIAL_BLOCKING.md` 的关系：** 这就是 `SPATIAL_BLOCKING.md` 定义的俯视调度图的故事板形式。当场景需要的是连贯动线而非镜头表现时使用。

### 提示词模板

```
**[场景名]调度分镜故事板提示：**

创建一组调度分镜，展示[人物]在[空间]中完成[完整动作流程]的全过程。

16:9 故事板格式，6-8 个面板（每个面板一个关键动作步骤）。
⚠️风格：极简火柴人/简笔画，不需要面部细节，重点是身体动态和位置关系。

每个面板标注：
- 黑色虚线箭头：人物移动路径（从上一面板到本面板的空间转移）
- 红色圆点：关键交互点（开冰箱、拿东西、放置物品的具体位置）
- 面板底部：简短动作描述 + 预计时长

[描述完整动作流程——从起始状态到结束状态，按时间顺序排列]

⚠️动作必须逻辑连贯——人物不能凭空从A位置跳到C位置，中间的B步骤必须画出来。
```

## ③ 动作分镜故事板 (Action / Combat Storyboard)

**适用：** 对抗性强的动作场景（格斗、拳击、武术、追打）。

**核心功能：** 手绘分镜 + 力量标注，拆解攻防过程。重点是 **冲击力** 和 **攻防节奏**——每一拳每一腿的发力方向、受力方向、反应动作都必须清晰。

**与①全维度板的区别：** ①侧重"镜头怎么拍"，③侧重"拳怎么打"——人体力学和攻防逻辑是核心。

### 提示词模板

```
**[场景名]动作分镜故事板提示：**

为故事板创建一个对抗性动作场景，专注于[角色A]与[角色B]之间的[格斗/追打/武术]对抗。

16:9 故事板表格，12 个电影风格面板。黑白粗糙铅笔线稿。

⚠️每个面板必须体现：
- 人物的发力方向（红色粗箭头标注攻击方向）
- 受力方向和反应动作（橙色箭头标注受击后身体运动方向）
- 身体重心变化和站位关系
- 力量感通过线条粗细和速度线表现——重击用粗线、快击用细密速度线

[描述完整攻防过程——起手式→攻击→防御/闪避→反击→...→终结动作]

镜头配合动作节奏：
- 全景建立站位关系
- 中景展示攻防交换
- 特写放大关键命中瞬间（拳头接触面部的变形、衣物飘动）
- 慢动作面板用放射状速度线标注

环境极简——只保留地面和大致空间边界。人物身体力学是核心。
```

## ④ 叙事分镜故事板 (Narrative Storyboard)

**适用：** 情感类、剧情类场景（偶遇、告白、道别、日常温馨互动）。

**核心功能：** 细腻手绘 + 情绪标注。重点是 **人物互动细节** 和 **氛围铺垫**——每个面板传递情绪，不是传递动作。

**与默认 12-panel 板的区别：** 默认板是通用型。叙事板在每个面板旁添加情绪标注（害羞、紧张、犹豫、释然等），让 AI 生成时有情绪方向。

### 提示词模板

```
**[场景名]叙事分镜故事板提示：**

为故事板创建一个情感叙事场景，专注于[角色之间的关系/情绪变化]。

16:9 故事板表格，12 个电影风格面板。黑白粗糙铅笔线稿。

⚠️每个面板旁标注情绪关键词（紫色文字）：
如 [害羞]、[犹豫]、[心跳加速]、[释然]、[不舍] 等。
面板的构图和人物姿态必须服务于标注的情绪——不能标注"害羞"但画出一个自信站姿。

[描述情感发展弧线——从初始状态（陌生/紧张/平静）到终点状态（亲密/释然/离别）]

镜头语言服务情绪：
- 远景/全景：建立两人距离感和空间关系
- 中景：日常互动、自然动作
- 特写：情绪转折点（低头、抿唇、眼神闪烁、手指动作）
- ⚠️情绪转折必须用特写（参考 CAMERA_EMOTION §10.5）

环境细节只保留情绪相关元素（飘落的花瓣、窗边的光线、雨滴、远处的钟声暗示）。
```

## ⑤ 动作拆解故事板 (Action Decomposition Board)

**适用：** 复杂技巧性动作（街舞、体操、特技、手工制作的精细步骤）。

**核心功能：** 将一个复杂动作拆解为 8–12 个关键帧，每帧标注身体位置和发力点。不是"镜头怎么拍"，而是 **"动作怎么做"**——让 AI 精准还原复杂运动。

**与①和③的区别：** ①侧重镜头运动，③侧重攻防逻辑，⑤侧重 **单一动作的关键帧分解**——一个旋风腿怎么起跳、怎么旋转、怎么落地。

### 提示词模板

```
**[动作名]动作拆解故事板提示：**

创建一组动作拆解关键帧，将[复杂动作名称]分解为[8-12]个关键姿态。

16:9 布局，[8-12] 个面板按时间顺序排列。黑白线稿。

⚠️每个面板要求：
- 清晰的身体姿态——关节角度、重心位置、四肢方向必须精准
- 红色圆点标注：发力点（哪个肌肉/关节在主动发力）
- 蓝色弧线标注：运动轨迹（肢体的旋转弧度、移动路径）
- 面板下方：关键帧编号 + 动作描述（如"起跳——左腿蹬地，右腿提膝"）
- 相邻面板之间用灰色虚线箭头连接，表示动作衔接

[描述完整动作——从准备姿势到起始、加速、高潮姿态、减速、落地/收束]

⚠️关键：面板之间的姿态过渡必须在物理上合理——人体不能从A姿态跳到C姿态而跳过中间的过渡姿态B。
```

## ⑥ 导演轨道故事板 (Director Track Storyboard)

**适用：** 奇幻、史诗、世界观宏大的场景——需要同时控制人物形象、场景风格和镜头运动。

**核心功能：** 三轨合一——**人物设定轨 + 场景设定轨 + 镜头轨道轨**在同一张故事板上同时可见。解决的问题：奇幻场景中 AI 容易"人物崩坏"、"场景风格跳变"、"镜头脱离空间"。

**与现有 skill 的关系：** 等于把 `storyboard-table-skill`（人物+镜头）和 `scene-board-skill`（场景锚定）合并在一张板上。当场景的三个维度都不稳定时使用。

### 提示词模板

```
**[场景名]导演轨道故事板提示：**

创建一张三轨合一的导演故事板，同时控制人物、场景和镜头。

16:9 布局，分为三个水平带：
- ⚠️上带（人物轨）：2-3 个角色关键姿态，锁定本场景中角色的视觉身份（面部、服装、道具、身体比例）。风格：简约角色速写。
- ⚠️中带（场景轨）：1 个宽幅场景概览，锁定环境结构、灯光方向、空间纵深。风格：线稿 + 简单明暗。
- ⚠️下带（镜头轨）：4-6 个小面板，按时间顺序展示镜头序列。每个面板标注镜头焦距、运动方向、景别。

三轨之间用虚线连接，表示"这个角色出现在这个场景的这个镜头中"。

[描述人物设定要点]
[描述场景结构和氛围]
[描述镜头序列和运动]

⚠️三轨的视觉风格必须统一——人物轨的角色和场景轨的环境必须看起来属于同一个世界。
```

## ⑦ 3D 白模故事板 (3D Whitebox Storyboard)

**适用：** 卡通角色、拟人化角色、动画场景——需要精准控制角色在 3D 空间中的位置和动作。

**核心功能：** 用 3D 简模（白色/灰色基础模型）搭建角色和场景的 **空间骨架**，再用这个骨架作为 AI 参考图。AI 在骨架上"着色"生成最终画面——角色位置、朝向、动作被骨架锁定，不会崩坏。

**现有 skill 中无对应。** 这是新增类型。

### 工作流

1. 在 Blender / Maya / 免费3D 工具中搭建极简白模场景（方块=建筑，球体=树，简单人形=角色）
2. 调整角色位置、朝向、简单姿态
3. 设置摄影机角度，渲染出白模截图
4. 将白模截图作为 AI 视频生成的 **参考图/控制图**

### 提示词模板（用于 AI 从白模生成最终画面）

```
**基于3D白模的视频生成提示：**

参考图为 3D 白模截图，展示[场景描述]中[角色数量]个角色的空间位置和基本姿态。

⚠️严格保留参考图中的以下空间信息：
- 角色的位置关系（前后左右距离）
- 角色的朝向和基本姿态
- 摄影机角度和景别
- 环境的大致结构（地面、墙面、道具位置）

在此空间骨架的基础上生成：
[最终风格描述——Pixar 3D 动画/写实/古风水墨等]
[角色外观描述——覆盖白模的表面细节]
[环境材质描述——覆盖白模的空间结构]
[灯光描述]

⚠️禁止改变参考图中角色的相对位置、朝向和基本姿态——白模是空间骨架，不是风格参考。
```

### Tips

- 白模不需要精细——越简单越好，AI 容易"读懂"简单的几何关系
- 对于拟人化角色（如 Momo 小汽车）特别有用——用方块+圆柱搭出基本车型，锁定位置和朝向
- 搭配 `@资产名` 角色身份板一起使用：白模锁位置，身份板锁外观

## ⑧ 场景概览故事板 (Scene Overview Board)

**适用：** 宏大场景的整体布局（古城全景、集市、战场、港口）。

**核心功能：** 线稿描绘场景的 **整体空间逻辑**——建筑位置、道路走向、水域、地形高低。重点是让 AI 理解宏观空间关系，避免生成时出现"建筑穿帮"、"道路不通"的问题。

**与 `scene-board-skill` 的关系：** 场景概览是 `scene-board-skill` 的一个特化变体——当场景规模大、元素多时，用线稿先锁定布局，再让 AI 填充细节。

### 提示词模板

```
**[场景名]场景概览故事板提示：**

创建一张 16:9 的场景概览线稿图，展示[场景名]的整体空间布局。

⚠️风格：建筑/城市规划式线稿——清晰的结构线条、标注文字、无渲染、无材质。
类似建筑平面效果图的透视线稿。

必须包含：
- 主要建筑/地标的位置和大致体量
- 道路/通道的走向和宽度
- 水域/地形的高低关系
- ⚠️入口和出口的明确标注
- 关键区域用文字标签标注（如"主街道"、"码头"、"城门"、"市集区"）

[描述场景的具体空间布局]

⚠️空间逻辑优先于美观——这张图的目的是让 AI 理解"什么在哪里"，而不是画出一张漂亮的概念图。

可选标注：摄影机可能的取景方向（蓝色三角标注），人物主要活动区域（红色虚线圈出）。
```

## ⑨ 场景规划故事板 (Scene Planning Board)

**适用：** 室内空间的功能分区和家具摆放（办公室、餐厅、厨房、工作室）。

**核心功能：** 规划室内的 **功能分区** 和 **动线逻辑**——让 AI 生成的室内场景布局合理、家具位置有使用逻辑。

**与 `scene-board-skill` 的关系：** 是 `scene-board-skill` 的室内特化变体。当场景是室内且涉及多个功能区时使用。

### 提示词模板

```
**[空间名]场景规划故事板提示：**

创建一张 16:9 的室内空间规划图，展示[空间名]的功能分区和家具布局。

⚠️布局形式：俯视平面图（top-down floor plan）+ 一张 45° 透视速写。

俯视平面图要求：
- 墙体用粗黑线，门窗用标准建筑符号
- 家具用简化图形（矩形=桌子、圆形=椅子、L形=沙发）
- 功能区用不同灰度或虚线框分区，文字标注区域名称
- 人物动线用红色虚线箭头标注（从入口到各功能区的移动路径）

45° 透视速写要求：
- 展示空间的纵深感和家具的高度关系
- 灯光方向标注（橙色箭头）
- 窗户位置和自然光方向

[描述具体的功能分区和家具摆放]

⚠️布局必须符合使用逻辑——厨房动线（冰箱→案台→灶台→出餐口）、办公室动线（入口→工位→会议区）等。
```

## ⑩ 场景固定故事板 (Fixed-Scene Multi-Angle Board)

**适用：** 同一空间需要多个机位展示（厨房的正面/侧面/俯视，客厅的全景/中景/特写）。

**核心功能：** 先确定空间的 **固定结构**，然后标注 **多个拍摄角度**，确保同一场景在不同镜头中风格统一、空间连贯。解决的问题：AI 在同一空间的不同角度生成中容易"换了个地方"。

**与 `ai-footage-qa.md` 的关系：** 这是从 **源头预防** QA 清单中"越轴"和"空间不连贯"问题的最佳工具。

### 提示词模板

```
**[空间名]场景固定故事板提示：**

创建一张 16:9 的场景固定故事板，展示[空间名]从多个角度拍摄的效果。

⚠️布局：
- 中央大图：空间的主视角（最常用的拍摄角度），完整展示空间结构
- 围绕中央图的 4-6 个小面板：同一空间的不同拍摄角度

每个小面板标注：
- 摄影机位置（在中央图上用编号圆点标注对应的机位）
- 镜头焦距和景别
- 拍摄方向（蓝色箭头从机位圆点指向拍摄方向）
```

## 类型组合使用指南

复杂场景通常需要组合 2–3 种故事板：

| 项目类型 | 推荐组合 |
|---|---|
| 动作片 | ① 全维度分镜 + ⑩ 场景固定（锁定打斗场景的空间） |
| 家庭剧 | ④ 叙事分镜 + ⑨ 场景规划（锁定室内布局） |
| 动画片 | ⑦ 3D 白模 + ① 全维度分镜（白模锁位置，分镜锁镜头） |
| 奇幻/史诗 | ⑥ 导演轨道 + ⑧ 场景概览（三轨统一 + 宏大场景锁定） |
| 教学/技巧展示 | ⑤ 动作拆解 + ⑩ 场景固定（分解动作 + 多角度展示） |
| 美食/生活vlog | ② 调度分镜 + ⑨ 场景规划（动线连贯 + 厨房布局） |
