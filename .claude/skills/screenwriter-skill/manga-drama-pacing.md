# Manga Drama Pacing（漫剧完播节奏）

漫剧 / 竖屏短剧的**产品层**节奏约束。不替代 McKee 结构；在短时长、高完播压力下叠加使用。

来源吸收：[`../docs/absorption/AIGC-漫剧课程吸收.md`](../docs/absorption/AIGC-漫剧课程吸收.md) §3.1。院线横屏长片默认跳过本文件。

---

## When to use

Trigger when the user mentions any of:

- 漫剧、短剧、竖屏、9:16、完播、钩子、爽点、虐点
- 霸总、玄幻、悬疑（三大流量赛道）
- 红果 / 番茄 / 抖音短剧投放
- 单集 30–90 秒、集末卡点

Do **not** force this onto theatrical feature treatments unless the user asks for short-form packaging.

---

## Hard rules（短剧单集）

1. **前 3 秒必须有钩子**  
   视觉冲击、冲突句、身份反差、危险物件、未完成动作 — 至少一种。禁止用空镜或纯气氛开场（除非气氛本身就是威胁）。

2. **每 8–15 秒至少一个信息增量或小反转**  
   新信息、态度翻转、权力位移、危险升级。禁止「同一情绪原地踏步」。

3. **集末必须留钩**  
   问号、未兑现承诺、新威胁出现、身份裂缝。禁止圆满收束（系列单集除外明确要求 HE 收束时）。

4. **对白预算**  
   30–60s 单集：核心对白 ≤ 6 句；优先动作与反应镜头承载信息。

5. **竖屏优先构图**  
   见 `shotlist-builder/reference/VERTICAL_SHORT.md`。横屏项目在 `pacing-lock.md` 中声明后可关闭。

## 开集钩子类型（选 1）

| 类型 | 说明 | 示例 |
|------|------|------|
| 冲突句 | 第一句对白即立场对立 | 「你以为你还能走？」 |
| 身份反差 | 身份与处境冲突的画面 | 总裁跪在雨里 / 魔君被锁链缚住 |
| 未完成动作 | 刀落一半、门推开一半 | 门缝里一只眼睛 |
| 物件威胁 | 信、刀、戒指、符箓特写 | 血封未干的信封 |
| 结果前置 | 先给结局残片再倒叙 | 葬礼 → 闪回相遇 |

## 题材模板（三大赛道）

### 霸总 / 强制爱

| 节拍 | 功能 |
|------|------|
| 钩子 | 权力压迫或被迫绑定 |
| 中段 | 拒绝 → 被迫靠近 → 裂缝温柔 |
| 爽点 | 护短、当众站队、身份碾压反转 |
| 虐点 | 误会、第三者、旧伤 |
| 集末 | 新契约 / 新威胁 / 「明天来签约」 |

### 玄幻 / 修仙

| 节拍 | 功能 |
|------|------|
| 钩子 | 异象、觉醒、杀局开场 |
| 中段 | 规则揭示 → 代价 → 越阶一击 |
| 爽点 | 装逼打脸、秘闻揭开、战力跃迁 |
| 虐点 | 师门背叛、心爱之人成祭品 |
| 集末 | 更大境界/敌人露面 |

### 悬疑

| 节拍 | 功能 |
|------|------|
| 钩子 | 异常细节或尸体/失踪 |
| 中段 | 线索 → 假解释 → 推翻 |
| 爽点 | 观众比角色早半步或晚半步的信息差 |
| 虐点 | 信任崩塌 |
| 集末 | 新疑点或「凶手就在房间里」 |

## Treatment 可选字段（漫剧项目）

在 synopsis / treatment 顶部追加：

```markdown
## Short-form packaging
- Platform: [红果 / 番茄 / 抖音 / 其他 / 未定]
- Aspect: [9:16 竖屏 / 21:9 / 16:9]
- Episode length: [30–60s / 60–90s / 自定义]
- Genre lane: [霸总 / 玄幻 / 悬疑 / 其他]
- Hook type (ep1): [冲突句 / 身份反差 / ...]
- Monetization intent: [平台分账 / 定制 / IP / 无]
```
