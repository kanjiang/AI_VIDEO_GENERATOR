# AI Footage QA Checklist (AI 素材质检清单)

AI 视频模型（Seedance、Kling 等）生成的片段在镜头逻辑上存在系统性盲区。模型能识别画面元素，但**不理解镜头之间的空间连续性**。每次拿到 AI 素材后，必须按以下清单逐项检查，先诊断再修复。

---

## 三步强制检查 (生成后必做)

拿到 AI 生成的视频片段后，按此顺序检查：

| 步骤 | 检查项 | 核心问题 | 通过标准 |
|---|---|---|---|
| 1 | **越轴检查** | 相邻镜头中人物朝向/运动方向是否一致？ | 同一场景内人物的左右朝向不发生无理由翻转 |
| 2 | **跳切检查** | 连续镜头的角度、景别是否有足够差异？ | 相邻镜头的角度差 ≥ 30°，或景别差 ≥ 1 级（中景→特写、全景→中景） |
| 3 | **音效匹配检查** | AI 生成的音效节奏是否匹配画面情绪？ | 音效与画面动作同步，情绪强度匹配（不是所有打斗都配相同的撞击声） |

原理、速度/方向匹配、时长与剪辑点选型见完整手册：[SHOT_CONTINUITY.md](SHOT_CONTINUITY.md)。

---

## 问题 1：越轴 (180° Rule Violation / Axis Crossing)

### 什么是越轴

两个连续镜头中，摄影机跨越了人物之间（或人物与视线方向之间）的 **180° 轴线**，导致：
- 人物突然从「面朝左」变成「面朝右」
- 运动方向突然反转（向左走 → 突然向右走）
- 观众的空间认知混乱——"他到底在哪边？"

### AI 为什么容易越轴

AI 逐段生成，每段独立选择摄影机位置。它没有"上一段摄影机在轴线哪一侧"的记忆，所以经常在相邻片段之间跨轴。

### 诊断方法

1. 将相邻两段 AI 视频并排播放。
2. 标记人物的朝向/运动方向：画面中人物面向左还是右？
3. 如果方向在无理由的情况下翻转 → 越轴。

### 修复方法

#### 方法 A：插入中性镜头 (推荐)

在越轴的两个镜头之间，插入一个**无明显方向性**的镜头，打断观众的轴线追踪：

| 中性镜头类型 | 示例 | 为什么有效 |
|---|---|---|
| 手部/物品特写 | 梳头的手、倒茶的壶、翻书的手指 | 画面中没有左右方向信息，观众的空间记忆被"重置" |
| 正面/正背特写 | 正脸特写、后脑勺 | 正面/正背没有左右之分 |
| 环境空镜头 | 窗外桃花、天空、水面倒影 | 完全脱离人物空间，是最强的轴线中断器 |
| 道具插入镜头 | 桌上的茶杯、地上的落叶 | 无方向性的静物 |

**CapCut 操作：**
1. 在越轴切点处分割时间线。
2. 从素材库（或额外用 AI 生成）选择一个 1–3 秒的中性镜头。
3. 插入到切点位置。
4. 可选：在中性镜头的入/出点加 0.1–0.2 秒叠化，使过渡更柔和。

#### 方法 B：水平镜像翻转

直接将越轴的那个镜头**左右翻转**，统一人物朝向。

**CapCut 操作：**
1. 选中越轴镜头。
2. 点击「编辑」→「镜像」→「水平翻转」。
3. 检查翻转后画面中是否有**文字、Logo、手表等不对称元素** — 如果有，翻转会暴露（文字反了），需要用方法 A 代替。

**适用条件：**
- 画面中无可读文字
- 无明显的不对称标记（如左手戴戒指）
- 背景无明显的左右不对称特征

#### 方法 C：Prompt 预防 (最佳)

在写视频提示词时就锁定摄影机位置，从源头避免越轴。在每个 prompt 的 `机位` 部分声明轴线侧：

```
机位：50mm中景。⚠️摄影机在人物右侧（与P03一致），人物面朝画面左方。
⚠️严格保持180°轴线——摄影机不越过人物正面与背面连线。与上一段摄影机同侧。
```

在 `【负面约束】` 中追加：
```
禁越轴（摄影机始终在人物[左/右]侧，人物朝向不翻转）
```

## 问题 2：跳切 (Unintentional Jump Cut)

### 什么是无意跳切

**有意的跳切**（见 `editing-techniques.md` §1）是一种剪辑手法——故意跳过时间创造节奏感。

**无意的跳切**是 AI 的常见错误：连续两个镜头的角度、景别几乎一致，但画面内容有细微差异（人物姿态、手的位置、道具位置），组接后产生明显的**抖动/跳动感**——观众感觉画面"闪了一下"而不是做了一次有意的剪辑。

### AI 为什么容易产生无意跳切

AI 在生成连续镜头时倾向于保持相似的构图（它认为这是"连续性"），但无法精确控制细节的一致性。结果：构图几乎相同 + 细节不同 = 跳切。

### 诊断方法

1. 将两段连续 AI 视频首尾相接播放。
2. 检查：角度差 < 30° 且景别相同？→ 高跳切风险。
3. 如果播放时感觉"闪了一下" → 无意跳切。

### 修复方法

#### 方法 A：调整构图参数重新生成

将跳切镜头的提示词修改为**与前一镜头差异明显的角度/景别**：

| 原始参数 | 修改方向 | 效果 |
|---|---|---|
| 30° 侧面 | → 90° 正侧面 | 角度差异足够大，消除跳切感 |
| 中景 | → 全景 or 特写 | 景别跳一级，视觉上是有意的切换 |
| 平视 | → 微俯 or 微仰 | 纵向角度变化也能消除跳切 |

**30° 规则：** 相邻镜头的角度差必须 ≥ 30°，否则观众会感觉是同一个镜头"跳"了一下。

#### 方法 B：插入中间镜头

与越轴修复一样，在两个跳切镜头之间插入一个**不同景别的过渡镜头**：

- 两个中景之间 → 插入特写
- 两个特写之间 → 插入中景或反应镜头
- 两个相似角度之间 → 插入反打（reverse shot）

#### 方法 C：Prompt 预防 (最佳)

在 shotlist 阶段就规划好**相邻镜头的角度/景别组合**，确保有足够差异：

```
【镜头1】机位：50mm中景，人物正面偏左30°。
【镜头2】机位：⚠️85mm特写（景别跳一级），人物右侧90°（角度差60°）。
【镜头3】机位：⚠️35mm全景（景别再跳），正面。
```

在 `【负面约束】` 中追加：
```
禁相邻镜头角度差<30°（必须有明显的角度或景别变化）
```

## 问题 3：音效节奏不匹配

### 表现

AI 生成的音效只做了基础的"画面元素→声音"映射（打斗→撞击声，鸟→鸟叫声），但缺乏**节奏控制**——所有声音等音量、等间距，没有强弱起伏。

### 修复

这不是一个单点修复问题，而是需要用 `sound-design.md` 中的完整技巧体系来重新设计音频层。核心操作：

1. **静音 AI 原生音效**（大多数情况下质量不够用）
2. **从零搭建音频**：环境底噪 → SFX 层 → 音乐层 → 对白层
3. **用 SFX Beat Sync (§3)** 让音效与画面动作节奏对齐
4. **用 Stem Editing (§8)** 让音乐情绪跟随画面起伏

## Prompt 级预防总结

最好的修复是不需要修复。以下规则应在写提示词时就嵌入：

| 预防规则 | 写入位置 | 示例 |
|---|---|---|
| 锁定轴线侧 | `机位` | `摄影机在人物右侧，与P03一致` |
| 禁越轴 | `【负面约束】` | `禁越轴、禁人物朝向翻转` |
| 30° 角度差 | `机位` | 相邻镜头角度差 ≥ 30° |
| 景别跳级 | `机位` | 相邻镜头景别差 ≥ 1 级 |
| 禁相似构图连接 | `【负面约束】` | `禁相邻镜头构图雷同` |

### 与 CAMERA_EMOTION.md 的关系

`CAMERA_EMOTION.md` 定义了每种情绪/意图该用什么镜头。本文件补充了一条**跨镜头规则**：不管单个镜头的设计多好，如果相邻镜头之间违反了越轴/跳切规则，组接后依然会出问题。

**检查时机：** 写完所有 prompt 后，在生成前做一次"相邻镜头对"扫描——逐对检查轴线一致性和角度/景别差异。
