# 《牙刷小英雄》Treatment · 100 秒节拍表（B 站大赛版）

依据 `science-explainer` 技能的 **Hook — Progression — Elevation** 结构，把 8 个知识点拆成 10 个节拍，构建"**一天时间循环**"叙事闭环——**偷懒(错) → 报应(苦) → 学习(转) → 升华(乐) → 邀请(转化)**。

│MAC │MAC │MIC  │MIC  │MAC  │MAC/M│MAC  │MAC  │MAC  │MAC   │

值转变走向：**极乐(+) → 偷懒可爱(±) → 反派得意(−) → 严重受伤(−−) → 后悔痛哭(−) → 反攻转折(±) → 学习进取(+) → 生活仪式(+) → 情感峰值(++) → 邀请高潮(++)**

## Beat 1 · HOOK · 生日狂欢 · 0-8 秒

### 场景
INT. 糖糖家客厅 — 傍晚，暖光。桌上有一个双层生日蛋糕，插着蜡烛，旁边散落着糖果、饮料、彩色气球。

### 动作
糖糖坐在餐桌前，头戴生日纸帽，捧着一大块粉色奶油蛋糕，咧嘴狠狠咬一大口。奶油沾在嘴角，草莓糖粒粘在门牙上。她笑得眼睛眯起来。桌上的蛋糕已经被她吃掉了一半。她又拿起一颗糖果剥开，塞进嘴里，边吃边笑。

### Value Shift
纯粹快乐（+）

### 知识点
无。本节拍用来抓注意力 + 建立"糖糖今天吃了很多糖" 的埋雷。

### 数据标注
无字幕。

### 尺度
MACRO — 客厅

### 音效关键点
- 咬蛋糕的清脆咔嚓声
- 童声笑声：**"呀哈！生日快乐！"**
- 剥糖果纸的"啪嗒"、嚼糖果的"嘎嘣嘎嘣"
- 背景欢快的生日主题音乐

### 设计意图
建立"糖糖今天吃了很多糖"的**信息埋雷**——观众下意识就知道"待会她的嘴巴里会出问题"。这是幼儿动画中最常用的因果预示手法。

---

## Beat 2 · WRONG CHOICE · 偷懒不刷 · 8-16 秒

### 场景
INT. 糖糖卧室 — 夜晚。粉红色小床，床头柜上有一杯装着牙刷的牙杯（牙刷警长住在里面）。

### 动作
糖糖穿着粉色小睡衣，打了个大哈欠 → 揉着眼睛走到床边 → 床头柜上牙刷警长伸出小手挥舞："**记得刷牙哦！**"（画外音） → 糖糖看都没看，摆摆手："**太累啦——明天再刷~**" → 直接扑到床上 → "**啪！**" 关灯 → 房间陷入蓝色月光下

镜头切到床头柜的牙刷警长——他垂下小手，无奈地摇头："**哎——**"

### Value Shift
快乐（+）→ 偷懒可爱（±）— **观众开始意识到"糟了她要出事"**

### 知识点
无直接。**这是本片全片最重要的"错误示范"节拍**——所有后续的因果都从这里开始。

### 数据标注
无字幕（保持叙事流畅）。

### 尺度
MACRO — 卧室

### 音效关键点
- 打哈欠"啊————"
- 糖糖偷懒台词："太累啦~ 明天再刷~"
- 关灯"啪！"
- 牙刷警长的失望叹息："哎——"

### 设计意图
让小朋友产生**"我也这样想过！"** 的心理共振。这是共鸣型 hook——观众带入的不是完美主角，而是**和自己一样偶尔偷懒的糖糖**，这样才能真正推动行为改变。

## Beat 3 · NIGHT PARTY · 夜里狂欢 · 16-28 秒

### 场景
INT. 糖糖的口腔内部 — 显微视角，夜间模式。口腔壁像糖果洞穴，8 颗白色小方块牙齿站成一排。

### 动作
镜头从糖糖张开的嘴巴（她张嘴呼呼睡）快速推入 → 口腔内一片黑暗 → "**啪！**" 一盏派对灯泡亮起 → 一群细菌欢呼冲出，头顶挂着"**通宵营业**"招牌

糖糖菌（戴着一顶夜光荧光帽）冲到镜头前，激动地大喊：**"耶——！她没刷牙！派对——通宵——不打烊！"**

细菌军团爆发欢呼，跳舞、开香槟、扭屁股，蛋糕碎屑洒了一地（就是糖糖吃剩的糖）。

牙齿小方块们（背景中）互相担忧地对视。

### Value Shift
偷懒（±）→ 反派得意（−）

### 知识点
- **K1**：嘴巴里住着蛀牙菌
- **K2**：细菌爱吃糖
- **K3**：不刷牙睡觉 = 细菌通宵开派对（本节拍核心）

### 数据标注
- 糖糖菌头顶飘出小旗子："**坏坏菌**"（2 秒后消失）
- 派对灯旁挂招牌："**通宵营业**"

### 尺度
MICRO — 显微夜派对

### 音效关键点
- 灯泡"啪！"
- 派对音乐（夜光荧光风格，滑稽 Q 版电子音）
- 集体欢呼、开香槟"啵！"
- 糖糖菌台词（夸张童声）

---

## Beat 4 · DAMAGE · 集体喷酸 + 月夜流逝 · 28-40 秒

### 场景
同上，口腔内部。夜间进行中。

### 动作
一群细菌**集体行动**：抱着糖果块疯狂啃食 → 肚子都鼓起来 → **"呃！呃！呃！"** 集体打嗝 → 喷出黄色酸水如同酸雨 → 一排牙齿被浇到

牙齿小方块们**集体哀嚎**："**哎哟！哎哟！**" 眼睛冒 T_T 泪花，表面出现深棕色小黑点，有的黑点开始扩大成小洞洞。

**时间流逝表现**：镜头切到口腔的一个"窗户"（隐喻性口腔构造） → 一轮明月从画面左边缓缓划到右边 → 天色由深蓝渐变到淡蓝晨光 → 派对灯泡熄灭 → 细菌们东倒西歪醉倒（打了个通宵）

结尾一颗最靠前的门牙（隐喻糖糖真实门牙位置）表面有一个**明显的黑点**。

### Value Shift
反派得意（−）→ 严重受伤（−−）

### 知识点
- **K4**：细菌喷酸让牙齿有洞洞（本节拍核心）

### 数据标注
- 每颗牙齿头顶"**哎哟！**"气泡（漫画风）
- 月亮划过时，字幕"**一整晚——**"淡入淡出
- 结尾门牙黑点特写时，"**呜——**" 心疼音效字幕

### 尺度
MICRO — 显微 + 时间过渡（月夜划过）

### 音效关键点
- 集体打嗝"呃！呃！呃！"
- 酸雨"哗啦——"
- 牙齿哀嚎"哎哟！"合唱
- 月夜过渡音（低沉悬念但仍带滑稽感）

## Beat 5 · CONSEQUENCE · 早晨牙痛 · 40-48 秒

### 场景
INT. 糖糖卧室 — 清晨，阳光洒进来。

### 动作
糖糖躺在床上打哈欠醒来 → 揉揉眼睛坐起 → 突然捂住嘴巴 → "**哎哟！牙齿好痛！**"（表情惊恐）→ 跳下床跑向镜子

镜前特写：糖糖张大嘴巴看镜子里的牙齿 → 惊讶发现门牙上有一个**明显的黑点**（与 Beat 4 结尾同一位置）→ 眼泪汪汪，"**呜——我的牙齿——**"

### Value Shift
严重受伤（−−）→ 后悔痛哭（−）— **本节拍是全片最关键的"因果闭环"锚点**

### 知识点
- **K4 强化**：不刷牙的后果就是牙齿真的会痛（把抽象威胁变成主角真实感受）

### 数据标注
- 特写门牙黑点时用红色圆圈标注 + 星形冲击波："**这里——！**"
- 糖糖泪珠特写

### 尺度
MACRO — 卧室（跳回现实世界）

### 音效关键点
- 醒来打哈欠"啊——"
- 突然的疼痛喊叫："哎哟！"
- 跑向镜子的急促脚步声
- 张嘴看镜子时的"啊——"
- 泪汪汪的抽泣声"呜——"

### 设计意图
**这一节拍决定全片的教育效果**。让小朋友看到"糖糖真的疼了" —— 这比任何家长说"不刷牙会蛀牙"都有力。因果闭环在这里完成第一次接触现实。

## Beat 6 · HERO ENTERS · 转折反攻 · 48-58 秒

### 场景
INT. 糖糖家卫生间 — 清晨。糖糖跑进卫生间，看向洗手台上的牙刷架。

### 动作
糖糖惊喜地看向洗手台 → 牙刷架上的**牙刷警长活了过来** → 眨眨眼睛，敬礼："**别怕，交给我！**"

糖糖破涕为笑，拿起牙刷警长，挤上一条薄荷绿牙膏。

**镜头切换到口腔内部（MICRO）**：牙刷警长带着泡泡军团冲入战场 → 挥刷横扫细菌 → 泡泡军团涌上包围残余细菌 → 细菌哭喊"**我们走啦——**"被泡泡卷走冲进"下水道"

牙齿小方块们眼泪消失，恢复闪亮微笑，头顶冒出星星光效。

### Value Shift
痛哭（−）→ 反攻（±）→ 希望（+）

### 知识点
- **K5**：牙刷警长可以救牙齿

### 数据标注
- 警长登场时头顶标签"**刷刷警长**"（红色描边警徽图标）
- 战斗结束时"叮！叮！叮！"清洁音字幕特效

### 尺度
MACRO（卫生间）→ MICRO（口腔战场）**双世界联动**

### 音效关键点
- 警长登场"叮咚——！"英雄号角
- 警长台词："别怕，交给我！"
- 挥刷"唰！唰！唰！"
- 细菌逃跑合唱"哎哟哎哟"
- 泡泡"啵啵啵"
- 牙齿被救音"叮叮叮"

## Beat 7 · TEACHING · 三步法教学 · 58-72 秒（14 秒，核心科普段）

### 场景
INT. 卫生间镜前。糖糖对镜刷牙。

### 动作
分为**三个 4-5 秒的教学子段**，每段包含 MACRO（糖糖示范）+ 插入 MICRO（口腔内警长动作示范）：

**Step 1 · 上下刷（58-62s）**
- MACRO：糖糖对镜，牙刷在门牙上做规范的上下运动
- 上方字幕大字弹入：**"上下刷"** + 大箭头 ⬆️⬇️
- 插入 MICRO 一闪：警长在牙齿正面像刷地板一样上下移动
- 童声口播："**上——下——像小刷子一样！**"

**Step 2 · 里外都刷（62-67s）**
- MACRO：糖糖张嘴刷牙齿背面（表情夸张地伸舌头够）
- 上方字幕：**"里外都刷"** + 大箭头 ⬅️➡️
- 插入 MICRO 一闪：警长绕到牙齿背面，"这里也不能漏！"
- 童声口播："**牙齿背面也要刷哦！**"

**Step 3 · 每颗都要（67-72s）**
- MACRO：糖糖认真地一颗一颗刷，牙刷慢慢从左边刷到右边
- 上方字幕：**"每颗都要"** + 数字 ①②③④⑤⑥⑦⑧
- 插入 MICRO 一闪：8 颗牙齿排成一列，警长挨个"叮"一下，最后一颗喊"耶！轮到我啦！"
- 童声口播："**一颗都不能漏——**"

### Value Shift
希望（+）→ 学习进取（+）— 情感稳定上升

### 知识点
- **K6**：正确刷牙三步法（本片教学核心）

### 数据标注（本节拍最重要）
- Step 1: "**上下刷**" 三字（每字弹入，糖果色描边） + 上下大箭头
- Step 2: "**里外都刷**" 四字 + 左右箭头
- Step 3: "**每颗都要**" 四字 + 数字标注 ①-⑧
- 每步骤字幕停留 4-5 秒

### 尺度
MACRO 卫生间 + 每步插入 1 秒 MICRO 示范（口腔内）

### 音效关键点
- 每步一个"叮"起始音
- 童声口播（要活泼、有节奏）
- 每颗牙齿被刷到的"叮"

### 设计意图
**本节拍是本次扩展的核心新内容**，也是大赛评委最关心的"实用知识点"。把巴氏刷牙法简化成 3 步，用视觉 + 字幕 + 口播三重加固，让小朋友即刻能跟着做。

## Beat 8 · RITUAL · 早晚仪式 + 沙漏 · 72-84 秒

### 场景
INT. 卫生间 — **左右分屏**：左边清晨（窗户阳光），右边夜晚（温馨黄灯）。

### 动作
**左半屏**（清晨）：糖糖穿粉色小睡衣，揉着眼睛，站在小板凳上认真刷牙。嘴角有点白泡沫。
**右半屏**（夜晚）：糖糖穿浅蓝色小睡衣，打了个哈欠，同样站在小板凳上刷牙。灯光温暖黄色。

画面上方：**☀️ 太阳（左）** 和 **🌙 月亮（右）** 大图标浮现。
画面中央：沙漏浮现，沙子快速流下（象征 2 分钟）。沙漏完成时"叮"，大数字"**2 分钟**"闪现后消散。

### Value Shift
学习（+）→ 生活仪式（+）

### 知识点
- **K7**：早晚各一次，每次 2 分钟

### 数据标注
- 上方左右：**☀️ 早上 · 🌙 晚上**（大字号糖果色）
- 中央：沙漏 + "**2 分钟**"（沙漏跑完时字体收缩消失）

### 尺度
MACRO — 卫生间双画面

### 音效关键点
- 左侧底噪：清晨鸟叫
- 右侧底噪：夜晚温馨风铃
- 共享：刷牙"沙沙沙" + 沙漏结束"叮"

## Beat 9 · ELEVATION · 闪亮笑容 · 84-92 秒

### 场景
INT. 糖糖卧室 — 清晨，阳光洒进来。糖糖穿粉黄条纹连衣裙（回到 Beat 1 的服装，象征"新一天开始"），站在镜子前。

### 动作
糖糖对着镜子露出灿烂笑容 → 镜头推进到门牙特写 → **"叮！"** 一声，门牙闪出十字星光 → **"闪闪亮"** 三字 + 星星特效飞出 → 镜头拉出，糖糖眯眼开心大笑，竖起大拇指 → 牙刷警长以缩小尺寸站在她左肩上，同样敬了一个礼

### Value Shift
仪式（+）→ 情感峰值（++）

### 知识点
- **K8**：坚持刷牙 = 闪亮笑容 = 每天最美的自己

### 数据标注
- 门牙闪光时飞出："**闪闪亮！**" + 星形特效
- 星星特效持续 1 秒

### 尺度
MACRO — 卧室

### 音效关键点
- 门牙闪光"叮！"
- 童声"闪闪亮！"
- 温馨童声主题歌前奏起

## Beat 10 · CALL TO ACTION · 邀请你 · 92-100 秒（打破第四堵墙）

### 场景
中性淡色背景（可以是糖糖卧室的模糊延续，或纯白/淡粉背景板）。糖糖占中景，面对镜头。

### 动作
糖糖直接看向镜头（大眼睛认真直视观众） → 挥挥手 → **"你也要早晚刷牙哦！"** → 牙刷警长从她肩上跳到画面前方，敬礼 → **"交给你啦！"**

画面渐显主题字幕：**"早晚刷刷刷，笑容闪闪亮！"**（大字号，圆润糖果色字体，随节拍逐字弹入）

最后 1 秒：字幕淡出 + 品牌/频道 logo（如有）淡入右下角。

### Value Shift
情感峰值（++）→ 邀请高潮（++）— **本片行为转化的关键**

### 知识点
- 综合升华：把知识点从"糖糖的故事"转化为"你的行动"

### 数据标注 / 字幕
- 主字幕：**"早晚刷刷刷，笑容闪闪亮！"**（逐字弹入，2 秒完成）
- 右下角：可选 B 站账号/大赛标识

### 尺度
MACRO — 直面镜头对话

### 音效关键点
- 糖糖直接对话："你也要早晚刷牙哦！"（暖童声，眼神真诚）
- 警长跳出"叮咚"
- 警长台词："交给你啦！"
- 主题歌尾句童声演唱：**"早——晚——刷刷刷，笑容闪闪亮！"**
- 结尾一个上扬"耶！"

### 设计意图
**打破第四堵墙**：让屏幕前的小朋友觉得"她真的在跟我说话"。3-6 岁儿童还没有完全形成"电视里的人不认识我"的认知，这种"直面邀请"能极大提升行为转化。这也是《芝麻街》《海底小纵队》等经典幼儿动画反复使用的手法。
