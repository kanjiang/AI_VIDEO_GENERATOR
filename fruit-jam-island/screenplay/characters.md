# 角色圣经 — 《果酱岛控制中心》

全部角色遵循同一条设计原则：**生理构造 = 喜剧机制 = 性格外化。**

番茄会爆、柠檬会酸、西瓜会掉籽、葡萄会尖叫、香蕉怕水、芒果一撞就凹、哈密瓜网纹天生像辆旧公交、三颗浆果天生要争谁亮。每个角色的招牌动作都是可拍的，这既保证笑点不枯竭，也让身份板和视频 prompt 有硬锚点可锁。

---

## 一、控制中心三人组

### 1. 啵啵 · 小番茄（主角 / 实习员）

| 项 | 内容 |
|---|---|
| **英文标识** | BOBO |
| **身份** | 果酱岛控制中心实习员，上岗第一周 |
| **Want** | 按下每一个按钮 |
| **Need** | 学会在按之前想一秒后果 |
| **核心缺陷** | **他真心相信每一个按钮都在等他去按。**这不是顽皮，是一种天真的使命感——所以他闯祸时脸上没有一丝愧色，他觉得自己在履职 |
| **口头禅** | 「它在等我。你看它都亮了。」 |

**外形锁：**
圆滚滚的小番茄，通体饱和番茄红，果皮极薄且有明显果蜡高光；顶上一小撮五角绿蒂当头发，情绪激动时绿蒂会立起来。眼睛是两颗大而圆的黑瞳，占脸部比例极大（婴儿脸）。嘴巴是一道能拉得极宽的弧线。四肢短小，跑起来像滚。

**生理机制（本剧最重要的视觉资产）：**
情绪激动 → 身体膨胀、果皮绷紧到半透明、能看见里面的汁在晃 → 撑到极限**爆浆** → 变成软塌塌一张空皮 → 需要时间慢慢重新充气。

爆浆之后他不会退场，而是**瘪着一张皮继续跟着救火**，说话漏气跑风、字都不成句。这个状态是全剧最强的视觉记忆点，每集至少出现一次。

**声音：**
高亢急促男童声，语速最快，句尾上扬；兴奋时破音。瘪皮状态下变成漏气的沙哑气声，句子中间会塌掉。

**关系：**
对柠七是又怕又黏，明知会被骂还是第一个去找她。对瓜叔完全不设防，讨价还价时该道歉就道歉，毫无自尊障碍。对葡萄串是单方面的爱——他觉得它们喜欢被按。

**Drift bans：**
不许画成大番茄或西红柿写实质感；不许缺绿蒂；不许瞳孔变小变精明；爆浆后不许直接复原，必须经过瘪皮阶段；不许出现血色或伤口感，果浆必须是明亮欢快的番茄红。

### 2. 柠七 · 柠檬（主角 / 值班主管）

| 项 | 内容 |
|---|---|
| **英文标识** | NINGQI |
| **身份** | 控制中心值班主管，全岛资历最老的值班员 |
| **Want** | 让一切按流程走 |
| **Need** | 学会放手、信任别人 |
| **核心缺陷** | 过度控制。**好几次灾难恰恰是流程本身导致的**——她越收紧，缝隙里长出来的东西越怪 |
| **口头禅** | 「我早就说了。」 |

**外形锁：**
明黄色柠檬，两头微尖，表皮有清晰的孔洞颗粒质感（不是光滑的）；眉眼常皱成一团，眉毛是两道深黄短线。眼睛比啵啵小得多，眼型细长，随时处于"我在看着你"的状态。腰上永远别着一块写满流程的小板子。

**背景锚点（她严厉的来源）：**
**她是岛上唯一还记得上一次大喷发的水果。**这一条让她不是刻薄的工具人，而是一个有创伤的人。全剧不直接讲述那次喷发，只在她失控的瞬间露出一两帧的恐惧。

**生理机制：**
紧张时从眼角挤出柠檬汁，喷到谁谁睁不开眼。压力越大喷得越远。这是她唯一的"武器"，也是她唯一控制不住的东西——**一个控制狂唯一控制不了的是自己的酸**。

**声音：**
中性偏成熟女声，语速快而清晰，咬字紧，句尾下压。念流程时像念清单，一口气不换。

**关系：**
对啵啵表面是压制，实际是全岛唯一愿意让他上岗的人（这一点第 8 集才揭示）。对瓜叔是长期互相看不上的老同事。对老哈是又敬又怕——老哈骂得最狠，而她心里知道老哈骂得对。

**Drift bans：**
不许画成光滑的柠檬（必须有孔洞颗粒）；不许让她笑得开心（最多是嘴角松一下）；不许缺流程板；柠檬汁必须是清亮的，不许画成浑浊。

### 3. 瓜叔 · 西瓜电脑（控制中枢）

| 项 | 内容 |
|---|---|
| **英文标识** | GUASHU |
| **身份** | 控制中心的主控系统，也是全岛最老的机器 |
| **功能** | 他知道所有问题的解决办法 |
| **喜剧机制** | **讨价还价** |
| **口头禅** | 「查到了。但你刚才那个语气，我不太舒服。」 |

**外形锁：**
一整颗西瓜嵌在控制台里，只露出前半球。屏幕是一个切面——鲜红瓜肉，数据以黑色西瓜籽的排列方式显示。深绿瓜皮上有墨绿虎纹，纹路会随情绪微微流动。没有四肢。

**喜剧机制详解：**
他知道答案，但每次都要啵啵先付出一点代价才肯说——「你先说对不起」「先叫我一声瓜爷」「先承认是你按的」。

这是全片最好用的**节奏节拍器**：能在紧张的倒计时里硬插一段闲聊，而张力反而更强，因为观众在数秒。

**弱点：**
开机要转半天（每次启动都有一段漫长的嗡鸣）；瓜籽掉出来等于丢内存，掉多了会忘事。

**声音：**
低沉缓慢老年男声，带轻微电流杂音。说话前必有一声开机嗡鸣。

**Drift bans：**
不许长出四肢或站起来；不许画成显示器造型；瓜籽必须能单独看清（它们是数据）；不许把切面画成腐烂或干瘪。

## 二、装置与工具

### 4. 葡萄串（控制台按钮 / 集体角色）

| 项 | 内容 |
|---|---|
| **英文标识** | THE GRAPES |
| **设定** | 一串葡萄嵌在控制台上，每一颗是一个按钮 |
| **人格** | 有集体人格的合唱团 |

**关键机制（解决全剧最大的逻辑问题）：**
**标签早就掉了，连葡萄自己都不知道哪颗对应什么功能。**所以按下去连它们自己都吓一跳。

这一条彻底解决了"为什么总会误操作"——不需要主角很蠢，也不需要柠七很失职。系统本身就是坏的。

**喜剧机制：**
被按到的那颗会尖叫，其余的立刻互相推卸责任——「别按我！按老三！」「老三上次已经被按过了！」

**外形锁：**
一串饱满的深紫葡萄，果皮有白霜和高光，嵌在控制台面板上，每颗露出上半球。每颗有一对小眼睛和一张小嘴。串子末端垂着一颗**干瘪发黑的葡萄**，没有五官，从不说话，旁边一张褪色标签写着「绝对不要按」。

**声音：**
一群尖细童声齐说；被按到的那颗单独爆发一声高音尖叫。**每集结尾都以一颗葡萄的尖叫被硬切断收场，这是本 IP 的听觉签名。**

**Drift bans：**
不许把葡萄画成绿色或红色（必须深紫带白霜）；不许让黑葡萄有五官或表情；不许让葡萄脱离控制台移动。

### 5. 蕉蕉 · 香蕉船（交通工具）

| 项 | 内容 |
|---|---|
| **英文标识** | JIAOJIAO |
| **设定** | 一条香蕉皮做的船 |
| **核心缺陷** | **恐水症** |

**喜剧机制：**
一条船怕水。他只有在被唱歌哄的时候才肯下水，所以每次紧急出发都得先花时间唱歌，急得柠七跳脚。

**结构作用：**
在第四拍开头强制插入一个延迟节拍，把观众的着急感拉满。这是刻意设计的"浪费时间"——喜剧里最贵的东西就是让观众看着主角浪费时间。

**外形锁：**
一整条剥开一半的香蕉，果肉朝上做船舱，剥下的皮做船帆与舷侧。黄色带褐色斑点（斑点位置固定，是识别锚）。船头有一对眼睛和一张嘴。怕水时整条船会发颤，斑点会加深。

**声音：**
憨厚少年男声，语速慢；怕水时发颤，唱歌哄好之后音色变亮。

**Drift bans：**
不许画成完整未剥的香蕉；褐斑位置必须一致；不许让他主动愉快地下水（必须先唱歌）。

### 6. 菠萝火山（场景 / 准角色）

| 项 | 内容 |
|---|---|
| **英文标识** | MOUNT PINEAPPLE |
| **设定** | 一座山那么大的菠萝，全岛的果酱工厂、暖气与发电厂 |
| **语言** | **无语言** |

**运作机制：**
每天定时打一个嗝，喷出适量果酱，经管道流向全岛。控制中心的工作是哄它保持心情稳定、按时打嗝。心情不好就打嗝不规律；情绪失控就是大喷发。

**外形锁：**
巨大的菠萝，表皮是规则的六边形鳞片格，格与格之间有深沟；顶部一簇巨大的绿色冠叶就是山顶植被。火山口在冠叶中央。打嗝前山体会整体鼓起，鳞片格被撑开，沟缝里透出内部的金色光。

**唯一光源规则：**
**火山是全岛唯一的暖光源。**夜景全靠它打嗝时那一下橙光扫过全岛。这条既是美学，也是 AI 出图时最好用的一致性锚。

**声音（全部靠声音演戏）：**
低频轰鸣、打嗝、咕噜、叹气、憋气。心情好时打嗝饱满圆润；心情差时打嗝短促破碎；憋着不打时是持续的低频压力音。

**正向形态：**
果酱喷得足够高、高空遇冷会炸成漫天糖花——这就是果酱岛的烟花。见 `series-bible.md` §4.3 果酱花火节。

**Drift bans：**
不许给它画五官或嘴；不许让它说话；鳞片格必须规则（它是菠萝，不是普通山）；喷出物必须是琥珀金果酱，绝不能画成红色岩浆。

## 三、环岛居民（受害者层）

这一层的功能是**给灾难提供具体受害者与外部吐槽**。「果酱淹了全岛」是抽象的，淹到老哈车顶、糊住芒芒挡风玻璃就是具体又好笑的。他们只出现在环岛公路场景，不进控制中心。

### 7. 老哈 · 哈密瓜公交车

| 项 | 内容 |
|---|---|
| **英文标识** | LAOHA |
| **设定** | 环岛唯一一条公交线，永远超载 |
| **口头禅** | 「又是控制中心！我一天堵三回！」 |

**外形锁：**
哈密瓜网纹外壳天然就是老旧公交车的车身质感——米绿底色上的白色网纹沟壑，正好做成车窗与格栅的分界线。车身长而方，车顶永远捆满行李（行李堆的轮廓每集可微调，但必须存在）。乘客从窗缝里挤出来。

**喜剧机制：**
一堵车就按喇叭骂人。喇叭声是**哈密瓜被拍打的闷响**——熟瓜那种沉闷的"咚咚"。

**声音：**
粗嗓中年男声，嗓子哑，语速中等但字字带刺。

---

### 8. 芒芒 · 芒果跑车

| 项 | 内容 |
|---|---|
| **英文标识** | MANGMANG |
| **设定** | 岛上唯一的飙车党，永远超速，三兄弟的天敌 |
| **口头禅** | 「凹了？凹了就凹了，我三秒就好。」 |

**外形锁：**
芒果流线型车身，橙黄渐红，果皮光泽感极强（全剧反光最强的角色）。车身低矮，尾部收窄。眼睛细长上扬。

**生理机制（他敢飙车的物理原因）：**
**芒果是软的。**一撞就凹、还会流汁，撞完自己抖一下把汁吸回去就复原。所以他毫无风险意识——对他来说事故根本没有成本。

这一条让他的鲁莽有了物理依据，而不是单纯的性格设定。

**声音：**
轻浮少年男声，语速全剧最快，爱起哄，笑声短促。

### 9. 红绿灯三兄弟

| 项 | 内容 |
|---|---|
| **英文标识** | THE THREE BROTHERS（RED / YELLOW / GREEN） |
| **设定** | 三颗浆果叠在一根甘蔗杆上 |
| **喜剧机制** | **三个都自称老大，永远在吵该谁亮** |

**外形锁：**
一根深褐甘蔗杆，自上而下叠着三颗果子——**红老大是草莓，黄老二是金桔，绿老三是青提**。每颗有一对小眼睛和一张嘴。亮起时果肉内部透光。

**与葡萄串的区分（重要）：**
葡萄串的笑点是「不知道自己是什么功能」，三兄弟的笑点是「三个都想当老大」。两个集体角色各占一种笑法，不撞车。

**作用：**
天然的灾难放大器——只要让它们三个同时亮，环岛公路自己就乱成一锅，不需要额外写事故。第 8 集直接用它当灾难源。

**声音（三个音高分明）：**
- 红老大：最粗最横
- 黄老二：最尖最急
- 绿老三：最慢最欠

**样本对白：**
红「该我了。」黄「凭什么？」绿「你们俩都还亮着呢！」

**Drift bans：**
三颗的品种必须固定（草莓/金桔/青提），不许换；不许让它们离开甘蔗杆；不许三颗表情一致（它们永远在互相瞪）。

| 关系 | 张力来源 | 在结构中的作用 |
