# Design: 陆景深 · 三重人格霸总短剧

**Date:** 2026-07-31  
**Working title:** 三个他，只许你知道  
**Project folder (proposed):** `lu-jingshen-three-selves/`  
**Format:** 竖屏短剧，约 40 集 × 60–90 秒  
**Genre lane:** 现代都市霸总甜宠（甜里藏刀）  
**Reference kernel only:** 《Kill Me, Heal Me》— 多人格男主 + 治愈/恋爱；不抄剧情与人物名

---

## 1. Logline

实习心理医生撞破霸总的三重人格，被「护卫人格」威胁封口，却被迫住进他身边当唯一知情者——她要治好他，也要在家族继承战里保住那个会怕黑的小女孩、那个会杀意的护卫，和那个不肯示弱的本尊。

## 2. Premise locks

| 项 | 锁定 |
|----|------|
| 起点 | 从零原创；只借多人格男主 + 治愈恋爱内核 |
| 赛道 | 霸总甜宠，甜里藏刀（日常甜，家族/继承战周期性捅刀） |
| 女主 | 心理/精神科实习医生 |
| 人格数 | 精简 3 人格 |
| 绑定 | 撞破切换 → 护卫人格威胁封口 → 女主成唯一知情者并入住 |
| 骨架 | 「唯一知情者」同居监护（方案 1） |
| 视觉 | 现实世界始终成年男主身体；人格靠语气、微表情、小道具区分；小女孩人格可在内心空间以儿童形象出现（可选） |
| **男主自知** | **完全不知道**。陆母长期以「焦虑症 / 失眠」假诊断掩盖，御医、药物、助理清场系统全部由她掌控。他相信"发作"是压力所致，从不追问背后。发现节奏由沈星野作为唯一知情者一步步撬开 |
| **女主自知** | 开场前**完全不知道**男主有多人格。Ep1 走"三段发现"：陆氏总部走廊初见本尊裂→夜出（无名）→ 陆宅天台捡到小小名字 → 陆宅客厅意识到男主自己也不知道 |
| **两人相识机制** | 由**陆承岳**在董事会推动"独立第三方精神健康评估"（因本尊近期有一次公开小失控），陆母被迫合规但施压院方派**实习生级别**支援，认为可控。沈星野以带教主任助手身份被派到陆氏总部走流程，撞见走廊那一幕。她**不是**男主主动找的，男主也不知道自己需要找——她是陆承岳继承战与陆母控制体系撞出来的意外变量 |

## 3. Characters

### 3.1 男主 · 陆景深（同一身体，三人格）

#### ① 本尊 · 陆景深

- **身份:** 陆氏集团继承人 / 执行总裁；28 岁气质  
- **Want:** 守住集团与「正常人」面具  
- **Need:** 允许被照顾；承认创伤不是软弱  
- **出场信号:** 袖扣整齐、语速慢、不笑；称呼女主「陆医生 / 你」  
- **例台词:** 「别同情我。你只需要让他们别在开会时出来。」

#### ② 护卫人格 · 「夜」

- **功能:** 危险时接管；威胁女主留下；对外敌意极强  
- **Want:** 彻底消灭威胁（含家族内部）  
- **Need:** 确认有人能在他失控前接住「小小」  
- **出场信号:** 领口松开、站姿前倾、眼神压人；可抽烟 / 解袖扣  
- **例台词:** 「说出去，我毁的不只是你的实习。」

#### ③ 小女孩人格 · 「小小」

- **设定:** 心理年龄约 7 岁；怕黑、黏人、只信任女主；**现实仍是成年身体**  
- **Want:** 有人陪、不被丢下  
- **Need:** 被告知「那晚不是你的错」  
- **出场信号:** 捏衣角、发绳/发圈、声音变软、踩着鞋跟走路  
- **例台词:** 「姐姐……灯可以开着吗？」

**人格关系:** 夜保护小小与本尊；本尊想压抑两人；小小只听女主——女主的杠杆。

### 3.2 女主 · 沈星野

- **身份:** 精神科实习医生，26 岁；缺钱/缺推荐信，底线硬  
- **Want:** 完成实习；证明自己不是「只会背书的实习生」  
- **Need:** 在权力不对等里仍选择真心，而不只是「正确治疗」  
- **对三人:** 对本尊专业冷静；对夜不跪不逃；对小小无条件温柔  
- **例台词:** 「你可以威胁我。但小小怕黑的时候，你换我来。」

### 3.3 反派与压力源

| 角色 | 功能 | 捅刀方式 |
|------|------|----------|
| **陆母（主使真凶）** | 表面护短，要「完美继承人」；童年伤害的主使 **+ 二十年 gaslighter** | 逼治疗、逼联姻、否认创伤；**长期以「焦虑症/失眠」假诊断掩盖多人格事实**；掌控御医、药物、助理清场系统；中后期揭开她才是「那一晚」的主使 + 二十年的欺骗者 |
| 叔伯线竞争对手 | 趁火打劫的继承对手（非童年真凶） | 挖多人格丑闻；设局让「夜」当众失控 |
| 前女友 / 联姻对象 | 情敌 + 舆论（可受陆母推动） | 假甜蜜、真监视，逼女主出局 |

**创伤核心:** 小小 ←「被丢在黑暗里的那一晚」（陆母主使）；夜 ←「有人必须动手才能活」；本尊靠遗忘活下来——**这份遗忘由陆母长期以假诊断维护**，他本人相信自己只是「焦虑症」。这是双重罪证：那一晚下令关门 + 之后二十年伪造诊断。

**小小为何是女孩（锁定）:** 陆母那晚以「哭得像女孩 / 不像陆家儿子」污名恐惧与眼泪；本尊把「被允许哭、怕黑、要人陪」的部分切出，故以小女孩形态存留。性别是陆母语言的罪证回声，不是随机反差。

**真凶锁定:** **选项 β — 陆母主使。** 叔伯只抢继承、不背童年施害锅；陆母的「爱」是控制与掩盖。

## 4. Story arc（约 40 集）

### 幕 1｜威胁同居（Ep1–10）

撞破 → 夜封口 → 女主入住。甜点：小小黏人、本尊吃醋式否认。集末刀：叔伯开始盯上女主。

### 幕 2｜依赖与心动（Ep11–20）

女主学会「认人」；本尊为她破例。刀：联姻对象入场 + 公开场合险些切换失败。

### 幕 3｜信任崩塌（Ep21–30）

丑闻将爆；夜过激护主；女主被逼选边。大刀：童年真相一角——**陆母不是盟友，而是主使。**

### 幕 4｜整合与反杀（Ep31–40）

Ep31–33 三人格与女主彻底同一战线，叔伯发起继承逼宫但功能锁定为继承对手，不背童年施害锅。Ep34–37 用旧儿童房、兔子灯、封存处置单、旧保姆证词与陆母失控口供，完整坐实陆母才是“那一晚”的主使。Ep38–40 才允许系列终局式圆满收束：继承战公开打脸，小小说出“不是我的错”并不再怕黑，夜收刀，本尊公开承认女主，并选择不消灭人格、而是带着他们一起活。

### 单集节奏锁

1. **前 3 秒钩子:** 切换 / 冲突句 / 危险物件，三选一  
2. **中段:** 甜或笑（小小或本尊破防）+ 信息增量  
3. **集末钩:** 问号（谁来了 / 哪个他醒了 / 把柄在谁手里）  
4. **对白预算:** 核心对白 ≤ 6 句 / 集（优先动作与反应）

## 5. Episode 1 hook（已锁定版，与 `screenplay/episode-01-screenplay.md` 同步）

**Ep1 人格出场硬锁**：本集**只出现 2 个人格**——本尊 + 夜。小小到 Ep3 才首次登场。切换次数：**1 次全切换**（陆氏总部 本尊→夜）+ 天台夜→本尊自然回归（不占额度）+ 客厅镜中半浮现（无名裂缝，不占额度）。

**开场（陆宅天台，雨夜）**  
雨。陆景深西装淋透地站在栏杆边——袖扣松了一颗，领带偏了，呼吸不像 CEO，右手在口袋里捏着什么让指节发白。沈星野从楼梯出来，停在六步外。她认出这只手（下午威胁过她的手）。他慢慢回头，眼神先空再对焦，重新记起自己是谁：**陆景深**："你怎么在这里？"（本尊冷声，仿佛下午没发生过任何事。）

**中段（闪回，陆氏总部评估等候区外走廊，傍晚）**  
沈星野抱病历夹等在会议室外。带教主任的空咖啡杯——他刚接电话出门（挂电话回来时眼神一躲，她没看见）。手机屏一亮：带教邮件"下周推荐信名单再审。请勿失误。"（**个人代价上桌**）  
门缝内，本尊看向投影——一角闪过"儿童精神评估·陆家封存"一秒（**陆母亲自审自己封存档案时留的窗口，她没来得及关屏——陆母控制体系的 Ep1 第一处疏漏**）→ 指节按发白 → 呼吸沉半拍 → 门拉开 → 夜逼近抵墙 → **夜**："说出去，我毁的不只是你的实习。"  
沈星野脚跟贴门框半寸（**想退没退——她第一次可见的害怕**）："你不是他。" → 夜顿住，火机灭 → **夜**："……你什么都不懂。"松手退走。

**集末（陆宅客厅，雨夜）**  
管家推着行李箱进门（陆母安排，陆母本人不出场）："夫人交代，沈医生今晚开始留下。"本尊换过衬衫下楼："我不需要日间照护。你可以走。"  
沈星野："下午在陆氏，你抵我上墙的时候——"  
本尊："我不记得抵过你上墙。"  
沈星野："你不记得，还是——不知道？"（**Ep1 核心翻转：她意识到他自己也不知道**）  
本尊答不出。绕过她走向楼梯。镜墙里眼神先硬住再一颤，**另一个他一秒探头**——无名，无形，只是一层裂缝。  
黑屏：**「三个他，只许你知道。」**

**Ep1 四大锁**：  
- 只 2 人格出场（本尊 + 夜），小小到 Ep3 首登  
- 女主全不知（她只知道"另一个他"，没有名字、没有形态，也不知道还有第三个）  
- 男主全不知（"我不记得"→"你不记得，还是不知道？"→他答不出，是本集情感钩子的翻转点）  
- 陆母是童年主使 + 二十年 gaslighter + Ep1 就有第一处控制疏漏（投影窗口没关）

## 7. Out of scope（本规格不写）

- 超过 3 个常驻人格（中后期若加第 4 个须另开变更）  
- 现实世界把男主视觉变成儿童身体  
- 照搬《Kill Me, Heal Me》具体情节、角色名、桥段顺序  
- 本阶段不写完整 40 集剧本正文（先 synopsis → characters → treatment）
