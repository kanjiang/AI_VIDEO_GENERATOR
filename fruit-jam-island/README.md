# 果酱岛控制中心 · Jam Island Control

爆笑冒险喜剧动画。横屏 16:9，每集约 4 分钟，第一季 10 集。3–8 岁通吃，成年人可刷。

> 一颗坚信「每个按钮都在等我按」的小番茄，和一颗还记得上次大喷发的柠檬，在一座会打嗝喷果酱的菠萝火山底下值班——每天的任务是哄火山保持心情稳定，而每天的结局是全岛被果酱淹一次。

## 这个 IP 的三条根

**火山不是灾难，是全岛的果酱工厂。**它每天定时打一个嗝，喷出果酱供全岛取暖、发电、吃饭。控制中心的工作是哄它保持心情稳定、按时打嗝。喷出来的是琥珀金果酱，永远不是红色岩浆。

**万物皆活。**火山会打嗝、西瓜电脑会摆烂、香蕉船怕水、葡萄按钮会尖叫、红绿灯三兄弟永远在吵谁该亮。笑点不用硬写，从角色的身体构造里自己长出来。

**每个角色的生理构造 = 喜剧机制 = 性格外化。**番茄会爆、柠檬会酸、芒果一撞就凹、哈密瓜网纹天生像辆旧公交。这既保证笑点不枯竭，也让出图有硬锚点可锁。

**控制中心三人组**

| 啵啵 | 小番茄，实习员，主角 | 真心相信每个按钮都在等他按；一激动就爆浆 |
| 柠七 | 柠檬，值班主管，主角 | 过度控制；岛上唯一记得上次大喷发的水果 |
| 瓜叔 | 西瓜电脑，控制中枢 | 知道所有答案，但每次都要先讨价还价 |

## 五个常设场景

控制中心内部、菠萝火山口、果酱岛全景（清晨态 / 喷发态）、果酱码头、环岛公路红绿灯路口。

五个场景撑十集，这是本项目最大的成本优势。季终额外做一个**花火节夜空**——漫天糖花，全季宣传封面镜头。

## 制作顺序

先做 **Ep 01「加速」**：十集里唯一零新增资产的一集，全部发生在五个常设场景内，靠打破「火山按时打嗝」这条规则把规则教给观众。跑通它就跑通整套流程。

之后是 Ep 08（验证环岛公路场景）、Ep 10（决定整季能否收住 + 产出封面镜头），其余七集批量制作。

低抽卡出图顺序：**角色身份板 → 黑白故事板表格 → 场景图 → 视频生成**。
