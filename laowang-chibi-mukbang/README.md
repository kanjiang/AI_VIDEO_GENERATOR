# 《老王Q版吃播·火锅篇》制作指南

## 制作流程

```
Step 1: 生成角色资产图 → Step 2: 生成场景资产图 → Step 3: 生成视频
```

---

## Step 1 — 生成角色资产（推荐工具：可灵/即梦/MidJourney）

### 1.1 Q版老王·角色设定（三视图）

> 复制以下提示词，配合 `assets/laowang-reference.png` 真人参考图一起投喂

```
Q版卡通角色设定图，3D皮克斯风格，大头小身比例（头身比约2.5:1）。角色：中东面孔青年男性，肤色小麦色，浓密修剪整齐的黑色短胡须，黑色短发微卷，浓眉大眼，眼睛炯炯有神带笑意。服装：黑色马甲+白色衬衫+蓝灰色领带，袖子卷到小臂。表情：标志性大笑，嘴角上扬，右手竖起大拇指。体型：微胖壮实，肩宽，Q版化后显得圆润可爱。3D渲染，柔和光影，皮肤质感圆润光滑，眼睛有高光反射，色彩饱和度高，干净白色背景，三视图（正面、侧面、3/4角度）。
```

**验收标准：**
- [ ] 面部特征保留（胡须形状、浓眉、肤色）
- [ ] 马甲+衬衫+领带穿搭清晰
- [ ] 头身比约2.5:1，圆润Q弹
- [ ] 三个角度都一致

Q版卡通角色表情图，3D皮克斯风格，大头小身比例。中东面孔青年男性，黑色短胡须，黑色短发微卷，黑色马甲白衬衫蓝灰领带。表情：极致满足——双眼挤成弯月，嘴巴大张，腮帮鼓起，脸颊泛红冒出粉色蒸汽，头顶冒出爱心和星星特效。双手捧脸，身体后仰微微飘起，表达"太好吃了升天"。3D渲染，柔和光影，卡通夸张，纯白色背景。

## Step 2 — 生成场景与道具资产

### 2.1 火锅桌面全景

```
Q版卡通场景，3D渲染，微缩模型感。中国火锅餐厅圆桌，桌面中央鸳鸯锅（红油+清汤），锅内冒密集气泡和白色蒸汽。配菜：雪花牛肉卷、翠绿生菜、金针菇、豆腐块、虾滑丸子，食材Q弹圆润有光泽。蘸料碟三个。背景暖色灯光，红色中式灯笼窗花虚化。暖黄色调，热气腾腾。俯视45度角。9:16竖屏构图。
```

### 2.2 筷子夹肉特写

```
Q版卡通道具特写，3D渲染。红色木筷夹着一片薄透的雪花牛肉卷，粉白相间，边缘微卷带光泽。下方是翻滚冒泡的红油火锅汤底，蒸汽升腾。聚焦筷子和肉片，背景虚化暖色光晕。
```

---

## Step 3 — 生成视频

将 Step 1/2 生成的资产图保存到 `assets/` 目录：

```
assets/
├── laowang-reference.png          ← 真人参考（已有）
├── laowang-chibi-main.png         ← Q版角色设定
├── laowang-chibi-reaction.png     ← Q版美味反应
├── hotpot-table-scene.png         ← 火锅场景
└── chopstick-meat-closeup.png     ← 筷子夹肉
```

然后打开 `screenplay/video-prompts.md`，按照其中 Shot 1 和 Shot 2 的提示词，在视频生成工具（可灵/Seedance/Runway）中：

1. 挂载对应资产图
2. 复制中文提示词
3. 设置参数：15秒 / 9:16竖屏
4. 分别生成两段，后期拼接

---
