# 角色身份板提示词 — 《果酱岛控制中心》

九个角色的 16:9 身份板生成提示词。全部**纯白 / 米白背景**、**艺术书非对称布局**、**多角度全身严格锁定身份**。

这九张图是所有 shotlist 和 Seedance 视频 prompt 的**角色一致性参考图**，是本项目最基础的视觉资产。出图顺序按本文件从上到下——两个主角先出，因为后面每一集都靠它们对齐。

---

## 共通规范

**共通视觉锚：**
- 整体风格 = Pixar 级 3D 糖果色动画 + 水果实体质感（Q 版比例，圆胖，大眼睛，可读性优先）
- **质感签名（本 IP 核心，每张必须命中）** = 果蜡高光、水珠、半透明果肉透光、糖浆拉丝
- 材质 = 果皮有真实的表面特征（番茄的蜡质、柠檬的孔洞、哈密瓜的网纹、葡萄的白霜），不是塑料
- 每张板必须包含：主英雄视角（正 3/4 全身）+ 辅助研究（正侧、正面脸部特写、后 3/4、俯视缩略）+ 表情条 + 剪影研究 + 简约角色 ID 卡

**⚠️ 灯光规范（重要，不要套用片中的光照规则）：**
身份板使用**中性柔和棚拍光，无强阴影、无环境反射、无色偏**。

片中「火山是全岛唯一暖光源」那条规则**不适用于身份板**。身份板的用途是让模型在任意角度、任意打光下重现角色身份，如果身份板本身带着橙色火山光，后续所有镜头都会被这个色偏污染，角色的固有色也就锁不住了。火山光只在场景板和视频 prompt 里出现。

**共通负面约束：**
不要人类角色，不要背景环境，不要广告海报感，不要商品摆拍感，不要网格 / 蓝图目录布局，不要重叠不同视角，不要裁切肢体或果体，不要让不同视角失去身份一致性，不要塑料质感，**不要红色岩浆（本片喷发物永远是琥珀金果酱）**。

## 1. 啵啵 · 小番茄（主角，第一优先）

**啵啵角色身份板提示：**

创建一张艺术性的 16:9 角色身份板。

[主体]：一颗 Q 版拟人化的小番茄，名叫啵啵。他是《果酱岛控制中心》的主角，一个刚上岗一周的实习员，一个真心相信「每个按钮都在等我按」的天真捣蛋鬼。

[身体设计]：完美的圆球体，饱和番茄红果皮，**果皮极薄**，表面有强烈的果蜡高光和几颗水珠。四肢短小圆胖（手脚像小豆子），跑动时整个人像在滚。身体比例约为头身一体（整颗番茄就是他的身体和头）。

[脸部设计]：两颗极大的圆形黑瞳占据脸部大部分面积（婴儿脸比例），瞳孔上有两点高光。嘴巴是一道能拉得极宽的弧线，可以张成 O 型、拉成大笑、瘪成一条线。没有鼻子。

[标志道具]：头顶一小撮五角星形的绿色番茄蒂当头发。**情绪激动时绿蒂会整根立起来**——这是他最重要的识别信号，必须在所有视角清晰可见。

[背景]：纯白色背景，无环境、无道具、无标志、无水印。

[灯光]：中性柔和棚拍光，无强阴影，无环境反射，无色偏。

[设计方向]：不要创建商品摆拍图。创建一张感觉像 Pixar 前期开发部艺术书的角色身份板。布局不对称、优雅、大片留白，多种视角尺寸交错。避免网格布局、蓝图三视图目录、宣传海报构图。

[重要布局规则]：不要重叠任何身体视角。每个视角必须清晰分离、有呼吸空间。禁止裁切四肢或绿蒂。禁止用局部特写替代完整身体视角。

[主要构图]：放置一个大型英雄视角作为视觉锚点——正 3/4 全身，前倾伸手去按什么东西的姿态（暗示核心性格），略微偏离画面中心。围绕它以干净间距排列较小的辅助研究：
- 正侧全身（展示球体轮廓与绿蒂）
- 后 3/4 全身
- 正面脸部特写（放大黑色大瞳孔、宽弧嘴、绿蒂根部）
- 俯视缩略（从上看下去的绿蒂五角形状）
- 一个「滚动前进」的动态姿势

⚠️ 所有身体视角必须完整可见（绿蒂顶到脚底），禁止半截裁切。

[**形态三阶段研究区**（本角色最重要的一块，必须包含）]：
一条横向的三格形变序列，展示他的招牌生理机制：
1. **常态** — 圆润饱满
2. **膨胀态** — 身体撑大约 1.5 倍，果皮绷紧到**半透明**，能看见里面的番茄汁在晃动，绿蒂完全立起
3. **瘪皮态** — 爆浆之后，变成一张软塌塌的空果皮，塌在地上，绿蒂垂下来，眼睛还在，嘴微张漏气

⚠️ 瘪皮态必须画成明亮欢快的番茄红空皮，**不要有任何血色、伤口或痛苦感**，这是喜剧不是恐怖。

[身份锁定]：所有视角保持严格一致——同款饱和番茄红蜡质果皮、同款五角绿蒂形状与位置、同款超大黑瞳与高光点、同款宽弧嘴、同款圆球比例。

[艺术性区域]：
- 剪影研究区：3 个纯黑色剪影，展示常态 / 膨胀态 / 瘪皮态三种轮廓的辨识度
- 表情研究区：6 个正面小图，情绪分别为跃跃欲试（瞳孔放大、绿蒂立起）、得意、假装没事（视线回避）、震惊（瞳孔炸开）、爆浆前一刻（果皮半透明）、瘪皮漏气（眼睛还睁着，嘴歪着）
- 细节研究区：绿蒂五角结构特写、果蜡高光与水珠的材质特写、半透明果皮透出内部汁液的效果特写

[角色 ID 块]：简约、大胆、艺术导向的手写风格标签。仅使用以下字段：
- Name: BOBO 啵啵
- Role: Control Room Intern / 控制中心实习员
- Voice: High fast boy, cracks when excited / 高亢急促男童声
- Signature: 「它在等我。你看它都亮了。」
- Palette: 番茄红 + 蒂绿 + 黑瞳

[风格]：简约、电影感、Pixar 高端艺术书感、干净、富有表现力、适用于制作。

[最终目标]：图像应能帮助 AI 后续在任何角度、任何情绪下重现啵啵的身份一致性，包括超大黑瞳、五角绿蒂、蜡质番茄红果皮，以及膨胀 → 爆浆 → 瘪皮这一整套形变。

## 2. 柠七 · 柠檬（主角，第一优先）

**柠七角色身份板提示：**

创建一张艺术性的 16:9 角色身份板。

[主体]：一颗 Q 版拟人化的柠檬，名叫柠七。她是《果酱岛控制中心》的值班主管，一个严厉、洁癖、过度控制的管理者，也是岛上唯一还记得上一次大喷发的水果。

[身体设计]：柠檬形身体，两头微微收尖，明黄色果皮。**表皮必须有清晰的孔洞颗粒质感，绝不能光滑**——这是她和其他角色最重要的材质区别。四肢短小但比啵啵纤细一点，站姿笔直。

[脸部设计]：眼睛比啵啵小得多，眼型细长上扬，虹膜深黄，随时处于「我在看着你」的审视状态。眉毛是两道深黄色短线，**常年皱成一团**。嘴巴是一道紧绷的短线，默认微微下压。

[标志道具]：腰上别着一块**写满流程条目的小板子**（浅米色板面，深色手写小字，字迹密集到发疯）。板子必须在正 3/4 和正侧视角清晰可见，是她的核心识别符号。

[背景]：纯白色背景，无环境、无道具、无标志、无水印。

[灯光]：中性柔和棚拍光，无强阴影，无环境反射，无色偏。

[设计方向]：Pixar 前期开发部艺术书感，非对称优雅布局，大留白，多视角尺寸交错。避免网格 / 蓝图 / 海报构图。

[重要布局规则]：不重叠、清晰分离、有呼吸空间。禁止裁切四肢或流程板。

[主要构图]：
- 大型英雄视角：正 3/4 全身，双手抱着流程板、身体微微前倾质问的姿态，略偏画面中心
- 辅助研究：正侧全身（展示腰间流程板）、后 3/4 全身、正面脸部特写（放大皱眉、细长审视眼、下压嘴线、孔洞果皮质感）、俯视缩略、一个「指着某处下命令」的姿势

⚠️ 所有身体视角必须完整可见。

[**喷酸机制研究区**（必须包含）]：
两格序列，展示她的招牌生理机制：
1. **紧张态** — 眉头锁死，眼角开始沁出一小滴清亮柠檬汁
2. **失控态** — 柠檬汁从眼角成股喷射出去（细而急的清亮弧线），她自己一脸难以置信

⚠️ 柠檬汁必须画成**清亮透明带高光**，不要画成浑浊或黄浊的液体。

[身份锁定]：所有视角保持严格一致——同款明黄孔洞颗粒果皮、同款细长审视眼、同款皱眉双线、同款下压嘴线、同款腰间流程板位置、同款两头微尖的柠檬轮廓。

[艺术性区域]：
- 剪影研究区：3 个纯黑色剪影，展示笔直站姿 / 前倾质问 / 转身离开三种「管理者姿态」
- 表情研究区：6 个正面小图，情绪分别为审视、不耐烦、念流程（眼睛半闭、嘴快速动）、强忍、一到两帧的恐惧（**唯一一张露出脆弱的表情，眼睛睁大、眉毛不再是皱而是抬起**）、嘴角极轻微松一下（她的最大笑容上限）
- 细节研究区：柠檬孔洞果皮的材质特写、流程板上密集手写字的特写、眼角柠檬汁的形成过程特写

[角色 ID 块]：
- Name: NINGQI 柠七
- Role: Duty Supervisor / 值班主管
- Voice: Crisp fast mature female, falling ends / 咬字紧、句尾下压
- Signature: 「我早就说了。」
- Palette: 明黄 + 深黄 + 清亮柠檬汁

[风格]：Pixar 高端艺术书、干净、紧绷感强、适用于制作。

[最终目标]：图像应帮助 AI 后续在任何角度稳定重现柠七的孔洞质感明黄果皮、细长审视眼、锁死的眉头、腰间流程板，以及眼角喷酸的机制。**并且必须保留那一张脆弱表情**，它是这个角色不流于刻薄工具人的关键。

## 3. 瓜叔 · 西瓜电脑（装置板，非全身板）

**⚠️ 本角色的板式与前两个不同。**瓜叔没有四肢、永不站起、永久嵌在控制台里，所以不做「全身多视角」，改做**装置板**：多角度展示嵌入状态 + 屏幕状态研究。

**瓜叔角色身份板提示：**

创建一张艺术性的 16:9 装置身份板。

[主体]：一颗 Q 版拟人化的西瓜电脑，名叫瓜叔。他是《果酱岛控制中心》的主控系统，也是全岛最老的机器——知道所有答案，但每次都要先讨价还价才肯说。

[本体设计]：一整颗西瓜的**前半球**嵌在控制台台面里，后半球埋在台面下看不见。深绿色瓜皮，墨绿色虎纹条带（纹路清晰、宽窄不一）。瓜皮有蜡质高光和几颗水珠。**没有四肢，没有脸，不会站起来。**

[屏幕设计]：本体正面被切开一个圆形切面当屏幕——**鲜红的西瓜瓜肉**，质地水润半透明、能看见细微的纤维。数据以**黑色西瓜籽的排列方式**显示在瓜肉上：籽排成行、排成阵列、排成箭头。⚠️ 每一颗籽必须能单独看清，它们就是数据本身，不能画成模糊的一团。

[标志细节]：台面边缘散落着几颗**掉出来的西瓜籽**（掉籽 = 丢内存，是他的核心弱点）。

[背景]：纯白色背景，只保留一小段承载他的控制台台面（浅色、简洁、无花纹），其余全白。无环境、无水印。

[灯光]：中性柔和棚拍光，无强阴影，无色偏。瓜肉屏幕本身可以有极轻微的自发光。

[设计方向]：Pixar 前期开发部艺术书感，非对称优雅布局，大留白。

[主要构图]：
- 大型英雄视角：正 3/4 嵌入状态（能同时看到瓜皮虎纹、红色瓜肉屏幕和一段台面），略偏画面中心
- 辅助研究：正面视角（屏幕正对观众，籽阵列完整可读）、正侧视角（展示嵌入台面的深度关系）、俯视缩略（从上看下去的圆形切面）
- 一个「开机中」状态：屏幕瓜肉偏暗，籽还没排列成形，边缘有嗡鸣的振动线

⚠️ 所有视角都必须表现「嵌在台面里」这一关系，不要出现悬空的完整西瓜。

[**屏幕状态研究区**（必须包含）]：
四格瓜肉屏幕特写，展示籽排列的四种状态：
1. **待机** — 籽稀疏随机分布
2. **计算中** — 籽排成密集的行列
3. **报出倒计时** — 籽排成一个巨大的数字
4. **丢内存** — 籽阵列缺了一块，缺口边缘的籽散乱，台面上多了几颗掉落的籽

[身份锁定]：所有视角保持严格一致——同款深绿瓜皮与墨绿虎纹、同款鲜红半透明瓜肉切面、同款黑籽作为数据、同款嵌入台面的关系。

[艺术性区域]：
- 剪影研究区：2 个纯黑色剪影，展示「半球嵌入台面」的轮廓辨识度
- 细节研究区：虎纹条带的走向特写、单颗西瓜籽的形态特写、瓜肉半透明纤维的材质特写、掉落籽粒的特写
- 情绪表达研究区：4 格，展示他没有脸却能表达情绪的方式——**虎纹条带随情绪微微流动**（得意时纹路上扬、不高兴时纹路收紧、开机时纹路暗淡、满意时纹路舒展）

[角色 ID 块]：
- Name: GUASHU 瓜叔
- Role: Main Console System / 主控系统
- Voice: Low slow elderly male with electrical noise / 低沉缓慢带电流杂音
- Signature: 「查到了。但你刚才那个语气，我不太舒服。」
- Palette: 深绿 + 墨绿虎纹 + 瓜肉红 + 籽黑

[风格]：Pixar 高端艺术书、干净、老机器的厚重感、适用于制作。

[最终目标]：图像应帮助 AI 后续稳定重现瓜叔嵌入台面的关系、瓜肉屏幕上以西瓜籽显示数据的方式，以及靠虎纹流动而非表情来演戏的机制。**绝不能画成有四肢或站立的西瓜，也绝不能画成显示器造型。**

## 4. 葡萄串 · 控制台按钮（集体装置板）

**⚠️ 本角色是集体角色 + 嵌入装置**，同样不做全身板，改做**装置板 + 个体表情研究**。

**葡萄串角色身份板提示：**

创建一张艺术性的 16:9 集体装置身份板。

[主体]：一串 Q 版拟人化的葡萄，嵌在控制台面板上，每一颗葡萄是一个按钮。它们是《果酱岛控制中心》的引爆装置——标签早就掉了，连它们自己都不知道哪颗对应什么功能。

[本体设计]：一整串饱满的**深紫色**葡萄，果皮带**白霜**（哑光的粉白覆层）和一处集中的镜面高光——白霜与高光并存是葡萄材质的关键。每颗葡萄嵌在控制台面板上，只露出上半球，像一排按钮。串子有清晰的主茎与分枝结构。

[脸部设计]：每颗葡萄有一对很小的圆眼睛和一张很小的嘴。**每颗的表情都不一样**——有的紧张、有的看向旁边、有的假装睡着、有的正在指控隔壁那颗。

[标志道具]：串子**最末端垂着一颗干瘪发黑的葡萄**——表皮皱缩、颜色近黑、**完全没有五官**。它旁边贴着一张褪色卷边的标签，手写着「绝对不要按」。⚠️ 这颗黑葡萄绝对不能有眼睛或嘴，它的「没有脸」就是它的恐怖来源，也是全季最重要的悬念道具。

[背景]：纯白色背景，只保留一小段承载它们的控制台面板（浅色、简洁），其余全白。无环境、无水印。

[灯光]：中性柔和棚拍光，无强阴影，无色偏。

[设计方向]：Pixar 前期开发部艺术书感，非对称优雅布局，大留白。

## 6. 菠萝火山（形态板，非角色板）

**⚠️ 本对象的板式与所有角色都不同。**火山是一座山那么大的菠萝，没有五官、没有嘴、永不说话，全靠**轮廓形变、缝隙透光和声音**演戏。所以不做「角色板」，改做**形态板**：轮廓研究 + 打嗝阶段序列 + 鳞片格与缝隙透光的材质研究。

**菠萝火山形态板提示：**

创建一张艺术性的 16:9 形态设定板。

[主体]：一座山那么大的巨型菠萝，它是《果酱岛控制中心》里全岛的果酱工厂、暖气与发电厂。它有情绪但**没有五官、没有嘴、不会说话**。

[本体设计]：巨大的菠萝山体，表皮是**规则的六边形鳞片格**，格与格之间有很深的沟缝。⚠️ 鳞片格必须规则、成阵列——它是一颗菠萝，不是一座长得像菠萝的普通山。顶部一簇**巨大的绿色冠叶**构成山顶植被，叶片厚实、边缘带锯齿、向四周张开。火山口位于冠叶正中央。

[材质]：菠萝金黄的鳞片表面有蜡质哑光反射；沟缝深处偏暗；山体下部有果酱流淌过后留下的琥珀色干涸痕迹。

[背景]：纯白色背景，**不要天空、不要海、不要岛、不要其他角色**。无水印。

[灯光]：中性柔和棚拍光为主，用于表现山体形态与鳞片材质。**唯一例外**：缝隙透出的内部金色光可以自发光（那是它的内部果酱在发光），但不要让这个光染到整张图。

[设计方向]：Pixar 前期开发部艺术书感的**环境形态研究页**，非对称优雅布局，大留白。避免风景插画感、避免旅游海报感。

[主要构图]：
- 大型英雄视角：正面全山体（能看到完整轮廓、鳞片格阵列、冠叶与火山口位置），略偏画面中心
- 辅助研究：正侧全山体（展示山体的坡度剖面轮廓）、后侧全山体、火山口俯视缩略（冠叶环绕中央的口）、山体下部特写（果酱流淌痕迹与管道接入口）

⚠️ 全山体视角必须完整可见（冠叶顶到山脚），禁止裁切山顶或山脚。

[**打嗝四阶段序列**（本板最核心的一块，必须包含）]：
一条横向的四格形变序列，这是它全部的表演方式：
1. **常态** — 山体安静，鳞片格闭合，沟缝暗
2. **蓄积态** — **整个山体向上鼓起膨胀**，鳞片格被撑开、格与格之间的距离变大，沟缝里开始透出内部的金色光
3. **打嗝态** — 一股**琥珀金色的果酱**从火山口喷出，划出一道弧线；山体处于最膨胀的瞬间，缝隙金光最亮
4. **松弛态** — 山体回落、鳞片格闭合、沟缝重新变暗，冠叶因为刚才的气流而向外翻了一点

⚠️⚠️ **喷出物必须是琥珀金色的浓稠果酱，绝对不能是红色岩浆、不能是火、不能是烟。**这是本 IP 最重要的一条视觉禁令。果酱应该有粘稠感、有拉丝、有流动的重量。

[**情绪状态研究区**（必须包含）]：
四个小幅山体轮廓，展示它靠形变表达的情绪：
- **心情好** — 山体舒展、冠叶张开、缝隙光温暖均匀
- **心情差** — 山体紧缩、冠叶下垂、缝隙光闪烁不稳
- **憋着不打嗝** — 山体膨胀到极限但火山口紧闭，缝隙光极亮且在渗漏，整体有一种憋住的张力
- **满意** — 山体微微下沉、冠叶松松垂着，缝隙光柔和

[身份锁定]：所有视角保持严格一致——同款规则六边形鳞片格阵列、同款巨大绿色冠叶形状、同款火山口位置（冠叶正中）、同款菠萝金黄蜡质材质。⚠️ 绝不给它画五官或嘴。绝不让它说话。

[艺术性区域]：
- 剪影研究区：4 个纯黑色山体剪影，展示常态 / 蓄积 / 打嗝 / 憋住四种轮廓的辨识度（这是观众唯一能读出它情绪的方式，所以剪影必须区分明显）

[ID 块]：
- Name: MOUNT PINEAPPLE 菠萝火山
- Role: Jam Factory / Heating / Power — the island's everything
- Voice: **No language.** Low rumble, burps, gurgles, sighs, held pressure
- Signature: （无台词）
- Palette: 菠萝金 + 冠叶绿 + 琥珀金果酱 + 缝隙内金光

[风格]：Pixar 高端艺术书的环境形态研究页、干净、有体量感与重量感、适用于制作。

[脸部设计]：车头两颗细长上扬的前灯做眼睛（虹膜琥珀、眼型狭长、常年半闭着一副没在听的样子）。前保险杠做成一张斜挑的嘴，默认**一侧嘴角上扬**成得意的坏笑。

[标志设计]：车身侧面没有任何贴纸或字（他不需要标识，他的身份就是那身反光）。⚠️ 不要给他加赛车条纹或号码，那会削弱「一颗芒果在飙车」的荒谬感。

[背景]：纯白色背景，无环境、无道路、无水印。

[灯光]：中性柔和棚拍光。⚠️ 例外：为了表现他极强的反光，可以有一条清晰的长条形高光带（像影棚灯管的倒影），但不要引入色偏。

[设计方向]：Pixar 前期开发部艺术书感，非对称优雅布局，大留白。避免汽车广告感。

[重要布局规则]：不重叠、清晰分离、有呼吸空间。禁止裁切车头 / 车尾 / 车轮。

[主要构图]：
- 大型英雄视角：正 3/4 全车身，车头微微下压的起步冲刺姿态，略偏画面中心
- 辅助研究：正侧全车身（完整展示芒果的流线轮廓与橙红渐变）、后 3/4 全车身（车尾收窄的尖端）、正面脸部特写（放大细长琥珀眼、单侧上扬的坏笑嘴、高光带）、俯视缩略（从上看下去的芒果形轮廓）
- 一个「过弯甩尾」的动态姿势

⚠️ 所有车身视角必须完整可见。

[**软体撞击四阶段序列**（本角色最重要的一块，必须包含）]：
这是他敢飙车的物理原因——**芒果是软的，事故对他毫无成本**：
1. **常态** — 车身饱满、高光完整
2. **撞击瞬间** — 车头一侧被撞出一个**深深的凹坑**，凹坑周围果皮起皱，高光被凹面扭曲
3. **漏汁** — 凹坑里渗出橙黄色的芒果汁，顺着车身往下流
4. **复原** — 车身抖一下（用轻微重影表现），汁被吸回去，凹坑弹回，高光恢复完整

⚠️ 凹坑必须画得明显、有深度、有果皮褶皱，但**不要画成破损、裂开或伤口**——它是软的，不是坏的。整个过程要读起来轻松无痛。

[身份锁定]：所有视角保持严格一致——同款橙黄到红的渐变果皮、同款全剧最强镜面高光、同款细长半闭琥珀眼、同款单侧上扬坏笑嘴、同款低矮流线芒果轮廓。⚠️ 绝不画成硬壳不可凹的车身，绝不画成哑光。

[艺术性区域]：
- 剪影研究区：3 个纯黑色剪影，展示起步冲刺 / 过弯甩尾 / 凹了一块三种轮廓
- 表情研究区：5 个正面小图，情绪分别为得意坏笑（默认）、起哄、超速兴奋（眼睛终于睁开）、撞完不当回事（耸肩式的车身倾斜）、**第一次真的慌了**（第 7 集用：眼睛睁大、嘴角落下、盯着自己没能复原的凹坑）
- 细节研究区：橙红渐变的过渡区特写、镜面高光带与环境反射的材质特写、凹坑处果皮褶皱的结构特写、芒果汁的流动质感特写

[角色 ID 块]：
- Name: MANGMANG 芒芒
- Role: Mango Street Racer / 芒果飙车党
- Voice: Flippant teenage male, fastest in the cast / 轻浮少年声，全剧最快
- Signature: 「凹了？凹了就凹了，我三秒就好。」
- Palette: 芒果橙 → 红渐变 + 强镜面高光 + 琥珀眼

[风格]：Pixar 高端艺术书、干净、轻浮的速度感、适用于制作。

[最终目标]：图像应帮助 AI 后续稳定重现芒芒的橙红渐变强反光车身、细长半闭的眼、单侧坏笑，以及**撞凹 → 漏汁 → 抖一下复原**这套软体机制。**必须保留那张「第一次真的慌了」的表情**，它是第 7 集结尾的关键。

## 9. 红绿灯三兄弟（集体角色板）

**⚠️ 本角色是集体角色**，板式为：整体装置全视角 + 三颗个体分别研究 + 亮灯状态研究。

**红绿灯三兄弟角色身份板提示：**

创建一张艺术性的 16:9 集体角色身份板。

[主体]：一组 Q 版拟人化的水果红绿灯，名叫红绿灯三兄弟。它们立在《果酱岛控制中心》环岛公路的路口，三个都自称老大，永远在吵该谁亮。

[本体设计]：一根**深褐色的甘蔗杆**当灯柱（有清晰的竹节状分节和纵向纤维纹理），杆上自上而下叠着三颗果子：
- **红老大 = 一颗草莓**（顶部，红色，表面有细小的黄色籽点，头顶残留一小片绿萼）
- **黄老二 = 一颗金桔**（中间，橙黄色，表皮有细密的油胞颗粒）
- **绿老三 = 一颗青提**（底部，黄绿色，半透明感最强，表面有白霜）

⚠️ 三颗的品种必须固定为草莓 / 金桔 / 青提，绝不替换。三颗紧紧叠在一起、被杆串着，不能脱离甘蔗杆。

[脸部设计]：每颗有一对小圆眼睛和一张小嘴。⚠️ **三颗永远不共享表情，它们永远在互相瞪或互相翻白眼**——至少有两颗的视线要落在另一颗身上。

[亮灯设计]：某颗「亮起」时，**它的果肉从内部透光发亮**（草莓透红光、金桔透橙光、青提透黄绿光），未亮的两颗则偏暗。青提因为半透明感最强，亮起来最通透。

[背景]：纯白色背景，无环境、无道路、无水印。

[灯光]：中性柔和棚拍光为底。⚠️ 例外：亮起的那颗果肉可以自发光，但不要让这个光染到整张图或另外两颗。

[设计方向]：Pixar 前期开发部艺术书感，非对称优雅布局，大留白。

[重要布局规则]：不重叠、清晰分离、有呼吸空间。禁止裁切甘蔗杆顶端、底座或任何一颗果子。

[主要构图]：
- 大型英雄视角：正 3/4 全装置（能同时看到甘蔗杆、三颗果子的叠放关系、以及三颗互相瞪着的表情），略偏画面中心
- 辅助研究：正面全装置（三颗正对观众，像一个真正的红绿灯）、正侧全装置（展示三颗叠放的厚度与杆的关系）、俯视缩略（从上看下去只看到红老大的顶）
- 三颗**分别的正面脸部特写**（各自单独一格，展示三种不同的果皮材质与性格）

⚠️ 全装置视角必须完整可见（杆顶到杆底）。

[**亮灯状态研究区**（必须包含）]：
四格状态序列：
1. **红亮** — 草莓透红光，金桔与青提偏暗
2. **黄亮** — 金桔透橙光，另两颗偏暗
3. **绿亮** — 青提透黄绿光，另两颗偏暗
4. **⚠️ 三颗同时亮（灾难态）** — 三颗全部透光发亮，三张嘴同时在说话，表情最激烈。这是第 8 集的灾难源，必须画得混乱且好笑

[**争吵研究区**（必须包含）]：
一格宽幅小场景，展示招牌喜剧机制：三颗同时张嘴，红老大瞪着黄老二，黄老二瞪着绿老三，绿老三悠悠地看着别处——三种不同的音高与脾气必须从表情上就能读出来。

[身份锁定]：所有视角保持严格一致——同款深褐甘蔗杆（竹节 + 纵纹）、同款草莓 / 金桔 / 青提三品种与上中下顺序、同款各自的果皮材质特征（草莓籽点、金桔油胞、青提白霜）、同款「永不共享表情」的关系。

[艺术性区域]：
- 剪影研究区：2 个纯黑色剪影，展示整根灯柱的轮廓辨识度（三颗叠放的大小差异必须在剪影里就能分辨）
- 表情研究区：9 个小图（每颗 3 个）——红老大：横、暴怒、勉强让步；黄老二：急、尖叫、幸灾乐祸；绿老三：慢、欠、假装没听见
- 细节研究区：甘蔗杆竹节与纵向纤维的材质特写、草莓籽点特写、金桔油胞颗粒特写、青提白霜与半透明透光特写

[角色 ID 块]：
- Name: THE THREE BROTHERS 红绿灯三兄弟
- Role: Ring Road Traffic Light / 环岛红绿灯
- Voice: Three distinct pitches — Red coarsest, Yellow shrillest, Green slowest / 红最横、黄最急、绿最欠
- Signature: 红「该我了。」黄「凭什么？」绿「你们俩都还亮着呢！」
- Palette: 草莓红 + 金桔橙 + 青提黄绿 + 甘蔗深褐

[风格]：Pixar 高端艺术书、干净、集体角色的性格层次、适用于制作。

[最终目标]：图像应帮助 AI 后续稳定重现三兄弟的甘蔗杆结构、草莓 / 金桔 / 青提的固定品种与顺序、三种截然不同的性格表情，以及**三颗同时亮起的灾难态**。
