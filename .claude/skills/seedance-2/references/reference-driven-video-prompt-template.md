# 参考图驱动的视频生成模板

这个模板用于最后的视频生成阶段。前提不是“从零写一个视频 prompt”，而是你已经准备好了：

1. 场景图
2. 角色身份板
3. 黑白故事板表格

## 输入顺序建议（空间优先原则）

输入顺序影响 AI 的空间识别权重。先空间再人物，减少空间漂移：

1. **图 1：场景图** — 锁定环境结构、灯光方向、空间比例
2. **图 2：角色身份板** — 锁定角色身份、服装、体态
3. **图 3：故事板表格** — 锁定镜头设计、动作推进

### 复杂走位场景（追加输入）

当场景涉及多人走位、追逐、打斗或复杂运镜时，在故事板表格之后追加俯视调度图：

4. **图 4：俯视调度图** — 仅作空间坐标与运动轨迹参考

调度图的生成方法和标注规范见 `../../shotlist-builder/reference/SPATIAL_BLOCKING.md` §8。

## 提示词模板

**视频生成提示词：**

【挂载资源与音频硬约束】本视频必须严格使用已挂载的参考资源。角色外貌、服装、发型、体态、身份感、空间结构、关键道具和界面状态只参考挂载图，不重新设计、不重新描述静态设定。只表现口型、眼神、呼吸、手指、重心、衣料受力、道具握持、屏幕/灯光状态和微表情。对白保持原文语言与原句，不翻译、不改写。若说话者声音持续但镜头切到道具、空间、背影、合照或另一人物反应，声音必须继续不断线，保持同一空间混响、距离感和声源方向；重新切回说话者脸部时，口型、下颌开合、呼吸停顿和当前音节必须同步。无字幕、无文字标题、无解释性屏幕文字、无背景音乐，只保留环境音、动作音效和真实语音混响。

【首帧衔接】除全片第一个视频外，本视频必须以上一个视频的尾帧作为本视频首帧。生成时请挂载或参考上一视频尾帧，第一帧的角色站位、身体方向、视线轴线、主光源方向、焦点距离、构图比例、道具状态和环境明暗必须与上一尾帧连续；先保持上一尾帧的空间与光线不跳变，再自然进入本镜头动作。

【规格】生成一个[时长]、[景别/镜头类型]的视频片段。[多镜头时加入时间分配，如：时间分配：镜头1（0-3秒，建立）、镜头2（3-8秒，核心）、镜头3（8-[时长]秒，收束）。]
画质：8K
质感：真人实拍电影质感，[胶片型号，如 柯达Vision3 500T / ARRI Alexa色彩科学]
光追：[光线追踪反射与光线追踪阴影 / 路径追踪]
噪点：轻微胶片颗粒
动态范围：HDR，10-bit色深
锐化：[高锐化边缘增强 / 中等锐化]

【电影化动态描述】初始画面承接首帧衔接状态。图 1 锁定空间结构、灯光方向、背景关系和环境氛围；图 2 锁定角色身份、服装、体态和关键道具；图 3 锁定镜头设计、动作推进、运动方向、节奏变化和收束姿势。[如有图 4 俯视调度图，锁定角色站位坐标、运动轨迹和摄影机路线。]

[多镜头时使用 【镜头N】[功能标签]（时间码）格式，如：]
[【镜头1】[建立]（0-3秒）...]
[【镜头2】[情感核心]（3-8秒）...]

摄影机按[运镜方式]执行，主体是[主体/戏眼]，速度策略是[慢推/快推/稳定跟拍/固定压迫]。画面核心是：[该镜头或该段落的具体动作与表演]。角色只表现可见动作：嘴角状态、眼部状态、面部肌肉状态、手部动作、身体姿态、视线方向、呼吸和重心变化；不要写抽象情绪。[关键物体/主体在当前光线下的材质表现——不只说"是什么"，要说"在这个光线下看起来是什么样"。]光线只来自场景内真实光源，环境必须保持与场景图一致的空间比例、前后景层次和主要物件位置。[⚠️关键约束内联——把最容易出错的细节约束直接写在相关动作旁边。]声音与对白按原语言保留，对白和系统播报只放在声音层，不生成字幕。最后 1 秒落在[本镜头叙事戏眼/情绪落点]。

【音画同步】如果说话者声音持续但镜头切到道具、空间、背影、合照或另一人物反应，声音必须继续不断线，保持同一空间混响和声源方向；重新切回说话者脸部时，口型、下颌、呼吸和当前音节必须同步。

【尾帧转场】（可选——仅当需要在本视频尾部规划转场效果时使用）本视频最后[1-3]秒为转场预备段。转场类型：[匹配剪辑/动作剪辑/甩镜转场/物体遮挡转场/推进转场/光线转场]。尾帧设计：[描述最后N秒的画面状态]。⚠️下一视频首帧必须从[描述下一段的开场画面状态]开始。

【负面约束】避免重新发明角色造型，避免镜头漂移，避免空间穿帮，避免背景随机变化，避免不受控的光线跳变，避免与故事板相冲突的新增动作。不要新增人物、字幕、品牌水印、无关 UI、镜面反射、解释性画外信息。禁塑料质感、禁平面光、禁均匀无方向光源、禁CG默认材质、禁3D渲染感、禁游戏CG感、禁插画感。[如有俯视调度图：禁止调度图标注线条、圆圈标记、箭头、文字标签出现在成片画面中——调度图仅作空间参考。][⚠️此处重复 【电影化动态描述】 中内联的关键约束作为安全网。]

## 使用原则

1. 视频提示词只负责动态信息，不负责重新定义静态设定。
2. 如果结果不稳定，优先回头修参考图，不要先无止境重抽视频。
3. 如果要改角色，就回修身份板。
4. 如果要改镜头，就回修故事板表格。
5. 如果要改空间和打光，就回修场景图。
6. 如果多人站位错乱或空间漂移，就生成俯视调度图锁定坐标和动线。
7. 复杂长镜头拆分多张俯视调度图——单张图只承载一组人物动线 + 一种运镜，防止 AI 同时识别多条轨迹混乱。
