# Episode 02 — 白日的空白

### 制作前置（不进画面，仅供拍摄参考）

**接续 Ep1**：夜里入住后的第一个白日。本尊立规矩 → 沈星野目击一次白日 mini blackout → 她开始记录规律。

**人格出场边界（Ep2 硬锁）**：本集**只出现本尊**。夜、小小都不出场。切换 0 次。观众此时的信息量：知道本尊有"空白"，知道另有一个"他"（Ep1 医院走廊那个），但既不知道夜的名字也不知道有第三个。

**沈星野的推进**：她从"看见"过渡到"记录"。她开始用带教主任的评估表反向做**自己的观察日志**——袖扣状态、口袋内容、时间跨度、异常反应。这是她把 Ep1 的震惊转化成方法的第一步。

**本尊的推进**：他二十年信"焦虑症"，但今天他要面对第一次**没法立刻合理化的空白**——他记不起早上八点到九点四十之间的四十分钟。他会试图用旧模板（会议延迟 / 助理走漏 / 焦虑发作）压过去，但他内心已经有第二个"未问出口的问句"。

### 渐入:

**内景 陆宅早餐间 — 晨**

（Hook 3 秒：冷光，硬规矩。）

**陆景深**

第一条——

镜头拉开。他坐在早餐桌一端。袖扣整齐。咖啡不加糖。

沈星野对面。手里一张打印规约。

**陆景深**

不进主楼二层。第二条，不问我昨晚在哪。第三条，只在预约时间内看我。

沈星野翻到第二页。

**沈星野**

昨晚在天台，你问我"你怎么在这里"——你不记得自己是怎么上去的？

陆景深顿了半秒。

**陆景深**

我在天台上想事情。你路过。这不需要解释。

（他答得太快。像背下来的。）

沈星野合上文件。没答。

（她意识到，他连自己走上天台的路都没有记忆。他甚至不知道自己不记得。）

**内景 陆氏总部 电梯 — 上午 09:41**

电梯门开。陆景深走出来。

助理迎上。

**助理**

陆总，早会已经推到十点半。

**陆景深**

早会本来就是十点。

**助理**（一顿）

……早会本来是八点。您没到。

陆景深脚步顿了半秒。

（观众看到：他手表上是九点四十一。他不记得八点到现在的一小时四十分钟。）

**陆景深**

早会推到十点半可以。

（他没问"我为什么没到"。他二十年被训练不问。）

他走开。

沈星野站在电梯口柱子后。手里带教主任的评估表。

她抽出笔。在评估表背面写：**08:00–09:40，空白**。

（这是她第一条观察记录。）

**内景 陆宅书房 — 傍晚**

陆景深脱西装外套。挂上衣架。

他解袖扣。

右手一顿。

袖口里——一张糖纸。

（不是他会带的东西。）

他捻起来。

指腹碰到纸的褶皱。

指节先僵住。

**陆景深**

……

（他没问出声。他把糖纸放进抽屉。抽屉里已经有几样类似的东西——一根旧发绳、一枚小发卡、一张折得发白的儿童画。他从没想过它们是谁放的，也从没让自己去想。）

**陆景深**（对着抽屉，很轻）

……焦虑症发作。

（他说服自己。他关上抽屉。）

镜头拉远。

沈星野的观察表在门外走廊——她刚要敲门，听见他这一句"焦虑症发作"，手在半空停住。

（她意识到：他有一个二十年的模板，把所有异常都塞进这四个字。她的推进从这一刻开始。她要拆的不是他的病，是这四个字。）

切黑。

**字幕：三个他，只许你知道。**

### 分析

价值弧：**立规矩 → 撞见空白 → 意识到他有一个二十年的自我合理化模板**。她没在 Ep2 直接戳他，因为她已经明白，戳一次没用。她要拆的是他一整套解释系统。

激活的 hamartia：
- **本尊**：他二十年信"焦虑症"，今天电梯口那句"我为什么没到"，他没问出来——这是他 hamartia 的第二次可见 tick（Ep1 是雨里的第一次）。他给自己的旧模板还在起作用，但沈星野第一次看到了模板的样子。
- **沈星野**：她从"目击者"变成"记录者"。她的 hamartia（先做正确的事）在这一集是**方法**：她不激他、不揭他，先建证据链。这是心理科实习医生的职业底色。观众此时开始信她。

本集人格出场硬锁：**只有本尊**。夜、小小都不出场。切换 0 次。

红旗 1：本集靠"没有切换"制造张力。60–90 秒内不出现另一个人格是有风险的——观众可能觉得没爆点。所以每一场戏都要有一个**微爆点**：
- 早餐间："你不记得自己是怎么上去的？" → 他答得太快
- 电梯：他不问"我为什么没到" → 沈星野在评估表背面写下第一条空白记录
- 书房：糖纸 → 他自言自语"焦虑症发作" → 她在门外听见

三个微爆点分布在 60–90 秒里，每 20–30 秒一个信息增量。密度够。

红旗 2：**抽屉里已经有几样类似物件**——一根旧发绳、一枚小发卡、一张儿童画。这些是给观众的钩子。观众此时看到"这些东西一直在"，但不知道是谁放的。小发卡是小小的信号物，将在 Ep3 首登时对上号。发绳是本集埋点，之后每集都会以不同方式出现（Ep5、Ep6、Ep15）。

红旗 3：陆母、夜、小小、陆承岳、宋晚棠、带教主任在 Ep2 全部不出场。这一集是**沈星野 vs 本尊**的双人密闭样本。观众通过她的眼睛认识到他的病比他自己以为的重得多。

红旗 4：Ep2 结尾"焦虑症发作"这四个字是关键台词。观众第一次听到这四个字——之后他每次说这四个字，都是他 hamartia 的复读，也是陆母控制系统的复读。这四个字要在 Ep10 之前反复出现，Ep11–Ep15 之间沈星野当面拆穿。
