**合计 11 条 / 165 秒（2分45秒）。**

> ⚠️ **交付形态：4 个情绪块，不是 11 条独立 BGM，也不是一条 165 秒总谱。**
>
> - **11 条独立 BGM** → 每 15 秒重启一次，开场被切成十一段广告。
> - **一条 165 秒总谱** → AI 音乐工具无法精确对齐 11 个切点，中段必然跑偏。
> - **4 个情绪块（30–60 秒/块）** → 块内连续、块间在画面转场点对齐，是唯一可执行的方案。
>
> 块划分见上表最右列，生成提示词见 Step 6。

## Step 3 — 核心母题

### 主母题 A（王国母题 · 完整版）

```
BPM=48  4/4  D小调（la 基小调记谱：6=D, 7=E, 1=F, 2=G, 3=A, 4=Bb, 5=C）

| 6 -  -  - | 5 -  -  - |
| 3 -  -  - | 2 -  -  - |

（4小节，约20s，D–C–A–G 四音下行；结束在 G（小调四级）——刻意不解决）
```

**设计意图：** 四音下行 = "下沉、躲藏、往更深处退"，正是涅柔斯的战略。结束在四级不回主音 = 这个王国没有安全的家。全片母题都从这 4 个音派生。

### 变体 B（猎杀 · 碎片化）

```
BPM: 112
调式: 无调性倾向——D小调骨架被减七与半音堆叠侵蚀
弦乐奏法: 低音弦乐切分 + 琴码颤音(sul ponticello tremolo)
威胁配器: 预置钢弦泛音、弓拉锯片、金属摩擦
织体: 4–5层，互相追逐
和声: 不稳定，无终止感
母题处理: 只取前2音（6–5 / D–C），反复撞击，从不完成
Exclude: 柔和垫底、大调和声、缓慢长弓、任何"英勇"感
适配: 01B 网弹与逃亡
```

### 变体 C（创伤 · 让位版）★对白段专用

```
BPM: 52
调式: D小调，和声悬置
弦乐奏法: 极长弓(molto legato)、低音提琴持续低音
织体: 1层（必要时2层），全部在 120Hz 以下
和声: 悬置——只有一个持续的 D 与偶尔的 Bb 摆动
母题处理: 母题被"呼吸"打断——奏出 6，停 3 秒，再奏 5，停 4 秒
Exclude: 中高频旋律、打击乐、任何清晰节拍重音、任何会与英文对白抢频段的音色
适配: 02A 全段（6句密集对白）
```

### 倒影母题 A′（玛伦母题 · 上行）★★全片核心对抗

```
BPM=44  4/4  D小调

| 6 -  -  - | 7 -  -  - |
| 2 -  -  - | 3 -  -  - |

（4小节，D–E–G–A 四音上行；结束在 A（属音）——同样不解决）
```

**设计意图：** 这是主母题 A 的**严格倒影**——每个音程方向翻转（下行大二度→上行大二度，下行小三度→上行小三度）。

| | 音型 | 含义 | 归属 |
|---|---|---|---|
| 母题 A | D–C–A–G ↓ | 往更深处退、躲藏 | 涅柔斯 / 王国 |
| 倒影 A′ | D–E–G–A ↑ | 上去、反抗 | 玛伦 |

两者是同一个母题的镜像，所以**听起来统一**；方向相反，所以**天然对抗**。这正是全片核心冲突——父亲要往下躲，女儿要往上去。

**使用规则：**
- 01A–02A：倒影**完全不出现**（玛伦还没决定）
- 02B（00:56）：变体 D 的尾音上挑到 A 是倒影的**预告**，不是全貌
- 03A（01:12）：倒影**首次完整出现**（她锁定了目标）
- 04A（01:38）：母题 A 与倒影 A′ **正面对位**——父女同时发声，音乐层面吵架
- 06（02:43）：倒影获胜并完整收尾，但坠饰音色同时开始变浊——**赢了，但已经在付代价**

### 母亲动机 M（永不完成）

```
BPM=40  自由速度  D小调

| 3 -  2 -  | [静默] |

（A–G–[空]，三音动机的第三个音永远不出现）
```

**设计意图：** 母亲去了边界"理解威胁"，没有回来。所以她的动机**在第三个音处永远静默**。观众每次听到都会本能地等那个音——它不来。

- 只在 04B（涅柔斯提起亡妻）出现一次，约 4 秒
- 全片其余段落禁止使用，保持其唯一性
- ⚠️**第三幕玛伦被永久困在人类形态时回收此动机并首次补上第三个音（D）**——母亲的句子由女儿说完

### 坠饰音色倒计时（音色即倒计时）

waterphone / 玻璃擦奏的音色状态**随剧情单向劣化**，让"坠饰变暗"有听觉对应物，而不只是视觉信息：

| 段落 | 坠饰状态 | 音色处理 |
|---|---|---|
| 01A 00:02.5 | （尚未聚焦，仅生物发光） | 清亮、纯净、无失谐 |
| 05A 02:07 | 满电脉冲 | **最清亮**，一次强泛音，音量峰值 |
| 05B 02:22 | 第一条微裂纹 | 加入约 15 cents 失谐，极轻 |
| 06 02:38 | 仍亮但不如赛宝稳定 | 玛伦音色略浊略低；赛宝音色清亮稳定，**两者同时出现形成对比** |

第二幕起继续劣化（加大失谐、降低高频、缩短衰减），第二幕下坠饰熄灭时该音色**永久消失**——之后全片再不出现，观众会下意识感到少了什么。

### 变体 D（决意 · 首次完整）★★母题亮相

```
BPM: 44
调式: D小调 → 结尾挂留 Gm–A（不解决）
弦乐奏法: 弱音中提琴起 → 大提琴接力 → 低音提琴垫入
装饰: waterphone 高把位泛音一次
织体: 2层 → 3层渐进
和声: 延迟解决——走到 A（属和弦）就停住，永不回 D
母题处理: **全段首次完整奏出 6–5–3–2**，然后尾音上挑到 3（A），把"下沉"翻成"我要上去"
Exclude: 打击乐、铜管、快速音型、任何煽情弦乐齐奏
适配: 02B 玛伦转身离席
```

## Step 4 — 逐镜配乐表

### 镜头 01A-1 — 深海峡谷建立（00:00–00:05）

| 层 | 内容 |
|---|---|
| 过渡 | 全片起点。**从纯静默进入**——第 0 秒不要有音乐，第 0.8 秒才让低音提琴从 pp 以下淡入（近乎听不见的门槛）。 |
| 音乐 | 变体 D 的织体密度，但只有一个音：低音提琴持续 D（约 40Hz 泛音区），molto legato，无起音感。waterphone 在第 2.5 秒和第 4.2 秒各擦出一次高泛音（对应画面生物发光星点闪烁）。 |
| 节奏 | BPM 48，但**无脉冲**——没有可辨的节拍。全靠长音呼吸。 |
| 音效 | `SFX-01 深海低频嗡鸣`（0.0s，-10dB，铺底贯穿）；`SFX-02 水流缓移`（1.5s，-12dB）。音效与音乐同处低频，需给 BGM 做 -2dB 侧链避让。 |
| 情绪 | "你还不知道要发生什么，但你已经开始屏住呼吸。" |
| 技法 | 6轴=[旋律:长音, 音区:极低, 织体:1层, 脉冲:无, 和声:悬置, 空间:极远]。开场 0.8 秒静默是刻意的——观众的耳朵先适应黑暗，音乐才出现。 |

### 镜头 01A-2 — 斥候巡逻（00:05–00:10）

| 层 | 内容 |
|---|---|
| 过渡 | 低音提琴 D 不断，**大提琴在第 5 秒叠入**，形成空五度（D–A）。空五度＝纪律、军事、无情绪。 |
| 音乐 | 母题第 1 音首次出现：大提琴奏 6（D），长音 3 秒，音量 pp→p。这是母题的第一个音节，观众不会察觉这是主题。waterphone 退出。 |
| 节奏 | BPM 48。第 6.5 秒起，低音弦乐加入极轻的三音循环脉动（对应三名斥候的纵队推进），但重音模糊，不成节拍。 |
| 音效 | `SFX-03 尾鳍推水`（5.2s / 6.4s / 7.6s，-4dB，三次，对应三名斥候）；`SFX-04 甲壳轻响`（8.0s，-6dB）。 |
| 情绪 | "他们是训练有素的士兵，不是美人鱼。" |
| 技法 | 6轴=[旋律:碎片(单音), 音区:低, 织体:2层, 脉冲:弱, 和声:悬置, 空间:远]。空五度是全片"人鱼军事纪律"的音响标记，之后每次出现斥候/战队都可复用。 |

### 镜头 01A-3 — 探测器升起（00:10–00:15）

| 层 | 内容 |
|---|---|
| 过渡 | 第 10 秒斥候急停 → **音乐抽空 0.6 秒**（所有弦乐骤停，只剩 SFX 的水流）。这个空白是威胁进场的门。 |
| 音乐 | 第 10.6 秒：预置钢弦泛音 + 弓拉锯片**首次进入**，一个缓慢上行的金属噪音层（不是音符，是质感）。低音提琴回到 D 但降低八度并加入极慢渐强 p→mf。母题不出现——机械没有主题，机械只有噪音。 |
| 节奏 | BPM 48→56 渐快（5 秒内完成），配合探测器上升。第 14.5 秒机械臂张开时，节奏感被低频嗡鸣完全吞掉。 |
| 音效 | `SFX-05 机械伺服声`（10.8s，-5dB，渐强）；`SFX-06 深海低频压迫嗡鸣`（12.0s，-3dB，压过一切）；`SFX-07 机械臂液压展开`（14.2s，-2dB）。 |
| 情绪 | "那道白光不属于这里。" |
| 技法 | 6轴=[旋律:无, 音区:极低+高噪层, 织体:3层, 脉冲:无, 和声:无调性, 空间:近]。**机械与母题严格隔离**——全片机械音永不使用弦乐母题材料，这是敌我音响分界。 |

### 镜头 01B-1 — 捕捉（00:15–00:21）

| 层 | 内容 |
|---|---|
| 过渡 | 承接 01A 尾帧的机械臂定格。第 15 秒网弹出，**直接切入**变体 B，无渐变——暴力不需要铺垫。 |
| 音乐 | 变体 B 全面进入：低音弦乐切分 + 琴码颤音，4 层追逐。母题只剩 6–5（D–C）两音，反复撞击，每次撞击对准一次视觉冲击。音量 f。 |
| 节奏 | BPM **56→112 瞬间跳变**（不是渐快，是切换）。第 15.0s 网弹、第 17.5s 斥候被裹、第 19.8s 撞向舱体——三个重音硬对齐画面。 |
| 音效 | `SFX-08 丝网弹射`（15.0s，0dB）；`SFX-09 气泡爆发`（17.2s，-3dB）；`SFX-10 甲壳刮擦金属`（19.6s，-1dB）。此段音效密度最高，BGM 中频需 -4dB 让位给刮擦声。 |
| 情绪 | "这不是战斗，这是收网。" |
