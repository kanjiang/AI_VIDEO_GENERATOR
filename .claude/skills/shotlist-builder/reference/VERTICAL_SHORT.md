# Vertical Short（竖屏 9:16 规则）

漫剧 / 抖音系短剧的构图与景别约束。仅当 `pacing-lock.md` 声明竖屏或用户明确要求 9:16 时启用。

来源吸收：[`../../docs/absorption/AIGC-漫剧课程吸收.md`](../../docs/absorption/AIGC-漫剧课程吸收.md) §3.3。

---

## Spec defaults

| 项 | 默认 |
|----|------|
| 画幅 | 9:16 |
| 单集时长 | 30–60s（以 pacing-lock 为准） |
| 单条生成 | 仍可按模型上限切 10–15s 多段再剪 |

在 `【规格】` 中写明 `9:16`（或项目约定分辨率），不要沿用横屏 21:9 默认除非 lock 关闭竖屏。

---

## Composition

1. **主体垂直居中偏上**  
   人脸/冲突核心落在上 1/2；下方留给手部动作、字幕安全区。

2. **忌宽银幕调度**  
   避免大横移双人全景并排；双人改用过肩、前后纵深、切正反打。

3. **前景遮挡可用，但勿堵脸**  
   门框、肩、栏杆可做纵深；字幕区（底部约 15–20%）保持可让。

4. **远景慎用**  
   建立可用短远景（≤2s），叙事主体尽快回到中近景/特写。

5. **文字安全**  
   关键信息不要只靠画面角落小字；平台会盖 UI。

---

## Shot size bias（相对横屏）

| 多用 | 少用 |
|------|------|
| 近景、特写、过肩 | 超广横构图群像 |
| 纵向跟拍、缓推脸 | 长横摇扫景 |
| 手/道具插入 | 无信息空镜 |

钩子镜头优先：**物件特写或压迫性近景**，再切关系镜头。

---

## Prompt reminders

- `【规格】`：时长 + `9:16` + 风格块
- 机位写明景别；竖屏里「全景」默认理解为**全身可见的竖幅全景**，不是电影宽银幕大远景
- 群戏：挂载人群资产，但构图仍以主角纵轴为中心，人群作虚化背景

---

## Off switch

`pacing-lock.md` 中：

```text
Vertical rules: VERTICAL_SHORT.md [off]
Aspect: [21:9 or 16:9]
```

关闭后全面回到仓库横屏电影默认（含 STYLE_BLOCK 的 21:9 等约定）。
