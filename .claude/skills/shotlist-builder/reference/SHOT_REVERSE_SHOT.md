# Shot / Reverse Shot（双人对话正反打）

**公式：** 场景统一 + 轴线稳定 + 正反打匹配 → 流畅对话镜；抑制人物漂移、道具错乱、视线穿帮、跳轴。

联用：[分镜规范.md](分镜规范.md) A1 · [CHARACTER_STAGING.md](CHARACTER_STAGING.md) · [SPATIAL_BLOCKING.md](SPATIAL_BLOCKING.md) · [MANGA_SHOT_PACK.md](MANGA_SHOT_PACK.md)（沉默反打镜等）

来源：[absorption/AIGC-双人正反打吸收.md](absorption/AIGC-双人正反打吸收.md)

## 一、空间轴线（重中之重）

1. 两人视线/躯干连线 = **关系轴线**；全部机位锁在轴线**同一侧**。  
2. ❌ 禁止跨轴，否则左右朝向翻转、对话逻辑断。  
3. 标准布局：  
   - **机位1（OTS）：** 近侧角色过肩/背影虚化，远侧角色正面清晰  
   - **机位2（反打）：** 对调，仍在同侧  

分镜标注示例：

```
轴线：A(画左)–B(画右) 连线，摄影机在轴线南侧（观众侧），禁越轴
机位1：过肩A拍B（A后脑/肩入前景虚化，B正面）
机位2：过肩B拍A（同侧，构图焦段匹配机位1）
视线：A面朝画右看B，B面朝画左看A；正反打全程互望
```

刻意越轴仅悬疑特批，须写 `⚠️刻意越轴-不安`（见分镜规范）。

## 二、场景一致性（生成前基准图）

**先出【双人大全景基准图】**，后续所有正反打/近景/特写**挂载同一环境+人物参考**，禁止无底图直出特写。

### 核验清单（基准图定稿后勾）

| 项 | 锁定内容 |
|----|----------|
| 人物 | 服饰、发型、面部特征、坐姿/站姿朝向 |
| 道具 | 茶具、桌椅位置与形态 |
| 光影 | 光源方向、色温、反差（夜暖灯笼 / 日硬光等全程不变） |
| 背景 | 门窗、灯笼、字画、陈设不增减 |
| 画质 | 胶片/画风、画幅（如 21:9）、STYLE 块 |

Seedance：基准图作 `@场景` / 地点挂载；角色仍用全身身份图；每段重申站位。

## 三、景别梯队（对话组合模板）

| 景别 | 作用 | 时机 |
|------|------|------|
| 大全景 | 空间位置、两人关系 | 开场、转场 |
| 中景 | 肢体、双人互动 | 长对话铺垫 |
| 近景 | 面部情绪、台词 | 核心对白 |
| 特写 | 眼神、微表情 | 爆发、停顿留白 |

**剪辑默认序：** 大全景起幅 → 中景铺垫 → 近景/特写 **正反打交替**。  
表情条目见 [MICRO_EXPRESSION_LIBRARY.md](MICRO_EXPRESSION_LIBRARY.md)；一句对白一组表情（分段生成）。

---

## 四、正反打成片规范

1. **形式：** 过肩（OTS）为主。  
2. **硬约束：**  
   - 视线互望，前后镜统一  
   - 两机位构图占比、焦段尽量匹配（常用 50–85mm 同级）  
   - 切换贴台词情绪，禁无规律乱切  
3. **匹配：** 动作/方向/位置三匹配（分镜规范 A3）；切点可用静接、眨眼、发力点。

| 步 | 动作 | 产出 |

## 六、可复制约束后缀（按项目改场景词）

```
【双人正反打约束】
严格遵循180度轴线，摄影机始终在两人连线同一侧；
人物位置、服饰、道具与参考大全景完全一致；
视线互相看向对方；过肩镜头，焦段与构图和配对反打匹配；
固定光源方向与色温，光影色调连贯，无元素突变。
画幅与风格按项目【规格】。
```

示例（古风夜景，可改）：

```
古装庭院夜景，暖黄灯笼柔光，固定光源方向，21:9，严格180度轴线，
人物服饰茶具与参考图一致，视线互望，不跳轴，过肩，85mm f/1.8，
面部细节丰富，五官自然联动。
```

负面：

```
人物变形，道具位置错乱，光线忽明忽暗，人物朝向翻转，
背景物体凭空消失或新增，五官崩坏，越轴，同角度微跳切
```

## 八、避坑

1. 无大全景基准直接特写 → 背景道具乱跳。  
2. 跨轴 → 视线反向。  
3. 正反打焦段/光影不统一 → 质感脱节。  
4. 景别乱跳无梯队 → 对话节奏崩。  
5. 只写「正反打」不写画左画右与轴线侧 → AI 仍漂移。
