使用说明：以下为 15 秒左右一条的 Seedance 风格中文提示词，每条均为完全自包含的重度版，可单独投喂模型。复制到 Seedance 时，必须连同每条 prompt 上方的 @image 行一起复制；@image1、@image2 的编号跟随本次上传顺序变化，但括号里的名字应保持稳定。本文件是段落压缩版，用于快速测试整段节奏；实际单镜头执行时，以 [screenplay/zhengci-zhiwai-act1-video-prompts-shot-by-shot.md](screenplay/zhengci-zhiwai-act1-video-prompts-shot-by-shot.md) 为准。第一幕整体拍法统一为：固定机位优先、真实场景光、克制表演、尽量少剪辑炫技。

## Prompt 01 [Multi-shot · 书房冷开场]

@image1 (LinShen) — 参考 lin_shen.png。
@image2 (StudyDeskWide) — 参考书房桌面与电脑的整体构图，主体是林深、电脑、台灯。
@image3 (StudyScreen) — 参考书房电脑音频编辑界面。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止插帧式过渡、禁止音乐、禁止字幕。单人单空间，林深始终位于狭小书房的书桌前，唯一光源是冷白台灯和电脑冷光，背景几乎全黑，禁止窗外光、禁止摆件、禁止额外人物。整体必须是超写实实拍电影质感，摄影机始终位于人物阴影侧。

【镜头1】
机位：50mm 中近景，固定。持续约5秒。
动作：林深戴着黑色有线耳机，独坐书桌前，脸色苍白疲惫，眼神不离电脑。桌面冷白台灯只照亮他半张侧脸和桌面，背景沉入死黑。动作极少，只允许他前倾极轻、手停在鼠标附近，整个人像被声音钉住。

【镜头2】
机位：85mm 屏幕特写，固定。持续约5秒。
动作：电脑音频界面里，同一段林晚录音波形被拖回起点，再播放，再拖回起点。声音内容只允许“如果我遇到意外。找我哥。把证据交给他。” 音质过于干净，无呼吸感，带轻微电流底噪。不能出现花哨 UI 漂移。

【镜头3】
机位：70度俯拍，50mm 定焦，固定。持续约5秒。
动作：白纸上写着“307、访问权限、声纹阈值”，林深拿黑色中性笔补一笔，又烦躁地划掉其中一行；随后他视线回到屏幕，房间只剩低频嗡鸣和极轻耳机漏音。手部要克制，不拍成发疯式乱划。

风格：8K IMAX，超写实，禁3D渲染，禁游戏引擎，禁游戏CG。摄影参考 Emmanuel Lubezki × Roger Deakins。灯光只允许台灯和屏幕冷光，禁止一切电影补光。色彩以冷白、灰黑为主。60fps，180度快门，物理镜头质感。禁音乐，禁字幕。

## Prompt 02 [Multi-shot · 周妍回到307]

@image1 (ZhouYan) — 参考周妍角色形象，克制、疲惫、警觉。
@image2 (Room307HalfMoved) — 参考半搬空的员工公寓307，墙面浅印、水磨石地面、薄灰。
@image3 (Room307PowerBox) — 参考玄关弱电箱，绿灯常亮。
@image4 (SmartSpeakerBlue) — 参考黑色智能音箱，落灰，蓝色待机灯轻微频闪。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。主空间必须是半搬空但未彻底退租的 307，室内无开灯，门外冷白走廊光从门缝切入，禁止拍成封条凶宅，禁止旧版录音笔和报警器道具。摄影机保持客观、固定、克制。

【镜头1】
机位：35mm 入口中景，固定。持续约5秒。
动作：门锁转动后，周妍推开307，先停半拍再迈进房间。室内大件家具已清空，墙面残留挂画浅印，地面有薄灰。她动作谨慎，视线快速扫过空房。

【镜头2】
机位：85mm 近景，固定。持续约4秒。
动作：镜头先落在两枚对称杯印和半包纸巾上，再切到玄关弱电箱绿灯常亮，最后停在角落落灰智能音箱的蓝色待机灯轻微频闪上。动作极少，只让空间本身成立。

【镜头3】
机位：50mm 周妍近景，固定。持续约6秒。
动作：周妍看到角落音箱后没有立刻靠近，只是站在屋内中段，呼吸压浅，眼神在空房与音箱之间来回一次后定住。情绪控制必须是警惕，不允许惊悚式大反应。

风格：8K IMAX，超写实，禁3D，禁游戏CG，禁音乐，禁字幕。灯光只允许门外走廊冷白光和室内残余环境反光。色彩冷灰、淡白、旧木色。60fps，180度快门，固定机位优先。

## Prompt 03 [Multi-shot · 死者语音来信 + 电话求助]

@image1 (ZhouYan) — 参考周妍角色。
@image2 (ZhouYanPhone) — 参考周妍手机聊天界面，“林晚”对话框弹出新语音。
@image3 (SmartSpeakerBlue) — 参考待机蓝灯音箱。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。整个段落只能围绕“周妍收到林晚语音，并因此把林深叫来”展开，不允许加入额外解释。声音设计必须突出林晚语音过于干净、没有真实呼吸感。

【镜头1】
机位：85mm 手机特写，固定。持续约4秒。
动作：周妍手机亮起，聊天界面弹出“林晚”对话框和一条新语音。先是手机震动，接着她指尖停住半拍，再轻收手机。UI 必须真实简洁。

【镜头2】
机位：85mm 周妍近景，固定。持续约5秒。
动作：周妍迟疑地点开语音，林晚声音从手机里完整响起：“如果我遇到意外。找我哥。把证据交给他。证据就在307的智能音箱上。密码只有我哥知道。只有他能解锁。” 她身体先僵住很短一拍，再极轻吸气，眼神死死钉在屏幕上。她手机壳边角短暂入画：旧、轻微开裂、花纹清楚；这组花纹要与后面露台白色手机保持一致。

【镜头3】
机位：50mm 半身中景，固定。持续约6秒。
动作：周妍站在307中部，压低声音给林深打电话：“林深，我收到一条晚晚的语音，说她出意外了，还说留了证据在音箱，你快过来吧。我怀疑这件事，和我们之前发现的那个机房有关系。” 说话时她目光缓慢转向角落音箱，房间里保留轻微空屋回音。

风格：8K IMAX，超写实，禁3D，禁游戏引擎，禁游戏CG，禁音乐，禁字幕。灯光只允许手机屏幕光、门外走廊冷白光和微弱环境反光。表演要克制，主情绪是震惊和强迫自己镇定。

## Prompt 04 [Multi-shot · 林深赶到307]

@image1 (LinShen) — 参考 lin_shen.png。
@image2 (ZhouYan) — 参考周妍角色。
@image3 (Room307HalfMoved) — 参考半搬空307。
@image4 (ZhouYanPhone) — 参考聊天界面语音消息。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务是让林深以“担心、谨慎、像在帮忙保全证据”的姿态进入，并把镜头推向角落音箱。摄影机保持固定，人物动作简洁、真实、留白。

【镜头1】
机位：50mm 门口中景，固定。持续约5秒。
动作：房门被推开，林深快步走入，先看周妍，再看角落音箱。动作要利落但不夸张，像真正担心，但步伐依旧稳定。

【镜头2】
机位：85mm 双人近景，固定。持续约5秒。
动作：周妍把手机递给林深，林深几乎立刻接过并贴耳听语音。林深眉心缓慢收紧，周妍盯着他脸上的反应。声音里的林晚语音只保留一句半，不要播完整段。

【镜头3】
机位：85mm 林深近景，固定。持续约5秒。
动作：听完后林深脸色更白，低声说：“千万别删，这条语音一定要留着。” 说完，他顺着周妍抬手的方向看向角落音箱。台词必须像保全证据的本能提醒，不像解释。

风格：8K IMAX，超写实，禁3D，禁游戏CG，禁音乐，禁字幕。灯光只允许307室内冷灰环境光和手机屏幕局部补亮。表演主情绪是谨慎控制，次级波动是伪装出来的担忧。

## Prompt 05 [Multi-shot · 数字口令解锁音箱]

@image1 (LinShen) — 参考 lin_shen.png。
@image2 (ZhouYan) — 参考周妍角色。
@image3 (SmartSpeakerRed) — 参考音箱亮起后的红色提示灯状态。
@image4 (SmartSpeakerRedGreen) — 参考音箱红绿闪烁再转绿的状态。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务是把“只有林深知道的那串数字口令”变成可信动作链，不允许拍成炫技解谜。智能音箱必须是普通家用旧设备，不允许高科技科幻感。

【镜头1】
机位：50mm 双人中景，固定。持续约4秒。
动作：周妍指向角落音箱，说：“她说，这个密码只有你知道。” 说完后，两人目光同时被音箱吸过去，空间静一下。

【镜头2】
机位：85mm 音箱特写，固定。持续约5秒。
动作：林深的手伸进画面按亮音箱，蓝灯熄灭，提示灯切成刺眼红色，系统机械音说：“请输入口令。” 这句系统音必须冷、短、毫无情绪。

【镜头3】
机位：先 85mm 林深近景固定，再无缝停在 85mm 音箱近特写，整体仍算一个镜头段。持续约6秒。
动作：林深垂眸停一秒，像在两组烂熟数字之间压平情绪；随后俯身在音箱自带输入屏上依次输入两段口令，后半截被他侧身挡住。音箱停顿两秒，机身轻微震动，指示灯红绿反复闪烁，随后才转纯绿，系统提示“解锁成功”。整个过程要有老旧延迟感。

风格：8K IMAX，超写实，禁3D，禁游戏CG，禁音乐，禁字幕。灯光以307室内冷灰环境光为主，音箱红绿灯是唯一颜色变化。表演主情绪是私人数字口令勾起的不适，次级波动是克制中的决断。

## Prompt 06 [Multi-shot · 第二段录音 + 上楼决定]

@image1 (SmartSpeakerGreen) — 参考解锁后绿灯状态。
@image2 (ZhouYan) — 参考周妍角色。
@image3 (LinShen) — 参考 lin_shen.png。
@image4 (Room307DoorDirection) — 参考307室内朝门口方向的构图。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务是把第二段录音里的死亡压迫、29楼设备间信息和消防楼梯路线，一次性推成行动。声音里的林晚必须比前面更像合成，但表面又足够逼真。

【镜头1】
机位：85mm 音箱特写，固定。持续约5秒。
动作：绿灯稳定后，第二段录音启动，林晚声音说：“如果听到这段声音，说明我已经走不掉了。” 声音比手机语音更像合成，但表面足够逼真。画面不动，只靠声音压出死亡感。

【镜头2】
机位：50mm 双人中景，固定。持续约5秒。
动作：录音继续说“我把最后关键东西，藏在二十九楼设备间。走消防楼梯上来。一定要亲自过来拿。” 周妍听到“二十九楼设备间”时呼吸明显一滞；说到“消防楼梯”时，周妍和林深几乎同时看向门外方向。

【镜头3】
机位：85mm 林深近景，固定。持续约5秒。
动作：林深看向门外，呼吸微微发紧，然后压住情绪说：“走，马上上去。” 语气不能像鼓动，而像顺着线索自然作出的决定。说完后画面停半拍，不立即切动作。

风格：8K IMAX，超写实，禁3D，禁游戏引擎，禁游戏CG，禁音乐，禁字幕。灯光只允许307室内冷灰环境光和音箱绿灯。主情绪是被命令式路线推着行动，次级波动是表面平静下的加速推进。
