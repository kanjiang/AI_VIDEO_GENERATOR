## 视觉与执行建议

| 项目 | 建议 |
| --- | --- |
| 视觉母题 | 门缝、屏幕、护栏、广播口、手机外放，所有边界都是被操控的声源接口 |
| 光源设计 | 书房用台灯硬光，307用走廊冷白渗光，电梯用惨白频闪，设备间用冷屏与指示灯，露台只保留城市夜光 |
| 机位风格 | 前半段稳拍克制，29楼后机位更贴人物，坠落闪回改成更硬更短的切换 |
| 声音策略 | 前半段林晚声音必须像真求救；直到设备间和坠落闪回再逐步露出人工质感 |
| 表演重点 | 林深不提前露凶；周妍始终是主动追真相的人；匿名保安只保留制度化执行者感 |
| AI视频提示词方向 | 书房假平静、307停摆公寓、旧音箱解锁、电梯停层、29楼声音工厂、露台白色手机、录音笔回放、匿名黑鞋 |
