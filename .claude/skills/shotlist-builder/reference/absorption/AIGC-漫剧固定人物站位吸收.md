# AIGC 漫剧固定人物站位吸收说明

来源：AI 漫剧「固定人物站位」实战教程（Skill+提示词替代导演台）。

---

## 总判断

| 教程观点 | 本仓库现状 | 决策 |
|----------|------------|------|
| 导演台操作复杂、耗积分、站位仍飘 | 不依赖导演台 | **认同** |
| 把人物占位空间描写写进**每一段**分镜提示词 | 已有 `SPATIAL_BLOCKING` + `⚠️空间布局`，但易被当成「复杂场景才画」 | **强化硬门：凡 2+ 人物镜必须占位句** |
| 上传「影视级分镜工厂.skill」给豆包 | 本仓库即 `shotlist-builder` | **不另造豆包 skill 文件**；原则并入 shotlist |
| 一句指令「每段都加占位」 | 缺一键口令文档 | **吸收**为标准触发语 |

本仓库已更深：俯视 SVG 确认、动线、调度图挂载。教程贡献的是**产品化硬规则与口令**，不是新光学理论。

多角色对话、打斗追逐、批量分镜：一律 **先占位后表演**；复杂场仍走 Phase 3 俯视图审批。
