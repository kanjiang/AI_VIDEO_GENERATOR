# 视觉风格指南 · Visual Style Guide

《糖糖的小英雄》系列的视觉锁定规范。**所有集数的美术输出必须遵守本指南**，才能形成统一 IP 视觉识别。

## 一、总体风格锁定

- **风格**：3D 皮克斯风（类比《海底总动员》《寻梦环游记》Q 版短片）
- **不是**：日系动漫 / 迪士尼手绘 / 宝宝巴士 2D / 真人拍摄
- **参考基准**：皮克斯短片《月神 La Luna》《美食总动员》《飞屋环游记》开头童年段落

## 二、调色系统

### 主色板（IP 通用）

| 用途 | 色值范围 | 描述 |
| --- | --- | --- |
| 主背景 | 暖白 / 淡奶油 / 淡粉 | 大部分场景基底色 |
| 糖糖主色 | 粉黄条纹（Beat 1/9/10） · 粉睡衣（Beat 2-8） | 醒目但温暖 |
| 牙刷警长 | 宝石蓝 + 红警帽 | 冷暖对比 |
| 睡眠精灵 | 月光银 + 星光淡蓝 | 冷调梦幻 |
| 蛀牙菌军团 | 糖果粉 / 紫 / 绿 | Q 版糖果色 |
| 熬夜怪 | 深紫黑 + 屏幕蓝荧光边 | **深但不真暗**，用荧光边保持糖果化 |

### 三大氛围调色（各场景通用）

| 氛围 | 调色 | 用于哪些节拍 |
| --- | --- | --- |
| **A · 暖光日常** | 暖黄 + 柔粉 + 淡奶油 | Beat 1 客厅、Beat 9 卧室、Beat 10 邀请 |
| **B · 冷月夜** | 蓝月光 + 深蓝阴影 + 星光点 | Beat 2 卧室夜晚、Beat 4 时间流逝 |
| **C · 微观奇幻** | 粉紫洞穴 + 荧光装饰 + 荧光光点 | Beat 3-4 反派微观世界 |
| **D · 清晨希望** | 淡金阳光 + 淡蓝空气 + 白纱窗光 | Beat 5 早晨、Beat 8 分屏左边 |

### 禁用色调

- ❌ 大面积纯黑（除非用作反派轮廓阴影）
- ❌ 血红 / 血橙
- ❌ 军绿 / 铁灰 / 军事色
- ❌ 高饱和荧光原色（除非用于反派荧光边）

## 三、光影原则

- **主光源**：柔和暖光（3D 全局照明）
- **阴影**：柔和的半透明，不要硬边黑影
- **发光元素**：糖糖门牙闪光 / 守护者登场光晕 / 星光沙轨迹 — 必须发光且带**多层柔光扩散**
- **反派光**：反派身上有微弱荧光边（表示"他们是异物"）

## 四、镜头语言（IP 通用）

### 常用景别

- **ECU 特写**（Extreme Close-Up）：面部/门牙/关键物品特写
- **MCU 中特写**（Medium Close-Up）：胸像 · 用于台词镜头
- **MS 中景**（Medium Shot）：全身 · 用于动作镜头
- **WS 广角**（Wide Shot）：环境展示 · 反派派对全景等

### 常用运镜

- **静态镜头**：默认。3D 皮克斯风格追求稳重构图
- **Dolly-In 慢推**：情感升华节拍（Beat 9 门牙特写）
- **Whip-Zoom 快速穿透**：MACRO→MICRO 尺度跳跃（Beat 3 进入反派世界）
- **Tracking Shot 平移**：Beat 8 分屏晨昏对照
- **手持轻微震动**：Beat 1 生日狂欢等活泼场面

### 尺度跳跃频率

**每 2-3 段 Beat 必须切换一次尺度**（MACRO ↔ MICRO / 幻境）。参照 `narrative-formula.md` 里每集的节拍尺度分配。

## 五、字幕设计规范

字幕是本 IP 教育功能的核心。3-6 岁儿童大多不识字，字幕必须**极清晰 + 有图标辅助**。

### 字体

- **主字体**：圆润糖果色字体（如"站酷高端黑"加圆化处理，或"胡晓波真帅体"）
- **描边**：3-4 像素的白色描边（保证在任何背景上都可读）
- **投影**：柔和淡阴影，不要硬阴影

### 尺寸

- 主要字幕（教学关键词/结尾邀请）：占画面高度 **12-15%**
- 辅助字幕（角色名字标签/拟声词）：占画面高度 **6-8%**

### 颜色

| 用途 | 主色 | 描边 |
| --- | --- | --- |
| 教学关键词（三步法） | 糖果粉 / 糖果黄 / 糖果紫 | 白色 |
| 数据（如"2 分钟"、"每颗"）| 亮橙 | 白色 |
| 拟声词（如"哎哟！"）| 卡通红 | 白色 |
| 结尾主题字幕 | 彩虹渐变 | 白色描边 + 星星特效 |

### 动画

- **弹入方式**：Q 弹弹跳（不是滑入，不是淡入）
- **停留时间**：每字幕停留 2-4 秒
- **图标伴随**：教学字幕必须配大箭头（⬆️⬇️/⬅️➡️/①②③）或图标（☀️/🌙）

## 六、音乐与音效风格

### 主题音乐

- **主旋律**：温馨童谣风，钢琴 + 木琴 + 弦乐拨奏
- **主题歌尾句**：儿童合唱，每集换动词但押韵到"闪闪亮/满满亮"
- **BPM**：中等偏欢快（100-120 BPM）

### 角色主题

- **糖糖**：钢琴 + 木琴，天真活泼
- **牙刷警长**：小号+军鼓，英雄进行曲
- **睡眠精灵**：竖琴+风铃+人声哼唱，梦幻风
- **蛀牙菌军团**：滑稽 Q 版电子音+马林巴（Marimba）
- **熬夜怪**：低音合成+电子干扰音（保持 Q 感）

### 情绪音效

| 情绪 | 音效 |
| --- | --- |
| 闪光 | "叮！"（水晶音） |
| 清洁 | "叮叮叮！"（金属铃铛） |
| 守护者登场 | "叮咚——！"（英雄号角） |
| 反派登场 | 派对喇叭+集体欢呼 |
| 反派溃败 | "哎哟哎哟"合唱 |
| 时间流逝 | 低沉悠长的过渡音（要滑稽感，不恐怖） |

## 七、每集视觉可复用资产

以下资产**做一次可跨集复用**，每集不用重做：

- 糖糖各套服装的身份板（服装库 A-G）
- 糖糖 10 种表情的表情板（E01-E10）
- 糖糖卧室 · 客厅 · 卫生间 · 餐厅的场景板（见 `world-and-locations.md`）
- 牙刷警长、睡眠精灵等守护者的身份板
- 主题字幕设计模板（"XX 刷刷刷，笑容闪闪亮！"格式）
- 数据标注图标库（☀️🌙⬆️⬇️⬅️➡️①-⑧星光T_T）
