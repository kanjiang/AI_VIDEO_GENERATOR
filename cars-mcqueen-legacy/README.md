# 《汽车总动员·传承之路》制作指南

**Lightning McQueen: Legacy**

> Logline: 退役冠军闪电麦昆发现，他最伟大的胜利不是冲过终点线——而是看着自己的徒弟做到这一切。

---

## 基本参数

| 项目 | 值 |
|------|------|
| 时长 | 60秒 |
| 画幅 | 16:9 横屏 |
| 风格 | 3D 皮克斯风格（接近原版电影质感） |
| 字幕 | 中英双语 |
| 平台 | B站 / YouTube |

---

## 制作流程

```
Step 1: 生成角色资产图 → Step 2: 生成场景资产图 → Step 3: 生成视频 → Step 4: 后期拼接
```

---

## Step 1 — 生成角色资产（推荐工具：可灵/即梦/MidJourney）

角色资产提示词详见 `screenplay/scene-character-prompts.md`

**核心角色：**

| 角色 | 说明 | 出场 |
|------|------|------|
| 闪电麦昆 Lightning McQueen | 退役冠军，油漆微旧，95号，红色涂装，智慧而温暖的眼神 | 全程 |
| 小焰 Blaze | 新生代赛车，亮橙色+白色闪电纹，充满冲劲但技术粗糙 | Shot 2–6 |
| 莎莉 Sally Carrera | 淡蓝色保时捷911，麦昆伴侣，知性优雅，引擎盖上架小眼镜 | Shot 1, 6 |
| 板牙 Mater | 锈色拖车，麦昆最好的兄弟，龅牙大笑，忠诚搞笑 | Shot 2, 3, 4, 6 |
| 路易吉 & 奎多 Luigi & Guido | 黄色菲亚特+蓝色小叉车，训练维修区+决赛pit crew | Shot 3, 4, 5, 6 |
| 雷蒙 Ramone | 紫色雪佛兰低趴车，改装大师，决赛前为小焰喷涂全新战甲 | Shot 5 |
| 风暴二世 Storm Jr. | 决赛对手，银灰+电蓝涂装，流线型，冷酷自信 | Shot 5 |

## Step 4 — 后期拼接清单

- [ ] Shot 1–6 按顺序拼接（总时长 60 秒）
- [ ] 配音对齐（中文旁白 + 角色台词）
- [ ] 中英双语字幕（底部居中，白字黑边）
- [ ] BGM：激昂赛车风格 → 温情过渡 → 热血高潮
- [ ] 音效：引擎轰鸣、轮胎摩擦、观众欢呼、金属碰撞
- [ ] 片尾字幕卡：「前方的路，是你的了。/ The road ahead is yours.」
