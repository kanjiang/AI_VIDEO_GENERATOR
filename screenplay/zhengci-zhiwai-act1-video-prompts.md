## Prompt 01 [Multi-shot · 书房来电与雨夜入局]

@image1 (LinShen) — 参考林深角色定妆。
@image2 (StudyRoomWide) — 参考书房全景。
@image3 (StudyScreenWaveform) — 参考书房隐藏声纹编辑界面。
@image4 (StudyDeskWide) — 参考书房桌面组合视角。
@image5 (StudyPhotoSet) — 参考书桌兄妹合照与耳机。
@image6 (UnknownCallerPhone) — 参考未知来电与语音界面。

完全自包含重度版：75秒，21:9，multi-shot，严格只允许 5 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务：先立住林深的普通人外壳，再把他压进307设局现场。整体要求：超写实实拍、真实场景光、克制表演、镜头之间只保留必要叙事推进。

【镜头1】
机位：中近景，固定侧拍，微慢推。持续约15秒。
动作：林深深夜独坐书房监听林晚残缺语音，普通加班假象先成立。
声音：林晚耳机音：...哥，如果我出现意外... / 设备低噪。
重点：开场先稳住日常感，再用“意外”一词埋下首个钩子。

【镜头2】
机位：特写，推近加局部摇移。持续约15秒。
动作：林深快速回放波形、放大噪点、拆解语音，桌面兄妹合照与耳机一闪而过。
声音：键盘敲击声、波形回放声、室内死寂。
重点：让分析行为显得过于熟练，为后续身份反转埋线。

【镜头3】
机位：近景，固定，轻微变焦。持续约15秒。
动作：未知来电打断分析，林深接听，镜头顺势扫过兄妹合照。
声音：周妍：林深吗？ / 林深：……你是谁？ / 周妍：你别管我是谁。你妹妹林晚出事了。
重点：电话一接通就把观众强行拖进剧情主线。

【镜头4】
机位：中近景，固定转轻推。持续约15秒。
动作：林深被电话信息压住，继续追问，对方只留下 307 时间地点后挂断。
声音：林深：晚晚？出什么事了？她人呢？ / 周妍：我也不知道她在哪，但她留了东西给我。今晚12点，长宁公寓307，你一个人来。 / 林深：你到底是谁？ / 电话忙音。
重点：把任务目标锁死在“307，你一个人来”。

【镜头5】
机位：全景，高空俯拍缓降转跟进。持续约15秒。
动作：雨夜中的长宁公寓被压向 307，林深已提前站在门口并推门入内。
声音：雨声、风声、楼道回声、门轴轻响。
重点：外景变成陷阱建立镜头，门在身后关闭形成段尾封口。

## Prompt 02 [Multi-shot · 307初见与监听前史]

@image1 (Room307Entry) — 参考307入口视角。
@image2 (ZhouYan) — 参考周妍角色定妆。
@image3 (LinShen) — 参考林深角色定妆。
@image4 (DeviceRoomDoorCrack) — 参考设备间门缝冷光。
@image5 (UnknownCallerPhone) — 参考未知来电与语音界面。

完全自包含重度版：75秒，21:9，multi-shot，严格只允许 5 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务：完成周妍和林深的陌生对接，并用闪回压实监听黑产前情。整体要求：超写实实拍、真实场景光、克制表演、镜头之间只保留必要叙事推进。

【镜头1】
机位：中景，肩后跟拍转固定。持续约15秒。
动作：307 半搬空客厅、冷白门缝光与角落音箱一起入画，镜头落到周妍身上。
声音：周妍：你是林深？ / 林深：嗯，你是？
重点：通过空间与站位先建立不信任氛围。

【镜头2】
机位：中近景，手持微晃，轻推。持续约15秒。
动作：周妍交代身份、失联事实与偷录住户声音的异常发现。
声音：周妍：我叫周妍，林晚的室友。她失联好几天了。 / 周妍：之前我们发现这栋公寓在偷偷录住户的声音。她失联……应该跟这事有关。
重点：林深仍站在“被动协助者”位置，关系暂时成立。

【镜头3】
机位：中景，手持跟拍，低角度仰拍。持续约15秒。
动作：闪回到一周前，两人顺着嗡鸣查到天花板暗槽里的监听设备。
声音：周妍旁白：一个星期前，我们在屋里听到天花板上面有种很奇怪的嗡嗡声。晚晚耳朵尖，当时就觉得不对劲。我们决定顺着声音往上查。
重点：用闪回把“怀疑”升级为可视证据。

【镜头4】
机位：近景，俯拍转横移。持续约15秒。
动作：吊顶被撬开，收音设备掉落；隐藏机房入口和服务器绿灯被发现。
声音：周妍旁白：天花板里藏满了收音设备。我们那时候就意识到，我们可能一直被人监听着。 / 周妍旁白：后来我们还发现公寓里有个隐藏的机房，晚晚怀疑有人在拿住户的声音做文章。
重点：监听和黑产在同一镜内闭环。

【镜头5】
机位：中景，手持跟拍转手机特写。持续约15秒。
动作：两人急着打包准备搬走，闪回切断后回到现实，周妍点开林晚语音。
声音：周妍旁白：我们当时就觉得得赶紧搬走。结果前几天晚晚突然就联系不上了——直到昨天，她给我发了条语音。 / 林晚手机语音：周妍——万一我出事了，去找我哥。号码存在你那条备忘录里。307音箱我留了线索，只有他能打开。
重点：语音把林深正式拉进“唯一权限人”的位置。

## Prompt 03 [Multi-shot · 音箱权限与29楼转场]

@image2 (SmartSpeakerIdle) — 参考音箱待机蓝灯。
@image3 (SecurityFlashlightGap) — 参考门缝手电与门外压迫。
@image4 (ZhouYan) — 参考周妍角色定妆。
@image5 (SmartSpeakerUnlocked) — 参考音箱解锁成功。

完全自包含重度版：60秒，21:9，multi-shot，严格只允许 4 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务：让权限机制、门外压迫和29楼线索在一段内连续成立。整体要求：超写实实拍、真实场景光、克制表演、镜头之间只保留必要叙事推进。

【镜头1】
机位：中近景，固定转轻移。持续约15秒。
动作：周妍指向音箱，林深走过去按下激活键，蓝灯亮起。
声音：周妍：她说线索在音箱里，你试试。 / 林深：那我说什么……小爱同学？ / 系统机械音：你好，林深。
重点：声纹秒过说明林深和系统存在天然绑定。

【镜头2】
机位：近景，固定，门缝摇移。持续约15秒。
动作：门外手电扫过门缝，林深立刻示意噤声，保安开始敲门试探。
声音：林深：别出声。 / 保安A：谁在里面？ / 保安A：里面有人吗？ / 保安B：怎么了？
重点：把音箱加载直接变成高压卡点。

【镜头3】
机位：中景，固定，轻微手持。持续约15秒。
动作：两人僵在暗处不动，门外保安继续判断并决定去拿备用钥匙。
声音：保安A：听起来里面有人在说话。 / 保安B：不会吧，这间房前几天就搬空了。 / 保安A：我听得很清楚，确实有声音。 / 保安B：那去保安室拿备用钥匙吧。 / 保安A：行，走。
重点：观众被迫接受“他们很快会回来破门”这层倒计时。

【镜头4】
机位：中景，固定转轻推。持续约15秒。
动作：保安刚走远，音箱绿灯亮起并复述 29 楼线索，两人立即决定转场。
声音：林深：小爱同学，林晚最后跟你说了什么？ / 智能音箱：林晚最后一条记录——她发现重要线索在二十九楼设备间。 / 周妍：他们马上就要回来了，没时间了。 / 林深：走，去29楼！
重点：用旧音箱完成第二层任务派发。
