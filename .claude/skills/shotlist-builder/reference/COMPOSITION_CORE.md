# 电影构图 7 大核心（速查表）

**本质：构图不是守规矩，是控制观众视线——先看哪里，再感受到什么。**

写 Seedance / 分镜时：先选本表技巧（意图）→ 再在 [COMPOSITION_LIBRARY.md](COMPOSITION_LIBRARY.md) 取句式编号。

来源：[absorption/AIGC-电影构图七技巧吸收.md](absorption/AIGC-电影构图七技巧吸收.md)

---

## 0. 决策三问（每镜必过）

1. 观众**第一眼**落在哪？  
2. 看完后应感到什么（权力 / 孤独 / 压迫 / 秩序…）？  
3. 用哪 1–2 种技巧把视线送到那里？（单镜技巧不宜堆超过 2 种）

---

## 1. 七技巧 → 情绪 → Prompt 后缀 → 词库

| # | 技巧 | 控视线怎么做 | 典型情绪 | Prompt 后缀（可粘贴） | 词库优先 |
|---|------|--------------|----------|----------------------|----------|
| 1 | **视觉焦点 Focal** | 减背景干扰，主体成唯一中心 | 清晰、强调 | `极简背景排除干扰，单一视觉焦点落在[主体]，其余压暗或虚化` | EC / FA 主体突出类 |
| 2 | **三分法 Thirds** | 眼/动作落交叉点；地平线上或下三分 | 协调、叙事感 | `主体落在三分线交叉点，地平线置于[上/下]三分，忌无意义居中` | FA-04 |
| 3 | **黄金三角** | 主对角+辅线，多主体各占一焦点 | 张力+平衡 | `黄金三角构图，主对角线连接[A]与[B]，辅线稳住[C]，多点平衡` | TP-04 |
| 4 | **引导线 Leading** | 路/廊/栏引向主体；或乱线造迷失 | 命运感 / 紧张 | `引导线（[走廊/楼梯/道路]）汇向[主体]` 或 `线条混乱反向引导，迷失压迫` | SE-04, SE-01, SE-10 |
| 5 | **正负空间** | 大留白=渺小；满幅=压迫；看向侧多留空 | 孤独 / 力量 / 自然 | `大面积负空间表现[孤独/渺小]` / `主体占满画幅压迫亲密`；`视线方向预留呼吸空间，头顶留白克制` | SE-03, EC-02 留白, CAMERA_EMOTION 负空间段 |
| 6 | **平衡/对称** | 对称=秩序权威；失衡=不安 | 仪式 / 焦虑 | `左右对称构图，秩序与权威` / `故意失衡构图，唤起不安` | TP-01, CA-06 |
| 7 | **框中框 Frame** | 门窗洞口框主体；窄框压迫；多层=旁观；**靴/胯下框**=前景强势局部碾压远景弱势 | 窥视/幽闭/权力 | `以[门框/窗/靴底]形成框中框`；`狭小框架压迫`；`前景[靴子]巨大，远景[弱势方]渺小` | SE-02, SE-09, FA 仰俯 |

### 英雄三角 / 背景分区（开场小队常用）

| 手法 | Prompt 后缀 |
|------|-------------|
| 稳定三角 | `三人黄金三角站位，顶点为[领袖]，画面平衡且突出核心` |
| 背景善恶分区 | `画面一侧背景开阔（英雄），对侧背景封闭山岩/墙体（威胁），背景本身叙事` |

详见 [VISUAL_LANGUAGE_SIX.md](VISUAL_LANGUAGE_SIX.md) §3。

### 额外：景深 Depth（常与上表叠用）

| 手段 | 写法 |
|------|------|
| 浅景深 | `浅景深虚化背景，焦点锁[主体眼睛/道具]` |
| 前景层次 | `前景[栏杆/树叶/门框]虚化挡一层，中景主体清晰` |
| 焦点转移 | `焦点从[A] rack 到[B]，视线随焦点转移` |
| 三层纵深 | `前景-中景-背景层次分明，二维画面有三维空间感` |

词库：SE-08 多层景深 · PROMPT_PATTERNS 空间语法。

## 2. 场景速配（一眼选）

| 戏型 | 优先技巧 | 少用 |
|------|----------|------|
| CEO / 董事会 / 宫殿 | 对称、框中框、焦点 | 大负空间孤独（除非刻意反讽） |
| 荒野单人 / 天台雨夜 | 负空间、三分、引导线 | 满幅特写堆满 |
| 走廊威胁 / 抵墙 | 框中框（窄）、失衡、浅景深 | 对称舒适 |
| 双人对峙 | 黄金三角或对称对分、视线空间 | 乱线引导（除非迷乱） |
| 门缝偷窥 | 框中框多层、焦点 | 对称仪式 |
| 漫剧竖屏 | 焦点+三分纵轴；见 VERTICAL_SHORT | 超广横构图群像 |

## 4. 终极原则

无绝对对错。技巧服务于：**让画面更有趣，且准确传递你要的情绪。**  
写完自问：去掉构图句后，观众还会不会先看对地方？若不会——补焦点或引导线，而不是再堆形容词。
