# Delivery Checklist（上线交付验收）

AI 成片在发布 / 路演 / 交片前的最终清单。  
生成素材级质检仍用 [ai-footage-qa.md](ai-footage-qa.md)（越轴 / 跳切 / 音效匹配）；本文件管**可上线交付**。

来源吸收：[`../../docs/absorption/AIGC-漫剧课程吸收.md`](../../docs/absorption/AIGC-漫剧课程吸收.md) §3.4。

---

## When to run

- 用户说：导出、发布、交片、路演、定稿、上线检查
- 剪辑与混音完成后、上传平台前
- 漫剧单集或微电影短片交付客户前

顺序：`ai-footage-qa` → 本清单 → 导出。

---

## A. 形态与时长

| 项 | 竖屏漫剧默认 | 横屏微电影 | 通过？ |
|----|--------------|------------|--------|
| 画幅 | 9:16 | 16:9 / 21:9（以项目为准） | ☐ |
| 单集/成片时长 | 30–60s（或 pacing-lock） | 以 treatment 为准 | ☐ |
| 片头无效黑场 | ≤0.5s | 同左 | ☐ |
| 集末钩子/收束 | 有明确卡点或收束 | 有明确结尾 | ☐ |

---

## B. 视听要素齐全

| 项 | 要求 | 通过？ |
|----|------|--------|
| 对白可懂 | 音量稳定；错读已替换（见 audio repair） | ☐ |
| 字幕 | 需要平台字幕时已加；错别字 / 谐音已校对 | ☐ |
| SFX | 关键动作有落点；无莫名循环音效 | ☐ |
| BGM | 有入出点；不压过人声；与 `bgm-scoring` 方案一致 | ☐ |
| 环境声 | 有底噪或有意安静，不「数字真空」 | ☐ |

---

## C. 画面质量

| 项 | 要求 | 通过？ |
|----|------|--------|
| 角色一致性 | 无崩脸、无换装漂移（对照 character-lock） | ☐ |
| 穿帮 | 无多余手指、无道具瞬移、无文字水印 | ☐ |
| 连续性 | 已过 ai-footage-qa 三步 | ☐ |
| 分辨率 | ≥1080 短边；导出清晰度符合平台 | ☐ |
| 字幕安全区 | 竖屏底部 UI 未遮关键脸/字 | ☐ |

---

## D. 叙事产品（漫剧开启时）

| 项 | 要求 | 通过？ |
|----|------|--------|
| 前 3 秒钩子 | 有冲突/反差/物件/未完成动作 | ☐ |
| 中段不注水 | 无超过 15s 无信息增量 | ☐ |
| 题材爽点 | 对照 genre lane 至少 1 个兑现 | ☐ |
| 合规 | 无平台敏感违规（暴力尺度、价值观等按目标平台） | ☐ |

院线项目：本节整表标记 N/A。

---

## E. 导出与发布

| 项 | 要求 | 通过？ |
|----|------|--------|
| 编码 | 平台推荐（如 H.264、高码率） | ☐ |
| 封面/标题 | 已备（若需要） | ☐ |
| 文件命名 | 项目_集数_版本 | ☐ |
| 备份 | 工程文件 + 导出文件已存 | ☐ |

---

## Sign-off

```text
Project:
Episode / cut:
Aspect:
QA (ai-footage): pass / fail
Delivery checklist: pass / fail
Notes:
Signer / date:
```

未勾满「必须项」不得宣称定稿。必须项 = A+B+C；D 仅漫剧；E 在实际上传前勾。
