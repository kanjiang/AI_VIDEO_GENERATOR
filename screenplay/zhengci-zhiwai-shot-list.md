# 证词之外 逐镜 Shot List

用途：导演分镜、摄影计划、AI 视频生成、后续故事板细化。

本版基于 2026-06-01 最新剧本重拆，当前全片按 6 个场次、72 个镜头组织，核心逻辑改为：林深在开场就已入局设套，307 音箱与 29 楼设备间只是分段诱导，终场以录音笔回扣而非“林晚未死监控反转”收束。

格式说明：

| 字段 | 说明 |
| --- | --- |
| 镜号 | 连续镜头编号 |
| 场次 | 对应剧本场次 |
| 景别 | 建议景别 |
| 机位/运动 | 固定、推进、横移、俯拍、主观等 |
| 画面内容 | 镜头内发生的主要动作 |
| 台词/声音 | 关键对白或声音提示 |
| 时长 | 估计时长 |
| 备注 | 用于 AI 视频、置景、表演与资产提示 |
