## 总判断

| 观点 | 与仓库关系 | 决策 |
|------|------------|------|
| 禁「悲伤地说」式标签表演 | 已有 MICRO_BEATS / emotion-micro | **强化**为台词时间轴六要素 |
| 保护层失效情绪曲线 | MICRO_BEATS §8 三段同向 | **吸收**为长弧节拍法 |
| AU / FACS 编码 | 仓库多为中文肌肉描述 | **吸收**为可选校准层 |
| 八维填表 | 缺统一长对白清单 | **新建**操作文档 |
| 三层：全局 / 镜头轴 / 表演 | PROMPT 分层思想已有 | **吸收**为长片对白结构 |
| 30s / 20:9 / 平台积分与爆款数据 | 营销与 UI | **不吸收** |
| 「仅靠提示词无垫图」主张 | 本仓库常要参考图一致性 | **仅记原则**：表演层可不依赖垫视频；资产层仍可挂参考图 |
| 小云雀操作步骤 | 绑平台 | **不绑**；原则复用到 Seedance 类模型 |

一句话：补「长对白演技时间轴 + AU 校准」，不替换现有短镜微表演体系。
