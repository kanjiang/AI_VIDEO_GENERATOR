# 证词之外 分镜节拍表

用途：导演分镜、前期沟通、AI 视频镜头拆解、拍摄节奏控制

基准：5 分钟左右悬疑短片，按当前定稿拆为 7 个场景，36 个逐镜头可归并为 24 个镜头块

## 视觉与执行建议

| 项目 | 建议 |
| --- | --- |
| 视觉母题 | 真声音来自平视和近距离，假声音来自头顶和控制系统 |
| 光源设计 | 出租屋只有窗外冷蓝夜光；走廊只有声控灯；307 只有月光、音箱红灯、录音笔屏光 |
| 机位风格 | 前半段多固定和慢推；发现假声后机位可微晃；高潮只给一次快动作 |
| 表演重点 | 林深全程克制，靠手指、停顿、眼神；陈伯靠低音量与不进门的站位制造压迫 |
| AI 视频提示词方向 | 老旧公寓、冷白走廊、月光旧客厅、真假声源、录音笔解锁、公共警铃、住户围观 |
