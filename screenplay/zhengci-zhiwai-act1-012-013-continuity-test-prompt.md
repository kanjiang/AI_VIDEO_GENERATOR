# 《证词之外》镜头012-013 连续测试稿

用途：专门测试“门外手电从307门底缝漏入 -> 保安敲307门 -> 门外判断 -> 去拿备用钥匙”的连续压迫段。

通用硬约束：严格沿用307客厅、林深、周妍、门缝手电压迫参考。林深、周妍外貌、服装、发型、气质不重新设计。保安A、保安B只闻其声，均在307门外走廊，隔门发闷并带走廊混响。门全程关闭，保安不入画。无字幕、无文字标题、无背景音乐。

## 012 门底手电漏光，保安敲门试探

@门缝手电压迫=门缝手电压迫
@林深=林深
@周妍=周妍
@猫耳音箱待机=猫耳音箱待机

【规格】约15秒，21:9，真人电影质感，307客厅暗冷，室内无人工照明，只用窗外冷蓝雨夜光、右侧柜上音箱蓝灯，以及从307门底缝隙漏入的保安手电冷白光。

【电影化动态描述】承接011尾帧：林深还在右侧柜前半侧身，手刚离开音箱按键；周妍在客厅偏左、靠近纸箱和白色地毯边缘。门外走廊传来极轻脚步时，林深先抬眼看向入户门，没有立刻冲过去；他抬手向周妍做一个压低、后退的手势，自己从右侧柜前贴着墙向门内侧移动两步，停在距离307入户门约1.5米的位置。周妍跟到他左后方半步，不与他并排堵在门前，身体半躲在纸箱阴影旁。50mm固定近景保持1.5秒安静，画面只给两人压住呼吸和门把手的暗轮廓；门外保安站在走廊上，用手电从307门底缝隙扫过，一道冷白窄光从门下缝漏进室内，在白色地毯上横向划过。光先扫过林深脚边，他身体一僵、呼吸停住，眼睛没有看周妍而是直接盯住门把；再扫到周妍脚边，她后退半步，脚跟轻碰纸箱，纸箱阴影轻轻晃一下。光束消失后，林深竖起食指贴住嘴唇示意噤声，同时轻按周妍前臂，让她留在自己身后。结尾停在两人屏息不动的门内近景，音箱蓝灯在画面边缘继续亮着，像一个不能被关掉的证据点。

【音画同步】说话者锁定：林深=画内近场男声，只说耳语“别出声。”；保安A=307门外贴近门板的中年男声，音色偏低哑、警觉、每句都像贴门确认；保安B=307门外走廊稍远处的另一名中年男声，音色更厚、更闷，带一点不耐烦和怀疑；A/B声纹必须不同，不互相混淆；周妍本镜不说话。所有保安声音都来自门外走廊，隔着307入户门传入室内，带门板闷声、走廊混响和距离差。起幅1.5秒纯雨声底噪，室内近乎真空，只能听见两人压住的浅呼吸和音箱微弱电子底噪。门外走廊先有一声极轻脚步（皮鞋踩瓷砖的“嗒”），随后短暂停住，像有人在门口侧耳听；手电冷白光再从307门底缝隙漏入室内。门底光束消失后0.5秒硬沉默，沉默里纸箱被周妍脚跟碰到，发出一声很轻的纸板摩擦。林深压到最浅气声：“别出声。”三个字一口气贴着牙缝送出，“声”字立刻收断。走廊上的保安敲307门，敲门声“咚——咚——”两声，间隔1秒，第一声试探，第二声稍重。保安A贴门低声：“谁在里面？” “谁”字微微抬高，像贴着门板听。1秒沉默。保安B从更远处发问：“里面有人吗？”声音比A更厚、更懒，尾音被走廊吃掉一层。保安A压低，像转头对同伴说：“怎么了？”尾音下坠，开始起疑。

【负面约束】手电光只能从307门底缝隙漏入室内；林深和周妍不要并排堵在门前；周妍必须在林深左后方半步；门保持关闭；保安不入画。

## 013 门外判断，决定去拿备用钥匙

@门缝手电压迫=门缝手电压迫
@林深=林深
@周妍=周妍

【规格】约15秒，21:9，真人电影质感，最暗压抑暗调，室内接近剪影。

【电影化动态描述】承接012尾帧：门仍关死，门底手电漏光已经消失，307入户门重新变黑。35mm固定中景一镜到底，林深停在门内侧前位，身体略挡在周妍和门之间；周妍在他左后方半步、靠纸箱阴影，几乎成为剪影。林深上一镜的噤声手势已经完成，他把手从唇边慢慢放低，掌心压在身侧，改用身体挡位和余光控制周妍不要出声；他的眼睛在门底缝、门把、音箱、周妍之间极小幅度切换，但每次看向音箱时都比看门把短半拍，像在克制自己不要暴露熟悉感。周妍抓住外套下摆，嘴唇抿直。听到“确实有声音”后，林深的下颌只收紧一下，没有慌乱后退；听到“去拿备用钥匙”后，周妍先看林深，林深没有立刻回头，只用余光确认她的位置，随后两人短暂对视不到半秒。门外脚步声渐远，镜头不切、不追，只让两人留在暗处，门把手仍停在画面一侧的黑影里。

【音画同步】说话者锁定：保安A=307门外贴近门板的中年男声，音色偏低哑、警觉、每句前半都像在贴门听；保安B=307门外走廊稍远处的另一名中年男声，音色更厚、更闷，语气更不耐烦、更偏判断和催促；A/B声纹必须不同，不互相混淆；林深、周妍本镜不说话。承接012保安A那句“怎么了？”后的继续判断。所有保安声音都来自门外走廊，隔着307入户门传入室内，带门板闷声、走廊混响、距离差和转头方向变化；室内只保留压住的呼吸、音箱底噪和偶尔雨点击窗。保安A贴近门板、压低嗓音：“听起来……里面有人在说话。” “听起来”后停0.25秒，像他正在复核刚才听到的动静，“有人”二字压得更低。保安B在更远处回话，声音更厚、更闷，带一点不耐烦：“不会吧？这间房前几天就搬空了。” “不会吧？”轻轻上扬，后半句像在否定A的判断。保安A靠近半步，声音稍清晰但仍隔门发闷：“我听得很清楚。确实有声音。”两句之间留0.25秒，“确实”压重，语气从怀疑变成确认。0.8秒沉默，门外犹豫，室内林深保持前位不动，周妍从他左后方看向他，两人在沉默中短暂对视；这段沉默里雨声和电流底噪被放大。保安B从稍远处做决定，语速放慢、带实务性的催促：“那去保安室拿备用钥匙吧。”保安A近门短促收尾：“行，走。” “走”字后立刻接脚步启动声，先是A近处皮鞋声，再叠上B更远的脚步声，两组脚步在走廊里由近到远，约3秒被雨声吞掉。镜尾两人同时松出一口极轻鼻息，马上又收住。

【负面约束】门底手电漏光已经消失，严禁出现侧边门缝常驻冷白光；两人几乎不移动、不开门；周妍保持在林深左后方半步；保安只闻其声不入画；不加字幕、水印、背景音乐。
