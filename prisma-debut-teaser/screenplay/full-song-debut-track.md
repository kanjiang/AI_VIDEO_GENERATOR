# PRISMA — 完整出道曲《PRISMA》

**Track title:** PRISMA
**Duration:** ~3:20
**Key:** F# minor（末段升调 G minor 制造 lift）
**BPM:** 140（bridge 段落 rubato 处理）
**Genre:** Dark K-pop × World Fusion × Cinematic Trap Pop
**参考坐标:** aespa <Savage> + BLACKPINK <Kill This Love> + ITZY <CHESHIRE> + (G)I-DLE <Nxde>
**与预告片关系:** 完全兼容——共享 F#m/140BPM/core motif/五国乐器色 identity，chorus hook 就是 teaser 里那个 sung hook 的扩展版

---

## 设计原则

1. **概念一致性** — 歌词全部围绕"棱镜/白光/五色/穿透"这一个母题展开，不写空洞励志口号
2. **语言分布** — 英文承担 70% 主体（副歌/rap/桥段全英），五国母语只用**短句 punchline** 点缀在各成员的段落里（每人 1-2 句母语，让语言色彩感强但不影响国际传播）
3. **五人分唱** — 按定位分配段落，每人有**记忆点位**（signature 段落 + signature sound）：
   - LAN 岚（队长/门面）：Pre-Chorus + Verse 2a
   - YEON 燕（主唱）：Verse 1a + Pre-Chorus 2
   - SKYE 星（rap）：Rap Break（专属 20s 说唱段）
   - MALI 曼（主舞）：Verse 2b + Dance Break adlibs
   - RANI 兰妮（主唱）：Verse 1b + Bridge belt（高音爆发）
4. **副歌 hook 复用 teaser** — teaser 里 "We are PRIS-MA" 的旋律在这里成为副歌主 hook（同调同 BPM 同旋律），预告片和正片音乐 DNA 一致

## 备选：策略 B · 分段生成 + 拼接（若单轨不够精准）

Suno 一次跑 3 分钟的痛点：
- 多语言 punchline 可能被跳过 / 发音跑偏
- 五人切换感觉不明显（Suno 会把所有 verse 用一个声线）
- 副歌和主歌的力量对比可能不够

**分段策略：** 拆成 5 段独立生成，每段 30-45s，拼接。

| Segment | 内容 | 长度 | Prompt 变化点 |
|---|---|---|---|
| **S1** | Intro + Verse 1a (YEON) + Verse 1b (RANI) + Pre-Chorus (LAN) | 48s | 强调"soft build, 3 different female voices, restrained" |
| **S2** | Chorus 1 + Verse 2 + Pre-Chorus 2 + Chorus 2 | 72s | 强调"group unison chorus, full trap drop, energetic" |
| **S3** | Rap Break (SKYE) | 20s | 强调"solo female rap, English only, trap production, aggressive flow" |
| **S4** | Dance Break + Bridge (RANI belt) | 32s | 强调"instrumental break with world instruments, then high-belt female bridge" |
| **S5** | Final Chorus (升调) + Outro | 28s | 强调"key up half-step, biggest energy, cascade whispers ending" |

**拼接方式：** 后期软件 crossfade 1s per junction。若声线不匹配，重跑相邻段直到声线接近。

**每段 prompt 模板：** 同策略 A 的 style tags + song description，Lyrics 框只放该段歌词。

## 生成 checklist（挑 mother track 的 5 条听感准则）

按优先度：

1. **副歌 hook "We are PRIS-MA" 咬字清楚吗？** 若唱成 "Priya" / "Prima" / "Prizmaaah" 淘汰
2. **五人的声线有区分度吗？** 主歌听得出至少 3 种不同 timbre = OK；全用一个 timbre 唱完 = 淘汰或用分段策略 B 重跑
3. **副歌 vs 主歌能量对比够强吗？** 副歌应该明显厚一档（unison + choir + full drop）
4. **rap 段是不是女声 rap，且咬字清晰？** 若变成 sung verse = 淘汰
5. **bridge 高音有没有 goosebump 瞬间？** RANI belt 位置应该是全片最爆的一秒

## 后续制作路径（若你要拍完整 MV）

拿到完整曲之后，如果你要做**完整 MV**（不只是 45s teaser），下一步物件是：

1. **MV 分镜表** — 3:20 会拆到 60-80 个镜头，按 verse/pre/chorus/rap/dance/bridge 分场景组
2. **舞蹈编排 brief** — 至少定 3 段 point choreography（副歌 hook 动作 + rap 段动作 + dance break 段）
3. **拍摄场景清单** — 至少 4-5 个大场景（每个成员 solo 场景 + 集体舞台 + 概念场景 + dance break 特殊场景）

**但这些不是这一轮的事。** 先跑出音乐是所有后续物件的锚点——**歌不定，MV 分镜没法起草**（一个 bar 都不能落）。

## 与 teaser 的关系速查

| 元素 | Teaser (45s) | Full Song (3:20) | 是否兼容 |
|---|---|---|---|
| Key | F# minor | F# minor → G minor | ✓（末段升调不影响 teaser） |
| BPM | 140 | 140 | ✓ |
| Core motif | 4-bar F#m descending | 同一 motif | ✓ |
| Hook "We are PRIS-MA" | 5s sung hook (末段) | 副歌主 hook (重复 4 次) | ✓ 完全同旋律 |
| 五国乐器 | 逐个亮相 | Chorus 和 Dance Break 齐奏 | ✓ 扩展使用 |
| 6 句母语呼喊 | 5 signature + 1 群喊 | 融入主歌各段 punchline + outro | ✓ 重新分配 |
| Trap 底盘 | 全程 | 全程 | ✓ |

**用途分配：**
- Teaser 用**独立 BGM composition** 里的 Track A + Track B（45s 版本）
- 正片 MV 用这里的 3:20 完整曲
- 两者可以在同一天发布（先 15s 抖音短版预告 → 45s teaser → 完整 MV）也可以间隔一周 tease → drop
