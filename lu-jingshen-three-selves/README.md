# 三个他，只许你知道

## Working Title
`三个他，只许你知道`

## Logline
实习心理医生撞破霸总的三重人格，被「护卫人格」威胁封口，却被迫住进他身边当唯一知情者——她要治好他，也要在家族继承战里保住那个会怕黑的小女孩、那个会杀意的护卫，和那个不肯示弱的本尊。

## Premise Locks
- 起点：从零原创；只借多人格男主 + 治愈恋爱内核
- 赛道：霸总甜宠，甜里藏刀（日常甜，家族/继承战周期性捅刀）
- 女主：心理/精神科实习医生
- 人格数：精简 3 人格
- 绑定：撞破切换 → 护卫人格威胁封口 → 女主成唯一知情者并入住
- 骨架：「唯一知情者」同居监护（方案 1）
- 视觉：现实世界始终成年男主身体；人格靠语气、微表情、小道具区分；小女孩人格可在内心空间以儿童形象出现（可选）
- 小小性别锁：因陆母以「像女孩」污名恐惧，切出之幼态人格为女孩（详见 `characters.md`）

## 40-Episode Structure（4 Acts × 10 Episodes）
- **Act 1（Ep1-Ep10）**：撞破切换 → 唯一知情者绑定 → 三人格逐一登场 → Ep10 三人格同集协作首次
- **Act 2（Ep11-Ep20）**：日常同居 → 沈星野扛心态债累积 → 五重证据链前置 → Ep20 三人格首次公开危机
- **Act 3（Ep21-Ep30）**：陆承岳借热搜夺位 → 五重证据链完成（密码卡/兔子灯/周姨匿名公证/病历原件/陆母亲口录音） → Ep30 股东大会陆母坦白
- **Act 4（Ep31-Ep40）**：三人格协作时代 → Ep34 小小→小景名字回收 → Ep35 夜先收刀 → Ep36 继承战打脸 → Ep37 主使坐实 → Ep38「我是我们」公开整合 → Ep40 带着他们活（终局）
