# 详情页五屏 — 宠物圣诞围脖披肩

手机竖版详情（建议设计宽 750px，每屏高度按模块 800–1200px）。  
原则：**卖点画出来**，每屏一个主目标，少堆字。

---

## 分屏结构

| 屏 | 目标 | 标题（≤12字） | 视觉重点 |
|----|------|---------------|----------|
| 1 | 建立认知 | 圣诞限定围脖披肩 | 佩戴主视觉 + 产品名 |
| 2 | 核心卖点 | 礼物感 一眼记住 | 蝴蝶结+配色语言 |
| 3 | 材质细节 | 呢面与毛绒看得见 | 微距三细节 |
| 4 | 使用场景 | 派对拍照都好看 | 场景佩戴 |
| 5 | 购买引导 | 选尺寸 安心戴 | 适用犬种/佩戴示意 |

---

### 第 1 屏 — 建立认知

**设计目标：** 3 秒看懂「节日宠物围脖披肩长什么样」

```
电商详情页第1屏，竖版手机宽度构图。上方大标题区短句「圣诞限定围脖披肩」。主画面：棕色卷毛小型犬佩戴墨绿呢面+白毛绒边+红绿蝴蝶结围脖，室内暖光圣诞氛围浅景深（可参考提供实拍风格）。底部一条极简卖点条：节日拍照·精致装饰。产品外观锁定参考图。高清商业详情设计，禁止大段正文。
```

---

### 第 2 屏 — 核心卖点可视化

**设计目标：** 把「礼物感/节日感」画成视觉，而非文字说明

```
电商详情页第2屏，竖版。设计目标：突出核心卖点「红绿蝴蝶结礼物感+墨绿白边节日配色」。主视觉为围脖蝴蝶结大特写或犬胸前特写；旁边用三个小图标化视觉块（非大段字）：①节日配色 ②立体蝴蝶结 ③白毛绒包边。浅色或柔和圣诞色背景，留白充足。产品与参考一致。标题短句「礼物感 一眼记住」。
```

---

### 第 3 屏 — 材质/工艺

**设计目标：** 材质好 = 局部放大，不写说明书

```
电商详情页第3屏，竖版。标题「呢面与毛绒看得见」。三格或三联微距：墨绿粗花呢织纹、白色仿毛绒包边纤维、红绿丝带蝴蝶结结心装饰；每格仅短标签。商业微距摄影质感，干净背景。禁虚假实验室/医学认证图。
```

---

### 第 4 屏 — 使用场景

**设计目标：** 使用场景展示效果

```
电商详情页第4屏，竖版。标题「派对拍照都好看」。1–2张情景：①圣诞树前佩戴特写 ②红色格纹毯/礼物盒旁全身或半身。同一只小型犬、同一款墨绿圣诞围脖，暖光喜庆。强调出片氛围，产品清晰可见。少文字。
```

---

### 第 5 屏 — 购买引导

**设计目标：** 降低顾虑，推动下单（合规，无假数据）

```
电商详情页第5屏，竖版。标题「选尺寸 安心戴」。左侧或上方：围脖平铺/三视图示意结构；右侧信息卡片化短句——适配小型犬（泰迪/贵宾/比熊等）、节日拍照/送礼、注意项（按实际尺码表留空位给商家填写）。底部购买引导区「立即选规格」按钮占位。风格与前几屏统一的节日配色，干净可信。禁伪造销量评价截图。
```

---

## 文案包（可直接贴详情）

**屏1副文：** 墨绿毛呢 × 白毛绒边 × 红绿蝴蝶结，小型犬节日穿搭。  
**屏2副文：** 中间立体蝴蝶结，胸前第一眼就是焦点。  
**屏3副文：** 呢面织纹与毛绒包边细节，暖冬精致感。  
**屏4副文：** 圣诞夜、家庭派对、写真局，戴上就出片。  
**屏5副文：** 下单备注宠物体重/颈围，获取尺寸建议（商家自填表）。

## PSD / 分层交付说明

```markdown
## Handoff
- 成图后建议拆层：背景 / 宠物或产品 / 光效 / 文案层
- 锁定层：产品外形与配色（与 source-ref / 精修一致）
- 尺码表、价格、店铺名由客户替换文案层
- 字体：圆润无衬线；标题可用稍重字重
```
