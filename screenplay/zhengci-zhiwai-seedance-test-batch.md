# 《证词之外》Seedance 2.0 测试批次 — 当前版 11 个优先镜头

使用方式：逐条复制 prompt 文本投喂 Seedance 2.0，每条同时上传对应图参。上传后，必须把对应参考图以 @image1、@image2 这种形式真正写进提示词正文里，不能只上传不写。@image 编号跟随本次上传顺序变化，但括号里的名字应保持稳定。

本批次目标：先验证当前版本最容易翻车的 11 个关键镜头。
1. 开场误导是否成立。
2. 307 智能音箱与兄妹数字口令是否成立。
3. 29 楼设备间与“语音复刻模型”是否可信。
4. 露台白色手机诱导、护栏异响、坠落是否真实。
5. 闪回里的即时触发机制是否说得通。
6. 终场林晚未死与系统播报是否够冷。

统一基准：
- 全部 21:9，one-shot，单镜头，无剪辑，无字幕，无音乐。
- 8K IMAX，超写实真实摄影，禁止3D渲染，禁止游戏引擎，禁止游戏CG，禁止插画感。
- 60fps，180度快门，物理镜头质感，禁止身份漂移，禁止光学畸变，禁止漂浮道具。
- 只允许场景内真实光源，禁止任何画面外补光。
