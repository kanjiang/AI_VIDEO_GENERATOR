## 使用规则

- 每个文件只放对应声源的一种基础声纹，不混入多个角色。
- 当前已放入的 `林深.mp3`、`周妍.mp3`、`林晚.mp3` 会作为三位主角的有效声纹参考。
- 样本尽量干净，无背景音乐，无强混响，无明显降噪泵动。
- 如果样本里有多句台词，保持同一情绪基准，不要一份文件里同时包含哭喊、耳语和大喊。
- 视频生成时，以本目录 MP3 为声纹最高参考；文字提示只用于控制情绪、距离、设备压缩和空间质感。
