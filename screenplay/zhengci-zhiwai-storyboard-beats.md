## 视觉与执行建议

| 项目 | 建议 |
| --- | --- |
| 视觉母题 | 栏杆、玻璃、监控屏、扬声器，所有“边界”都在骗人 |
| 光源设计 | 公寓偏冷灰；公司大厅偏洁净白；29 楼实验区用屏幕蓝光和设备红点；露台只留城市夜光 |
| 机位风格 | 前半段稳；上到 29 楼后镜头更贴；推落后闪回切得更硬更短 |
| 声音策略 | 前半段林晚的声音要像真的；露台和坠落里再让合成质感慢慢暴露 |
| 表演重点 | 林深前半段要像真正心疼妹妹；推人后仍然不爆；陈伯始终像流程执行者 |
| AI 视频提示词方向 | 员工公寓遗物、企业大厅、29楼实验区、露台高空、合成语音、坠落闪回、监控终幕 |
