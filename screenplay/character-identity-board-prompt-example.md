# 角色身份板提示词示例

**角色身份板提示：**

创建一张艺术性的 16:9 角色身份板。

[主体]：使用参考图像。

[身份定位]：突出角色的职业属性、社会位置、生活状态、情绪底色与核心矛盾，让观众一眼看出这个人是谁、从哪里来、处于怎样的压力或命运之中。

[造型要求]：保留参考图像中的关键身份识别点，强调服装轮廓、材质层次、身体比例、姿态习惯、面部张力、发型细节、手部状态以及最能代表角色经历的道具。角色必须具有明确的轮廓可读性和身份说服力，而不是泛化的人物时尚照。

[画面设计]：以电影化的方式组织一张完整的 16:9 身份板，让主体占据主导视觉中心，同时允许少量辅助小画面或局部切片展示手部、侧脸、鞋履、关键道具、服装纹理或表情变化。整体版面要有展示感、叙事感和视觉节奏，但不要做成商业海报，也不要堆砌过多信息。

[氛围与灯光]：根据角色身份设计环境气压、色调倾向、光线方向、明暗反差和整体质感，让光影服务于角色性格和命运状态。氛围必须帮助观众理解角色，而不仅仅是制造好看画面。

[附加信息]：可以加入少量身份标签、关键词注释、材质说明、道具说明、世界观碎片或简短手写批注，但这些信息只能作为辅助阅读层，不能压过角色主体本身。

[最终要求]：整张图必须更像电影项目中的角色身份展示板，而不是广告海报、杂志大片或普通角色立绘。优先保证角色身份的清晰传达、气质统一、版面控制和参考图像的一致性。

负面约束：不要做成纯海报，不要过度平面设计，不要信息过载，不要失去参考图像中的核心身份特征，不要把角色处理成无来源感的时尚模特照。
