# 02 — Product Assets（精修 + 三视图）

在主视觉/模特之前，建立**可复用的产品视觉底座**。后续所有生成必须引用精修图与三视图（或等价多角度）。

---

## 问题 A：客户图「全损」不能用

目标：修复瑕疵、统一材质与光影，输出**电商可用精修图**（透明底或干净棚拍底，按渠道）。

### 精修 prompt 骨架

```
商业产品精修摄影。完整保留产品造型、比例、Logo 与包装结构，不重新设计产品。
修复：[污渍/划痕/压损/色差]；强化材质真实感：[金属拉丝/玻璃折射/皮革纹理/塑料高光…]；
棚拍柔和主光+轻微轮廓光，高光干净，阴影通透；背景 [纯白/浅灰无缝]；
电商主图级清晰，边缘锐利，无水印无文字（除非包装自带）。
禁变形、禁改 Logo、禁添加未有配件、禁过度磨皮塑料感。
```

把括号换成 brief 里的材质与问题列表。输出文件建议：`product-hero-retouch.png`。

---

## 问题 B：缺角度 / 要一致性

目标：正/侧/背或 ¾ 多角度，**同一产品、同一材质、同一光比**。

### 三视图 / 多角度 prompt 骨架

```
同一产品的标准电商三视图（正面、侧面、背面）[或：正面+45°+顶视]，
严格同一造型、材质、颜色、Logo 位置；纯白背景，对齐居中，比例一致，
商业棚拍光，无文字无水印。参考已锁定的精修产品外观，禁止换款。
```

若模型支持多图参考：强制「以精修图为唯一产品外观参考」。

建议文件：`product-threeview.png` 或分文件 `front/side/back`。

---

## 一致性门禁（进入 Phase 3 前）

| # | 检查 | 失败则 |
|---|------|--------|
| 1 | 精修未改结构/Logo | 重跑精修 |
| 2 | 多角度同款同色 | 重跑三视图 |
| 3 | 背景干净可抠 | 换白底再出 |
| 4 | brief 卖点相关部件可见 | 补特写角度 |
