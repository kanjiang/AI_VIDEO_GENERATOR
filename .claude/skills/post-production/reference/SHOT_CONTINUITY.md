# Shot Continuity（镜头组接逻辑手册）

从原理到实操：解决衔接生硬、节奏混乱、空间跳脱。  
**生成前**写进 Seedance；**生成后**用本手册 + [ai-footage-qa.md](ai-footage-qa.md)。

**分镜规范精简版（首选写入脚本）：** [分镜规范.md](../../shotlist-builder/reference/分镜规范.md)

来源：[absorption/AIGC-镜头组接逻辑吸收.md](absorption/AIGC-镜头组接逻辑吸收.md) + 老登日记三大模块提炼。

> 勿把逻辑、时长、切点混成「凭感觉」。拆成：**空间连续性 → 镜头时长 → 剪辑点**，并选用**景别组接公式**。

## 0. 一页速查

| 规则 | 一句话 | 违则观感 |
|------|--------|----------|
| **30°** | 同主体相邻角度 ≥30°（或景别差 ≥1 级） | 无意跳切、廉价 |
| **180°** | 机位不越过主体轴线 | 左右站位/朝向反了 |
| **动作匹配** | 前镜动势在后镜延续；动作中间剪 | 动作撕裂 |
| **方向匹配** | 运动/视线统一；改向加过渡 | 掉头违和 |
| **位置匹配** | 画左/画右相对位置稳定 | AI 人物乱跑 |
| **时长** | 信息 + 情绪 + 音乐/台词 | 看不清或走神 |
| **剪辑点** | 顶点/发力/拐点/遮挡/静接；眨眼 | 切肉感 |
| **景别公式** | 递进 / 倒退 / 两极 / 平稳 | 开场散、悬疑无钩 |

## 1. 模块 A — 空间连续性

### 1.1 30° 原则

同主体相邻镜角度变化 **≥30°**；建议同时改景别。  
禁：两个几乎同角度的中景硬切。

```
机位：50mm中景，约45°侧面（相对上一段再偏30°+）。
⚠️角度差≥30°或景别差≥1级，禁同角度微姿态跳切。
```

### 1.2 180° 原则

机位保持轴线同一侧。  
**刻意越轴**仅悬疑/不安，须标注；常规禁止。

```
⚠️180°轴线——摄影机在A–B连线[左/右]侧，与上一段同侧。
```

```
⚠️刻意越轴——制造不安：本段越过轴线，人物左右关系翻转。
```

占位见 [CHARACTER_STAGING.md](../../shotlist-builder/reference/CHARACTER_STAGING.md)。

### 1.3 三大匹配

| 匹配 | 要求 |
|------|------|
| **动作匹配** | 前镜走势在后镜延续；动作中间剪最顺 |
| **方向匹配** | 运动/视线统一；转向加过渡镜 |
| **位置匹配** | 画面相对位置稳定 → 每段写画左/画右 |

速度/运镜速率应对齐；差太大则变速或重生成。

## 2. 模块 B — 镜头时长

| 区间 | 观众 |
|------|------|
| 0.1–0.3s | 光影色 |
| 0.3–0.5s | 轮廓 |
| **0.5–3s** | **读懂（常规基准）** |
| ＞6–8s | 易走神 |

1. **信息密度**：复杂拉长，简洁可短（信息须传完）。  
2. **情绪**：＜1.5s 紧张追逐；＞3s 沉静悬念内心。  
3. **节奏载体**：卡点跟音乐；**对话跟台词语义**，勿强行卡鼓点。

配合 [DIRECTOR_BEATS.md](../../shotlist-builder/reference/DIRECTOR_BEATS.md)。

---

## 3. 模块 C — 剪辑点

优先五类：动作顶点、发力起始、方向拐点、遮挡、静接点。  
加分：眨眼切。  
慎用有意跳切于抒情场；规划见 [分镜规范.md](../../shotlist-builder/reference/分镜规范.md) §H。无意跳切（＜30°）是事故。

详见 [editing-techniques.md](editing-techniques.md) §1。

---

## 4. 四种景别组接公式

| 公式 | 序列 | 用途 |
|------|------|------|
| **递进式** | 全景→中景→近景→特写 | 开场收束情绪 |
| **倒退式** | 特写→近景→中景→全景 | 悬疑首选 |
| **两极** | 全景↔特写 | 转折冲击；禁频繁 |
| **平稳叙事** | 中景↔近景 | 对话文戏；仍要 30° |

场次头标注：`组接公式：倒退式`。

## 6. 避坑与质检

1. 同景别硬切角度不足 30°  
2. 两极狂切冲击失效  
3. 镜长平均  
4. 越轴当常规  
5. 不写画左画右
