# 《身体小队》片头曲

## Suno 使用说明

1. 打开 Suno，选择 **Create** → **Custom Mode**
2. 将下方 **Style of Music** 内容粘贴到风格栏
3. 将 **Lyrics** 内容粘贴到歌词栏（保留所有方括号标注）
4. 设置时长为 **1 分钟**
5. 建议生成 3-4 个版本挑选最佳

---

## Style of Music

```
adventure orchestral, children's anime opening, brass fanfare, epic drums, upbeat march tempo 140bpm, Disney Pixar animation style, Chinese vocals, energetic choir, heroic and cute
```

## Negative Tags

```
sad, slow, dark, horror, jazz, lo-fi, ambient, whisper, ballad
```

## 歌词说明

| 段落 | 对应角色/概念 | 时长 |
|------|-------------|------|
| Intro | 铜管号角建立冒险感 | ~8秒 |
| Verse 1 | 红小达（氧气快递）、白小锋（巡逻战队） | ~14秒 |
| Verse 2 | 闪闪（警报信号）、板板（修补钉+凝血网） | ~14秒 |
| Chorus | 全队合唱，核心口号"身体小队" | ~20秒 |
| Outro | 器乐收尾 | ~4秒 |
