# 01 — Product Brief（先分析，再出图）

错误：拿到产品图直接「设计一张高级海报」→ 好看但难用、风格飘。  
正确：先拆产品与用户，锁视觉方向，后续全部引用本卡。

---

## Intake checklist

向用户要齐（缺则一次问清）：

- 产品照片（可多张，含「全损」也行）
- 品类 / 品牌名（若有）
- 目标渠道：淘宝天猫主图、详情、京东、抖音小店、独立站…
- 价格带与人群一句话
- 必须出现的卖点（≤5 条）与绝对禁止（竞品元素、虚假功效等）

---

```markdown
- 是谁：

- 决策顾虑：

## 核心卖点（按优先级，最多 5）

## 视觉方向（三选一主风格，可微调）
- 主风格：[科技未来 / 美妆质感氛围 / 食品诱人食欲 / 其他：…]
- 关键词 5 个：
- 色彩逻辑（主/辅/点缀）：
- 摄影语气：[棚拍干净 / 情景生活 / 暗调奢华 / 明亮清新…]
- 字体与排版语气：[无衬线科技 / 优雅衬线 / 手写亲和…]
- 禁止：

## 物料范围（勾选）
- [ ] 精修 + 三视图
- [ ] 主视觉 KV
- [ ] 模特/情景套图
- [ ] 多尺寸营销海报
- [ ] 样机
- [ ] 电商主图套装
- [ ] 详情页分屏
- [ ] 短视频（交 product-video）

## 确认
用户确认视觉方向后，才能进入精修/主视觉。
```

---

## 品类方向速查

| 品类 | 视觉重心 | 慎用 |
|------|----------|------|
| **科技** | 未来感、结构、功能信息层级、干净几何光 | 过度生活化杂乱背景 |
| **美妆** | 质感、光泽、氛围、使用后气质 | 假临床夸张、脏乱台面 |
| **食品** | 诱人、新鲜、蒸汽/冷凝、进食欲望 | 塑料感、脏渍、冷灰食欲抑制 |
| **家居** | 场景融入、尺度、材质触感 | 过度棚拍假人感 |
| **服饰** | 版型、面料垂感、上身关系 | 变形人体、乱纹 |
