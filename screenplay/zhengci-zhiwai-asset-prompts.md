# 《证词之外》资产生成提示词（2026-06-01 重拆版）

用途：为新版《证词之外》生成角色定妆、核心场地、关键道具和少量二层补充图参，服务于新版 shot list、reference map 和 asset canvas。

生成原则：

1. 一次只生成一个明确主体，不把角色、场地、道具混在同一条里。
2. 全部按超写实照片思路写，禁止插画、禁止3D、禁止游戏CG。
3. 人物资产默认输出 16:9 角色身份板：以主体肖像为核心，可带少量局部切片，但不再统一走纯白五视图。
4. 场地资产默认输出 16:9 场景锚点图：优先锁空间结构、灯光方向、动线和可拍性，不在一张图里塞完整剧情。
5. 屏幕与UI资产保持真实工业软件感，不做赛博霓虹，不做华丽浮层。
6. 本套资产与当前工作流对齐：角色身份板 -> 场景图 -> 道具/UI，再进入故事板和视频生成。
7. 本套资产只服务新版结构：书房冷开场、307设局、电梯停层、29楼设备间、露台白色手机、录音笔收尾。
