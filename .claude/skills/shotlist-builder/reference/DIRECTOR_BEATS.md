# Director Beats（找重点 → 找节奏 → 找关系）

把普通短视频镜流升级为**有电影感的悬疑/戏剧叙事**的导演层方法。  
在写 Seedance 提示词、画俯视图之前，先填本卡。

来源：[absorption/AIGC-导演级分镜三步法吸收.md](absorption/AIGC-导演级分镜三步法吸收.md)。

---

## When to use

- 悬疑、反转、线索揭示、情感爆发场
- 用户说：电影感分镜、找重点、控节奏、铺垫关系、不要流水账
- 一场戏镜头数 ≥4，或单集里有「必须让观众记住的一件事」

Skip：纯空镜材质测试、单人无剧情试镜。

## 三步法详解

### 1. 找重点

**逻辑：** 每场只有一个主菜。开门、走路、拉椅、坐下 = 铺垫 → 快切或一镜带过。  
「看手机：中了 1000 万」= 重点 → 拉长，咬住表情与微表情。

落到 prompt：

- 铺垫镜：`时长偏短`、可合并进一条 15s 里的前 2–3 秒。  
- 重点镜：单独一条或占 `【镜头N】` 最大时长；配合 `MICRO_BEATS` 写清眼神/呼吸。  
- 叙事功能标签优先用：`核心` / `情感高点`（见 PROMPT_PATTERNS）。

### 2. 找节奏

**逻辑：** 节奏 ≠ 一味快剪，而是编排观众「何时急、何时憋、何时懂」。

| 观众状态 | 常用镜法 |
|----------|----------|
| 着急 | 多角度、短镜头、翻找/奔跑动作碎切 |
| 屏息 | 骤停、前一秒美学、环境声突出、人影一闪 |
| 得答案 | 稳定特写拉长、信息入画停住 |

**悬念升级手法：** 表层问题最烫时，插入更高阶威胁（找彩票 → 水杯后的人影），再回来或转入新线。

### 3. 找关系

**逻辑：** 爆发前用镜头让观众「先感到不对」，再给答案。

常用（可与 COMPOSITION_LIBRARY 联用）：

- 前景遮挡（杯/门框/窗帘后拍主体）→ 窥视感  
- 画外空间 / 角色看向画外  
- 空椅、多一双鞋、未关的门  
- 过肩但焦点在暗处

规则：关系镜头必须出现在**爆发镜之前**，否则算「无铺垫爆发」。

---

## 三禁（写分镜时）

1. **禁信息重复** — 多镜同义，只留最强一镜。  
2. **禁节奏平均** — 禁止所有镜头同等时长。  
3. **禁无铺垫爆发** — 反转/惊吓前至少 1 个关系或细节铺垫镜。

## 迷你范例（彩票悬疑压缩）

| 步 | 填写 |
|----|------|
| 重点 | 女主看见彩票中奖短信时的表情 |
| 铺垫快切 | 进门、走路、拉椅、坐下 |
| 着急 | 多角度翻找彩票 |
| 升级 | 最想看到彩票时 → 切水杯倒影里的人影 |
| 关系铺垫 | 翻找时已有「从杯后拍」的窥视构图 |
| 得答案 | 中奖手机屏 / 或人影现身（二选一作本场唯一重点） |
