## 三大模块（勿混为一谈）

| 模块 | 解决什么 | 主要落点 |
|------|----------|----------|
| **A. 空间连续性** | 不迷路、不瞬移、**无意**跳切 | 机位句 + 占位句 |
| **B. 镜头时长** | 看清 / 紧张 / 不走神 | 每镜时长策略 |
| **C. 剪辑点** | 切哪一帧最顺 | 后期切点 / 段尾动作设计 |
| **H. 有意跳切** | 去冗余、提完播、提密度 | 关键节点规划（见下） |

> **有意跳切 ≠ 无意跳切。**  
> 有意：故意跳过过程，只留节点，且**景别/角度差够大**。  
> 无意：同景别+角度＜30° 的「闪一下」——事故，见模块 A2 / QA。

---

## A. 空间连续性

### A1. 180° 轴线（多人对话刚需）

- 视线/运动轨迹成轴，机位保持**同一侧**。  
- 违规：人物左右互换感、空间错乱。  
- **刻意越轴**：仅悬疑/不安（如《证词之外》类），须在分镜注明 `⚠️刻意越轴-制造不安`；常规叙事禁止。

### A2. 30° 机位

- 同主体相邻镜：角度变化 **≥30°**。  
- 反面：只轻微放大 → 无意跳切、观感廉价。  
- 建议：**角度变化 + 景别变化** 双保险。  
- 避坑：相邻两个「中景」不要只换一点点角度硬切。

### A3. 三大匹配（上下镜硬标准）

| 匹配 | 要求 |
|------|------|
| **动作匹配** | 前镜动作走势在后镜延续；**动作中间**剪最顺 |
| **方向匹配** | 运动/视线方向统一；转向必须加过渡镜 |
| **位置匹配** | 人物画面相对位置稳定（AI 防乱跑核心）→ 每段写画左/画右 |

分镜标注最低字段：

```
机位：[焦距][景别][相对上镜的角度差或轴线侧]
站位：[角色]画左/画右，面朝[…]，距[…]约Xm
视线/运动方向：[…]
轴线：同侧 / 刻意越轴（注明目的）
```

## B. 镜头时长

| 区间 | 观众 |
|------|------|
| 0.1–0.3s | 只感光影色 |
| 0.3–0.5s | 轮廓 |
| **0.5–3s** | **读懂信息（常规基准）** |
| ＞6–8s | 易走神（除非强情绪/高信息密度） |

**决策三要素**

1. **信息密度**：复杂→拉长；单一清晰→可缩短（信息须传完）。  
2. **情绪**：＜1.5s 紧张冲突追逐；＞3s 沉静悬念内心。  
3. **节奏载体**：卡点跟音乐；**剧情对话跟台词语义**，勿强行卡鼓点。

禁：全片统一镜长。

## C. 剪辑点（优先这 5 类）

| 类型 | 切点 |
|------|------|
| 动作顶点 | 幅度/力量最大瞬间 |
| 发力起始 | 动作启动瞬间 |
| 方向拐点 | 转向/转头瞬间 |
| 遮挡 | 遮挡主体、出画/入画 |
| 静接点 | 静止画面，情绪或一句台词结束处 |

**加分：** 眨眼瞬间切（文戏无痕）。  
**有意跳切：** 见下方 **§H**（提节奏万能手法；抒情场慎用）。  
**无意跳切：** 30° 不足——事故，不是手法。

---

## D. 四种万能景别组接公式（直接写入分镜）

| 公式 | 序列 | 用途 |
|------|------|------|
| **1. 递进式** | 全景→中景→近景→特写 | 开场由环境收到人物，情绪收紧 |
| **2. 倒退式** | 特写→近景→中景→全景 | 先抛细节悬念再展开，**悬疑首选** |
| **3. 两极镜头** | 全景 ↔ 特写 | 剧情转折冲击；**禁频繁连续**，冲击会失效 |
| **4. 平稳叙事组** | 中景 ↔ 近景 | 对话、日常文戏基础 |

分镜示例标注：`组接公式：倒退式` 或 `组接公式：平稳叙事+30°换角`。  
若本场用跳切提速：`组接公式：递进式+有意跳切` 或 `跳切：同主体关键动作节点`。

---

## E. 实战避坑（必查）

1. 同景别相邻硬切且角度＜30° → 改角度或改景别。  
2. 两极镜头无过渡狂切 → 冲击失效。  
3. 镜长平均 → 无重点（配合 DIRECTOR_BEATS）。  
4. 把越当常规剪法 → 仅特殊气氛使用。  
5. 批量 AI 分镜不写左右站位 → 后期修不完。  
6. 抒情/重要情绪戏滥用跳切 → 情绪被掐断。  
7. 同景别跳切 → 廉价闪跳（应改景别或角度）。  
8. 为快而快、节点无故事逻辑 → 观众看不懂。

## F. Seedance Prompt 前置块（复制）

```
【分镜规范】
组接公式：[递进/倒退/两极/平稳][+有意跳切]
轴线：与上一段同侧（或：刻意越轴-不安）
机位差：相对上一段≥30°或景别升降一级
位置匹配：[A画左面朝右 / B画右面朝左…]
方向匹配：运动/视线向[…]
动作匹配：承接上段[动作中段/…] 或 跳切节点：[抬手/关门/亮证…]
时长意图：[短<1.5s紧张 / 常规0.5–3s / 长>3s沉浸]
跳切规划（可空）：本场关键节点①…②…③…（三画面一组）
```

## G. IP 速配

| 场景 | 建议 |
|------|------|
| 悬疑 | 倒退式 + 遮挡；线索发现用跳切：全景→线索特写→表情近景 |
| 武打 | 出拳/格挡/反击节点跳切；动作匹配+顶点切 |
| 漫剧批量 | 每镜预留可跳切的核心画面；写清节点 |
| 科普/口播 | 去过程留结论节点；卡点配鼓点 |
| 抒情文戏 | **少跳切**，用静接/眨眼/长镜 |

## H. 有意跳切（提节奏 / 提完播）

### 定义

剪掉不必要的过渡过程，**只保留关键动作/信息节点**，在同一主体或同一场景中打破连续时间线，加快节奏、提高信息密度与完播率——且**不丢故事逻辑**。

### 两大实战场景

| 场景 | 做法 | 例子 |
|------|------|------|
| **1. 同场换景别** | 全景→中景→近景快速跳 | 《无间道》天台：景别递进强化情绪 |
| **2. 同主体抓动作节点** | 在关键瞬间切 | 抬手瞬间切手；关门瞬间切全景（《让子弹飞》《功夫》类） |

可与 §D **递进式** 叠加：递进本身常靠跳切实现「去过程」。

### 分镜前置（给 AI 生成用）

每个计划跳切的镜头只写**节点**，不写完整过程：

```
【跳切节点组】三画面一组
① 全景：[场景状态一句] — 禁走路过场细节
② 中/近：[关键动作顶点或信息] — 如抬手扣扳机前
③ 特写/近：[结果或表情]
⚠️各镜景别差明显；机位差≥30°；后期可再掐头去尾。
```

### 练习法

- **三画面一组**：每组只留最关键部分。  
- 单段时长：以**能看清信息**为准（常落在 0.5–3s 甜蜜区），别无意义碎闪。

### 效果增强

- 鼓点 / 环境音咬准切点（跳得越准越有节奏）。  
- 节奏跟情绪：紧张→快跳切；抒情→慢跳切或不用。
