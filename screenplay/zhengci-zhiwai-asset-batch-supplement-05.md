# 《证词之外》Batch C 缺图直投包

用途：这组对应当前缺图任务看板里的 Batch C，用来补齐第三幕反转、闪回闭环和终场物证。优先建议先补 RecorderPenClose，再补 AudioProfitDashboard 与 LockedRoomWide，最后补匿名执行者相关画面。

建议触发规则：
- 终场物证不够明确：补 RecorderPenClose
- 黑鞋收尾的匿名压迫不够：补 GroundShoesClose
- 闪回里的黑产盈利逻辑不够清楚：补 AudioProfitDashboard
- 林晚“活着但被控制”的状态不够落地：补 LockedRoomWide
- 预设陷阱镜头里执行者轮廓不够可信：补 SecurityGuardShadow
