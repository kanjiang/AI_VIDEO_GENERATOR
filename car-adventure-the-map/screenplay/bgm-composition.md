## 全局参数

| 项目 | 参数 |
|------|------|
| 总时长 | ~150s（2:30） |

## 分镜配乐表

### P01 — 车库与照片（0:00 - 0:15）

| 层 | 内容 |
|---|---|
| 过渡 | 全片起始。从2秒纯环境音（灰尘飘浮的微弱空气声）开始，钢琴在第3秒轻轻进入 |
| 音乐 | 主旋律B前4小节（柔情版），仅Felt Piano独奏，pp极弱。第12秒起加入一声竖琴泛音（当Momo看向照片时） |
| 节奏 | BPM=76，自由节奏（rubato），不打拍子感 |
| 音效 | [车库环境音]（微弱空气流动+灰尘）0-15秒；[Momo怠速声]（极轻引擎怠速嗡嗡）3秒起 |
| 情绪 | "这个小车每天都这样看着那张照片吧" |
| 技法 | 钢琴触键极轻，像在说悄悄话。第12秒竖琴泛音=视线落在照片上的"叮"感 |

### P02 — 今天也只是看看（0:15 - 0:30）

| 层 | 内容 |
|---|---|
| 过渡 | P01尾音（钢琴延音）自然延续至P02，不断裂 |
| 音乐 | 主旋律B后4小节。Felt Piano + 大提琴拨弦（每2拍一下低音拨弦=心跳节奏）。"今天也只是看看"台词时音乐抽空0.5秒 |
| 节奏 | BPM=76，大提琴拨弦提供隐性节奏 |
| 音效 | [微风吹入门缝]8秒；[照片纸张被风掀起]9秒；[Momo保险杠按住照片]9.5秒（轻微金属触碰纸面声） |
| 情绪 | "他每天都对自己说这句话——已经不知道第几天了" |
| 技法 | 台词"今天...也只是看看"前0.5秒音乐全部抽空（只留怠速声），让对白完全干净地落入寂静。台词后钢琴以B旋律最后2个音回归 |

### P03 — 外面太快了（0:30 - 0:45）

| 层 | 内容 |
|---|---|
| 过渡 | P02尾部大提琴拨弦最后一下延音→P03开头0.5秒沉默→跑车声突然冲入 |
| 音乐 | 前6秒：音乐完全退出，仅SFX。跑车掠过后1秒寂静。第8秒起：主旋律B变体（Em调），单音钢琴，极慢，每个音之间1.5秒间隔。"我想去"时加入单簧管长音（温暖的一线光）。"可是我不敢"时单簧管消失，只剩钢琴单音 |
| 节奏 | 前6秒无节奏感（纯SFX驱动）。8秒后BPM=66，极自由 |
| 音效 | [大车驶过环岛]1-3秒；[红色跑车极速掠过+气流冲击]4秒（⚠️最响的SFX——Momo恐惧的物理源头）；[Momo急刹弹跳]4.5秒；[车库门震动滑落]6秒；[Momo怠速声变弱]7秒 |
| 情绪 | "他真的很害怕——不是装的那种害怕" |
| 技法 | 跑车SFX是全集音量最高点→之后的极静形成强烈对比。"我想去/可是我不敢"两句之间插入1秒完全寂静（连怠速声都压低），放大那个停顿的重量 |

### P04 — 地图飞来（0:45 - 1:00）

| 层 | 内容 |
|---|---|
| 过渡 | P03尾部钢琴单音自然衰减→P04开头2秒环境音（街道安静）→风起 |
| 音乐 | 新素材：木琴单音跟随纸张飞行轨迹——每次纸张翻转一次，木琴叮一下（约4-5次叮）。底层：弦乐泛音长音铺垫（暗示命运感）。纸贴上挡风玻璃瞬间：竖琴快速上行琶音 |
| 节奏 | BPM=88，但节奏由纸张飞行动态决定，木琴叮声间隔不等 |
| 音效 | [风起+落叶翻飞]3秒；[送货卡车远处驶过]4秒；[纸张在空中翻飞]5-11秒（持续的纸张飘动声）；[纸贴上挡风玻璃"啪"]12秒；[Momo大灯闪亮]12.5秒（微弱电子亮灯声） |
| 情绪 | "有什么东西正在飞过来——不是偶然的" |
| 技法 | 弦乐泛音铺底制造"命运降临"感，但音量极低（pp），不喧宾夺主。木琴跟踪纸张是关键——让观众耳朵跟着纸走 |

### P05 — 是照片上的地方（1:00 - 1:15）

| 层 | 内容 |
|---|---|
| 过渡 | P04竖琴琶音尾音延续→P05钢琴进入 |
| 音乐 | 前6秒：主旋律A前2小节变体（好奇/轻快），Felt Piano + 木琴双声部。"这个圆圈..."时木琴停，钢琴独奏转慢。后9秒：⚠️关键发现时刻——"是照片上的地方"前1秒完全寂静→台词后主旋律A完整进入（第一次以完整形态出现），Piano + 大提琴拨弦 + 弦乐铺底（pp→mp），情绪第一次真正打开 |
| 节奏 | 前6秒BPM=92（好奇感稍快）。后9秒BPM=88（回归基准，稳定而温暖） |
| 音效 | [雨刷刷动]2秒、4秒；[纸张展开]5秒；[Momo倒车]7秒 |
| 情绪 | "他发现了——照片里的地方是真实存在的，而且有路可以到达" |
| 技法 | ⚠️"是照片上的地方"是信息转折点。台词前1秒音乐抽空+环境音压低=真空感。台词后主旋律A首次完整出现=情绪释放。这是全集第一个"音乐真正响起来"的瞬间 |

### P06 — 路会来找你（1:15 - 1:30）

| 层 | 内容 |
|---|---|
| 过渡 | P05主旋律A最后2小节弦乐铺底延音→P06钢琴转为B旋律 |
| 音乐 | 镜头1（照片翻面/文字）：主旋律B前4小节，Piano独奏，回到极简。镜头2（"我不是不想去"）：Piano保持B旋律但加入大提琴长弓（温暖的低音支撑）。镜头3（雨刷压住照片+地图并列）：主旋律A后4小节变体，木琴回归+弦乐铺底渐入——暗示"准备好了" |
| 节奏 | 镜头1：BPM=76。镜头2：BPM=76→80（微加速，决心在萌芽）。镜头3：BPM=84 |
| 音效 | [风吹照片翻面]2秒；[引擎咕噜=吞咽]9秒（⚠️这个声音要和大提琴低音在同频段，形成"身体在说话"的感觉）；[雨刷压下照片]12秒；[雨刷压下地图]13秒 |
| 情绪 | "他一直在等一个理由——现在理由齐了" |
| 技法 | 引擎咕噜声=情绪吞咽，需要和BGM大提琴错开0.3秒（先咕噜→后大提琴音），不抢位。镜头3木琴回归=呼应P04（地图飞来时的命运感），制造"这些事件是有联系的"暗示 |

### P07 — 环岛出口（1:30 - 1:45）

| 层 | 内容 |
|---|---|
| 过渡 | P06弦乐铺底渐弱→P07开头2秒仅环境音（环岛远处车流微弱声）→钢琴进入 |
| 音乐 | 主旋律B变体（犹豫版）：钢琴右手弹主旋律但每个音后有0.5秒停顿（像在犹豫要不要弹下一个音）。左右转向时分别对应两个不同的音——左转=低音G（安全/家），右转=高音D（远方/梦想），来回交替。"如果路真的来了..."时音乐定格在高音D上不解决 |
| 节奏 | BPM=76，大量留白。钢琴的"犹豫停顿"制造不规则节奏 |
| 音效 | [环岛远处车流]0-15秒（背景层，-10dB）；[Momo轮胎转向]6秒、8秒（两次方向变化） |
| 情绪 | "他在岔路口站了那么久——左边是确定的安全，右边是不确定的一切" |
| 技法 | 钢琴不解决和弦=悬而未决感。高音D停在空中不落回主音=台词"如果路真的来了..."的音乐化——话没说完，音也没落完 |

### P08 — 那我就试一下（1:45 - 2:00）

| 层 | 内容 |
|---|---|
| 过渡 | P07高音D延音继续悬挂→P08跑车冲过打断→2秒寂静→钢琴重新开始 |
| 音乐 | 前7秒：引擎差点熄火时——完全寂静（全集最安静的2秒）。后8秒：⚠️⚠️⚠️全集情感转折——"那我就试一下"前0.5秒完全真空→台词落下→台词后1秒，主旋律C（收束/出发版）以Felt Piano独奏极轻进入（pp），第3秒起大提琴长弓+弦乐铺底渐入。Momo背影远去时音乐渐强至mp。⚠️注意：不要做成宏大的出发曲——保持安静坚定感，像一个孩子小声做了决定然后默默走了 |
| 节奏 | 前7秒无节奏。后8秒BPM=88，稳定，不加速——坚定不是快，是稳 |
| 音效 | [红色车掠过+气流]1秒；[Momo弹跳后缩]2秒；[引擎差点熄火]3-5秒（从嗡嗡→咕咕→沉默）；[引擎重新抓住]8秒（一声稳定的嗡） |
| 情绪 | "他说得那么轻，但那是他这辈子做过最大的决定" |
| 技法 | ⚠️这是全集音乐的核心转折。"那我就试一下"必须落在寂静中——台词本身就是音乐。台词后钢琴进入的方式必须极轻（像回应而非引领）。主旋律C第一次出现=出发主题确立，后续集数复用此旋律代表"在路上" |

### P09 — 不要回头（2:00 - 2:15）

| 层 | 内容 |
|---|---|
| 过渡 | P08主旋律C弦乐铺底延续→P09无缝衔接，音乐不断 |
| 音乐 | 主旋律C完整8小节。Piano + 大提琴拨弦（恢复心跳节奏，但这次比P02的心跳更稳定更坚定）+ 弦乐铺底（mp）。"不要回头"台词时：仅Piano独奏保留，其他乐器瞬间退出0.5秒→台词后全部回归 |
| 节奏 | BPM=92（比基准略快——在路上的行进感）。大提琴拨弦=稳定的前进节奏 |
| 音效 | [轮胎在山路上行驶]0-15秒（持续低频底噪）；[树荫婆娑/鸟鸣]背景层；[后视镜转动]9秒 |
| 情绪 | "他真的在路上了——虽然还是害怕，但轮子没有停" |
| 技法 | 大提琴拨弦从P02的"无奈心跳"变为P09的"前进心跳"——同一音色/节奏型，但情绪含义完全翻转（呼应手法）。"不要回头"台词周围的乐器退出=突出这句话是他给自己的指令 |

### P10 — 求救声（2:15 - 2:30）

| 层 | 内容 |
|---|---|
| 过渡 | P09主旋律C最后一个音不落回主音→悬挂→P10音乐渐薄 |
| 音乐 | 悬念动机D：单音钢琴，每3-4秒敲一个音，大量reverb。第一声喇叭后钢琴停止。第二声喇叭后完全寂静——只有山路环境音。切黑时无任何音乐 |
| 节奏 | BPM=66→无节奏。逐渐消解所有节奏感 |
| 音效 | [山路行驶底噪]0-2秒；[第一次嘀嘀嘀]2秒（小摩托喇叭，画外右侧，有山谷回声，-3dB）；[Momo急刹]3秒；[安静]3-6秒（只有极微弱风声）；[第二次嘀嘀嘀]6秒（稍近，仍画外右侧）；[Momo轮胎转向]12秒；[切黑——所有声音在0.3秒内fade out]13秒 |
| 情绪 | "有人在叫救命——而且很小、很慌张" |
| 技法 | 全集在声音上的"收束"——从P08的音乐高点逐步减薄到P10的近乎纯SFX。切黑时不用"当"一声的结尾感，而是所有声音同时消失→制造"故事被截断"的悬念感。留给Episode 02 |

## 混音备注

1. **BGM总音量**：-6dB（为对白和SFX让出空间）
2. **对白优先**：所有台词时间点BGM自动ducking至-12dB（sidechain或手动）

   - 高频（>6kHz）：弦乐空气感 + 风/树叶声
