## 0. 通用节点逻辑（本仓库映射）

```
锁图A（场景/地图/白天）
  → 锁图B（变体：手持模型 / 夜景 / 鸟瞰扩图 / 图钉浮现）
  → 视频：A+B（+可选人物/标注路径）按因果过渡
```

| LibTV 概念 | 本仓库做法 |
|------------|------------|
| 无限画布节点 | 项目 `screenplay/` + asset 挂载；或任意图床路径 |
| 文本 / 脚本节点 | `screenwriter-skill` → 再进 shotlist |
| 图片节点连线 | 参考图驱动：先定 A/B 静帧再写视频 prompt |
| 视频节点提示词 | Seedance / 可灵等；写清物理、路径、音效 |
| 音频节点 | `bgm-scoring` / 后期音效轨 |
| 扩图 / 多角度 / 打光 / 抠图 | 静帧预处理（见 §0.1）；scene-board 锁空间 |
| 俯视图**标注航线** | 在鸟瞰图上画路径，或文案写清路径点序（FPV 必备） |
| 提示词优化 / 运镜模板 | 用 CAMERA_LEXICON + COMPOSITION_CORE；人工改，不绑平台按钮 |
| 工作流打组复用 | 保存本文件配方 + 项目内复用 prompt 块 |
| 爆款拉片复刻 | `benchmark-breakdown`：拆结构不抄镜头 |
| 可选 GUI | [liblib.tv](https://www.liblib.tv/) — 非依赖；原则可在任意图+视频模型复现 |

**硬规则：** 图 A→图 B 必须写「**什么不变、什么变**」；视频只演过渡，禁止重设计建筑/人脸。

### 0.1 静帧预处理清单（出视频前）

按需选用，不绑某软件按钮名：

| 需求 | 做什么 |
|------|--------|
| 构图不够飞 | **扩图**再标 FPV 路径 |
| 日夜/多机位 | **多角度**或固定机位只改时间光 |
| 光不对 | **打光/重绘**只改光，锁建筑轮廓 |
| 手/模型扣不清 | **抠图**后再合成到锁死背景 |
| 路径要准 | **标注**飞行/运镜路线后再进视频节点 |

## 1. 万物生长 / 抛掷微缩落地

**效果：** 掌心微缩模型抛出 → 空中翻转 → 落回原位并「生长」成实景建筑群。

**静帧链**

1. 图A：地标/城市场景建立（或已有实拍）。  
2. 图B：同一背景，手掌心朝上托微缩模型，焦点在模型，背景尽量不变。

**视频要点**

```
承接图B首帧。手抛出微缩[地标]，空中翻转约3圈，精准落回掌心/原位置，
真实重力与惯性，落地轻震；随后模型尺度增大生长为完整建筑群（或切到图A实景），
匹配抛掷风声+落地轻响。背景透视与光照与静帧一致，禁换建筑造型。
```

适合：开场钩子、城市介绍转场。

---

## 2. 日夜延时

**效果：** 同一机位白天→黄昏→夜，天空/灯/水面同步变。

**静帧链**

1. 图A：白天风景（固定视角）。  
2. 图B：`保持视角、建筑轮廓与构图不变，仅时间变为夜晚；灯光与倒影合理出现`。

**视频要点**

```
日夜延时：天空渐变，建筑逐次亮灯，水面倒影同步，可含月亮升起；
机位与建筑轮廓全程锁定，禁止镜头游移换机位。匹配低频城市环境音。
```

适合：城市空镜、章节间隔。

---

## 3. FPV / 穿越机运镜

**效果：** 第一人称高速穿城、过桥、贴水面。

**静帧链**

1. 图A：风景或航拍建立。  
2. 图B：范围更广的鸟瞰（含对岸/路径所需建筑），注明时间光（如早上10点）。  
3. （推荐）在图B上标注飞行路线，或文案写清路径点序。

**视频要点** — 完整句式见 PROMPT_PATTERNS §6.15；最短版：

```
FPV穿越机视角，按路径：[起点]→[转折]→[终点]；低空高速，一镜到底，
轻微鱼眼与螺旋桨微振可选；匹配风噪。人物若出场须挂载身份板，禁换脸。
```

效果差时：先改**路径点是否写清**与**速度词**，再改风格形容词。

## 4. 图钉地图转场

**效果：** 拔图钉 → 建筑从地图浮现（撕纸感）→ 接到实拍。

**静帧链**

1. 图A：目的地地图截图。  
2. 图B：地图 + 图钉 + 图钉处 mini 地标。  
3. 图C：建筑从地图浮现，底部撕纸/纸质边缘。  
4. 图D：实拍建筑（目标落点）。

**视频要点**

```
一镜到底：图钉被取走 → 建筑从地图浮现（撕纸边缘）→ 过渡到实拍图D；
地图比例与图钉位置连续，禁跳切换地标。匹配纸张/轻金属轻响。
```

适合：旅游 Vlog 片头、目的地标题卡。
