# 《证词之外》资产生成提示词

用途：为当前版《证词之外》生成角色定妆、核心场地、关键道具参考图，服务于 [screenplay/zhengci-zhiwai-shot-list.md](screenplay/zhengci-zhiwai-shot-list.md) 与 act1-act3 视频 prompt。

生成原则：
1. 一次只生成一个明确主体，不把角色、场地、道具混在同一条里。
2. 全部按“超写实照片”思路写，禁止插画、禁止 3D、禁止游戏 CG。
3. 场地优先做干净稳定的基底图，后续镜头靠 prompt 补充动作，不在资产图里塞剧情。
4. 所有屏幕、门牌、标签文字都要少而准，宁可少，不要 UI 花哨。
5. 本套资产统一服务当前版本：三楼 307、消防楼梯、二十九楼设备间、露台白色手机、林晚语音合成系统。
