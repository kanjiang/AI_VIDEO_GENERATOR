# 短片场景制作五技（开场·转场·呼吸·双态锁·环境戏）

短剧 / 漫剧 / 微恐喜剧常用。**情绪与神秘感靠镜语，不靠一上来正脸亮相。**

联用：[VISUAL_LANGUAGE_SIX.md](VISUAL_LANGUAGE_SIX.md) · [PROJECT_LOCKS.md](PROJECT_LOCKS.md) · [PERFORMANCE_EIGHT_DIM](../seedance-2/references/PERFORMANCE_EIGHT_DIM.md) · [scene-board-skill](../../scene-board-skill/SKILL.md)

来源：[absorption/AIGC-短片场景五技吸收.md](absorption/AIGC-短片场景五技吸收.md)  
结构参照（只取节拍，不抄镜头）：外卖天师式「夜探公寓」微恐喜剧。

## 1. 开场：先时空，后人物；延迟露脸

| 做 | 不做 |
|----|------|
| 大全景/俯拍先交代**时间**（夜）与**空间**（老旧公寓） | 第一镜主角正脸特写自我介绍 |
| 环境阴森/生活质感做满再引入人物 | 空荡布景里突然跳人 |
| 背面跟拍、剪影、局部（头盔/手）保留神秘感 | 进门前就把人设演完 |

**Prompt 后缀：**  
`开场大全景俯拍锁定[夜晚·老旧公寓]，再逐步引入[角色]；优先背面/剪影/局部，延迟正脸亮相。`

对齐：VISUAL_LANGUAGE 悬念「反应/揭示分期」；COMPOSITION 负空间与纵深引导线。

---

## 2. 转场：环境特写当胶水

切场时**不要硬切下一张正脸**。用环境/动作插入桥：

- 空调外机、灯管闪、门缝光  
- 脚步、手套按门铃、外卖箱特写  
- 楼道声画先到，人后到  

**Prompt / 剪辑：**  
`转场不切正脸；经[空调外机/脚步/门把手]环境特写过渡，再接到下一人物状态。`

对齐：editing-techniques 动作连续；VISUAL_LANGUAGE §6 声音桥可选。

---

## 3. 对话呼吸感：停顿 + 开口前小动作

禁止「摆脸念词」式对白镜。

| 要素 | 写法 |
|------|------|
| 开口前 | 先笑一下 / 吸气 / 看一眼门外 / 整理外卖箱 |
| 句间 | 短停顿（决定是否说下一句） |
| 镜头 | 可微手持呼吸感，但表演停顿优先于运镜花活 |

对齐：PERFORMANCE_EIGHT_DIM 六要素；MICRO_BEATS；video-dialogue-punctuation。

**后缀：**  
`对白前加入可见小动作与停顿（先[笑/吸气/看一眼]再开口），禁生硬口型开场。`

---

## 4. 角色一致性：双形态必须双锁

凡人态 / 鬼态（或西装/便装、白天/夜人格）**= 两套身份板**，不是一句「变成鬼」。

写入 `character-lock.md`：

```markdown
## [角色] — 形态 A（人）
- 脸/发型/妆/瞳：
- 服装：
- 禁：与形态 B 混用五官

## [角色] — 形态 B（鬼/异态）
- 相对 A 的可变项（肤色/眼/齿/伤口）：
- 不变项（骨相、发型骨架、身高）：
- 切换触发（剧情条件）：
```

生成时：`@角色人=` / `@角色鬼=` 分挂；切换镜写清「从 A 参数过渡到 B，骨相不变」。

对齐：PROJECT_LOCKS · asset-canvas · seedance 挂载规则。

---

## 5. 环境交互：光与物随剧情变

环境不是贴图。随节拍改 **practical 光 / 道具状态**：

| 节拍 | 环境变化例 |
|------|------------|
| 礼貌上门 | 暖黄门灯、正常曝光 |
| 进屋不安 | 灯管频闪、色温偏冷、角落变暗 |
| 异态揭示 | 主光源骤暗或单侧惨白 |
| 制服/收束 | 光回稳或只留手电/符纸光 |

**后缀：**  
`环境随剧情变化：[灯光从暖黄渐变昏暗/灯管频闪]；禁全程静态不变背景。`

对齐：scene-lock 写「光状态机」；STYLE_BLOCK practicals-only。

---

## 6. 节拍骨架示例（外卖天师式 · 可改题材）

只作结构卡，禁止逐镜抄袭：

1. **开场** — 夜·旧公寓全景 → 骑手背面跟拍入楼道  
2. **上门** — 敲门；房客开门；短对白+呼吸；邀请进屋  
3. **屋内** — 环境异常（光/物）→ 房客露异态 → 冲突  
4. **转折** — 主角用专属手段制服；新订单打断（喜剧回调）  
5. **结尾** — 离开；标题卡定格  

自检：开场是否延迟露脸？转场是否经环境？对白前有无小动作？双态是否双挂载？灯光是否有状态变化？
