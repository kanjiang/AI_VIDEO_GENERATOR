# Episode 03 — 第三个他

### 制作前置（不进画面，仅供拍摄参考）

**接续 Ep2**：Ep2 结尾她在门外听见"焦虑症发作"这四个字。Ep3 白日她把观察日志摆到他面前直接戳这四个字。傍晚陆母助理临时叫她走（**陆母的调虎离山**——她要求沈星野远离本尊），本尊在偏楼 blackout，小小首登。

**人格出场边界（Ep3 硬锁）**：本集出现 **本尊 + 小小**。夜不出场。**1 次全切换**（本尊→小小）。

**小小首登的触发结构**：触发 A（陆宅偏楼停电走廊黑）+ 触发 B（被丢下信号：沈星野被陆母助理临时调开）+ 空间触发（本尊 blackout 后无意识 drift 到旧儿童房外——那是他童年被关的地方）。三重命中。

**发绳的来路**：Ep2 抽屉里放的其中一根。切换发生的时候，"某只手"（观众不知道是他自己还是他不知道的自己）路过抽屉取了出来挂上手腕。观众此时不需要解释——只需要看到，物件是"从他自己房间里"出来的，不是外部塞的。

**为什么陆宅有"旧儿童房"**：陆宅是陆家老宅，陆景深从小在这里长大。他童年被关的那间房还在偏楼保留着——陆母以"这是你成长的地方"为由不许拆。Ep24 兔子灯揭开时对上号。

**陆母仍未正面出场**：她的存在感通过管家 + 助理的调虎离山手法暗示。她在陆宅的控制线是**可见的但不露脸的**。她 Ep4 才正面首登（电话）。

### 渐入:

**内景 陆宅书房 — 午后**

（Hook 3 秒：观察表被推到他面前。）

沈星野把一张手写观察表放到桌上。

**沈星野**

昨天八点到九点四十，你没到早会，你不记得。昨天下午三点四十到四点二十，你在电梯里独处二十六分钟，回到办公室时你外套内袋多了一支不是你抽的烟，你也不记得。

（她一字一顿。）

**沈星野**

这不是四次"焦虑症发作"。这是**规律**。

陆景深看着那张表。

指节按向袖扣。

**陆景深**

焦虑症发作，一天可以有很多次。

**沈星野**

你二十年只有一个答案。

陆景深眼底动摇一秒。

（他刚要问"你想说什么"——他把这句话压回去。二十年的模板还在起作用，但今天他压得用力。）

**陆景深**

出去。

沈星野转身走。

走到门口。回头。

他没动。他正盯着那张表。

（她第一次看到他"念头没被立刻压下去"。）

**内景 陆宅侧楼过道 — 傍晚**

沈星野接到内线电话。

**管家**（V.O.）

沈医生，夫人助理有一份补充协议需要您签字。请到侧楼会客室。

（她一顿。她可以拒绝——拒绝她能留在本尊附近；答应她能看见陆母想干什么。）

（她选择去。）

她走进侧楼。

走廊灯忽然全灭。

黑。

一秒。

应急灯亮起来一半。

沈星野停住。

（她意识到这不是巧合。）

她转身，往回走。

**内景 陆宅偏楼 · 旧走廊 — 夜**

沈星野拐进主楼后侧的一条偏走廊。

应急光是白冷的。

走廊尽头，一扇旧木门虚掩着。门口——

成年身体的陆景深抱着一只枕头，坐在门槛内侧。

肩膀轻轻抖。

手腕上挂着一根发绳。

（不是本尊——袖扣松开又没系回去。）

（不是下午威胁她的那个他——没有火机，没有前倾的杀气。）

（第三个。）

沈星野在门口停住。

**沈星野**（很轻）

……你在这里做什么？

他抬起眼。

（那个眼神里没有陆总的克制。没有那个他的狠。只有一个孩子等人的期待。）

**小小**

姐姐？

沈星野的心跳漏一拍。

**小小**

灯灭了。姐姐……灯还会开吗？

沈星野走过去。慢。

**沈星野**

会。

她把手电亮起来。递给他。

**小小**

姐姐，你会走吗？

沈星野在他身边坐下。没碰他。

**沈星野**

不走。

她把门推开一半，让应急光进来。

好一会儿。

他慢慢靠过来一点。头搁在自己的枕头上。

**小小**（很小很小）

小小说了不该出来的。

沈星野的手一顿。

（他自报了名字。她第一次拿到"小小"这个词。她第一次意识到——不是两个他，是**三个**。）

**沈星野**

是谁告诉你不该出来？

**小小**

……

（他没答。他捏紧发绳。眼睛看向别处。）

沈星野没再问。

她把自己的外套披到他肩上。

镜头拉远。

走廊尽头，那扇旧木门虚掩着。门缝里能看见一角糊了旧墙纸的墙。

（观众此时不知道这是什么房间。）

切黑。

**字幕：三个他，只许你知道。**

### 分析

价值弧：**戳穿模板 → 被调虎离山 → 见到第三个他**。她这一集从"记录者"变成"接住的人"——首次听到"小小"名字后没有立刻追问"是谁告诉你的"，而是先兑现"我在"。她的方法论已经从"戳穿"进化成"先安顿再拆解"。集末在小小"是谁告诉你不该出来"上悬着不答——观众看到陆母语言留在小小体内的印记，Act 3 揭穿时对上号。

激活的 hamartia：
- **本尊**：他二十年模板"焦虑症发作"第一次被人当面质疑到眼底动摇。他刚要问"你想说什么"就压回去了——但这一次压得用力，观众能看出模板已经开始松动。
- **小小**：出现于三重触发（黑 + 被丢下 + 童年空间）。他遵循内在规则"不该出来"，但当被丢下的信号足够强时他不得不出来。他不敢答"是谁告诉你不该出来"——这是童年语言的封条。
- **沈星野**：她做了一个**可见的选择**——接到陆母助理的电话时她本可以拒绝，她选择去。这不是天真，是主动测试。她想知道陆母想干什么。这让她 Ep3 的"卷入"是自己选的，不是被拽的。

红旗 1：Switching Protocol 命中。
- 本尊→小小：三拍完整（呼吸放慢 + 走姿改变 + 手腕自动挂上发绳 → 抱枕头坐门槛内侧 → 软声"姐姐"）。三档视觉区分：**袖扣松开又没系回去 = 小小**；vs Ep1 医院走廊 **领口松开 + 火机 = 夜**；vs 本尊 **袖扣整齐 = 本尊**。
- 本集只 1 次全切换，用完额度。

红旗 2：**"是谁告诉你不该出来？"这句是 Ep3 埋的关键钩子。**观众此时不知道答案（陆母童年语言）。Ep34 小小顺着旧儿童房、兔子灯回想那晚"让他怕一次，才会学乖"时，Ep3 这句问话会以回响的形式重新出现——十字型剪辑对位。

红旗 3：**旧木门 + 旧墙纸**是本集的第二个钩子。观众此时看到"陆宅有一间保留着旧墙纸的房间"，但不知道是什么房间。Ep24（兔子灯揭开）+ Ep34（小小回忆）时对上号。

红旗 4：陆母**本集仍未正面出场**——只通过管家 + 助理传话。她的存在感通过"调虎离山"的手法暗示。她在陆宅的控制线是**可见的但不露脸的**，这一集完成了她 Ep1 投影疏漏之后的第二次系统性动作。她的正面首登要等 Ep4。

红旗 5：本集只有沈星野 + 陆景深（本尊/小小）+ 管家画外音。60–90 秒预算舒适。若要压缩：可先砍侧楼过道转场 2 秒；不建议砍"你会走吗？"→"不走。"——那是小小 arc 的核心节奏。

红旗 6：**沈星野"选择去侧楼"**是她 Ep3 的主动性可见点。她不是被拽入陆家，她是**看到局在摆开就要走进去**。这一秒把她从 Ep1-Ep2 的被动/记录者立起来成主动局中人。
