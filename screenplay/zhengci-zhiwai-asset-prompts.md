# 《证词之外》资产生成提示词

所有提示词用于生成 shotlist 所需的参考图片（角色定妆照、场地参考、道具特写）。
生成后请按文件名命名上传。

Nano Banana 使用原则：
1. 一次只生成一个明确主体，不要把角色、场地、道具混在同一条提示词里。
2. 优先单机位、单光源、单情绪，不要写成小说段落。
3. 双视图场地如果出图不稳定，就拆成两张分别生成。
4. 每条提示词都明确写“超写实照片、禁3D、禁插画、禁游戏CG”。
5. 文字内容要少而准，尤其是门牌、标签、纸条文字。
