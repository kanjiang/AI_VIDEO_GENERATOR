# 《南风解鬓柔》角色圣经

用途：统一锁定本剧所有角色的外貌、服装、性格、弧光、声音与关系，作为剧本、资产生成与视频提示词的唯一人物基准。任何分镜、提示词、配音都不得与本文件冲突。

时代背景：架空朝代「大靖」，江南苏州，晚秋。礼教森严、商贾兴盛、宗族当道。

核心母题：女子自救——不是被人拉出泥泞，而是自己踏碎荆棘、奔赴属于自己的天光。

资产对应：角色图见 `asserts/nanfeng-asset-prompts.md`，视频提示词见 `asserts/nanfeng-seedance2-video-prompts.md`。

## 一、沈清晏（女主）

- **对应资产**：`character_shen_qingyan_identity.png`（身份基准）、`character_shen_qingyan_street_state.png`（街巷自由态）、`character_shen_qingyan_night_resolve.png`（夜间决意态）
- **身份定位**：沈家主脉嫡女，17 岁。表面温顺守礼的深宅闺秀，内里是胸有丘壑的商事谋略者。全剧绝对主角与视角中心。
- **外貌锁定**：身形纤细但脊背始终挺直；肤色冷白；杏眼干净温润，眉眼清浅；未施浓妆；长发仅用一支哑光素银簪松松挽起。气质清冷克制，眼底常凝着怅然与执拗。
- **服装锁定**：素色青布襦裙、宽袖为主基调；街巷状态加浅色披帛；夜间为素衣。全程不戴华丽首饰，唯一固定配饰是素银簪。**禁**艳色、禁繁复珠翠、禁影楼古风。
- **关键道具**：袖中一枚打磨尖锐的素银簪——既是发饰，也是她藏在温顺之下的反抗象征（见 `prop_sharp_silver_hairpin.png`）。后期反击的核心是连夜誊写的账目证据与整改方案（见 `prop_account_evidence_plan.png`）。
- **性格内核**：清醒、隐忍、藏锋。读山河商事、市井杂记，借打理家事核账摸透沈家商事门道。不甘做笼中雀，但绝不鲁莽——步步谨慎、速去速回、以规矩为掩护。
- **人物弧光**：
  1. 困局（被困深宅、婚约将至、禁足）→
  2. 微光（书摊知己、短暂自由）→
  3. 绝境（构陷、逼婚、夺权、至亲牺牲）→
  4. 清醒（退让必死，唯有自救）→
  5. 反击（宗族厅堂当众列证、翻盘）→
  6. 立世（商业逆风破局、世俗偏见中自成格局）→
  7. 自由（不依附、自己做主）。
- **声音 / 台词气质**：大量 VO 内心独白，语气平稳、克制、清醒，句子有书卷感与逻辑性；正面对峙时声线清亮、字字铿锵但不嘶吼。**对白保持原文，不改写。**
- **表演要点**：情绪藏在微表情里——长睫轻颤、眼底凉意一闪、唇角平直、指节攥紧。**禁**崩溃大哭、瞪眼、表演过度。她的力量是「冷静」，不是「爆发」。
- **关系**：与晚翠是主仆兼唯一可信之人；与陆时安是平等知己（非依附、非救命依仗）；与父母是被牺牲的女儿；与旁支是被构陷夺权的对象。

## 二、陆时安（男主）

- **对应资产**：`character_lu_shian_identity.png`
- **身份定位**：城西书摊的清冷书生，看似闲散，实则事事知情、步步预判，身份神秘。是女主的精神知己与「懂得者」，而非拯救者。
- **外貌锁定**：身形挺拔清瘦；素色布衣；长发简单束起；面容干净沉静；目光坦荡通透，无猎奇无轻佻；笑意温和克制，只到眼底。周身书卷气极浓。
- **服装锁定**：素色布衣，简洁，**禁**华贵官服、禁锦绣纹饰、禁现代发型。
- **关键道具**：书摊上的山河杂记、市井策论、商事典籍等冷门书（见 `prop_rare_books_commerce_travel.png`）；夜间书摊的一盏孤灯与未翻的旧书（见 `prop_oil_lamp_old_book.png`）。
- **性格内核**：温润、通透、洞察。一眼看穿女主藏在规矩下的不甘与本心。从不越矩、不施恩、不定义她，只笃定她终能自救。
- **人物弧光**：相对静态的「定锚型」角色——从初遇懂她，到深夜遥望沈府笃定明日，到结局点破「你的自由与底气从来只属于你自己」。神秘感贯穿，身份留白。
- **声音 / 台词气质**：轻声温润、低稳、点到为止，常有禅意箴言式短句（「人心自在，便无牢笼」「规矩束得住身形，束不住本心」）。
- **表演要点**：克制的眼神戏，微动的眼底笑意，绝不油腻轻佻。**禁**偶像剧式贴近、禁暧昧肢体接触。
- **关系**：与女主平等并立、灵魂对等；与其他角色几乎无交集，强化其「局外洞察者」的神秘定位。

## 三、晚翠（女主侍女）

- **对应资产**：`character_wancui_identity.png`
- **身份定位**：沈清晏的贴身侍女，忠心耿耿，是女主在深宅中唯一可信、可用之人。
- **外貌锁定**：朴素灰绿色侍女服；利落发髻；面容干净自然；眼神焦灼但真诚。后期夜间状态：脸色惨白、额角冷汗、含泪。
- **服装锁定**：muted 灰绿侍女服、布带发髻，**禁**贵女华丽首饰、禁艳色。
- **关键道具**：白瓷热茶盏、青竹油纸伞（见 `prop_white_porcelain_tea_and_bamboo_umbrella.png`）。
- **性格内核**：忠诚、急性、护主。消息灵通（偷听到旁支阴谋），行动急促却始终守礼、压低声音。
- **人物弧光**：报信者与情绪放大器——多次以「慌张急报」推动剧情危机升级（旁支构陷、婚期提前、夺权真相），并在女主决意反击时坚定相随。
- **声音 / 台词气质**：压低声音、急促、句尾带喘；夜间报信时含泪急哭但仍不敢张扬。
- **表演要点**：焦急写在眉眼与呼吸上，但**禁**嚎啕大哭、禁大喊惊动全院。她的慌张要「压着」，与女主的冷静形成反差。
- **关系**：对女主绝对忠诚；是观众了解旁支阴谋的「信息通道」。

## 四、沈母

- **对应资产**：`character_shen_mother_identity.png`
- **身份定位**：沈家世家主母，礼教与家族颜面的执行者。前期是女主的压迫者，后期幡然醒悟、满怀愧疚。
- **外貌锁定**：深青褐色贵妇服；正式发髻；仅戴玉簪或木簪；眼神严厉；怒气克制而非疯癫。
- **性格内核**：重家族颜面甚于女儿幸福；震怒时一掌拍案，决绝禁足、撤仆、收书。但本性非纯恶——结局声音沙哑、满是愧疚地向女儿认错。
- **人物弧光**：高压问责（震怒呵斥、禁足判决）→ 认清旁支构陷、看错人心 → 愧疚醒悟、归还商事大权。
- **声音 / 台词气质**：前期狠厉、字句干脆重压（「不守妇道！」「半步不得出！」）；后期沙哑、低落、自责。
- **表演要点**：威严来自家族权威而非咆哮，拍桌是压迫的顶点；**禁**夸张反派妆、禁撒泼。
- **关系**：女主的母亲与前期主要施压者；与沈父共同决定女主命运。

## 五、沈父

- **对应资产**：`character_shen_father_identity.png`
- **身份定位**：沈家主脉家主，冷淡保守，为家族安稳牺牲女儿终身的决策者。
- **外貌锁定**：深色士绅长袍；身姿端正；表情稀少；情感疏离。
- **性格内核**：以家族秩序为先，情感克制到近乎冷漠。三日落印的婚约判决出自他口。后期与沈母一同醒悟，宣布退婚、彻查旁支、将商事交予女主。
- **人物弧光**：沉冷判决（婚约即刻落印）→ 醒悟悔过（退婚、还权）。
- **声音 / 台词气质**：低沉、沉冷、不带温情（「为保家族安稳，三日后，婚约即刻落印，再无转圜」）。
- **表演要点**：用「回避情感」表演，而非愤怒；说判决前有半拍停顿。**禁**官服铠甲、禁现代感。
- **关系**：女主的父亲；家族秩序的最终拍板者。

## 六、宗族族老与旁支族人（群像）

- **对应资产**：`character_clan_elders_and_branch_family.png`
- **身份定位**：宗族问责场的施压群体。族老代表礼教大义，旁支族人是构陷夺权的幕后推手。
- **外貌锁定**：族老——白发、深色族袍、面色严厉、可拄杖；旁支族人——立于一侧，暗自窃喜、贪婪算计。面孔各异，不可复制粘贴。
- **性格内核**：族老笃信礼教、句句诛心；旁支族人觊觎主脉商事多年，借礼教大义行谋私夺权之实。
- **人物弧光**：声势浩大施压（笃定女主认命）→ 被账目铁证当场击溃，神色剧变、哑口无言。
- **声音 / 台词气质**：族老厉声呵斥、步步紧逼（「即刻认罪，应允婚约」「速速认命」）。
- **表演要点**：群体压迫感，**禁**戏剧化反派脸、禁重复脸。旁支族人脸色由得意转惨白是关键反转表演。
- **关系**：女主反击的主要对手群；与旁支下人是同一阴谋的上下层。

## 七、旁支下人（下人甲 / 下人乙）

- **对应资产**：`character_shadow_servants.png`
- **身份定位**：旁支老爷指使的爪牙，负责夜间盯梢、散播流言、坐实「私会外男」的把柄。
- **外貌锁定**：粗布仆役服；下人甲瘦削尖眼、低声耳语；下人乙更壮、冷笑附和。夜巷中大半身隐于阴影，只露面部戾气。
- **性格内核**：阴鸷、贪婪、狡诈，执行构陷主脉、败坏名声、逼婚夺权的脏活。
- **人物弧光**：纯功能性反派——负责把「旁支阴谋」可视化曝光给观众（夜巷密谋戏）。
- **声音 / 台词气质**：压低声线、近距离、带夜巷回声；句尾常带阴冷冷笑。
- **表演要点**：阴影里的表演，**禁**站到亮处露全脸、禁现代黑帮感、禁过度狰狞。
- **关系**：受旁支老爷指使；与旁支族人同属夺权阴谋链条。

## 八、市井群像（伙计 / 摊贩 / 路人 / 商户）

- **对应资产**：`character_shop_staff_and_townspeople.png`
- **身份定位**：环境与舆论载体。前期是看衰、非议女主的悠悠众口，后期是被业绩折服、噤声敬畏的见证者。
- **外貌锁定**：江南晚秋市井服饰；商铺伙计、摊贩、路人、书生、船工、外地商户，面孔多样不重复。
- **代表台词气质**：
  - 路人甲（看衰）：「就是那个忤逆失德的沈家女，还想做生意立世？迟早倒闭！」
  - 路人乙（轻蔑）：「小小年纪、深闺养尊，懂什么市井商事？……必定惨败翻车！」
  - 伙计（丧气）：「姑娘，全城商户都在排挤我们，货源断了，这生意做不下去了。」
- **人物弧光**：非议嘲讽 → 被沈家商铺逆风翻盘的口碑与业绩堵住众口 → 敬畏噤声。
- **表演要点**：自然市井活动，**禁**现代配饰、禁重复脸、禁空背景。
- **关系**：世俗偏见的具象化，是女主「以口碑破围剿」的对照面。

## 九、人物关系总览

- **沈清晏 ↔ 陆时安**：平等知己，灵魂对等，不依附、不暧昧、不救赎。
- **沈清晏 ↔ 晚翠**：主仆 + 唯一信任 + 信息通道。
- **沈清晏 ↔ 沈父母**：被礼教与家族颜面牺牲的女儿；父母后期醒悟悔过。
- **沈清晏 ↔ 族老/旁支**：被构陷夺权的对象；最终以铁证反杀。
- **旁支族人 → 旁支下人**：阴谋的指使与执行关系。
- **市井群像**：环境与舆论的对照群，从看衰到敬畏。
