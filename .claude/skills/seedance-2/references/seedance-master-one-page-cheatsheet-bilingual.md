# Seedance One-Page Cheat Sheet (ZH + EN)

用途 / Purpose: 每条镜头开写前先填这张卡，30 秒内完成可执行 prompt 骨架。 / Fill this card before drafting each shot to get an executable prompt skeleton within 30 seconds.

---

## 1) 六行口令 / Six-Line Command

```text
主情绪 Main emotion: {one}；次级波动 Secondary fluctuation: {one}
面部三拆 Face decomposition: 嘴角 mouth {...}｜眼部 eyes {...}｜面部肌肉 face-muscle {...}
动作载体 Action carriers: 手部 hand {...}｜姿态 posture {...}｜视线 gaze {A->B->lock}
主运镜 Primary camera intent: {push/pull/rear-follow/side-follow/front-follow/orbit/dolly-zoom/tilt-up}
速度策略 Speed strategy: {slow push-in/fast push-in}；主体 Subject: {person/object/emotion core}
负面约束 Negative constraints: no subjectless drift, no arbitrary speed shifts, no repeated same-amplitude actions
```

---

## 2) 情绪速选 / Emotion Quick Pick (10)

- 开心 Happy: 嘴角轻上扬，眼神柔和，肩线放松。 / Slight corner lift, softened gaze, relaxed shoulder line.
- 被误会 Misunderstood: 嘴角轻压后回平，眼眶微红，先回避再对视。 / Mouth corners dip then neutral, slight eye redness, avoid then return to eye contact.
- 紧张 Tense: 嘴角轻抿，眨眼略增，拇指蹭指节一次。 / Thin lip press, slightly higher blink rate, thumb rubs knuckle once.
- 生气（克制）Controlled anger: 嘴角边缘绷紧，目光锁定，手掌收紧不挥动。 / Tense mouth edges, locked gaze, tightened palm without swinging.
- 惊讶 Surprise: 嘴角短张，眼裂放大后回稳，手指短暂停住。 / Brief mouth open, eyes widen then settle, fingers pause.
- 害怕（克制）Restrained fear: 嘴角绷紧，重心后移半步，先扫出口再回看风险源。 / Tight mouth line, half-step weight shift back, scan exit then threat source.
- 悲伤（克制）Restrained sadness: 嘴角下压后平直，呼吸变浅，先看地面再抬眼。 / Corners dip then neutral, shallow breath, gaze down then up.
- 厌恶（克制）Restrained disgust: 上唇轻提，鼻翼轻收，目光短停即移开。 / Slight upper-lip lift, nostrils tighten, brief look then pull away.
- 惊喜（正向）Pleasant surprise: 嘴角先张后扬，眼神变亮，肩线放松。 / Mouth opens then lifts, eyes brighten, shoulder line relaxes.
- 困惑 Confusion: 嘴角单侧微压，眉心轻皱，视线 A->B->A 往返。 / One-side mouth press, soft brow pinch, gaze alternates A->B->A.

---

## 3) 运镜速选 / Camera Quick Pick

- 推镜头 Push-in: 向主体靠近，做聚焦与压迫。 / Move toward subject for focus and pressure.
- 拉镜头 Pull-out: 从近到远，揭示环境信息。 / Near-to-wide reveal of environment context.
- 后跟 Rear follow: 增强代入感。 / Increase immersion.
- 侧跟 Side follow: 交代人物与环境关系。 / Show character-environment relation.
- 前跟 Front follow: 突出表情与动作。 / Emphasize expression and action.
- 360 环绕 Orbit: 强化主角中心性。 / Reinforce protagonist centrality.
- 希区柯克变焦 Dolly zoom: 强调心理冲击。 / Emphasize psychological shock.
- 上摇 Tilt-up: 增强气势与压迫。 / Build scale and pressure from low to high.

---

## 4) 速度口令 / Speed Command

- 慢推进 Slow push-in: 克制、压抑、迟滞。 / Restrained, suppressed, delayed tension.
- 快推进 Fast push-in: 情绪拐点瞬时爆发（主体必须明确）。 / Instant impact at emotional turning point (subject must be explicit).

---

## 5) 景别口令 / Shot-Scale Command

- 85mm 近景 / 85mm close: 微表情优先，运镜轻推稳住。 / Prioritize micro-expression; use stable gentle push.
- 50mm 中近景 / 50mm medium close: 手部+姿态+轻跟拍。 / Hand action + posture + light follow.
- 35mm 远景 / 35mm wide: 姿态与空间关系优先，常用拉镜或侧跟。 / Prioritize posture and spatial relation; prefer pull-out or side follow.

---

## 6) 出片前 6 项检查 / Six Checks Before Render

- [ ] 是否写了嘴角/眼部/面部三拆分
- [ ] 是否有手部/姿态/视线载体
- [ ] 是否只有一个主运镜意图
- [ ] 是否写明速度策略
- [ ] 快推进是否有明确主体
- [ ] 是否有负面约束（防漂移、防乱变速、防过火）

- [ ] Mouth/eye/face decomposition explicit
- [ ] Hand/posture/gaze carriers present
- [ ] Single primary camera intent
- [ ] Speed strategy explicit
- [ ] Fast push-in has clear subject
- [ ] Negative constraints included (anti-drift, anti-chaos, anti-overacting)
