# 场景板提示词 — 《果酱岛控制中心》

场景板 = 空间 / 灯光 / 材质 / 通行路径的**锁**。五个常设场景撑十集，加一个季终特集场景和一张色卡。

---

## 共通规范

### 烘焙规则（本项目特有，务必先读）

本项目有几个角色是**永久固定装置**，它们不烘焙进场景板的话，场景板就是一个带洞的台面，没法当背景底板用。所以分两类处理：

| 烘焙进场景板 | 理由 |
|---|---|
| **菠萝火山** | 它就是环境本身，也是全片唯一暖光源 |
| **瓜叔**（嵌在控制台） | 永不移动、永不离开，是控制台的一部分 |
| **葡萄串**（嵌在台面） | 同上，它就是台面上那排按钮 |
| **三兄弟**（钉在灯杆） | 永不移动，是路口的固定装置 |

| 留空、只标站位 | 理由 |
|---|---|
| 啵啵、柠七 | 可移动主角，由 Seedance 视频阶段合成 |
| 蕉蕉 | 会出航，码头只画空泊位 |
| 老哈、芒芒 | 会跑，路口只画空车道 |

⚠️ 烘焙固定装置时，**必须把对应的身份板作为参考图一起喂进去**（`guashu-identity-board.png`、`grape-console-identity-board.png`、`traffic-brothers-identity-board.png`、`volcano-identity-board.png`），否则会和身份板漂移。

### 光照签名（全片最重要的一条视觉锁）

**冷天光 + 暖火山光的二元对立。**

- 天光是**冷的**——偏蓝白的高空散射，色温约 7000K
- 火山是全岛**唯一的暖光源**——琥珀金，色温约 2700K，从缝隙和火山口透出

这条对立带来一个非常有用的效果：角色的暖色（番茄红、柠檬黄、芒果橙）在冷天光下会被压住，**只有靠近火山、或火山打嗝的那一瞬间才被真正点亮**。所以「火山打嗝」不只是剧情事件，它是全片的打光事件。

⚠️ 不要给任何场景加影棚柔光箱、抽象补光或无来源的暖光。所有光必须来自：天空、火山缝隙、火山口、果酱自身的微弱透光、控制台屏幕、红绿灯果肉透光。

### 尺度基准

世界里没有人类。**尺度基准单位 = 1 个啵啵高。**所有台面、门、栏杆、路缘都按啵啵校准。

关键设定：**控制台台面高度约 1.2 个啵啵高**——他必须跳起来才能按到最上面那排葡萄。这既是笑点，也解释了为什么他总是压到、撞到、碰到别的东西。

### 共通视觉锚

- 整体风格 = Pixar 级 3D 糖果色动画环境 + 水果实体质感
- **质感签名（每张必须命中）** = 果蜡高光、水珠、半透明果肉透光、糖浆拉丝
- 果酱材质 = 琥珀金，浓稠，有重量、有流动感、有拉丝，冷却后转为半透明硬糖
- ⚠️ 喷发物永远是琥珀金果酱，**绝不是红色岩浆、不是火、不是烟**

### 共通负面约束

不要人类，不要可移动主角（啵啵 / 柠七 / 蕉蕉 / 老哈 / 芒芒），不要广告海报构图，不要影棚柔光箱或无来源补光，不要红色岩浆 / 火焰 / 浓烟，不要塑料质感，不要过度装饰，不要打光漂移，不要鱼眼变形。

## 场景 1 · 控制中心内部（最高优先，每集主场景）

**控制中心内部场景图提示：**

这张图的核心目标是锁定控制中心的空间关系、控制台上瓜叔与葡萄串的固定位置、观景窗与火山的视线关系、以及冷天光与暖火山光在室内的分区，让全季所有控制中心镜头（占全片约六成）都建立在同一个空间逻辑上。

[空间结构]：一间圆形的地下控制室，天花板是穹顶，墙体由压实的火山岩层与嵌入的果酱输送管道构成。

- **画面中景正中是控制台**——一张宽大的弧形台面（高度约 1.2 个啵啵高），台面材质是打磨过的浅色石材。
- 台面正中嵌着**瓜叔**：一整颗西瓜的前半球嵌入台面，深绿瓜皮配墨绿虎纹，正面被切开一个圆形切面作为屏幕，鲜红半透明瓜肉上以黑色西瓜籽排列出数据。
- 台面前缘嵌着**葡萄串**：一串深紫带白霜的葡萄，每颗只露上半球，像一排按钮，有清晰的主茎分枝结构。串子最末端垂着**一颗干瘪发黑、完全没有五官的葡萄**，旁边贴一张褪色卷边的手写标签。
- **画面后方是一整面弧形观景窗**（占后墙约七成），玻璃厚重、边框是黄铜色金属。**透过窗能看到菠萝火山的山体下部与部分鳞片格**——这是全片最重要的一条构图关系：威胁永远在画面里。
- 画面左侧墙边是柠七的值班位：一张小台子，上面立着一块写满流程条目的板子的架子（板子本体由视频阶段合成，此处只画空架）。
- 画面右侧墙面是密集的果酱输送管道，管道内部有琥珀金果酱缓慢流动，**管壁半透明，能看见果酱的流动**（这是室内的第二暖光源）。
- 地面是深色哑光石材，有历年果酱溢出留下的琥珀色干涸痕迹（浅浅的、洗不掉的层叠印子）。

[材质]：台面石材哑光带细颗粒；瓜叔瓜皮蜡质高光；葡萄有白霜哑光覆层配单点镜面高光；观景窗玻璃厚而通透，边缘有轻微绿色；管道半透明，管内果酱浓稠拉丝；墙体火山岩粗糙哑光；地面果酱痕迹是半透明的琥珀色薄层。

[灯光和氛围]：这是本片光照签名最集中的一张图。

- **冷侧**：观景窗透进来的冷蓝白天光（约 7000K），照亮控制室后半部与台面后缘，在地面投下窗框的长影
- **暖侧**：右侧管道内流动果酱透出的琥珀金光（约 2700K），照亮控制室右半部与管道附近的地面
- **中央**：瓜叔瓜肉屏幕的微弱红光，只照亮台面正中一小片区域
- 整体氛围：一间又旧又暖又有点乱的值班室，不是高科技指挥中心。⚠️ 不要冷蓝色科幻感，不要全息投影，不要 LED 灯带
- ⚠️ 默认无啵啵、无柠七；他们的站位由后续视频合成

[摄影机兼容性]：稳定水平地平线，透视焦点落在控制台与观景窗之间。构图保留前景约 30% 地面作为角色进场路径；台面前方留出足够的双人 blocking 空间（啵啵在台前、柠七在台侧的正反打关系必须成立）。焦段等效 35mm–50mm。景深：台面最锐，观景窗外的火山略柔化但轮廓清晰可辨。

[标注 / 关键锚点]：
- 控制台弧形台面 = 空间锚点 1
- 瓜叔（台面正中）= 固定装置，已烘焙
- 葡萄串（台面前缘）= 固定装置，已烘焙，**末端黑葡萄位置必须清晰可见**
- 观景窗（后墙）= 火山视线关系锚点，全季不变
- 地面浅色标记：台前一处标注啵啵常驻站位，台左一处标注柠七值班站位（只画标记，不画角色）
- 右侧管道 = 室内暖光来源

[最终连续性要求]：这张图是全季约六成镜头的空间底板。不论镜头是台面近景、双人正反打、俯视全景还是从观景窗方向反打，**控制台弧度、瓜叔与葡萄串在台面上的相对位置、观景窗方位、管道在右侧**这四条必须永远一致。灾难时的果酱倒灌、糖化、漂浮等 VFX 由视频阶段添加，本图只画干净的常态。

**负面约束：** 不要人类，不要啵啵 / 柠七，不要高科技指挥中心感，不要 LED 灯带 / 全息投影 / 冷蓝科幻光，不要影棚补光，不要红色岩浆，不要窗外出现完整的火山全貌（只看到山体下部，保持压迫感）。

## 场景 2 · 菠萝火山口

**菠萝火山口场景图提示：**

创建一张电影化的 16:9 场景设定图。

这张图的核心目标是锁定火山口的空间形态、冠叶环绕的结构、果酱井的深度关系、管道接入位置，以及火山口作为全片唯一强暖光源的照明逻辑，让所有登顶救援镜头建立在同一空间上。

[空间结构]：菠萝火山的顶部，处于**巨大绿色冠叶的环抱中央**。

- 冠叶从四周向内向上包围，叶片厚实、边缘带锯齿、表面有蜡质高光；叶片高度约 4 个啵啵高，形成一圈天然围栏
- 冠叶环抱的正中是**火山口**——一个近圆形的深井，井口直径约 12 个啵啵宽，井壁是层层收窄的六边形鳞片格，越往下鳞片格越暗
- 井底深处是**缓慢起伏的琥珀金果酱液面**，浓稠、表面有大气泡缓慢鼓起破裂，能看到糖浆拉丝
- 井口边缘一圈是可站立的**鳞片格平台**（略微倾斜、有果酱溢出后干涸的琥珀硬壳，踩上去会脆响）
- 画面右前方，两根粗大的**果酱输送管道**从井口边缘接入，管口探进井内一段；管道半透明，能看见果酱被抽走时的流动
- 画面左侧冠叶之间留出一个**缺口**，是从山下爬上来的路径入口（地面被踩出一条痕迹）
- 远景越过冠叶可以看到极小的一角岛屿与海面，提供高度感

[材质]：冠叶蜡质高光、叶脉清晰、边缘锯齿；鳞片格哑光带蜡感，沟缝深处暗；井壁鳞片格上挂着未流尽的果酱，拉出细长的糖丝；井口平台的干涸硬糖壳半透明、有裂纹；管道半透明带内部流动感。

[灯光和氛围]：

- **主光源 = 火山口本身**。井底果酱液面自发出强烈的琥珀金光（约 2700K），**自下向上打亮**整个场景——冠叶的内侧被照成暖金色，叶脉逆光透亮，井口平台上的每一道裂纹都被拉出长长的向外投影。这是全片唯一一次强暖光主导的白天场景
- **补光 = 冷天光**。头顶开阔天空的冷蓝白散射（约 7000K），只照亮冠叶的外侧与顶面。**冠叶的内暖外冷是本图的关键**
- 空气中有轻微的热浪扰动与糖香雾气（细小悬浮颗粒），越靠近井口越明显
- 整体氛围：又危险又诱人、又壮观又甜。不是地狱、不是工业锅炉
- ⚠️ 默认无角色

[摄影机兼容性]：稳定水平地平线（或极轻微俯角），透视焦点落在火山口井心。构图让井口占据画面中下部约四成，冠叶占据上部与两侧边框，形成天然的**框式构图**。井口边缘平台必须留出足够的角色 blocking 空间（要能站人、能奔跑、能被顶飞）。焦段等效 28mm–35mm 以强调空间深度与体量。景深：井口边缘最锐，井底果酱液面略柔化以强化深度。

[标注 / 关键锚点]：
- 火山口井心 = 空间锚点 1，也是唯一主光源
- 井口边缘鳞片格平台 = 角色主要活动区
- 左侧冠叶缺口 = 唯一上下山路径（所有角色从这里进出）
- 右前方管道接入口 = 果酱被抽走的位置
- 井底果酱液面 = 深度与危险感的底

[最终连续性要求]：这张图是所有登顶镜头的空间底板。**冠叶的环抱关系、井口的圆形轮廓、左侧路径缺口、右前方管道位置**四条必须一致。火山蓄积时的山体膨胀、鳞片格撑开、缝隙透光增强等形变由视频阶段处理，本图画的是常态（山体未膨胀、鳞片格闭合）。

**负面约束：** 不要人类，不要角色，不要红色岩浆 / 明火 / 浓烟 / 火星，不要地狱或工业锅炉氛围，不要影棚补光，不要冠叶稀疏（必须密实成环），不要井底见底（必须有深度）。

## 场景 3 · 果酱岛全景 · 清晨态

**果酱岛清晨全景场景图提示：**

创建一张电影化的 16:9 场景设定图。

这张图的核心目标是锁定整座岛的地理关系——火山居中、环岛公路成环、码头在西、路口在东、管道网辐射——让每集的固定开场镜头和所有建立镜头都用同一张地图。

[空间结构]：一座小岛的大远景，略带俯角的空中视角（约 25° 俯角）。

- **画面正中是菠萝火山**，占画面高度约六成。规则的六边形鳞片格阵列清晰可辨，顶部巨大绿色冠叶张开。此刻山体处于**常态**（未膨胀、鳞片格闭合、沟缝暗）
- 火山山脚向四周辐射出**半透明的果酱输送管道网**，像树根一样铺向全岛，管内琥珀金果酱缓缓流动
- 一条**环岛公路**绕岛一周，是完整闭合的环，路面深灰哑光
- **画面左侧（西）是果酱码头**，一道石质栈桥伸进海里，栈桥旁有一个空泊位
- **画面右侧（东）是红绿灯路口**，环岛公路在这里有一个交叉，能看到一根极小的灯柱剪影
- 岛上散布着低矮圆润的水果居民建筑（宽门、低顶、糖果色墙面），沿环岛公路两侧分布
- 围绕小岛的是**果酱海面**——琥珀金、浓稠、波纹缓慢厚重，不是水的质感。海面在远处渐渐变淡
- 天空开阔，有几片高而薄的冷调云

[材质]：火山鳞片格哑光蜡感；管道半透明带内部流动；公路深灰哑光；建筑墙面糖果色哑光；果酱海面浓稠、有厚重的缓慢波纹与糖浆光泽；云层薄而冷。

[灯光和氛围]：

- **主光 = 清晨冷天光**（约 7000K），从画面左上方低角度斜射，色调偏蓝白，在岛上投下长而柔的影子。整座岛在这道冷光下偏冷、偏静
- **唯一暖源 = 管道网**。半透明管道内的果酱透出细细的琥珀金光脉络，像血管一样在冷调的岛上发亮。⚠️ 这是本图最重要的效果：**冷岛 + 暖脉络**
- 火山此刻不发光（常态，沟缝暗）
- 整体氛围：安静、清爽、日常感、一切正常。这是每集的"灾难前"基准态
- ⚠️ 默认无任何角色

[摄影机兼容性]：稳定水平地平线，约 25° 俯角，透视焦点落在火山。构图让火山居于画面正中偏上，环岛公路的完整环形关系清晰可读。焦段等效 24mm–35mm。景深全景清晰，远处海面略柔化。

[标注 / 关键锚点]：
- 火山（正中）= 地理锚点 1，全岛方位的基准
- 环岛公路（闭合环）= 交通逻辑锚点
- 西侧码头栈桥 = 蕉蕉泊位方位
- 东侧路口 = 三兄弟灯柱方位
- 管道网 = 唯一暖光脉络

[最终连续性要求]：这张图与「喷发态」是同一视角、同一构图的两版，**只有光照与火山状态不同，地理关系必须完全一致**。全季所有建立镜头都从这两张里选。方位关系（火山中、码头西、路口东）一旦定下全季不许改。

**负面约束：** 不要人类，不要角色，不要蓝色海水（海是琥珀金果酱），不要红色岩浆，不要火山发光（清晨态火山是暗的），不要黄昏 / 夜晚 / 暴雨，不要密集城市感建筑。

## 场景 4 · 果酱岛全景 · 喷发态

**果酱岛喷发全景场景图提示：**

创建一张电影化的 16:9 场景设定图。

⚠️ **本图必须与「清晨态」使用完全相同的视角、俯角、构图和地理关系。**唯一的区别是火山状态与全岛光照。建议直接以清晨态成图作为参考图输入，只改光与状态。

[空间结构]：与清晨态完全一致——火山正中、管道网辐射、环岛公路成环、码头在西、路口在东、果酱海面环绕。

**状态差异：**
