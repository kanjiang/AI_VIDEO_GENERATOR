# 视听语言六维（开场 / 无对白叙事）

**拉片看什么：** 不是剧情复述，而是导演如何用镜头**替代台词**——悬念、运镜、构图、情绪、高潮、转场。

经典参照（只取结构，不抄镜头）：《玩具总动员3》开场幻想戏。  
联用：[DIRECTOR_BEATS.md](DIRECTOR_BEATS.md) · [COMPOSITION_CORE.md](COMPOSITION_CORE.md) · [CAMERA_EMOTION.md](CAMERA_EMOTION.md) · [EMOTION_ARC_EDIT.md](../../post-production/reference/EMOTION_ARC_EDIT.md) · [editing-techniques.md](../../post-production/reference/editing-techniques.md)

来源：[absorption/AIGC-玩具总动员3开场拉片吸收.md](absorption/AIGC-玩具总动员3开场拉片吸收.md)

## 0. 总原则

| 原则 | 写法含义 |
|------|----------|
| **情绪先于叙事** | 先定观众感受，再排信息；画面本身要会「说话」 |
| **观众比角色晚半步** | 悬念≠藏死信息，而是晚半拍给答案 |
| **多箭齐发才有高潮** | 动作 + 运镜 + 声音叠满；再靠**停顿**把能量砸出去 |
| **单镜技巧 ≤2** | 与 COMPOSITION_CORE 一致，勿堆满 |

写 Seedance 前：六维里本场只用 **2–3 维** 做主武器，其余作辅。

---

## 1. 悬念：反应 → 等待 → 三次释放

| 步 | 做法 | Prompt / 分镜要点 |
|----|------|-------------------|
| 1 反应先行 | 先拍角色惊讶/指向，**不拍**刺激源 | `先近景[角色]震惊反应，刺激源暂不出画` |
| 2 轴线空镜 | 顺指尖方向切大面积天空/空景留白 | `顺手指轴线切空镜，大面积负空间，等待感`（COMPOSITION 负空间） |
| 3 信息×3 | 光点 → 轮廓 → 完整登场 | `信息分三次释放：①[光点] ②[轮廓] ③[完整主体登场]，逐步放大期待` |

自检：若第一镜就全貌英雄登场 → 悬念死了，改回反应先行。短片开场「先环境、延迟正脸」另见 [SHORTFORM_SCENE_CRAFT.md](SHORTFORM_SCENE_CRAFT.md) §1。

---

## 2. 运镜：纵深冲击 + 能量惯性

| 技巧 | 何时用 | 要点 |
|------|--------|------|
| **纵深优先** | 英雄冲镜、坠落砸入 | 冲向/远离镜头 > 纯横向扫；可叠激光/粒子等方向性特效 |
| **低机位加速** | 砸落、冲锋 | 机位越低，纵深幅度与速度感越强 |
| **维持能量** | 对峙、僵持 | 慢推 / 慢拉 / 远景横移皆可，关键是**运动惯性不断**；静止对峙可单靠慢推升温 |

词库：[CAMERA_LEXICON](CAMERA_LEXICON.md) 推近压迫、跟镜；CAMERA_EMOTION 前推加温。

---

## 3. 构图：强弱反差不用台词

| 技巧 | 画面 | 情绪 |
|------|------|------|
| **胯下/靴底框架** | 前景强势局部（靴、膝、枪）巨大；远景弱势方渺小 | 权力碾压（西部/黑帮/动作通用） |
| **英雄三角** | 三人稳定三角，顶点=核心领袖 | 小队登场、秩序感 |
| **背景分区叙事** | 英雄侧开阔；反派侧封闭山岩/墙 | 正邪对立，无需旁白 |

映射：COMPOSITION_CORE 框中框 / 黄金三角 / 负空间；词库 FA 仰俯、TP 三角、SE 框架。

---

## 4. 情绪：先加温，再讲事

1. 持续**慢前推** = 情绪加温器（对峙可几乎无表演，只推镜头）。  
2. 背景对比（开阔 vs 封闭）本身就是情绪轨。  
3. 与表演层分工：八维/微表情管脸；**本维管镜头与空间是否先把气场做满**。

---

## 5. 高潮铺垫：叠加 → 停顿 → 阴影先行

| 手法 | 做法 |
|------|------|
| **多箭齐发** | 同一拍叠：动作冲击 + 运镜加速 + 音效/配乐抬升 |
| **停顿造高潮** | 最带劲瞬间：**动作、吼声、音乐一并抽掉** →「没有停顿就没有高潮」；再接 Boss/反转。对齐 [EMOTION_ARC_EDIT](../../post-production/reference/EMOTION_ARC_EDIT.md) 静默段 |
| **阴影先行** | Boss 真身前先给阴影/压迫轮廓；**压迫感先到，解释后到** |

---

## 6. 虚实 / 时空转场

| 手法 | 做法 |
|------|------|
| **匹配前推速度** | 内外景/色调可跳变，但推镜头速度曲线一致 → 观感仍顺 |
| **动作连续剪** | 按键→开盖→投掷等因果动作串场景（动作匹配剪辑） |
| **声音桥梁** | 激昂配乐骤停，用笑声/一声门响/一记呼吸接「幻想→现实」；声先于画或声画同切 |

剪辑细则：`editing-techniques.md`；配乐 drop：`bgm-scoring`。

## 7. 开场戏检查清单（可打印）

- [ ] 有没有「反应先于揭示」？  
- [ ] 关键是一次倒完还是分 2–3 拍？  
- [ ] 冲击镜是否用了纵深或低机位？  
- [ ] 强弱是否靠构图（框/大小/背景）而不是台词解释？  
- [ ] 高潮前有没有静默停顿或阴影先行？  
- [ ] 时空切换有没有匹配速度 / 动作链 / 声音桥至少一种？
