# 《证词之外》Seedance 参考图对照表（当前版）

用途：按镜号快速确认生成时应该把哪些角色、环境、道具以 @image 形式写进提示词正文。

使用规则：

1. @image1、@image2 的编号跟随你本次上传顺序变化。
2. 括号里的别名保持稳定，例如 LinShen、TerraceWide、SmartSpeakerUnlocked。
3. 角色放前面，场景放后面，道具最后；如果镜头是纯场景或纯道具，不要硬塞角色图。
4. 本表只使用当前资产体系，不再沿用旧版别名。
5. 未列出的镜头，优先复用同场次相邻镜头的绑定组合，不要为了保险把所有图都塞进去。

## 最稳的 Seedance 写法

如果一个镜头里既有人物又有场景又有道具，推荐顺序是：

1. 角色
2. 场景
3. 道具

示例：

```text
@image1 (LinShen) — 参考 lin_shen.png。
@image2 (TerraceWide) — 参考 terrace_wide.png。
@image3 (WhitePhoneCall) — 参考 white_phone_call.png。
```

不要为了保险把所有图都塞进去。镜头只锁定真正需要稳定的角色、环境和关键道具。
