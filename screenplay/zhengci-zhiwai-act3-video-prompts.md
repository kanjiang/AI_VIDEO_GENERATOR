## Prompt 01 [Multi-shot · 露台危险空间 + 白色手机诱导]

@image1 (TerraceWide) — 参考夜晚高层露台、护栏、维修箱与白色手机的整体关系。
@image2 (WhitePhoneCall) — 参考白色手机外放通话状态。
@image3 (ZhouYan) — 参考周妍角色。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务是先把露台的危险空间讲清，再让白色手机成为唯一能吸走周妍的声源。

【镜头1】
机位：35mm 露台广角，固定。持续约5秒。
动作：夜风、高空、护栏、维修箱和放在维修箱上的白色手机同时入画。护栏连接处只能显得老化危险，不能明显像被人为破坏。

【镜头2】
机位：85mm 手机近景，固定。持续约5秒。
动作：白色手机停留在通话状态，屏幕极暗或近乎黑屏，只从扬声器里传出林晚声音：“我在下面一层平台。” 声源必须真实贴在手机本体上。

【镜头3】
机位：50mm 周妍中景，固定。持续约5秒。
动作：周妍听到声音后立刻快步逼近栏杆边，肩背前倾，呼吸乱掉，视线只往栏杆外下方找，不再回头看林深。不要拍成奔跑或夸张扑冲。

风格：8K IMAX，超写实，禁3D渲染，禁游戏引擎，禁游戏CG，禁字幕，禁音乐。灯光只允许城市夜光和极弱安全灯反射。60fps，180度快门，物理镜头质感。

## Prompt 02 [Multi-shot · 伪保护 + 铁门合拢 + 最后的希望]

@image1 (LinShen) — 参考 lin_shen.png。
@image2 (ZhouYan) — 参考周妍角色。
@image3 (TerraceWide) — 参考露台栏杆与铁门关系。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务是让林深最后一次维持“好人”姿态，同时把退路和希望一起封死。

【镜头1】
机位：50mm 双人近景，固定。持续约5秒。
动作：周妍刚靠近栏杆，林深立刻攥住她的小臂，动作必须像本能救人。他低声说：“别再往外探了，危险。” 但那只手始终没把她真正往回带离栏杆。

【镜头2】
机位：85mm 铁门近景，固定。持续约4秒。
动作：露台铁门在两人身后沉闷合拢，门响克制，但必须足够像退路被客观切断。

【镜头3】
机位：50mm 双人中景，固定。持续约6秒。
动作：周妍急问：“她没死，对不对？你告诉我！” 她的眼睛一直往栏杆外下方找。林深不回答，只看着她，让这句问话自己掉下去。

风格：8K IMAX，超写实，禁3D，禁游戏CG，禁字幕，禁音乐。灯光只允许露台实景夜光。人物表演禁止失控尖叫，只要把希望压到最后一秒。

## Prompt 03 [Multi-shot · 最后一声诱导 + 护栏异响 + 坠落]

@image1 (WhitePhoneCall) — 参考白色手机通话界面。
@image2 (TerraceWide) — 参考露台护栏与外立面高度关系。
@image3 (LinShen) — 参考 lin_shen.png。
@image4 (ZhouYan) — 参考周妍角色。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务是让最后一次声音诱导和真实物理失控连成一气，不能拍成推人动作，而要拍成被布局好的失衡。

【镜头1】
机位：85mm 手机近景，固定。持续约4秒。
动作：白色手机屏幕突然亮起一瞬，外放声更贴耳、更急：“往下看。” 亮屏时间极短，像诱饵最后一次闪光。

【镜头2】
机位：85mm 护栏连接处特写，固定。持续约4秒。
动作：护栏某个连接点在受力后发出清脆短促的裂响，金属轻微错位，但不能夸张飞散。

【镜头3】
机位：高空远景或外立面斜远景，固定。持续约7秒。
动作：周妍整个人翻出栏杆，沿外立面直坠。林深留在栏杆内侧，只保留短促失手的错觉，不能做夸张扑救动作。风声瞬间灌满声场。

风格：8K IMAX，超写实，禁3D渲染，禁游戏引擎，禁游戏CG，禁字幕，禁音乐。灯光只允许高空夜景与实景反射光。动作必须突然、真实、不可挽回。

## Prompt 04 [Multi-shot · 坠落中的三刀闪回]

@image1 (LinShen) — 参考 lin_shen.png。
@image2 (StudyScreenWaveform) — 参考书房音频编辑界面。
@image3 (ChenBo) — 参考 chen_bo.png。
@image4 (Room307Door) — 参考307门口与门牌关系。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务是让坠落中的第一组闪回先揭开林深是谁、开场在干什么、第一段语音是怎样被触发的。

【镜头1】
机位：50mm 会议近景，固定。持续约5秒。
动作：冷白会议室里，一份报表只被推到林深面前，周围人都沉默等他拍板；桌对面一个董事级男人低声问：“林总，两名调查者，怎么处理？” 林深只看报表一眼，整个人已经像在处理业务。

【镜头2】
机位：85mm 屏幕特写，固定。持续约4秒。
动作：书房电脑上原始波形与伪造波形几乎重合，播放头反复穿过“如果我遇到意外，找我哥”，鼠标拖拽动作熟练、冷静。

【镜头3】
机位：85mm 监控屏加人物侧脸近景，固定。持续约6秒。
动作：陈伯盯着 307 室内监控画面，不是在门锁一动就发送，而是等周妍已经进屋、停下两步开始看房间时，才按下发送。必须拍清“她已进屋”与“发送成功”的先后关系；发送后，他顺手拿起那台白色手机起身离开，去露台预置最后一道诱饵。

风格：8K IMAX，超写实，禁3D，禁游戏CG，禁字幕，禁音乐。闪回必须像刀片一样快、准、冷，不做花哨转场。

@image5 (ChenBo) — 参考 chen_bo.png。

【镜头1】
机位：50mm 设备界面与音箱状态近景，固定。持续约4秒。
动作：后台命令发出后，307 智能音箱（正面带大尺寸触摸屏）被远程唤醒，触摸屏显示数字口令校验中；原本灰掉的解锁权限在数字口令输入后瞬间转绿。不要拍成黑客炫技。

【镜头2】
机位：85mm 屏幕界面特写，固定。持续约4秒。
动作：后台界面里“林晚 语音复刻模型”运行到最后一步，进度已逼近完成，只差最后一下提示弹出；背后隐约带出真实工业软件界面。

【镜头3】
机位：仰拍，固定。持续约7秒。
动作：回到周妍坠落中的最后视角，她仰头只看见林深站在栏杆前，身形稳得过分；露台铁门旁的阴影里，陈伯的人影慢半拍现身。风声继续灌满整个声场。

风格：8K IMAX，超写实，禁3D渲染，禁游戏引擎，禁游戏CG，禁字幕，禁音乐。主情绪是技术闭环和现场布局同时锁死。

## Prompt 06 [Multi-shot · 清除物证 + 控制室终极反转]

@image1 (WhitePhoneCall) — 参考白色手机破裂后的状态。
@image2 (LinShen) — 参考 lin_shen.png。
@image3 (ChenBo) — 参考 chen_bo.png。
@image4 (DeviceRoomWide) — 参考控制区与设备空间的冷色质感。
@image5 (LinWanBound) — 参考 lin_wan_bound.png。
@image6 (HardDriveRack) — 参考硬盘柜与数据采样设备质感。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务是先把露台上的物证处理干净，再把镜头送入控制室，最后落在“人只是样本”的终幕上。

【镜头1】
机位：85mm 露台地面近景，固定。持续约5秒。
动作：白色手机摔裂在地，仍漏出断续人声；林深俯身捡起，一键挂断，然后把手机丢回地面，一脚碾碎残余裂屏和通话界面。动作必须像处理垃圾，不像发泄。

【镜头2】
机位：50mm 门口中景，固定。持续约4秒。
动作：林深低声说：“你非要闯进禁区，谁都拦不住。” 陈伯从露台铁门后的阴影里走出。接着两人一前一后走入值班室或控制区入口。

【镜头3】
机位：先 85mm 监控屏特写固定，再落到 50mm 收尾中景固定。整体作为一个压缩段。持续约6秒。
动作：监控画面里，林晚仍被绑在椅子上；系统界面持续录入情绪样本；最后系统女声平静播报：“周妍坠楼前尖叫采集成功。” 林深站在屏幕前不回头。

风格：8K IMAX，超写实，禁3D，禁游戏CG，禁字幕，禁音乐。空间不能拍成科幻秘密基地，而要拍成真实、冷静、持续运转的声音工厂。
