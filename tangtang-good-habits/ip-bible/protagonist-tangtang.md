# 糖糖 · 主角圣经（IP 跨集通用版）

**本文件是《糖糖的小英雄》系列的主角设定标准，任何一集都必须以此为准。**

## 一、基础信息

| 项 | 设定 |
| --- | --- |
| 姓名 | 糖糖 |
| 昵称 | 小糖糖、糖豆、糖果 |
| 名字寓意 | 她爱吃糖糖，也是"甜"的化身 |
| 年龄 | 4 岁半 |
| 性别 | 女 |
| 就读 | 幼儿园中班 |
| 家庭 | 与爸爸妈妈同住 |
| 常驻场景 | 客厅、糖糖卧室、卫生间、餐厅、幼儿园 |

## 二、外观（视觉锁定 · 生成 AI 参考图必用）

### 面部

- 圆脸，苹果肌明显
- 大眼睛（棕色瞳孔），双眼皮
- 小鼻子，圆润
- 门牙有明显的两颗小方块（这是刷牙特写时的主角）
- 皮肤：亚洲儿童小麦白，健康红润
- 表情基线：默认灿烂笑容，露门牙

### 头发

- 浅棕色齐耳短发
- 头顶两个小啾啾扎起来（红色发圈）
- 头发有轻微弹动感（3D 皮克斯风的动态感）

### 身形

- 3D 皮克斯"小英雄大冒险"比例——**头身比 1:3**
- 圆滚滚可爱
- 手脚是短短胖胖的婴儿肥造型

### 视觉参考锚点（给图像生成 AI）

- 皮克斯《月神 La Luna》里的小男孩比例
- 《头脑特工队》Riley 小时候的圆润脸型
- 《寻梦环游记》Miguel 的活泼眼神
- **破第四堵墙眼神参考**：《爱探险的朵拉》Dora 对镜头直视问话时的眼神

### 禁忌

- ❌ 不要真实儿童面部（避免 uncanny valley 和肖像权）
- ❌ 不要日系动漫大眼比例（本片是皮克斯风）
- ❌ 服装不要黑白灰暗色系（受众是幼儿）

## 五、性格与心理

### 核心性格
- **爱吃糖、爱撒娇、有点小懒**（真实幼儿园儿童的通病）
- **心地善良、容易开心、也容易哭**
- **好奇心强、爱模仿、愿意学新东西**

### 心理弱点（Hamartia · 全 IP 通用）
- **偏爱短期满足**：现在快乐比未来后果重要（吃糖不刷牙、看屏幕不睡觉、玩玩具不收拾）
- **易被朋友带跑**：动画/糖果/小怪兽的诱惑，她抵抗力不强

### 心理弧线（跨集慢成长）
- Ep01 结尾：学会刷牙 → 认识到"守护者存在"
- Ep02 结尾：学会早睡 → 认识到"守护者可能不只一个"
- Ep05-10：逐步认识"生活里每一个小习惯都有一个守护者"
- 大结局（若有）：糖糖成为一个真正闪闪亮的小朋友，守护者们不再需要现身

**这条弧线不需要每集都强调**，它是 IP 的"隐形骨骼"，为未来做大电影/合集留可能。

## 六、语言习惯

### 口头禅
- 快乐时："**呀哈——！**"
- 撒娇时："**太累啦~**"、"**明天再刷嘛~**"、"**再一次嘛~**"
- 惊讶时："**哎哟！**"
- 委屈时："**呜——**"
- 惊喜时："**哇！**"
- 决心时："**我要变得闪闪亮！**"
- 邀请时（结尾必用）："**你也要 X X X 哦！**"

### 台词风格
- 短句为主，每句不超过 8 个字
- 大量拟声词
- 直呼守护者名字表示亲近："**牙刷警长！**"、"**睡眠精灵！**"
- 结尾邀请必须**眼神直视镜头**、**温柔真诚**

## 七、声音设计（配音要求）

- 声调：清亮童声，5-7 岁女童配音
- 语速：中速偏慢，让 3-6 岁观众能听清
- 情绪：夸张但不做作，像跟好朋友说话
- **禁忌**：不要"甜妹配音"套路，不要装嫩发嗲；也不要用成人配音模仿童声
