# 证词之外 逐镜 Shot List

用途：导演分镜、摄影计划、AI 视频生成、后续故事板细化

格式说明：

| 字段 | 说明 |
| --- | --- |
| 镜号 | 连续镜头编号 |
| 场次 | 对应剧本场次 |
| 景别 | 建议景别 |
| 机位/运动 | 固定、推进、横移、低机位、俯拍等 |
| 画面内容 | 镜头内发生的主要动作 |
| 台词/声音 | 关键对白或声音提示 |
| 时长 | 估计时长 |
| 备注 | 可用于 AI 视频、置景、表演提示 |

## AI 视频拆解建议

| --- | --- |
| 单镜测试 | 先做 005、011、020、024、030、036 六个镜头的视觉验证 |
