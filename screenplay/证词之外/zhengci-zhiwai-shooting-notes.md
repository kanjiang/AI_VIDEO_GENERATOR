# 《证词之外》拍摄备注

## 目标版本

本片当前建议按 6 到 7 分钟悬疑短片执行。主剧本负责动作和对白，这份备注只保留拍摄执行层真正需要的补充信息。

## 场景与功能

1. 书房：建立林深的正常人假象，不能提前露出幕后身份。
2. 307：建立周妍与林深的陌生关系，完成音箱解锁与第一次错误信任。
3. 电梯 / 29楼走廊：做一轮被困和被监视的心理施压。
4. 设备间：把非法收音证据拍实，同时把周妍从取证推回救人。
5. 露台：完成手机诱饵、退路切断和护栏事故。
6. 外立面 / 地面：完成黑化揭示、闪回回收和录音笔反扣。

## 角色执行要点

### 林深

- 前四场都按“可靠哥哥”演，不要提前露冷感。
- 表演核心不是凶，而是稳。每次推进节奏都像在帮周妍。
- 真正翻脸只留到松手和最后俯视两处。

### 周妍

- 不是尖叫型受害者。前半程始终在判断、记录、克制。
- 她的失误不是愚蠢，是在“救林晚”这件事上被情感压过理性。
- 露台前必须先建立她有取证意识，否则后面录音笔会显得像编剧硬塞。

### 林晚

- 正片里只以语音和闪回碎片出现。
- 语音前半段要足够真，29楼之后再让观众慢慢意识到这是合成声。

## 道具连续性

必须统一的核心道具只有七组：

1. 林深书房电脑：要准备普通办公界面版和闪回揭示版两套素材。
2. 林晚生活照：放在书房桌面，强化兄妹关系。
3. 周妍手机：外壳裂纹必须稳定，307 场次要拍到一次。
4. 黑色智能音箱：307 和设备间的声源设备需要视觉统一。
5. 设备间文件界面：文件名要和剧本一致，能一眼看出是住户私密声音采样。
6. 白色手机：露台诱饵机，外观不能和周妍手机混淆。
7. 微型录音笔：终场物证，前面最好在周妍衣服或包上留一次不抢眼的存在痕迹。

## 空间与调度

### 307

- 周妍先占空间中心，林深进门后逐步把她逼到“看音箱、听声音、立刻转移”这条动线上。
- 林深输入口令时必须背对周妍，不能拍到她能看到的密码动作。

### 电梯

- 核心不是故障本身，是停在15楼后的等待。
- 门外脚步只要一次停顿，不要演成打斗或强闯。

### 设备间

- 周妍先看屏幕，再拍证据，再被声音带走，顺序不能反。
- 这场的价值转换是“接近真相”变成“再次被诱导”。

### 露台

- 手机位置必须迫使周妍越过安全边线，事故才成立。
- 林深先拉、后松，动作逻辑要让外人看上去像救援失败。

## 声音策略

1. 全片不靠音乐抬戏，主要靠环境音、门外脚步、电梯机械声、风声和录音回放。
2. 林晚语音分三层：307 最自然，设备间略空，终场闪回里可以彻底暴露合成感。
3. 录音笔回放一定要清楚，不能被环境声吃掉。

## 摄影与剪辑建议

1. 主剧本已经尽量去掉镜头说明，执行时保持“能看清动作因果”优先。
2. 前半程多用稳定或克制移动，后半程再逐步压近。
3. 闪回全部按短促硬切处理，不做抒情蒙太奇。
4. 终场黑鞋只拍脚和拾取动作，不给身份答案。

## 安全与拆拍

1. 露台抓手腕、松手、俯视、坠落、地面落点必须拆拍，不要连做。
2. 护栏需要准备可控断裂版本，断点要服务特写和中景各一套。
3. 外立面悬挂镜头优先棚拍或安全替代方案，地面冲击镜头独立完成。

## 开拍前必须确认

1. 设备间文件名是否与主资产和 UI 图一致。
2. 录音笔是否在前文留下过足够弱但可追认的存在。
3. 307、29楼、露台三段夜戏的服装污损和发型是否连续。
4. 林深松手前后的表情变化是否只在一个镜头点爆，不要提前泄底。
