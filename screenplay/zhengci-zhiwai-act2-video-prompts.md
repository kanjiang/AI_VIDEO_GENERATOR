# 《证词之外》第二幕视频提示词

范围说明：第二幕 = S3-S4，对应 [screenplay/zhengci-zhiwai-shot-list.md](screenplay/zhengci-zhiwai-shot-list.md) 的 026-048 镜头。

使用说明：以下为 15 秒左右一条的 Seedance 风格中文提示词，每条均为完全自包含重度版，可单独投喂模型。复制到 Seedance 时，必须连同每条 prompt 上方的 @image 行一起复制；@image1、@image2 的编号跟随本次上传顺序变化，但括号里的名字应保持稳定。本文件是段落压缩版，用于快速测试整段节奏；实际单镜头执行时，以 [screenplay/zhengci-zhiwai-act2-video-prompts-shot-by-shot.md](screenplay/zhengci-zhiwai-act2-video-prompts-shot-by-shot.md) 为准。第二幕整体拍法统一为：空间轴线稳定、楼层关系清楚、真假声源分离、设备间 UI 可读、固定机位优先。

## Prompt 01 [Multi-shot · 离开307，进入消防楼梯]

@image1 (Room307Door) — 参考307房门内侧与门框关系。
@image2 (FireStairDoor) — 参考老式消防铁门与楼梯间冷光。
@image3 (FireStairWide) — 参考公寓消防楼梯纵深。
@image4 (ZhouYan) — 参考周妍角色。
@image5 (LinShen) — 参考 lin_shen.png。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务是把“307 的封闭感”平滑转成“被线索推着上楼”的禁区感。摄影机保持固定，空间必须真实老旧，禁止现代感过强的楼梯间。

【镜头1】
机位：50mm 门口中景，固定。持续约4秒。
动作：周妍和林深离开画面，307房门在他们身后轻轻合上。关门声克制、不炸，屋内冷灰环境光像被切掉一截，形成阶段切换。

【镜头2】
机位：50mm 楼梯入口近景，固定。持续约5秒。
动作：消防铁门被推开，空楼梯间冷白光外泄。周妍先冲进去，林深紧跟半步。门轴声必须老旧、干涩。

【镜头3】
机位：35mm 楼梯中景，固定。持续约6秒。
动作：两人一前一后冲进楼梯间，脚步声砸出空洞回响。动作不能像动作片奔跑，只是被焦虑推快了步伐，周妍始终在前，林深始终落后半步。

风格：8K IMAX，超写实，禁3D渲染，禁游戏引擎，禁游戏CG，禁音乐，禁字幕。灯光只允许307残余环境光、楼梯间冷白顶灯和极弱反射光。60fps，180度快门，物理镜头质感。

【镜头3】
机位：先 50mm 29楼出口近景固定，再落到 35mm 29楼广角固定。整体作为一个压缩段。持续约6秒。
动作：安全门被推开，惨白冷光倾泻出来；紧接着空旷走廊、玻璃墙、机房门和露台铁门同时入画。空间里不能出现任何住户生活痕迹。

风格：8K IMAX，超写实，禁3D，禁游戏CG，禁音乐，禁字幕。灯光只允许楼梯间冷白顶灯和29楼更冷更平的楼层光。画面必须稳定、线条笔直。

## Prompt 03 [Multi-shot · 设备间门缝把周妍拽过去]

@image1 (Floor29Wide) — 参考29楼走廊空间。
@image2 (DeviceRoomDoorCrack) — 参考设备间虚掩门缝。
@image3 (ZhouYan) — 参考周妍角色。
@image4 (LinShen) — 参考 lin_shen.png。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务是让“既有调查史”和“模糊女声的牵引”在同一段里成立，让周妍不是被人推，而是被声音自己拉过去。

【镜头1】
机位：50mm 双人中景，固定。持续约5秒。
动作：周妍低声问：“这里的设备间，跟我们之前偷拍到的普通机房完全不一样，权限更高、更隐秘。” 她的声音必须轻，像怕被楼层本身听见。林深顺着她视线看向尽头。

【镜头2】
机位：85mm 门缝特写，固定。持续约5秒。
动作：虚掩的设备间门缝里漏出细碎女声和设备嗡鸣，声音不能清晰成完整句子，只能让人本能觉得像林晚。门缝内光比外面更冷、更青。

【镜头3】
机位：85mm 周妍近景，固定。持续约5秒。
动作：周妍肩背先一僵，再几乎不受控制地往前迈。动作幅度很小，但要让“被声源拖住”成立。林深只在边缘或后景保持跟随，不抢主体。

风格：8K IMAX，超写实，禁3D渲染，禁游戏引擎，禁游戏CG，禁音乐，禁字幕。灯光只允许29楼冷平楼层光和设备间门缝内更冷的青白光。声音设计以模糊女声和设备嗡鸣为主。

## Prompt 04 [Multi-shot · 设备间真相空间建立]

@image1 (DeviceRoomWide) — 参考设备间内部：硬盘柜、工作台、拾音器、旧音箱。
@image2 (HardDriveRack) — 参考硬盘柜近景。
@image3 (DeviceScreenFiles) — 参考设备间电脑屏幕文件列表。
@image4 (ZhouYan) — 参考周妍角色。
@image5 (ZhouYanPhoneGallery) — 参考手机相册边角露出旧偷拍照片。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务是把设备间拍成一套真实运转的人声采样系统，而不是抽象邪恶实验室。UI 必须清晰可读，周妍的偷拍反应必须克制。

【镜头1】
机位：35mm 入口广角，固定。持续约5秒。
动作：设备间内部全景建立。成排硬盘柜、工作台、拾音器、小音箱、冷青设备光同时成立，空间要像维护良好的数据采样间。

【镜头2】
机位：85mm 插入特写组接感压缩成一镜，固定。持续约5秒。
动作：先拍硬盘指示灯规律闪烁，再落到屏幕滚动“喘息、争吵、哭泣”等文件名。禁止复杂花哨动画，只要让“记录正在持续”成立。

【镜头3】
机位：85mm 周妍近景，固定。持续约5秒。
动作：周妍抬手机偷拍，脸色一点点沉下去；手机相册边角露出早前偷拍的普通公共机房照片，与眼前29楼设备间形成明显差异。她不能惊呼，只能更紧地控制自己。

风格：8K IMAX，超写实，禁3D，禁游戏CG，禁音乐，禁字幕。灯光只允许冷青设备光和屏幕冷光。主情绪是“真相规模第一次被看见”。

## Prompt 05 [Multi-shot · 合成声音接管空间]

@image1 (WallSpeakerRed) — 参考设备间墙面音箱与红灯状态。
@image2 (ZhouYan) — 参考周妍角色。
@image3 (LinShen) — 参考 lin_shen.png。
@image4 (DeviceScreenPopup) — 参考设备间电脑弹窗界面。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务是先让合成声音把空间接管，再让“林晚 语音复刻模型——生成完成”这个弹窗第一次击中周妍。真假声源必须区分：这次是系统音箱在说话，不是手机、不是广播。

【镜头1】
机位：85mm 墙面音箱特写，固定。持续约5秒。
动作：墙面音箱红灯亮起，林晚合成声从墙里传出：“我在露台边上，风好大，我有点撑不住。” 声音要像系统接管空间，近但不是贴耳。

【镜头2】
机位：50mm 双人中景，固定。持续约4秒。
动作：听到墙面音箱里的林晚声音后，周妍先转头，林深几乎同步跟上。两人的反应都要小，但方向必须一致。

【镜头3】
机位：先 85mm 屏幕弹窗特写固定，再落到 85mm 周妍近景固定。整体作为一个压缩段。持续约6秒。
动作：屏幕突然跳出“林晚 语音复刻模型——生成完成”；紧接着周妍低声重复：“语音复刻……？原来之前的声音，全是假的？” 她不是崩溃，而是第一次意识到死亡也可能被做出来。

风格：8K IMAX，超写实，禁3D渲染，禁游戏引擎，禁游戏CG，禁音乐，禁字幕。灯光只允许设备间冷青光和屏幕冷白弹窗光。表演必须比信息更克制。

## Prompt 06 [Multi-shot · 林深把线索引向露台]

@image1 (LinShen) — 参考 lin_shen.png。
@image2 (ZhouYan) — 参考周妍角色。
@image3 (DeviceScreenPopup) — 参考弹窗界面。
@image4 (CeilingSpeaker) — 参考天花板嵌入式广播音箱。
@image5 (DeviceToTerraceDoor) — 参考设备间朝露台铁门方向的构图。

完全自包含重度版：15秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务是让林深迅速收口，把“查证”硬切成“救人”，并把露台变成唯一出口。声音层次必须递进：先是他的话，再是广播，最后是沉默中的视线统一。

【镜头1】
机位：85mm 林深近景，固定。持续约4秒。
动作：周妍手机里已经拍下弹窗和文件列表，林深手指快速关掉弹窗，眼神立刻压平，像什么都没发生；接着压低声音说：“这里只是AI生成终端，真正的源头和线索，都在露台。” 语气必须像顺着现场判断，不像明显诱导。

【镜头2】
机位：85mm 顶角广播近景，固定。持续约5秒。
动作：天花板嵌入音箱广播：“周妍。我在露台。” 这次声音要比墙面音箱更空、更像建筑内部广播，把空间彻底推向露台。

【镜头3】
机位：50mm 门口方向中景，固定。持续约6秒。
动作：广播结束后，周妍先低头看一眼手机里刚拍下的画面，明显还想继续留证；但下一秒她还是和林深一起望向尽头紧闭的露台铁门，空气突然凝住。动作极少，只需把那股吸力拍出来，让观众知道下一步一定会去那里。

风格：8K IMAX，超写实，禁3D，禁游戏CG，禁音乐，禁字幕。灯光只允许设备间冷青光和远端更冷的露台方向环境光。主情绪是露台成为唯一出口。
