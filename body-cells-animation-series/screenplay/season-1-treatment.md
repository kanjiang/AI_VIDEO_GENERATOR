# 《身体小队》第一季 Treatment

## Season Format

- 集数：8 集
- 单集时长：8 到 12 分钟
- 结构：每集一个身体危机，同时推进“感染入侵”主线
- 第一季主线：病原体从皮肤破口进入身体，逐步潜伏和扩散，最终被小队与记忆细胞识别并阻止

---

# Episode 1. 《破口警报》

皮肤边境出现小伤口，板板带队修补，白小锋冲进破口清理外来物。红小达在运输路线上发现一枚不属于身体的碎片。白小锋以为战斗结束，板板却发现破口边缘还在松动。小队第一次意识到，这不是普通擦伤。

科普点：皮肤屏障、血小板、凝血、外来物进入身体。

Value shift：安全感 → 警觉。

---

# Episode 2. 《红热工地》

伤口周围的炎症警报塔启动，局部道路变窄，红小达配送受阻。白小锋认为炎症是混乱，想强行压下警报。闪闪追上他，把更多白细胞调来。小队发现红、肿、热、痛不是敌人，而是身体在召集防线。

科普点：炎症反应、局部红肿热痛、免疫细胞集合。

Value shift：混乱 → 有序防御。

---

# Episode 3. 《发烧城市》

体温升高，整座身体城市进入节能和防御状态。红小达的氧气配送变慢，白小锋抱怨环境变差。病原体的复制速度也被拖慢。小队必须在身体消耗增加前找到感染源头。

科普点：发烧的作用、能量消耗、病原体复制受影响。

Value shift：不适 → 防御代价。

---

# Episode 4. 《咳嗽风暴》

入侵者留下的刺激物抵达呼吸道区域，强风通道突然启动。闪闪把咳嗽信号传出，红小达被气流卷入支路。白小锋误以为风暴妨碍任务，后来看到刺激物被排出。小队学会利用咳嗽风暴清理通道。

科普点：咳嗽反射、呼吸道清理、刺激物排出。

Value shift：阻碍 → 清理工具。

---

# Episode 5. 《抗生素误会》

身体外部送来药物援助，部分细菌被压制，白小锋以为所有敌人都会被药物解决。记小忆第一次出现，指出不同敌人需要不同识别方式。小队发现药物不是万能武器，错误使用会让战局更乱。病原体趁小队松懈转入潜伏。

科普点：抗生素针对细菌、不针对病毒；合理用药；药物协助身体。

Value shift：依赖外援 → 理解边界。

---

# Episode 6. 《假信号》

警报在多个区域同时响起，闪闪来回奔跑，白小锋分兵追击。红小达发现真正堵点只有一处，其他信号是连锁反应。小队把所有警报按紧急程度排序，集中力量守住关键路线。病原体留下的核心碎片被记小忆收进档案盒。

科普点：身体信号、疼痛和不适的定位、系统连锁反应。

Value shift：失控 → 优先级。

---

# Episode 7. 《档案里的敌人》

记小忆在免疫档案库比对碎片，发现入侵者多次改变外形，但核心标记相同。白小锋急着出击，要求马上给结论。记小忆拒绝草率记录。病原体突破一条侧路后，记小忆必须边追踪边完成识别。

科普点：免疫识别、抗原特征、记忆细胞。

Value shift：等待 → 识别。

---

# Episode 8. 《身体保卫战》

病原体冲向关键通道，血管主干道拥堵，氧气配送受影响。板板用修补钉封堵扩散口，红小达绕小路维持供氧，闪闪发出准确调度信号。白小锋没有立刻蛮攻，而是拖住敌人，等记小忆完成识别。抗体防线启动，入侵被控制。身体城市恢复运行，档案库留下新的敌人标记。

科普点：免疫协作、抗体识别、记忆免疫、身体恢复。

Value shift：孤军战斗 → 系统协作。

---

## Season Arc

白小锋从“先打再说”变成能等待证据和调度队友的队长。红小达从只负责运输，变成身体路线的关键观察者。板板从按流程施工，变成能在危急时设计临时方案的工程师。闪闪从急着传递所有信号，变成能判断优先级的信使。记小忆从旁观记录者，变成季终防御的关键。

## Season Ending

小队没有让身体变成永远不会生病的地方。他们让身体学会了这一次敌人的特征。下一次同类入侵，身体会反应更快。

## Open Door for Season 2

季终后，身体城市恢复。远处出现新的信号：这一次没有外敌，警报却在内部响起。第二季可以进入过敏、免疫误判或代谢超载线。
