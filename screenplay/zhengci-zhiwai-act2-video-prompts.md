# 《证词之外》第二幕视频提示词

范围：015-024 镜头

说明：本文件是 第二幕 的段落压缩版，按当前 shot list 聚合成 3 条 multi-shot prompts，用于 Seedance 快速测试整段节奏。单镜执行仍以逐镜版为准。

## Prompt 01 [Multi-shot · 电梯停层与29楼入口]

@image1 (ElevatorCabin) — 参考电梯轿厢空间。
@image2 (ElevatorPanel29) — 参考电梯楼层与停层面板。
@image3 (ZhouYan) — 参考周妍角色定妆。
@image4 (LinShen) — 参考林深角色定妆。
@image5 (Floor29Wide) — 参考29楼走廊全景。
@image6 (DeviceRoomDoorCrack) — 参考设备间门缝冷光。

完全自包含重度版：60秒，21:9，multi-shot，严格只允许 4 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务：把离开307、电梯卡层和29楼异常空间做成一次连续升级。整体要求：超写实实拍、真实场景光、克制表演、镜头之间只保留必要叙事推进。

【镜头1】
机位：中景，跟拍转固定。持续约15秒。
动作：两人离开 307 冲进电梯，林深立刻按下 29 楼。
声音：关门声、按钮提示音、钢缆嗡鸣。
重点：不给周妍停下来复盘的时间。

【镜头2】
机位：近景，固定，轻微变焦。持续约15秒。
动作：电梯在 15 层骤停频闪，周妍一手扶内壁一手捂紧口袋。
声音：周妍：怎么回事？ / 林深：应该只是电梯故障。 / 电流声、机械骤停声。
重点：同时放大失重、口袋录音笔和林深的假镇定。

【镜头3】
机位：中景，固定转门口主观轻摇。持续约15秒。
动作：林深抬手噤声，门外脚步在轿厢外停留片刻后远去，电梯重启。
声音：制式脚步声、灯管杂音、电梯重启提示音。
重点：危机解除得过于巧合，继续制造局感。

【镜头4】
机位：全景，轻推跟进。持续约15秒。
动作：两人抵达 29 楼，空旷走廊与设备间门缝冷光同时入画，推门而入。
声音：设备低频嗡鸣、门缝风声、模糊女性气音。
重点：29 楼空间本身先成为第三层陷阱。

## Prompt 02 [Multi-shot · 设备间真相与伪求救]

@image1 (DeviceRoomWide) — 参考设备间全景。
@image2 (DeviceScreenFiles) — 参考采样文件列表界面。
@image3 (ZhouYan) — 参考周妍角色定妆。
@image4 (ElevatorPanel29) — 参考电梯楼层与停层面板。
@image5 (WallSpeakerRed) — 参考墙面广播音箱红灯。
@image6 (LinShen) — 参考林深角色定妆。

完全自包含重度版：45秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务：先让黑产证据落地，再被墙内求救声强行改写目标。整体要求：超写实实拍、真实场景光、克制表演、镜头之间只保留必要叙事推进。

【镜头1】
机位：广角，固定转局部快切。持续约15秒。
动作：满墙机柜与亮屏把设备间压成“声音工厂”，林深指向深处亮屏。
声音：林深：那边有个显示器是亮的，过去看看。 / 周妍：这是……这全是长宁公寓住户的音频数据！
重点：非法采样规模第一次被直观看见。

【镜头2】
机位：中近景，手持微晃，快速推近。持续约15秒。
动作：林深忙着复制导出，周妍回头看见电梯楼层已到九楼，危险逼近。
声音：周妍：林深——有人上来了！电梯已经到九楼了！ / 林深：还要多久？ / 周妍：很快！他们上得很快！
重点：“取证”与“追兵”两股压力撞到一起。

【镜头3】
机位：中景，固定转跟移。持续约15秒。
动作：林深继续操控节奏，让周妍盯电梯；墙面红灯音箱骤亮，伪造求救声把她拖向露台。
声音：林深：你盯着电梯，我再拍下证据。 / 林晚回声：周妍，周妍！
重点：从“查证”硬切到“救人”，局势被再次夺走。

## Prompt 03 [Multi-shot · 露台诱饵与翻坠]

@image1 (TerraceWide) — 参考露台全景。
@image2 (WhitePhoneCall) — 参考露台白色手机通话状态。
@image3 (ZhouYan) — 参考周妍角色定妆。
@image4 (RailingJointClose) — 参考护栏连接处特写。
@image5 (LinShen) — 参考林深角色定妆。

完全自包含重度版：45秒，21:9，multi-shot，严格只允许 3 个镜头，禁止额外镜头、禁止字幕、禁止音乐。段落任务：用白色手机、危险地形和护栏崩裂把周妍逼到露台外。整体要求：超写实实拍、真实场景光、克制表演、镜头之间只保留必要叙事推进。

【镜头1】
机位：全景，跟拍转固定高位。持续约15秒。
动作：周妍推门冲入露台，高空围栏、维修箱和白色手机同框。
声音：大风声、金属门轻晃、手机震动闷响。
重点：先把危险地形讲清楚，再把诱饵摆进画面。

【镜头2】
机位：中近景，跟拍轻推。持续约15秒。
动作：周妍被白色手机吸住，快步逼近，身体重心不断越过安全线。
声音：周妍：是晚晚的手机！她肯定在附近！ / 手机震动声、急促脚步声。
重点：希望感越强，坠落越不可避免。

【镜头3】
机位：特写，快切转仰拍定格。持续约15秒。
动作：护栏连接处崩裂，周妍翻坠，林深大手骤然抓住她手腕。
声音：周妍：啊啊啊啊啊！ / 金属断裂脆响、风声猛增。
重点：先给“舍命救人”的强错觉。
