# 视频渲染质量指令库

AI 视频出现"塑料感"的关键原因不是模型，而是提示词中缺少引擎级渲染指令和光追强化指令。本文件是完整的指令目录，按类别组织，每条指令标注目标效果和适用场景。

---

## 一、引擎级渲染指令

引擎级指令告诉模型用哪种渲染管线来模拟画面。缺少这类指令时，模型会退回到默认的"通用CG"风格，这就是塑料感的根源。

| 目标效果 | 中文提示词 | 英文提示词 | 适用场景 |
|---------|-----------|-----------|---------|
| 黑神话风格写实光影 | 虚幻引擎5.3 Lumen全局光照 | Unreal Engine 5.3 Lumen global illumination | 写实动作、奇幻、开放世界 |
| 建模细节拉满 | Nanite虚拟几何体，影视级资产 | Nanite virtual geometry, film-grade assets | 需要极致几何细节的近景 |
| 电影级材质节点与光效 | Octane X渲染，光谱光照 | Octane X render, spectral lighting | 产品级质感、高端材质展示 |
| 毛孔级写实质感 | Redshift RT，微表面散射 | Redshift RT, microsurface scattering | 角色脸部特写、皮肤/有机材质 |
| 室内外真实光环境模拟 | V-Ray 6全局光照，物理相机 | V-Ray 6 global illumination, physical camera | 建筑可视化、室内戏、混合光源 |

### 使用原则

- 每个提示词只选一个引擎指令作为主锚点。
- 可以叠加一个几何/材质指令（如 Lumen + Nanite），但不要同时写三个不同引擎。
- 引擎指令放在全局风格声明或【规格】段落中，不要散落在动作描述里。

## 二、光线追踪强化指令

光追指令让反射、阴影和光路变得物理正确。没有光追指令时，模型会用近似算法，反射和阴影会看起来"贴上去的"。

| 目标效果 | 中文提示词 | 英文提示词 | 适用场景 |
|---------|-----------|-----------|---------|
| 金属铠甲/车漆真实反射环境 | 光线追踪反射 | ray-traced reflections | 金属、玻璃、水面、抛光表面 |
| 阴影边缘柔和自然 | 光线追踪阴影 | ray-traced shadows | 所有需要自然阴影过渡的场景 |
| 整张图光影物理正确 | 路径追踪 | path tracing | 最高质量要求、产品级渲染 |

### 组合建议

- **基础组合**：光线追踪反射 + 光线追踪阴影 — 适合大多数写实场景
- **顶级组合**：路径追踪 — 单条指令覆盖反射、阴影、全局光照，适合质量优先的特写镜头
- 光追指令可以与任何引擎指令叠加使用

## 三、胶片模拟与色彩科学

胶片/色彩科学指令给画面加上真实摄影机的色彩响应和颗粒特征。没有这类指令时，AI视频会呈现"数字感"——颜色太均匀、太干净、没有生命力。

### 经典胶片模拟

| 中文提示词 | 英文提示词 | 色彩特征 | 适用场景 |
|-----------|-----------|---------|---------|
| 柯达Vision3 500T电影卷 | Kodak Vision3 500T | 暖色调、肤色偏暖黄、暗部偏青、经典好莱坞色彩 | 夜间室内、暖色叙事、情感戏 |
| 富士Reala 500D | Fuji Reala 500D | 自然饱和、绿色准确、肤色自然、日光平衡 | 日间外景、自然光场景 |
| 爱克发Vista 400 | Agfa Vista 400 | 高饱和、偏暖、对比度较高、复古感 | 复古风格、夏日色调 |

### 现代数字色彩科学

| 中文提示词 | 英文提示词 | 色彩特征 | 适用场景 |
|-----------|-----------|---------|---------|
| ARRI Alexa色彩科学 | ARRI Alexa color science | 宽容度极高、肤色自然、暗部细节丰富、电影感最强 | 当代电影、高端叙事 |
| RED Komodo肤色 | RED Komodo skin tone | 肤色偏红润、质感锐利、细节极强 | 人物特写、肤色敏感场景 |
| 索尼威尼斯滤镜 | Sony Venice filter | 色彩平滑、高光柔和、双原生ISO | 暗光场景、柔和情绪 |

### 选择原则

- 胶片模拟适合需要"有温度"的画面——情感戏、复古场景、暖色叙事。
- 数字色彩科学适合需要"当代电影感"的画面——现代题材、商业级质感。
- 每个提示词只选一种色彩科学，不要混搭两种胶片。

## 四、锐化与噪点控制

锐化和噪点是画面"质感"的关键参数。过锐看起来假，太柔看起来糊，太干净看起来数字，太多噪点看起来低质。

### 锐化等级

| 中文提示词 | 英文提示词 | 效果描述 |
|-----------|-----------|---------|
| 极高锐化 | ultra-high sharpness | 每个边缘都清晰锐利，适合产品、建筑、机械 |
| 高锐化，边缘增强 | high sharpness, edge enhancement | 边缘清晰但不过度，适合大多数写实场景 |
| 中等锐化 | medium sharpness | 自然锐度，适合人物和室内 |
| 柔和，无锐化 | soft, no sharpening | 画面柔和如胶片，适合梦境、回忆、浪漫 |

### 噪点等级

| 中文提示词 | 英文提示词 | 效果描述 |
|-----------|-----------|---------|
| 轻微胶片颗粒 | light film grain | 模拟35mm胶片颗粒，增加画面温度和真实感 |
| 细腻胶片颗粒 | fine film grain | 更精细的颗粒，适合高端电影感 |
| 无噪点纯净画面 | clean, no noise | 完全干净，适合商业、科幻、产品 |
| 风格化纸纹颗粒 | stylized paper grain | 纸张/画布质感，适合手绘风格 |

## 五、动态范围

动态范围决定了画面亮部和暗部能同时保留多少细节。

| 中文提示词 | 英文提示词 | 效果描述 | 适用场景 |
|-----------|-----------|---------|---------|
| HDR高动态范围 | HDR, high dynamic range | 亮部不过曝、暗部有细节 | 逆光、窗光、混合光源 |
| 10-bit色深 | 10-bit color depth | 色彩过渡平滑、无色带 | 渐变天空、肤色、柔和光线 |
| 12-bit RAW | 12-bit RAW | 最大后期空间、极致细节保留 | 最高质量要求 |
| SDR标准动态范围 | SDR, standard dynamic range | 传统电视/网络视频动态 | 日常、低对比度场景 |

## 八、物理材质与表面细节

材质和表面指令让物体看起来像真实的物理存在，而不是贴了一层颜色的几何体。这是消除"塑料感"的最后一公里。

### 天然材质

| 中文提示词 | 英文提示词 | 视觉特征 |
|-----------|-----------|---------|
| 花岗岩粗粝表面 | rough granite surface | 矿物颗粒可见、不规则反光、石材真实感 |
| 大理石纹理 | marble veining | 脉络走向、半透光、抛光反射 |
| 木材年轮 | wood grain, growth rings | 年轮纹路、色差、表面纤维 |

### 人造材质

| 中文提示词 | 英文提示词 | 视觉特征 |
|-----------|-----------|---------|
| 抛光镜面不锈钢 | polished mirror stainless steel | 镜面反射、环境映射、指纹油渍 |
| 清透玻璃 | clear transparent glass | 折射、反射、焦散光、边缘折光 |
| 高光ABS塑料 | glossy ABS plastic | 光滑高光、微弧面反射、注塑痕迹 |

### 表面状态

| 中文提示词 | 英文提示词 | 视觉特征 |
|-----------|-----------|---------|
| 表面水珠流淌 | water droplets running on surface | 水珠折射、湿润反光、流痕 |
| 剥落墙皮 | peeling wall paint | 多层露出、边缘卷翘、历史痕迹 |
| 灰尘堆积 | dust accumulation | 表面雾化、光路散射、时间感 |

### 使用原则

- 材质指令描述对象的物理真实性，放在该对象第一次出现的描述旁边。
- 表面状态指令描述环境磨损和时间痕迹，用于增加场景的"活过的感觉"。
- 不要给每个物体都加材质指令——只给画面重点对象和近景物体加。

## 九、光学特效

光学特效模拟真实镜头和光线的物理行为，让画面脱离"完美渲染"进入"真实拍摄"的质感。

### 折射与反射

| 中文提示词 | 英文提示词 | 视觉特征 | 适用场景 |
|-----------|-----------|---------|---------|
| 镜面反射 | specular reflection | 光滑表面的清晰环境映射 | 金属、玻璃、水面 |
| 漫反射 | diffuse reflection | 粗糙表面的柔和环境映射 | 墙面、布料、哑光材质 |
| 焦散光线 | caustic light rays | 光线穿过透明物体后在表面形成的亮纹 | 玻璃杯、水池、钻石 |

### 体积光

| 中文提示词 | 英文提示词 | 视觉特征 | 适用场景 |
|-----------|-----------|---------|---------|
| 丁达尔效应 | Tyndall effect, god rays | 光束穿过烟尘/雾气时可见光路 | 森林、教堂、窗光、晨雾 |
| 雾中光路 | volumetric light in fog | 雾气中的光柱和光晕 | 夜间、雨天、恐怖/神秘场景 |
| 水下光斑 | underwater caustic patterns | 水面折射在水底形成的动态光网 | 水下场景、泳池、海底 |

## 十三、混合媒介渲染配方

### 核心概念：分层风格声明

传统提示词对整个画面使用统一的渲染风格。混合媒介将画面拆成**独立图层**，每层使用不同的渲染管线，制造视觉碰撞：

```
传统（单层统一）：
  整帧 → 虚幻引擎5 + ARRI色彩

混合媒介（多层碰撞）：
  背景层 → 实拍质感（自然光晕、真实景深）
  角色层 → CG渲染（次世代引擎、菲涅尔反射）
  特效层 → 2D手绘（水墨晕染、飞白笔触）
  叠加层 → 胶片质感（16mm漏光、VHS噪点）
```

### 分层声明语法

在全局风格块或【规格】中，使用 `[层名]：` 前缀分别声明各层的渲染风格：

```
风格：混合媒介——
  [背景层]：实拍质感，自然光线，真实镜头色差与光晕
  [角色层]：CG写实渲染，虚幻引擎5.3 Lumen，光线追踪反射
  [特效层]：2D手绘水墨，边缘飞白，墨迹扩散动画
  [光影匹配]：角色光照方向与背景主光源严格一致，阴影投射到背景层
```

### 六个经典混搭配方

#### 配方 A：实拍背景 + CG 角色

**视觉效果：** 真实环境中放入精细CG角色，光影融合自然。

```
[背景层]：实拍素材质感——自然光照、真实镜头色差、浅景深背景虚化、阳光穿过树叶产生真实光晕
[角色层]：CG写实渲染——虚幻引擎5.3 Lumen全局光照，Nanite几何细节，光线追踪反射
[光影匹配]：⚠️CG角色的主光方向、色温、阴影硬度必须与背景实拍光源完全一致。角色在地面/物体上投射的阴影使用光线追踪阴影，与背景阴影融合。角色身上有背景环境的反射映射（绿叶反射在盔甲上、水面反射在脸上）。
[禁止]：禁角色光影与背景光影方向矛盾、禁角色无阴影悬浮感、禁背景和角色锐度差异过大
```

**适用：** 仙侠/奇幻角色在真实自然环境中、科幻角色在实拍城市中

#### 配方 B：3D 角色 + 2D 手绘特效

**视觉效果：** 写实3D角色身上叠加手绘特效，两种视觉语言碰撞。

```
[角色层]：3D写实渲染——虚幻引擎5.3，光线追踪反射与阴影，次表面散射皮肤
[特效层]：2D手绘风格——施法/能量/气场特效采用手绘水墨晕染，笔触边缘有飞白效果，墨迹扩散带有毛笔运笔的速度感，线条粗细不均匀
[碰撞规则]：⚠️3D角色和2D特效的交汇处有自然过渡——特效不是"贴"在角色身上，而是从角色动作中"生长"出来。特效的光照不需要匹配3D光源（这是刻意的风格差异），但特效的运动方向必须与角色动作方向一致。
[禁止]：禁特效变成3D粒子（必须保持手绘质感）、禁2D笔触过于工整（需要手工不规则感）
```

**适用：** 国风仙侠（写实角色+水墨法术）、格斗动作（写实角色+漫画式打击特效）

#### 配方 C：数字渲染 + 复古胶片叠加

**视觉效果：** 未来感的清晰数字画面被复古胶片质感覆盖，制造"时间错位"。

```
[底层]：高清数字渲染——8K清晰度，现代色彩科学（ARRI Alexa），干净锐利
[叠加层]：16mm胶片质感——胶片漏光（画面边缘随机暖色/冷色光斑）、VHS磁带噪点干扰纹（水平扫描线间歇出现）、高光溢出带模拟信号过载感（高光区域边缘有色彩溢出/bloom）、轻微画面抖动（手持16mm摄影机的不稳定感）
[融合规则]：⚠️底层画面保持全清晰度渲染，胶片质感作为后期叠加层处理。噪点强度不均匀——暗部噪点更重，亮部噪点更轻。漏光随机出现在画面边缘，不固定位置。
[禁止]：禁底层画面因胶片叠加而模糊（底层必须锐利）、禁噪点过重到看不清内容、禁漏光覆盖主体面部
```

**适用：** 赛博朋克、复古未来、MV风格、回忆闪回

#### 配方 D：写实场景 + 水墨/国画元素

**视觉效果：** 写实3D场景中，部分自然元素（云、雾、水、树）呈现水墨画质感。

```
[场景层]：写实3D渲染——Lumen全局光照，路径追踪，物理正确的材质和光影
[水墨层]：场景中的云雾/水流/远山/树冠采用水墨画风格——墨色浓淡层次分明，留白处见宣纸纹理，笔触方向跟随自然元素的运动方向（云向右飘则笔触向右），边缘有墨色渗透的不规则感
[融合规则]：⚠️水墨元素和写实元素的交界处有自然渐变——不是硬切，而是写实材质逐渐"溶解"成水墨笔触。近景偏写实、远景偏水墨（利用空气透视强化融合感）。
[禁止]：禁水墨元素有3D光影（水墨层应该是平面化的）、禁水墨笔触过于工整规则
```

**适用：** 国风场景、山水叙事、武侠意境

#### 配方 E：赛博数字 + 有机生物

**视觉效果：** 硬质科技表面和有机生物质感的对比融合。

```
[科技层]：赛博数字渲染——金属表面高反射、全息UI界面叠加、霓虹灯光源、硬边缘几何体
[生物层]：有机写实渲染——次表面散射（皮肤/植物透光）、微表面散射（毛发/绒毛）、湿润表面（粘膜/露珠）、柔和边缘有机形态
[碰撞规则]：⚠️科技元素和生物元素的交界处有"入侵/共生"感——电路纹路长在皮肤上时，皮肤边缘微微隆起；植物缠绕金属时，金属表面有氧化和腐蚀痕迹。两种材质不只是"贴在一起"，而是互相影响。
[禁止]：禁科技层和生物层完全独立不互动、禁生物层失去有机柔软感、禁科技层失去硬质反射感
```

**适用：** 生化科幻、赛博朋克生物改造、AI与自然融合主题

#### 配方 F：AI 生成素材 + 拼贴/杂志质感

**视觉效果：** AI生成的精美画面被拼贴处理，制造"从杂志上剪下来"的手工感。

```
[底层]：AI生成的高质量画面——写实或风格化均可
[拼贴层]：杂志拼贴质感——画面边缘有撕纸/剪纸的不规则白边、部分区域有报纸网点印刷纹理（半调网点）、局部色块用纯色几何形状覆盖（孟菲斯风格）、手写标注和箭头散落画面、贴纸/胶带痕迹
[融合规则]：⚠️拼贴元素的"手工感"必须可信——撕纸边缘有纤维感，胶带有半透明质感，手写字有笔压变化。拼贴元素不遮挡主体关键部位（面部、关键动作）。

```

**适用：** 时尚内容、MV、综艺片头、社交媒体封面

### 光影匹配规则（混合媒介通用）

混合媒介最常见的穿帮是**光影不一致**。以下规则在所有配方中生效：

| 规则 | 说明 |
|---|---|
| **主光方向一致** | 所有写实层的主光方向必须相同。在提示词中用 `⚠️主光方向：[方向]` 显式声明 |
| **色温一致** | 背景层和角色层的光源色温必须匹配（除非刻意制造碰撞，如配方C） |
| **阴影方向一致** | 角色的投射阴影方向必须与背景中其他物体的阴影方向相同 |
| **反射映射** | 角色的反射表面（盔甲、眼睛、湿皮肤）必须映射背景环境色 |
| **2D/手绘层豁免** | 2D手绘层和拼贴层不需要匹配3D光影——这是风格差异的一部分 |

### 提示词注入方式

混合媒介声明可以替换或追加到全局风格块中：

```
原文：
风格：8K，电影写实

混合媒介版：
风格：8K，混合媒介——
  [背景层]：实拍质感，自然光线，柯达Vision3 500T色彩
  [角色层]：CG写实渲染，虚幻引擎5.3 Lumen，光线追踪反射
  [光影匹配]：主光方向左上方45°，色温5600K日光，阴影方向一致
```

也可以在【规格】中简写：

```
【规格】15秒，16:9，混合媒介（实拍背景+CG角色），Lumen光追，光影匹配主光左上45°
```

### 常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| "CG角色像浮在背景上" | 缺少投射阴影和环境反射映射 | 增加光追阴影 + 环境反射映射指令 |
| "2D特效和3D角色脱节" | 特效运动方向与角色动作不一致 | 增加 `特效运动方向跟随角色动作方向` 约束 |
| "胶片叠加把画面弄脏了" | 噪点和漏光强度过高 | 降低叠加层透明度，限制噪点区域（暗部重亮部轻） |
| "两种风格没有碰撞感" | 层间差异不够大 | 加大对比——一层更写实，一层更风格化 |
| "AI把所有层统一成一种风格了" | 分层声明不够显式 | 用 `⚠️` 强调每层的风格独立性，增加 `禁统一渲染` 约束 |
