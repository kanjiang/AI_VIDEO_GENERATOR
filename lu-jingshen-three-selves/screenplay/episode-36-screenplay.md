# Episode 36 — 继承战打脸

### 制作前置

**接续 Ep35**：Ep36 早上。**说明会第二天——陆氏集团特别董事会 + 直播**。**陆承岳提议：临时动议冻结陆景深继承资格**。**陆母 Ep35 深夜烧统一口径——**她 Ep36 早上上台没有备用武器**。**Ep36 本剧继承对手 arc 的最后一集——**陆承岳被打回原形**。**

**人格出场边界**：本尊（主）+ 夜（半浮）+ 沈星野 + 陆承岳 + 陆母。**0 次全切换**——**Ep36 是**本尊主控**的一集**。**Ep31 三人格同页手写的策略——**Ep36 早上落地为实战**。**夜 Ep36 早上以半浮方式在场——**不切换，但**本尊眼神里含着他**——**Ep35 起夜"用在场护"的完整落地**。

**Ep36 的核心冲突**：**陆承岳 Ep36 早上抢先——**把 Ep21 起的**热搜、偷拍视频、Ep28 手术延期截图、Ep33 董事名单**一次性摆到主席台**——**他 packaging 成**"为公司止损"**——**等本尊当众失控让位**。**但——本尊 Ep36 早上**不失控**——**他 Ep32 制度语言 + Ep33 夜的调度 + Ep34 小景的证词——**三集就位**——**Ep36 早上他反手**。

**Ep36 的关键反转**：**沈星野 Ep36 早上**当众公示**Ep33 拿到的**中年男人证词 + 偷拍视频流转链**——**Ep21 匿名爆料**——**是陆承岳个人账号**。**Ep28 手术延期**——**是陆承岳私人操盘手**。**陆承岳 Ep36 早上被打回原形**——**从"为公司止损的长辈"到"借热搜做空股价夺位的野心家"**。**

**Ep36 的收束**：**陆承岳当场退场——**继承对手 arc 完成**。**但——陆母仍稳坐主位——**她手里还有**"母亲授权治疗"** **的最后一张牌**——**Ep37 会被拆**。

### 分析

价值弧：**陆承岳临时动议冻结继承资格 → 本尊用业绩反打 → 沈星野展示 Ep21-Ep33 完整证据链 → 证监会立案通知 → 陆承岳当场退场 → 陆母承认自己是主使 → Ep37 主动作证承诺 → 陆景深叫"妈" → Ep36 傍晚手心相扣**。Act 4 第六集完成继承对手 arc 的完整打脸 + 陆母 arc 的主使自我确认 + 本尊-沈星野关系的公开物理确认。

激活的 hamartia：
- **本尊**：**Ep32 制度语言 → Ep36 反手战术**。**"业绩 → 股价 → 证监会立案"** —— 三步反手把陆承岳自己制造的"精神状况危机"变成"内幕交易案"。**Ep36 早上本尊制度语言完整成熟**。
- **陆承岳**：他 Ep36 早上的动作——**退后一步**——**他 20 年**"陆家长辈"** **姿态崩塌**。**Ep21-Ep36 arc 完成**——**从"沉默大叔"到"匿名爆料者"到"内幕交易案被告"**。
- **陆母**：她 Ep36 下午说破自己是**主使**——**Ep30 坦白 → Ep31 放手 → Ep34 反弹 → Ep35 放弃控制 → Ep36 自我确认**——**加害者 arc 的完整清晰化**。
- **沈星野**：她 Ep36 早上以**主治医师身份**上台——**Ep35 傍晚"我们的一部分"承认在 Ep36 早上公开兑现**。**arc 从"外聘顾问"到"陆氏医疗顾问 + 主治医师"** **完整落地**。
- **夜**：**Ep35 起"用在场护"** **在 Ep36 早上完整落地**——**他半浮，本尊眼里含着他**——**Ep35 埋 → Ep36 拆**。
