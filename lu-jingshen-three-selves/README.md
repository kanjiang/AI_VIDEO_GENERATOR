# 三个他，只许你知道

## Working Title
`三个他，只许你知道`

## Logline
实习心理医生撞破霸总的三重人格，被「护卫人格」威胁封口，却被迫住进他身边当唯一知情者——她要治好他，也要在家族继承战里保住那个会怕黑的小女孩、那个会杀意的护卫，和那个不肯示弱的本尊。

## Premise Locks
- 起点：从零原创；只借多人格男主 + 治愈恋爱内核
- 赛道：霸总甜宠，甜里藏刀（日常甜，家族/继承战周期性捅刀）
- 女主：心理/精神科实习医生
- 人格数：精简 3 人格
- 绑定：撞破切换 → 护卫人格威胁封口 → 女主成唯一知情者并入住
- 骨架：「唯一知情者」同居监护（方案 1）
- 视觉：现实世界始终成年男主身体；人格靠语气、微表情、小道具区分；小女孩人格可在内心空间以儿童形象出现（可选）

## 人格名单
1. `陆景深` - 本尊
2. `夜` - 护卫人格
3. `小小` - 小女孩人格

## 真凶锁定
`陆母主使`
