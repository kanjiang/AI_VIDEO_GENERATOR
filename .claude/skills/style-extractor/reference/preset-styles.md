# Preset Style Recipes (预置风格配方)

Pre-extracted style specs ready to apply directly. Each recipe includes the full 画风说明书 format so it can be plugged into any prompt's style block without running Step 1.

## How to use

1. Pick a recipe from this file
2. Skip Step 1 (extraction) — the style spec is already done
3. Optionally generate a color card using the recipe's `调色` values (Step 1.5)
4. Proceed to Step 2 (application) as normal

## Recipe 1: Vox Collage (Vox 复古拼贴动画)

外网爆火的复古报纸拼贴风格，适合科普、财经、文化、历史类内容的可视化叙事。核心特征是多层纸质拼贴的立体感 + 复古印刷质感 + 纵深运镜。

### 画风说明书：Vox Collage

**提取自：** Vox 频道视觉风格 + DannyZ 复古拼贴教程

#### 逐维度风格声明

```
风格：复古报纸拼贴动画——多层纸质剪贴的立体纸艺感，手工剪贴的层次与拙趣，非3D建模
摄影：纪录片式叙事运镜 × 手工定格动画质感
质感：旧报纸/牛皮纸/印刷品的纤维纹理，边缘有手撕毛边或剪刀裁切痕迹，
      纸张表面可见折痕、泛黄氧化斑、打字机油墨不均
光追：无——本风格禁止写实光追，使用平面化的手绘阴影模拟层次
灯光：无方向性主光——均匀的扫描仪式平光，层次感完全由纸片的叠压关系和投影实现，
      投影为硬边45度手绘阴影（非真实光照计算）
调色：60:30:10——泛黄牛皮纸色60% / 旧报纸灰白30% / 红色线条与图表点缀10%，
      整体低饱和偏暖黄，墨色为深棕而非纯黑
动态光源：无
噪点：明显的纸质纤维纹理噪点，模拟扫描旧纸张的效果
锐化：中低——边缘柔和保留手工感，禁止锐利数码边缘
动态范围：低对比——模拟旧报纸印刷品的低对比度，高光不过曝（纸张不反光），
         暗部不死黑（墨色为深棕）
完美度：低——刻意保留手工拼贴感、拙趣。禁过度精修、禁完美对称、禁AI光滑质感、
       禁3D渲染质感。边缘要有手撕/剪切的不规则感
```

#### 氛围关键词

复古、手工、学术、怀旧、纸质

#### 禁止（与此风格冲突的元素）

```
禁3D渲染质感、禁光滑表面、禁写实光影、禁高饱和色彩、
禁纯黑色（用深棕替代）、禁完美几何边缘、禁数码感渐变、
禁真实光照/光追/全局光照、禁照片级写实材质、
禁现代极简设计（圆角、毛玻璃、渐变阴影）
```

#### 平面设计维度

```
字体：复古印刷体/打字机体为主，标题用粗衬线报纸标题字体，
      正文用打字机等宽体，允许字号不统一、间距不均匀——模拟活字印刷的不完美
装饰元素：手绘红色线条图表、箭头、圆圈标注、下划线、
         剪报碎片、邮戳、回形针、胶带痕迹、图钉、钢笔批注
版式：非对称拼贴——元素以3-5度随机倾斜角度叠放，
      层次关系=前景剪纸片→中景图表/文字→背景旧报纸/牛皮纸底
背景处理：旧报纸或牛皮纸全幅铺底，有明显的折痕、泛黄、氧化斑
```

#### 拼贴层次结构（Vox 特有）

Vox 拼贴风格的核心是 **3-4 层纸质层叠**，每层有独立的视觉深度：

```
Layer 4 (最前景)：重点标注——红色箭头、圆圈、手写批注、图钉
         ↑ 移动速度最快（视差最强）
Layer 3 (前景)：主体剪纸片——人物/物体的报纸风格剪影，手撕/剪切边缘
         ↑ 跟随镜头移动
Layer 2 (中景)：信息图表——柱状图、折线图、流程图、数据标签，红色线条
         ↑ 轻微视差移动
Layer 1 (背景)：底纸——旧报纸/牛皮纸铺底，印刷文字模糊可见，不可读
         ↑ 移动速度最慢（视差最弱）或静止
```

#### 运镜规则（Vox Collage 专用）

| 运镜 | 效果 | Prompt 描述 |
|------|------|------------|
| 纵深推镜 | 穿越纸层进入画面深处，视差感最强 | 镜头沿Z轴缓慢推进，前景剪纸片向两侧滑出画外，中景图表放大，背景报纸纹理保持静止 |
| 俯视下降 | 从上方下降至桌面，模拟"俯看桌面文件" | 正上方俯视角度缓慢下降，纸片层次逐渐清晰，边缘泛黄的报纸铺满画面 |
| 平移扫描 | 水平扫过拼贴板，展示多组信息 | 镜头水平平移，依次经过不同的剪纸片和图表区域，前景纸片以更快速度移动（视差） |
| 缓慢旋转 | 围绕中心主体微幅旋转，增加纵深感 | 镜头以画面中心为轴缓慢顺时针旋转5-10度，所有纸层随旋转角度产生微幅位移 |
| 弹出定格 | 新纸片从画面外弹入并"钉"在当前层 | 一张剪纸片从画面右侧快速滑入，伴随图钉声效，定格在中景层，轻微弹跳后静止 |

#### 色卡参数（可直接用于 Step 1.5 色卡生成）

```
主色（60%）：泛黄牛皮纸色 HEX:#D4B896
辅色（30%）：旧报纸灰白 HEX:#E8E0D4
点缀色（10%）：复古红 HEX:#C4463A
阴影色调：深棕墨色 HEX:#3E2F23
整体饱和度：低饱和
整体对比度：低对比
```

#### 跑偏自检清单

| # | 检查项 | 通过标准 | ⚠️常见跑偏 |
|---|---|---|---|
| 1 | 纸质质感 | 看得见纸张纤维/折痕/泛黄 | AI 生成光滑数码表面 |
| 2 | 边缘处理 | 手撕毛边或剪刀裁切痕 | AI 生成完美几何边缘 |
| 3 | 层叠关系 | 可辨认至少3层纸片叠压 | 所有元素在同一平面 |
| 4 | 色调 | 整体偏暖黄/棕 | AI 偏冷蓝或高饱和 |
| 5 | 红色点缀 | 仅图表/线条/标注使用红色 | 红色扩散到主体元素 |
| 6 | 黑色使用 | 深棕替代纯黑 | 出现纯黑色#000000 |
| 7 | 光影 | 平面化手绘阴影 | 出现写实3D光照/投影 |
| 8 | 文字 | 打字机/印刷体，不完美间距 | 出现现代无衬线字体 |
| 9 | 完美度 | 手工拙趣感 | 过度精修、边缘锐利 |

#### 适用内容类型

| 类型 | 适合度 | 示例 |
|------|--------|------|
| 科普/知识解释 | ★★★★★ | 比特币原理、物理定律、历史事件 |
| 财经/商业分析 | ★★★★★ | 经济趋势、公司故事、市场分析 |
| 文化/社会议题 | ★★★★☆ | 文化现象、社会变迁、人物传记 |
| 历史纪录片 | ★★★★☆ | 历史事件、时代变迁、老照片风 |
| 科技产品介绍 | ★★★☆☆ | 适合讲"背后原理"，不适合展示现代UI |
| 情感/剧情 | ★☆☆☆☆ | 不适合——拼贴风格与情感叙事冲突 |

## Recipe 2: INS Sticker Healing (INS 风治愈贴纸)

真实照片背景 + 极简黑白单线人物贴纸的混合媒介风格。核心特征是高清实景与手绘线条人物的反差感，营造清新、治愈、文艺的 INS 简约氛围。适合生活方式、旅行、情感治愈类内容。

### 画风说明书：INS Sticker Healing

**提取自：** INS 风治愈海报制作教程

#### 逐维度风格声明

```
风格：真实照片+极简黑白线条贴纸——实景高清背景上叠加手绘风格的黑白单线人物，
      人物以贴纸形态存在（有白色裁切边），而非融入场景
摄影：静态平面摄影视角，模拟手机直拍的自然构图
质感：背景保持原片高清质感（8K级清晰度），
      贴纸人物为纯黑线条+纯白填充，线条粗细均匀约2-3px，
      贴纸外围有2-4px白色裁切边（模拟从纸上剪下的效果）
光追：无——贴纸层完全平面化，不参与场景光照计算
灯光：仅背景实景保留自然光照，贴纸人物无光影变化——
      纯黑线条+纯白填充，不受环境光影响
调色：背景保持原片色调（偏清新自然），贴纸层仅黑白两色，
      可搭配少量纯黑色块作为贴纸人物的接地阴影（硬边、45度、低透明度）
动态光源：无
噪点：背景保持原片噪点水平，贴纸层无噪点——纯矢量感的干净线条
锐化：背景中等锐化保持清晰，贴纸线条边缘锐利无锯齿
动态范围：背景保持原片动态范围，贴纸层无动态范围概念（纯黑白二值）
完美度：混合——背景保持照片级真实感（高完美度），
       贴纸人物保持手绘极简感（中等完美度，线条可有轻微不规则）
```

#### 氛围关键词

治愈、清新、文艺、极简、INS风

#### 禁止（与此风格冲突的元素）

```
禁贴纸人物出现彩色（仅黑白）
禁贴纸人物出现写实光影/渐变/阴影（保持平面矢量感）
禁贴纸人物与背景融合（必须保留白色裁切边的"贴上去"感）
禁背景模糊/滤镜化（保持原片高清质感）
禁复杂装饰元素过多（极简为核心）
禁暗色调/低调光线（整体偏明亮清新）
禁贴纸人物面部细节（五官用最简线条概括，如两点一线）
```

#### 平面设计维度（海报模式）

```
字体：手写体为主（如日系手写、英文cursive），轻松随意，
      大小混排，允许轻微倾斜，与极简线条人物呼应
装饰元素：小线条图案（星星、心形、箭头、波浪线），密度极低，
         仅用于填补留白或引导视线，风格与贴纸人物一致（黑色单线）
版式：大面积留白，主体（贴纸人物）占画面30-40%，
      文字与装饰散落在留白区域，不遮挡背景主要景物
背景处理：保留原片实景，不做任何滤镜/调色处理，
         背景是"真实世界"，贴纸是"想象叠加"
```

#### 混合媒介层次结构（INS Sticker 特有）

本风格的核心是 **真实与手绘的二元对比**，严格分为两个视觉层：

```
Layer 2 (前景/叠加层)：贴纸人物——黑白单线手绘，白色裁切边，
         平面化，不受光照影响，可有微动（点头、挥手、弹琴）
         + 手写文字 + 小装饰线条
         ↑ 视频模式：仅此层有微动
Layer 1 (背景层)：真实照片——高清实景，保持原片色彩和光影，
         完全静止不动
         ↑ 视频模式：完全静止
```

#### 动态规则（视频模式）

| 规则 | 说明 |
|------|------|
| **背景** | 完全静止——禁止任何镜头推拉、摇动、平移 |
| **贴纸人物** | 仅轻微动态——交谈点头、递物品、弹吉他等小幅循环动作 |
| **动作幅度** | 极小——人物位置不移动，仅肢体末端有微动（手指、头部、手臂） |
| **时长** | 3-5 秒（短循环，适合 INS Reels / 朋友圈视频） |
| **画面稳定** | 零晃动——模拟三脚架固定拍摄 |

Prompt 示例（视频模式）：

```
【规格】5秒，3:4竖版，30fps

【电影化动态描述】
高清实景背景完全静止不动——[描述真实场景：街角咖啡厅/海边栈道/公园长椅]，
画面中央有一个极简黑白单线贴纸人物，白色裁切边清晰可见，
人物正在[描述微动：轻轻弹吉他/向同伴递一杯咖啡/坐在长椅上翻书]。
⚠️ 仅贴纸人物有微幅动态，背景实景完全静止。
⚠️ 贴纸人物为纯黑线条+纯白填充，无彩色、无光影渐变。
⚠️ 镜头完全固定——零推拉、零摇动、零平移。
```

#### 色卡参数

本风格不需要传统色卡——背景保持原片色彩，贴纸层仅黑白。
但如果需要统一多张海报的背景色调，可生成一张"背景氛围色卡"：

```
主色（60%）：背景实景主色调（根据拍摄场景而定，如海边=天蓝+沙白，咖啡厅=暖棕+奶白）
辅色（30%）：纯白（贴纸填充+裁切边+留白区域）
点缀色（10%）：纯黑（贴纸线条+文字+装饰元素）
```

#### 跑偏自检清单

| # | 检查项 | 通过标准 | ⚠️常见跑偏 |
|---|---|---|---|
| 1 | 贴纸 vs 背景分离 | 贴纸有明显白色裁切边，"贴上去"的感觉 | AI 将人物融入场景（无裁切边） |
| 2 | 贴纸色彩 | 纯黑线条+纯白填充，无任何彩色 | AI 给贴纸人物上色 |
| 3 | 贴纸光影 | 纯平面，无光影渐变 | AI 给贴纸加真实光影 |
| 4 | 背景清晰度 | 原片级高清，无模糊/滤镜 | AI 将背景也卡通化 |
| 5 | 线条风格 | 极简单线，五官概括（两点一线） | AI 画出详细五官/阴影线 |
| 6 | 动态范围 | 仅贴纸微动，背景静止 | 背景也跟着动 |
| 7 | 裁切边 | 白色、均匀、2-4px | 无裁切边或边缘不规则 |
| 8 | 整体氛围 | 清新、明亮、治愈 | 暗调、压抑、复古 |

#### 适用内容类型

| 类型 | 适合度 | 示例 |
|------|--------|------|
| 生活方式/日常 vlog | ★★★★★ | 咖啡厅、散步、阅读、做饭 |
| 旅行/风景 | ★★★★★ | 海边、山顶、古镇街道 |
| 情感治愈/心情 | ★★★★☆ | 孤独感、小确幸、治愈时刻 |
| 产品/美食展示 | ★★★☆☆ | 贴纸人物与产品互动 |
| 科普/知识 | ★★☆☆☆ | 风格太轻松，不适合严肃知识 |
| 剧情/叙事 | ★☆☆☆☆ | 表现力太弱，无法承载复杂情节 |

#### 制作流程提示

完整制作涉及三个 skill 的协作：

```
1. style-extractor (本配方)  → 定义视觉风格
2. shotlist-builder           → 写 prompt（使用上方的动态规则）
3. post-production            → 图层合成（视频层 + PNG 海报叠加）
```

后期合成关键步骤（CapCut/剪映）：
1. 动态视频放在下层（Timeline 底层）
2. 无背景 PNG 海报放在上层（Timeline 上层）
3. 对齐两层位置
4. 导出

未来可扩展更多预置风格配方：赛博朋克、水墨、像素、蒸汽波、包豪斯等。
