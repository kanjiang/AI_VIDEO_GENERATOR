# Character Staging（人物占位空间描写）

用**提示词占位**替代导演台抽卡。Seedance 等模型不理解「导演台」，但理解「谁在画左、距谁几米、面朝哪」。

来源：[absorption/AIGC-漫剧固定人物站位吸收.md](absorption/AIGC-漫剧固定人物站位吸收.md)。完整俯视流程见 [SPATIAL_BLOCKING.md](SPATIAL_BLOCKING.md)。

---

## 一句话指令（可直接对 Agent 说）

> 每一段分镜 / 每一条视频提示词都要增加**人物占位空间描写**，具体根据画面而定；2 人及以上禁止省略。

英文等价：`Add explicit character staging (who/where/facing/distance) to every multi-character prompt.`

---

## 硬门

| 条件 | 必须写入 |
|------|----------|
| 画面 ≥2 可辨认人物 | `⚠️空间布局` 或等价占位句（画左/画右、前后、间距、朝向） |
| 单人特写且无他人入画 | 可省略站位；若有画外关系可写「画右画外站着…」 |
| 打斗/追逐/换位 | 静态起始位 + 动线（见 SPATIAL_BLOCKING §6） |
| 同场分段续写 | 重申占位，禁止默认 AI「自由站位」 |

失败模式：**人物换边、贴脸重叠、对话双方站位对调、追逃穿帮** → 几乎都是缺占位或占位只写在第一段。

---

## 最小占位块（每段都贴）

```
⚠️空间布局（MAIN VIEW=从[机位朝向]看向[场景锚点]）：
- [角色A]：画[左/中/右]，位于[家具/门/墙相对位置]，面朝[方向]，距[角色B]约[X]米
- [角色B]：画[…]，…，面朝[…]
- 前后关系：[谁在前/谁被谁遮挡]
⚠️禁交换左右站位；禁角色漂到未声明区域。
```

对话场可再压成一行（仍必须每段重复）：

```
站位锁定：A 画左中景面朝右，B 画右中景面朝左，两人间距约1.5米，互为过肩轴；全程禁换边。
```

## 场景速用模版

### 双人对话（过肩轴）

完整流程（基准大全景 → OTS 正反打 → 近景特写）：见 [SHOT_REVERSE_SHOT.md](SHOT_REVERSE_SHOT.md)。

```
⚠️空间布局：角色A在画左（或机位过肩侧），角色B在画右，两人面对面，间距约1.2–2米；
轴线为A–B连线，摄影机不越轴。禁两人挤到同一画半区。
```

### 三人（三角）

```
⚠️空间布局：A 画左前，B 画右前，C 画中后（略被遮挡或居中后方1–2米）；
面朝关系：[谁看谁]。禁 C 无故落到 A/B 前方。
```

### 审讯 / 对峙（权力）

```
⚠️空间布局：权力方靠[窗/桌内侧/画深]，被审方靠[门/画近]；
距离约[X]米，桌面为中轴。禁双方绕桌漂移到对调座位。
```

### 追逐（动线一句）

```
起始站位：逃者在巷道南端画中，追者在北端画深约15米处。
动线：逃者沿巷道向南跑出画；追者同路径跟进，间距保持约8–10米；禁追者瞬移到逃者前方。
```

### 打斗

```
起始：A 画左弓步，B 画右；圆心为两人中点。
动线：A 右拳攻向 B 左肋；B 后撤半步仍在画右半区。禁互换半场。
```

## 与俯视图流程的关系

| 复杂度 | 做法 |
|--------|------|
| 简单双人、站位不变 | 只用本文件最小占位块，每段重复 |
| 多人 / 换位 / 复杂动线 | Phase 3 画俯视 → 批准 → 再写入每段 `⚠️空间布局` |
| 批量分镜 | 同一场戏**复制同一段占位原文**，只改动作句；勿每段重新发明左右 |
