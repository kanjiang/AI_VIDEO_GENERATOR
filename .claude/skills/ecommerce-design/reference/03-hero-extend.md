# 03 — Hero & Extend（主视觉 → 整套延展）

核心逻辑：**先锁定一张主视觉**，再延展模特套图、多尺寸海报、样机。禁止无主视觉直接批量出「好看图」。

---

## 主视觉（Key Visual）

引用：`brief` 视觉方向 + 精修产品图（+ 三视图若需要结构准确）。

### Prompt 骨架

```
电商主视觉 KV。[brief 主风格与关键词]。
产品以精修外观为准，居中或按构图：[居中英雄位/三分法左侧…]；
场景与光影服务卖点「[Top 卖点]」，氛围 [科技/奢华/清新/食欲…]；
可留主标题区安全空间（勿在产品上乱加字，文字可后叠或单独说明）。
高清商业摄影质感，风格与 brief 一致。
禁换产品、禁杂乱道具抢主体、禁低质滤镜。
```

确认问题：> 主视觉定稿用这张方向吗？确认后开始延展。

---

## 延展 A — 模特 / 情景套图

错误：直接「生成模特拿产品」→ 丑且每次漂移。  
正确：**引用精修 + 三视图 + 主视觉风格**，只规定动作与环境。

```
商业电商模特套图。产品外观严格参考精修/三视图，禁止换款变形。
视觉风格对齐主视觉：[风格关键词]。
模特：[性别/年龄感/穿搭]，动作：[手持展示/开盖/涂抹/饮用…]，
环境：[厨房/浴室/桌面/户外…]，光影与主视觉一致。
产品Logo可读，手部遮挡合理。禁崩脸、禁多余手指、禁产品贴图错误。
```

一套建议 3–6 张：手持特写、半身使用、场景远景各至少 1。

---

## 延展 B — 多尺寸营销海报

营销海报 = **品牌氛围**（可大字报、活动信息）；与主图分工见 `04-main-images.md`。

按尺寸分别出 prompt，共用主视觉元素：

| 用途 | 比例 |
|------|------|
| 竖版活动海报 | 3:4 或 9:16 |
| 横版广告 | 16:9 / 2:1 |
| 社交方形 | 1:1 |

```
营销海报，[竖版3:4/横版16:9/方形1:1]。延续主视觉色彩与产品外观，
强调品牌氛围与活动感；主标题区、副标题区留白清晰；产品来自精修参考。
[活动一句文案可写入或留空供后期排版]。
```

---

## 延展 C — 样机（Mockup）

手机界面、包装、广告牌、展架、线下空间等——**突出商业展示**，产品贴图来自精修/主视觉。

```
高真实感产品样机展示：[iPhone 屏幕/纸盒包装/灯箱广告牌/柜台展陈]。
画面内产品视觉来自已定主视觉，透视与接触阴影合理，环境略虚化衬托。
禁歪曲 Logo、禁假界面乱码抢眼。
```

---

## 延展清单（确认主视觉后一次列出）

```markdown
## Extend plan
- [ ] 模特套图 ×N — 动作列表：…
- [ ] 海报 3:4 / 16:9 / 1:1
- [ ] 样机：手机 / 包装 / 广告牌
```

逐项生成，每项引用同一产品底座与风格句。
