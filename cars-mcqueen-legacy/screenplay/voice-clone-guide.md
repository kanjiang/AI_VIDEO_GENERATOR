# 《汽车总动员·传承之路》AI 声音克隆配音指南

> 目标：用 AI 声音克隆工具，基于原版中配音色，生成本片全部角色台词的中文音频

## 一、推荐工具对比

| 工具 | 特点 | 参考音频需求 | 中文支持 | 推荐指数 |
|------|------|-------------|---------|---------|

**推荐方案：Fish Audio（快速出片） 或 GPT-SoVITS（效果最佳）**

## 二、参考音频获取方法

> ⚠️ 仅用于个人创作参考，不可商用原版音频

### 每个角色的参考音频来源

| 角色 | 中配演员 | 参考音频来源 | 搜索关键词 |
|------|---------|-------------|-----------|
| **闪电麦昆** | 藤新（赛车总动员3） | B站/YouTube 中配预告片、配音花絮 | `赛车总动员3 中文配音 预告` `汽车总动员 麦昆 中文` |
| **板牙** | 张伟（赛车总动员系列） | B站中配正片片段、预告片 | `赛车总动员 板牙 中文配音` `板牙搞笑片段 中配` |
| **莎莉** | 季冠霖（赛车总动员3） | B站配音片段 | `赛车总动员 莎莉 中文` `季冠霖 赛车总动员` |
| **路易吉** | — | B站中配片段 | `赛车总动员 路易吉 中文` `轮胎 赛车总动员 意大利` |
| **小焰（原创）** | 无原版参考 | 建议用年轻活力女声 | 见下方"小焰音色指导" |

### 音频提取步骤

1. **找到参考视频**：在B站搜索上述关键词，找到包含该角色台词的中配片段（预告片/花絮/正片片段）
2. **下载视频**：使用 `yt-dlp` 或B站下载工具下载视频
   ```bash
   # B站视频下载（安装 yt-dlp 后）
   yt-dlp "https://www.bilibili.com/video/BVxxxxxxxxxx" -o "reference_%(title)s.%(ext)s"
   ```
3. **提取音频**：用 FFmpeg 提取纯音频
   ```bash
   ffmpeg -i reference_video.mp4 -vn -acodec pcm_s16le -ar 44100 reference_audio.wav
   ```
4. **裁剪角色片段**：用 Audacity 或 FFmpeg 裁剪出目标角色的清晰台词片段（去掉BGM和音效尽量干净）
   ```bash
   # 裁剪 10秒到25秒 的片段
   ffmpeg -i reference_audio.wav -ss 00:00:10 -to 00:00:25 -c copy mcqueen_ref.wav
   ```
5. **人声分离（可选但推荐）**：用 UVR5 或 Demucs 去除背景音乐，获取干净人声
   ```bash
   # 使用 demucs 分离人声
   demucs --two-stems=vocals reference_audio.wav
   ```

**音色特征：** 成熟男中音，沉稳温暖，带一丝沧桑感。不再是年轻时的张扬，而是经历过一切后的从容。

**参考音频要求：**
- 文件：`reference/mcqueen_ref.wav`
- 时长：10–30秒干净对白
- 内容建议选取平静叙述的台词（非喊叫/激动片段）

**生成台词清单：**

| 编号 | 台词文本 | 情绪标注 | 对应Shot |
|------|---------|---------|---------|
| MCQ-01 | 每条赛道都有终点。 | 低沉、回忆、平静 | Shot 1 |
| MCQ-02 | 最快的？先学会过弯再说。 | 淡然、微笑、略带调侃 | Shot 2 |

## 四、Fish Audio 操作流程（推荐）

### Step 1 — 上传参考音频创建音色

1. 访问 [fish.audio](https://fish.audio)，注册登录
2. 点击「创建音色」→ 上传 `reference/mcqueen_ref.wav`
3. 填写音色名称（如 `麦昆-退役版`）、描述
4. 等待处理完成（约 1–3 分钟）
5. 对其他角色重复以上步骤

### Step 2 — 逐条生成台词

1. 选择目标音色（如 `麦昆-退役版`）
2. 在文本框输入台词（如 `每条赛道都有终点。`）
3. 调整参数（参照上方各角色设置建议）
4. 点击「生成」，试听效果
5. 满意后下载 MP3

## 五、GPT-SoVITS 操作流程（效果最佳）

> 适合有 NVIDIA 显卡（6GB+ 显存）的用户

### 环境安装

```bash
# 克隆项目
git clone https://github.com/RVC-Boss/GPT-SoVITS.git
cd GPT-SoVITS

# 安装依赖（推荐 Python 3.10）
pip install -r requirements.txt

# 下载预训练模型（按项目 README 指引）
```

### 快速推理流程（零样本/少样本）

1. **准备参考音频**：3–10秒清晰人声 WAV，44100Hz
2. **启动 WebUI**：
   ```bash
   python webui.py
   ```
3. **在推理页面**：
   - 上传参考音频 → 输入参考音频对应的文本
   - 输入目标台词文本
   - 调整语速、情绪参数
   - 生成并导出

### 精细训练流程（效果更好）

1. 准备 3–5 分钟的角色音频素材
2. 使用内置工具进行：音频切分 → 语音识别 → 标注校对
3. 训练 SoVITS 模型 + GPT 模型（各约 10–30 分钟）
4. 用训练好的模型推理生成台词

## 六、后期处理

### 音频统一处理

```bash
# 统一响度标准化（-16 LUFS，适合视频配音）
ffmpeg -i input.mp3 -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 44100 output_normalized.mp3

# 添加轻微混响（模拟空间感）
ffmpeg -i input.mp3 -af "aecho=0.8:0.88:60:0.4" output_reverb.mp3
```

### 质检清单

- [ ] 每条音频无爆音、无杂音、无截断
- [ ] 各角色音色辨识度清晰（闭眼能分清谁是谁）
- [ ] 情绪与标注匹配（板牙的哽咽 vs 兴奋要区分明显）
- [ ] 时长与对应 Shot 的时间窗口匹配
- [ ] 统一响度后音量一致
